## 制作方針の提案

### A案: 外注中心
- イラスト/スプライト → 外注
- UI装飾/アイコン → 外注またはアセットストア
- エフェクト → アセットストア
- BGM/SE → アセットストア

### B案: アセットストア中心
- 汎用アセットで代用可能なものは購入
- ゲーム固有のもの（カードイラスト等）のみ外注
- コスト削減・スピード重視

### C案: ハイブリッド
- 超高優先・高優先 → 外注（品質重視）
- 中優先・低優先 → アセットストア（効率重視）
- 段階的にリプレイス可能な設計
