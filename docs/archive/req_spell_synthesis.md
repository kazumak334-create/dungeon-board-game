# 要件定義書: 呪文合成システム (Spell Synthesis)

作成日: 2026-04-25  
状態: 承認済み・実装待ち

---

## 概要

バトル中、呪文スロット（Q1/Q2/Q3）間でD&Dを行い  
同名カードまたは定義済み異名ペアを合成して強化呪文を生成する。

---

## REQ-SYN-01: D&D操作仕様

| 項目 | 仕様 |
|------|------|
| ドラッグ元 | Q1/Q2/Q3のいずれかのスロット（バトル中のみ） |
| ドロップ先 | Q1/Q2/Q3のいずれかのスロット（自分以外） |
| キャンセル | スロット以外にドロップ → 何も起きない |
| 空スロット | ドロップ先が空の場合は合成不可（スワップも不可） |

---

## REQ-SYN-02: 合成条件（共通）

以下をすべて満たす場合のみ合成可能：

1. ドラッグ元のスロットに呪文がある
2. ドロップ先のスロットに呪文がある
3. ドロップ先スロットの合成Lvが 3 未満（最大Lv3）
4. **現在マナ ≥ ドラッグ元カードのマナコスト**（通常キャストと同じ条件）
5. 同名合成 または 異名合成テーブルに定義済みの組み合わせ

---

## REQ-SYN-03: 同名合成ルール

```
条件: ドラッグ元.base_spell_name == ドロップ先.base_spell_name
      AND ドロップ先.synth_level < 3
結果レベル: min(source_level + target_level, 3)
```

| 合成前 | 合成後 |
|--------|--------|
| Lv1 + Lv1（同名） | Lv2 |
| Lv2 + Lv1（同名） | Lv3 |
| Lv2 + Lv2（同名） | Lv3（上限で確定） |
| Lv3 + 何でも | **不可**（Lv3が上限） |

※ドラッグ元がLv2でも可。base_spell_nameが一致していれば合成できる。

---

## REQ-SYN-04: 強化テーブル（同名合成）

| Lv | 効果値倍率 | 範囲 | 効果時間倍率 |
|----|-----------|------|-------------|
| 1（通常） | ×1.0 | 1マス（元定義） | ×1.0 |
| 2 | ×1.8 | 1行 **or** 1列（50%ランダム・合成時に確定） | ×1.5 |
| 3 | ×3.0 | **元カードのターゲット属性で自動決定**（ランダムなし） | ×2.5 |

- **CDは合成で変化しない**（常に元定義の値を使用）
- **効果時間適用条件**: `CardDB.SPELLS[name].get("duration", 0) > 0` の場合のみ倍率適用
- **ランダム決定タイミング**: Lv2のみ合成時に確定。結果はスロットUIに表示する
- **Lv3範囲の決定ルール**:
  - 元カードが敵対象（enemy系）→ **全敵**（敵陣3×3全マス）
  - 元カードが味方・自マス対象（ally/self系）→ **自陣全体**（自陣3×3全マス）
- 判定キー: CardDB.SPELLS[name].get("target", "enemy") で分岐

---

## REQ-SYN-05: 消費・捨て札タイミング

```
【合成実行時】
  ドラッグ元カード → 即・捨て札（deck_manager.discard に追加）
  現在マナ       → ドラッグ元のマナコスト分消費
  ドロップ先スロット → 合成カード（Lv2/Lv3）に変化

【合成カード発動時】
  消費マナ       → ドロップ先（base_card）のマナコスト分
  合成カード内部の base_card → 捨て札
  合成カード自体  → 消費（除外。捨て札・山札どちらにも入らない）

【合成カード右クリック破棄時】
  合成カード内部の base_card → 捨て札
  合成カード自体  → 消費（除外。発動時と同じ扱い）

【バトル終了時・スロットに合成カードが残っている場合】
  base_card → 捨て札
  合成カード自体 → 消費（除外。デッキには戻らない）

【外部効果による強制クリア（「全スロット捨て札」等）時】
  合成カード自体 → 消費（除外）
  base_card → 捨て札
  ※ 通常カードのみ通常捨て札処理。合成カードは例外なく消費。
```

> **原則: 合成カードはスロットから離れる瞬間に消費。理由を問わない。**

**base_card の引き継ぎルール（Lv3合成時）:**
```
Lv2.base_card = A（Lv2生成時にスロットにあったカード名）
Lv3.base_card = Lv2.base_card = A（チェーン引き継ぎ）
Lv3.mana_cost = A のマナコスト（ドロップ先コストを継承）
```
→ Lv3発動時の捨て札は A 1枚のみ。消費マナも A のコスト。

**捨て札循環による Lv3 生成例:**
1. 火球A(slot1) + 火球B(slot2) → Lv2火球(slot1), Bが捨て札
2. 捨て札→山札リシャッフルで火球Bを再ドロー
3. 火球B(slot2) を Lv2火球(slot1) に合成 → Lv3火球(slot1)
4. Lv2+Lv2合成も可（結果は同じくLv3）

## REQ-SYN-06: 異名合成テーブル（初期定義）

```gdscript
# CardDB.SPELL_SYNTHESIS: Dictionary
# キー: "呪文A名+呪文B名"（アルファベット順ソートで正規化）
# 値: {result: "新呪文名", type: "spell", rarity: "rare"}
```

初期テーブルは実装フェーズで別途定義。  
**テーブル未定義ペア**: 合成不可（ドラッグ中に「合成不可」を表示）

異名合成結果は **Lv1扱い**。以降 同名合成で Lv2/Lv3 に昇格可能。

---

## REQ-SYN-07: キャストゲージ（グローバルCD）

- グローバルCD間隔: **3秒**（`cast_interval = 3.0`）
- 合成操作はキャストゲージに **影響しない**
- キャスト中（CD中）でも合成は実行可能

---

## REQ-SYN-08: UI要件

| 状態 | 表示 |
|------|------|
| ドラッグ中（同名あり） | 対象スロットを緑ハイライト |
| ドラッグ中（異名・定義済み） | 対象スロットを青ハイライト |
| ドラッグ中（合成不可） | 対象スロットを赤ハイライト |
| 合成済みスロット | スロット内に「Lv2」「Lv3」バッジ表示 |
| 範囲確定後 | スロット内に「行」「列」「全敵」「自陣」のラベル表示 |
| マナ不足でドロップ | 「マナ不足（合成不可）」バブル表示 |

## REQ-SYN-09: SpellSlotSystem 拡張仕様

```gdscript
# スロットデータ拡張
slots[i] = {
  "spell": UnitData or null,
  "condition": String,
  "mana_cost": int,
  "synth_level": int,        # 0=通常, 1=Lv1, 2=Lv2, 3=Lv3
  "base_card_name": String,  # 発動時に捨て札に送るカード名
  "range_variant": String,   # "default"|"row"|"col"|"all_enemy"|"all_ally"
}

# 新メソッド
func can_synthesize(slot_from: int, slot_to: int) -> bool
func synthesize(slot_from: int, slot_to: int) -> bool
func _determine_range_variant(level: int, spell_target: String) -> String
# Lv2: 50%ランダムで "row" or "col"
# Lv3: spell_target=="enemy"系 → "all_enemy"、それ以外 → "all_ally"
func _apply_synth_to_spell(spell, level, range_variant) -> UnitData  # 強化コピー生成
```
