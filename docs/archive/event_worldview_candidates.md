## 世界観の核

- **ATLAS**: システム名（正体不明）
- **灰色の疫病**: 何かの象徴（詳細不明）

- **盤面**: 金属デバイスのような...？（確信が持てない）

**原則**: 真実を明かさない。違和感だけを積み重ねる。

## Act 1: 違和感レベル1（ノイズ）

### 1-1. 記憶の断片

```
床に散らばった古い記録を見つけた。
文字が滲んで読みにくいが、数字が見える。

「#2891 - 適応率 ██.█% - 次フェーズ ██████」

...#2891。どこかで見たような数字だ。
```

**選択肢:**
- A) 記録を読み進める → Gold +60、フレーバーテキスト「...記憶...保持...条件...」判読不能
- B) 破り捨てる → 何も起こらない
- C) 持ち去る → アーティファクト「実験体の札」獲得 + Gold +30

**意図**: 番号の一致による違和感。何の実験かは不明。

---

### 1-2. ATLAS端末α

```
古びた端末が起動している。
画面には「ATLAS - ████ Security Lv.3」の文字。

ログイン画面が表示されている。
```

**選択肢:**
- A) 適当な番号を入力 → 「アクセス拒否」Gold +40
- B) 2891を入力してみる → 「...許可」Gold +80 + アーティファクト1個（Common-Uncommon）
- C) 端末を無視する → 何も起こらない

**意図**: 番号が何かの鍵になる。ATLASが何かは不明。

---

### 1-3. 灰色の染み

```
壁一面に灰色の染みが広がっている。
近づくと、かすかに蠢いているように見える。

触れてはいけない、という直感がある。
```

**選択肢:**
- A) 触れてみる → HP -15、「灰色の疫病を思い出す...」
- B) 距離を取る → 何も起こらない
- C) 染みを調べる → フレーバーテキスト「染みの中に人の形が見える。動かない。」

**意図**: 灰色の疫病の視覚的描写。恐怖を煽る。

## Act 2: 違和感レベル2（ノイズ増幅）

### 2-1. 動かない何か

```
通路の隅に、何かが倒れている。
よく見ると...人の形をしている。金属のような質感。

胸部に文字：「#1247 - ████████」
```

**選択肢:**
- A) パーツを回収する → アーティファクト1個（Uncommon-Rare） + Gold +50
- B) そっとしておく → 何も起こらない
- C) 近づいて調べる → フレーバーテキスト「冷たい。動かない。あなたと似ている...？」Gold +30

**意図**: 自分と似た何かの存在。それが何かは不明。

---

### 2-2. 音声ログ

```
再生装置が起動した。ノイズ混じりの声。

「...2891号...適応...記憶...は...
...灰色...サンプル...接触...
...最後...ATLAS...録...」

ノイズ。沈黙。何を言っていたのか分からない。
```

**選択肢:**
- A) ログを最後まで聞く → Gold +70、フレーバーテキスト「...希望...」途切れる
- B) 装置を止める → 何も起こらない
- C) ログを持ち帰る → アーティファクト「記憶の鍵」獲得 + SP +2

**意図**: 断片的な情報。何の実験か、灰色とは何か、不明。

---

### 2-3. グリッチ現象β

```
視界が歪む。盤面が...デバイスが...金属の床が見える。

一瞬、あなたは実験室のカプセルの中にいる。
周囲には同じカプセルが無数に並んでいる。全て空だ。

視界が戻る。いつもの通路だ。
```

**選択肢:**
- A) 現実を疑う → SP +2、「真実を知りたいか？」
- B) 幻覚だと割り切る → 何も起こらない
- C) もう一度見ようとする → HP -10、警戒レベル-2

**意図**: 現実と仮想の境界。プレイヤーが何者かの疑問。

**意図**: 何かの出口。何の出口？どこへの出口？不明。

## 世界観イベントの原則

1. **報酬は通常イベント並み** - Gold 60-100、アーティファクト、HP/SP。世界観は報酬の言い訳
2. **選択肢に「調べる」を含める** - フレーバーテキスト閲覧用
3. **真実は明かさない** - Act 1-3すべて「違和感」レベル。答えは与えない
4. **ノイズを積み重ねる** - 断片的な情報、判読不能な文字、意味不明な音声
5. **プレイヤーの妄想を誘う** - 「何かある」と思わせるが、確信は与えない
