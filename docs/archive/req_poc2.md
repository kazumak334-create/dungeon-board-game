# PoC2 要件定義書

更新日: 2026-04-29
STATUS: 有効

## 概要

「設計フェーズで経済計画を立てるだけで、バトルが自律的に成立するか？」を検証するPoC。

- エントリポイント: `Poc2Main` (scripts/poc2/Poc2Main.gd)
- 既存PoCと完全に独立した別ディレクトリ (`scripts/poc2/`)
- シーンファイル不要（GDScriptのみでNode生成）
- 既存流用: HexGrid.gd（ロジックそのまま流用）、PoCUnit.gd（戦闘ユニットロジック流用）

---

## フェーズ定義

### フェーズ1: 設計フェーズ（プレイヤー操作）

- ハーベスター最大3体を盤面に配置（クリックで配置）
- 建造物を配置: 兵舎×1〜2、砦×0〜1
- 資源優先度を選択: 木材優先 / 石材優先 / 小麦優先
- 「バトル開始」ボタンで観戦フェーズへ遷移

### フェーズ2: バトル（完全オート・観戦のみ）

プレイヤー操作なし。全て自動で進行。

---

## 盤面設計

HexGrid流用（ROWS=11、偶数行=6列、奇数行=5列）

### 資源エリア（固定マス）

| 資源 | マス |
|------|------|
| 木材 | row4〜5、col2〜3 |
| 石材 | row4〜5、col0〜1 および col4〜5 |
| 小麦 | row3 および row6 の全マス |

### ゾーン定義

| row | ゾーン |
|-----|--------|
| 0〜2 | プレイヤー設置エリア（設計フェーズで配置可） |
| 3〜7 | 中立エリア（資源マス含む） |
| 8〜10 | 敵スポーンエリア |

---

## エンティティ定義

### ハーベスター (Poc2Harvester)

- 非戦闘員
- HP=50
- 移動速度=0.8セル/秒
- 挙動:
  1. 優先資源エリアへBFS移動
  2. 到達したら採掘開始（3秒ごとに+1資源）
  3. 小麦不足時に脱落確率発動（_consume_wheat参照）

### 兵舎 (Poc2Building / type=BARRACKS)

- 配置マスに固定（移動しない）
- 木材5消費ごとに突ユニット（PoCUnit.UnitType.ATTACKER）を隣接マスに生産
- 生産した突ユニットはPoCUnit.Side.PLAYERとして敵へ自動移動・攻撃
- 配置上限: 2体まで

### 砦 (Poc2Building / type=FORTRESS)

- 配置マスに固定（移動しない）
- 同一マスにいるユニットへの受ダメージを50%軽減（バトル中に判定）
- 配置上限: 1体まで

### 敵ウェーブ

- 30秒ごとにウェーブ発生
- 突ユニット（PoCUnit.UnitType.ATTACKER）3体をrow8〜10のランダムマスにスポーン
- PoCUnit.Side.ENEMYとして自動侵攻
- 合計5ウェーブ

## 資源システム

### 資源種類

| 資源 | 初期値 | 上限 |
|------|--------|------|
| 木材 (wood) | 0 | なし |
| 石材 (stone) | 0 | なし |
| 小麦 (wheat) | 10 | なし |

### 消費ルール

- **小麦消費**: 5秒ごとに「全ユニット数（戦闘ユニット＋ハーベスター） × 0.5」を消費（端数切り捨て）
- **小麦不足**: 小麦が0になるとハーベスター1体をランダムで脱落させる

### 兵舎生産条件

- wood >= 5 のとき自動消費してATTACKER突ユニット1体を隣接マスに生産

---

## 勝敗条件

| 結果 | 条件 |
|------|------|
| 負け | 敵ユニットがrow0に到達 |
| 勝ち | 敵ウェーブを5回撃退（5回目のウェーブを全滅） |

## UI仕様

### 上部 (CanvasLayer)

- 資源カウント: 「木材: X  石材: X  小麦: X」
- フェーズ表示: 「設計中」/ 「観戦中」
- ウェーブカウント: 「ウェーブ: X/5」

### 左側パネル（設計フェーズのみ有効）

- [ハーベスター配置] ボタン（残り配置数を表示）
- [兵舎配置] ボタン（残り1〜2を表示）
- [砦配置] ボタン（残り0〜1を表示）
- 資源優先度ラジオボタン3択: 木材優先 / 石材優先 / 小麦優先
- [バトル開始] ボタン

### 盤面

- 資源エリアを色分け表示（木材=緑、石材=灰、小麦=黄）
- 設置エンティティをアイコン/文字で表示

### 下部ログ (RichTextLabel)

| イベント | 書式 |
|---------|------|
| 採掘 | 「[採掘] 木材+1 (row4,col2)」 |
| 生産 | 「[生産] 突ユニット (兵舎@row1,col3)」 |
| 脱落 | 「[脱落] ハーベスター (小麦不足)」 |
| ウェーブ | 「[ウェーブ2] 敵3体スポーン」 |

## ファイル構成

```
scripts/poc2/
  Poc2Main.gd        # エントリポイント・UI構築・フェーズ管理・入力ハンドリング
  Poc2Battle.gd      # バトルシミュレーション（ウェーブ管理・勝敗判定・砦ダメージ軽減）
  Poc2Economy.gd     # 資源管理・採掘・小麦消費ロジック
  Poc2Harvester.gd   # ハーベスターエンティティ（移動・採掘）
  Poc2Building.gd    # 建造物エンティティ（兵舎・砦）
```

---

## 既存コードとの関係

- `scripts/poc/HexGrid.gd` をそのまま参照（class_name HexGrid で利用可）
- `scripts/poc/PoCUnit.gd` をそのまま参照（class_name PoCUnit で利用可）
- **既存ファイルは一切変更しない**

---

## 実装上の注意

1. Poc2Main._input() でクリックされたヘックスセルを判定し、選択中の配置種別に応じてエンティティを配置する
2. 砦ダメージ軽減は Poc2Battle.update() 内でユニットがダメージを受ける直前に砦マス判定を行う
3. BFSは既存 HexGrid.bfs_path() を流用する
4. ハーベスターは PoCUnit を継承せず独自クラスとする（戦闘ロジック不要）
5. ログは Poc2Main._append_log() で管理し、最大100行を維持する
