# ショップ画面 UI/UX企画書

作成日: 2026-04-10
作成者: planning Agent

---

## 1. 画面の目的

プレイヤーが**ゴールドを消費して戦力を強化する**画面。
ローグライク構造におけるビルド構築の重要な分岐点として機能する。

**核となる体験との整合性**
- 盤面設計: ユニット・呪文の購入により次バトルの初期配置が変わる
- 介入の仕込み: 素材購入により長期的な強化を仕込む
- リロール機能により**ゴールドをリソース管理する戦略性**を生む

## 2. レイアウト構成

### 画面サイズ
1280×720（固定）

### 領域分割

| 領域 | 位置（左上） | サイズ（幅×高さ） | 説明 |
|-----|------------|----------------|------|
| タイトル | (0, 30) | 1280×40 | 「ショップ」 |
| 所持金表示 | (0, 72) | 1280×30 | 「所持金: XXG」 |
| 商品カードエリア | (80, 120) | 1120×320 | 3〜5個の商品パネル（横並び） |
| リロールボタン | (490, 460) | 300×50 | 「商品入れ替え: 50G」 |
| 戻るボタン | (40, 530) | 180×45 | 「← マップへ」 |

### 視線の流れ
1. 画面中央「所持金」で現状把握
2. 商品カードエリアで選択肢確認
3. リロールor購入の判断
4. 戻るボタンで次へ

## 3. 色彩設計（MaterialSelect.gd踏襲）

| 用途 | 色コード | 備考 |
|-----|---------|------|
| 背景 | `Color(0.08, 0.08, 0.12)` | ダークグレー |
| パネル背景 | `Color(0.13, 0.13, 0.2)` | 薄いダークブルー |
| 枠線（通常） | `Color(0.3, 0.3, 0.4)` | グレー |
| 売り切れ背景 | `Color(0.4, 0.1, 0.1)` | 暗い赤 |
| タイトル文字 | `Color(0.9, 0.85, 0.6)` | 金色 |
| 価格文字 | `Color(0.9, 0.8, 0.3)` | 明るい金色 |
| 通常テキスト | `Color(0.8, 0.8, 0.8)` | ライトグレー |
| ユニットタイプ | `Color(0.5, 0.7, 0.9)` | 青 |
| 呪文タイプ | `Color(0.7, 0.5, 0.9)` | 紫 |
| 素材タイプ | `Color(0.6, 0.8, 0.6)` | 緑 |

**統一感のポイント**
- MaterialSelect.gdと同じ`COLOR_BG`, `COLOR_PANEL`, `COLOR_TITLE`, `COLOR_BORDER`を使用
- 価格表示には専用の金色（`COLOR_PRICE`）を割り当て、視認性を確保
- 売り切れ状態は暗い赤背景で一目で判別可能

## 4. UIコンポーネント一覧

### 4.1 タイトルラベル
- **テキスト**: 「ショップ」
- **フォントサイズ**: 28
- **色**: `COLOR_TITLE`
- **配置**: 中央揃え

### 4.2 所持金ラベル
- **テキスト**: 「所持金: XXG」（GameSession.goldから動的生成）
- **フォントサイズ**: 20
- **色**: `COLOR_PRICE`
- **配置**: 中央揃え
- **更新タイミング**: 購入時・リロール時

### 4.3 商品パネル（PanelContainer）
- **サイズ**: 220×320（最小サイズ）
- **背景**: `COLOR_PANEL`（通常） / `COLOR_SOLDOUT`（購入済み）
- **枠線**: 2px、`COLOR_BORDER`
- **角丸**: 8px

**内部構成（VBoxContainer, separation: 8）**

1. タイプラベル（Label）
   - テキスト: 「ユニット」「呪文」「素材」
   - フォントサイズ: 12
   - 色: タイプごとに異なる（上記色彩設計参照）

2. 名前ラベル（Label）
   - テキスト: カード名（`data.display`）
   - フォントサイズ: 18
   - 色: `COLOR_TITLE`

3. 説明ラベル（Label）
   - テキスト:
     - ユニット: 「ATK:X HP:X SPD:X」+ スキル名
     - 呪文: 効果テキスト
     - 素材: 説明文
   - フォントサイズ: 12
   - 色: `COLOR_TEXT`
   - 自動折り返し有効

4. 価格ラベル（Label）
   - テキスト: 「価格: XG」
   - フォントサイズ: 16
   - 色: `COLOR_PRICE`

5. 購入ボタン（Button）
   - テキスト: 「購入」（通常） / 「売り切れ」（購入済み）
   - フォントサイズ: 16
   - disabled状態: 購入済みor所持金不足

### 4.4 リロールボタン
- **テキスト**: 「商品入れ替え: 50G」
- **フォントサイズ**: 18
- **サイズ**: 300×50
- **disabled状態**: 所持金 < 50G

### 4.5 戻るボタン
- **テキスト**: 「← マップへ」
- **フォントサイズ**: 16
- **サイズ**: 180×45
- **遷移先**: SceneManager.MAP_SELECT

## 5. インタラクション

### 5.1 購入フロー
1. プレイヤーが商品パネル内の「購入」ボタンをクリック
2. 所持金チェック（不足ならログ出力して処理中止）
3. GameSession.gold -= 価格
4. 購入済みリストに追加（`_purchased.append(index)`）
5. デッキまたは素材リストに追加
   - ユニット: `GameSession.selected_deck.append({"name": id, "col": 1})`
   - 呪文: `GameSession.selected_deck.append({"name": id, "col": -1})`
   - 素材: `GameSession.materials.append(data)`
6. UI更新（`_update_ui()`）
   - 所持金表示更新
   - 購入済みパネルを赤背景に変更
   - 購入ボタンをdisabled化、テキストを「売り切れ」に変更
   - 他の商品の購入ボタンのdisabled状態を再評価（所持金不足チェック）
   - リロールボタンのdisabled状態を再評価

### 5.2 リロールフロー
1. 「商品入れ替え: 50G」ボタンをクリック
2. 所持金チェック（不足ならログ出力して処理中止）
3. GameSession.gold -= 50
4. `_generate_goods()`で商品リストを再生成
5. `_rebuild_goods_ui()`で商品パネルを全削除・再生成
6. `_update_ui()`で所持金表示・ボタン状態を更新

### 5.3 状態変化の可視化

| 状態 | 視覚的表現 |
|-----|----------|
| 購入可能 | パネル背景: `COLOR_PANEL`、購入ボタン有効 |
| 所持金不足 | 購入ボタンdisabled化 |
| 購入済み | パネル背景: `COLOR_SOLDOUT`、ボタンテキスト「売り切れ」、disabled化 |
| リロール不可 | リロールボタンdisabled化 |

## 6. UI基準チェック

### 6.1 3秒ルール
**評価: ✅ 合格**

- 画面上部に「所持金」が大きく表示され、現状把握が即座に可能
- 商品パネルが横並びで一覧性が高く、タイプ・名前・価格が一目で分かる
- 「購入」「商品入れ替え」「戻る」の3つのアクションが明確

### 6.2 視線の一本化
**評価: ✅ 合格**

視線の流れは以下の通り：
1. 中央上部「所持金」
2. 下方向に移動して「商品カード」
3. 「リロールボタン」または「戻るボタン」

複数の情報が散らばらず、中央→下への一本道で設計されている。

### 6.3 状態の可視化
**評価: ✅ 合格**

- 購入済み: パネル背景が赤に変化
- 所持金不足: ボタンがdisabled化（グレーアウト）
- リロール不可: リロールボタンがdisabled化

プレイヤーが「今何ができるか」を常に把握できる。

### 6.4 操作の最小化
**評価: ✅ 合格**

- 購入: 1クリック（商品パネル内のボタン）
- リロール: 1クリック
- 戻る: 1クリック

無駄なモーダルや確認ダイアログはなし（リソース管理の判断はプレイヤーに委ねる）。

### 6.5 配信映え
**評価: ✅ 合格**

- 商品名・価格・タイプが大きく表示され、視聴者も「何を買ったか」が分かる
- 所持金が常に画面上部に表示され、リソース管理の緊張感が伝わる
- リロールギャンブルの判断が視聴者にも共有される

### 6.6 世界観の匂わせ
**評価: ✅ 合格**

- MaterialSelect.gdと統一された色彩設計（ダークファンタジー + 無機質）
- 金色の価格表示がゴールドのリソース感を強調
- 「売り切れ」の暗い赤が商人の無慈悲さを演出
- タイプごとの色分けが機能的で無機質な美しさを持つ

---

## 7. まとめ

ショップ画面は**「リソース管理の戦略性」**を生む重要な分岐点として機能する。

- MaterialSelect.gdのUIスタイルを踏襲し、統一感のあるデザイン
- 3秒ルール・視線の一本化など全てのUI基準をクリア
- 購入・リロール・戻るの3アクションに絞り、操作を最小化
- 状態変化の可視化により「今できること」が常に明確
- 配信映えを意識した大きな文字・明確な価格表示
