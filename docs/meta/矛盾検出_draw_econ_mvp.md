### 【緊急 2】手札MAX時のドロー保留挙動の矛盾（完全矛盾）

| 項目 | 内容 |
|------|------|
| 分類 | 完全矛盾 / 仕様不整合 |
| 重要度 | 緊急 |
| 修正対象 | 要件定義書（記述が自己矛盾） |

**矛盾内容:**

要件定義書 §4.3 内で挙動が**自己矛盾**している。

| 該当箇所 | 記述 |
|---------|------|
| 要件定義書 §4.3 表内 | "保留中もゲージは満タンのまま停止（次の30秒タイマーは開始しない／要確認）" |
| 要件定義書 §4.3 注記 | "推奨案: ターンは独立進行。ドロー保留は『保留枚数』をスタックし、手札が空くたびに1枚ずつ解決する" |
| 要件定義書 §16 Q11 確定値 | "**満タンで停止／ターンは独立進行**" |
| 企画書 §5.2.2 ドローゲージ | "手札 MAX で保留中はゲージをグレー化＋『MAX』表示" |

§4.3 表 = 「ゲージ満タンで停止＝次の30秒タイマー開始しない」と読める。
§4.3 推奨案・§16 Q11 = 「ターンは独立進行＝次の30秒タイマーは進む」と読める。

**ターンとドローゲージは同期する（§4.2 §9.1）**ため、「ターン進行している＝ドローゲージは進行している」はず。それが「ゲージは満タンで停止」と並立すると、ターン進行＝ドロー解決のはずなので**ドロー保留が消化されないまま次ターンが来る**矛盾が生じる。

具体例:
- ターン1で手札5枚 → MAX → pending_draws=1
- 30秒経過、ターン2へ。ターン2のドローはどうなる？
- 「ターン独立進行」なら pending_draws=2 に増える
- 「ゲージ満タンで停止」ならゲージが進まないのでターン2ドローも発火しない

**修正提案:**

要件定義書 §4.3 を以下のように整合させる:

```
| 項目 | 仕様 |
|------|------|
| 手札上限 | 5枚 |
| 上限到達時のドロー | 保留（pending_draws++）|
| 保留の解除 | 手札 ≤ 4 になった次フレームで pending_draws を1つ消化 |
| ドローゲージへの影響 | 満タンで一時停止（手札MAX中はゲージは100%表示で待機） |
| ターン進行への影響 | 影響なし（current_turn は battle_elapsed_sec から独立算出） |
| 強制突撃ゲージへの影響 | 影響なし（ターン進行で進む） |
```

実装挙動:
- ドロー時刻が来たが手札MAX → pending_draws++、draw_gauge_value は max のまま停止
- 手札が空く → try_resolve_pending_draws() が pending_draws を1消化、draw_gauge_value=0 にリセット
- ターン番号は battle_elapsed_sec / TURN_DURATION_SEC で独立算出（ゲージ停止と無関係）

| 要件定義書 §5.1.1 | "もうすぐドロー: 進捗 80〜100%（= 残り 6.0〜0秒）" |
| Designer 仕様書（要確認） | （Designer 仕様書 §3 を要確認）|

企画書「残り3秒」と要件定義書「残り6秒（80%以降）」で時間軸がずれている。3秒の方は明滅で、6秒の方は色変化、という二段階演出なら矛盾しないが、明示されていない。

**修正提案:**

要件定義書 §5.1.1 に注記:

```
- 残り 6.0〜0秒（80〜100%）: 色変化（COLOR_ACCENT_GOLD_BRIGHT）+ 1.0秒周期明滅
- 残り 3.0〜0秒（90〜100%）: 明滅周期を 0.5秒に強化（最終接近を強調）
```

または企画書側を「残り 6 秒で色変化」と書き換える。

## 最終判定

### 矛盾の有無
**あり（13件、内 緊急3件）**

### 実装着手可否
**修正後 OK**

緊急3件の修正は要件定義書・企画書の小規模な追記・修正で完了する。Architect が以下を実施すれば実装着手可:

1. 企画書ステータス更新（5分作業）
2. 要件定義書 §4.3 のドロー保留挙動の整合化（10分作業）
3. 企画書 §8.2 への仮確定値集約（10分作業）

これら3点の修正後、Implementer に着手指示可能。

高〜中の論点（住居破壊優先順位、並存システム責務分離の比較表、市場の詳細仕様）は実装中の追加判断で吸収可能だが、実装前に確定する方が手戻りが少ない。

### 待ち項目
**なし**（CEO 決裁待ち項目はすべて Q1〜Q12 で確定済）
