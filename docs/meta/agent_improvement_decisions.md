## 却下項目（1件）

### Marketing#2: タグ/ジャンルのベクトル比較による競合分析

**却下理由**:
- ベクトル計算環境・類似度アルゴリズムが必要で高コスト
- 個人開発・1プロジェクトにはオーバーエンジニアリング
- 目視比較でも差別化ポイント抽出は十分可能

**代替方針**: 目視での競合分析を継続、WebSearch付与（Marketing#1採用）で補強
