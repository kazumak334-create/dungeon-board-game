# 要件定義書: EconMVP 集結点UI（複数旗 + 建物接続）

更新日: 2026-05-01
STATUS: 企画確定（次回MVP実装対象）

企画書: ユーザー指示 2026-05-01 / Designer企画書 2026-05-01

---

## 0. スコープ

EconMVP の集結点（ラリーポイント）を「単一固定」から「複数旗 + 建物接続」に拡張する。

### 核となる体験との整合性

- 「旗の配置と接続の設計」がバトル前の設計フェーズに深みを加える
- 「設計して観戦する」体験と整合する（バトル前に旗配置・接続を完結させる）
- KISS原則: 旗は is_connected フラグ1つで集結旗/経由旗を区別

### スコープ外（次回MVP以降）

- 奇襲隊フラグ（経由旗）の実装 → §2 に企画のみ記載
- 旗ごとの個別突撃指示 → 全旗同時突撃を維持

---

## 1. 概要

### 1.1 変更前後の比較

| 項目 | 変更前 | 変更後 |
|------|--------|--------|
| 集結点数 | 1箇所固定 | 複数設置可（上限 = 未定・実装時に決定） |
| 建物との接続 | すべての建物が同一集結点に送る | 建物ごとに接続する旗を指定 |
| 接続なし旗 | なし | 設置可（将来の奇襲経由点として機能） |
| 突撃指示 | 単一旗を横に倒す | 全旗を同時に横に倒す（一括操作） |

### 1.2 設計ルール

- 1つの建物は1本の旗にのみ接続可能（1建物1旗）
- 1本の旗に複数の建物を接続可能（N建物1旗）
- 接続なし旗はユニットを集めない（将来の経由点として予約）
- 旗の設置コストはなし（設計書§15準拠）

## 2. 奇襲隊フラグ（経由旗）企画仕様

STATUS: 企画確定・実装未定

### 2.1 定義

| 旗の種類 | 定義 | バトル中の動作 |
|---------|------|--------------|
| 集結旗（接続あり） | 特定の建物と紐づけられた旗 | 紐づけ建物のユニットがここで待機する |
| 経由旗（接続なし） | どの建物とも紐づけられていない旗 | 突撃時に「経由点」として機能する |

### 2.2 経由旗の動作仕様

- 突撃指示時、経由旗が存在する場合、ユニットは「集結旗 → 経由旗 → 敵BASE」の順に移動目標を設定する
- 経由旗を通過したユニットはその後は通常攻撃AIに戻る
- 複数の経由旗がある場合は、集結旗から最も近い経由旗を選択する
- 当面は全ユニットが経由する（建物別の経由先指定は将来拡張）

### 2.3 奇襲として機能する理由

- 既存仕様「敵には集結点の位置が見えない」（設計書§15）と組み合わせることで成立
- 経由旗もプレイヤーにしか見えない → 回り込みルートが読まれない
- 経由旗を山岳地帯の裏に設置 → 敵の防衛ラインを迂回できる

### 2.4 実装フェーズの推奨タイミング

複数旗UI（本ドキュメントの実装）が安定した後の次スプリント。
複数旗UIなしに「接続なし旗」の概念はプレイヤーに伝わりにくい。

## 3. 実装仕様（集結旗・次回MVP対象）

### 3.1 データ構造

```gdscript
# 旗データ（EconMain.gd または専用クラスで管理）
{
    "flag_id": int,                    # 旗の識別子（0から連番）
    "grid_pos": Vector2i,             # 設置位置
    "is_connected": bool,             # true=集結旗 / false=経由旗（将来用）
    "connected_buildings": Array,     # 接続済み建物の grid_pos リスト
    "is_assault_mode": bool,          # 突撃モード（横に倒れているか）
}
```

### 3.2 建物データへの追加フィールド

```gdscript
# EconBuilding.gd に追加
var connected_flag_id: int = -1       # -1 = 接続なし
```

### 3.3 UI実装仕様

#### 旗アイコン

- サイズ: 24×24px（HEX_SIZE = 24px に合わせる）
- 集結旗（接続あり）: 明黄色 #FFD700
- 経由旗（接続なし）: 淡青 #7EC8E3
- 突撃モード時: 回転90°のアニメーション
- 描画: CanvasItem._draw() でポリゴン/テクスチャ描画

#### 接続線

- 建物グリッド中心 → 旗グリッド中心を結ぶ破線
- 線幅: 2px
- 建物種別による色分け:
  - 兵舎（突）: #FF8C00（橙）
  - 要塞（守）: #4169E1（青）
  - 工房（崩）: #9932CC（紫）
  - その他建物: #888888（グレー）
- 描画関数: CanvasItem.draw_dashed_line(from, to, color, width, dash=8.0)

#### 接続数バッジ

- サイズ: 12×12px
- 位置: 旗アイコンの右上
- 表示: 接続中の建物数（0のとき非表示）
- 色: #FFFFFF 文字 + 暗背景

### 3.4 インタラクション仕様

#### 旗の設置

| 操作 | 動作 |
|------|------|
| 空きヘックスを右クリック | コンテキストメニュー表示 |
| 「旗を置く」を選択 | 集結旗を設置（黄色・接続なし状態） |
| F + 左クリック | ショートカット設置（上級者向け） |

設置不可条件:
- 敵エリア（col 8以上）
- 建物・資源タイルが存在するヘックス
- すでに旗が存在するヘックス

#### 建物と旗の接続（メイン操作: ドラッグ）

| 操作 | 動作 |
|------|------|
| 建物の上でマウス左ボタン長押し（0.3秒） | ドラッグ開始・接続プレビュー線が追従 |
| 旗の上でドロップ | 接続確定・接続線が描画される |
| ESCキー | 操作キャンセル |

#### 建物と旗の接続（代替操作: クリック×2）

| 操作 | 動作 |
|------|------|
| 建物を左クリック | 「接続元として選択」（建物に選択枠） |
| 旗を左クリック | 接続確定 |
| ESCキー | 操作キャンセル |

#### 接続の解除

| 操作 | 動作 |
|------|------|
| 接続線の上を右クリック | 「接続を切る」メニュー表示 |
| 建物を右クリック → 「接続を切る」 | 建物側からの接続解除 |

#### 旗の削除

| 操作 | 動作 |
|------|------|
| 旗を右クリック → 「旗を撤去する」 | 旗削除・接続していた建物の接続もすべて解除 |

#### 突撃指示（旗を横に倒す）

- 旗を1秒長押し → 回転アニメーション → 突撃モード（設計書§15準拠）
- 複数旗がある場合: 全旗が同時に横に倒れる（一括操作）
- 旗ごとの個別突撃は提供しない（KISS原則）

## 7. 進軍ルートプレビュー（クラスター起点・旗/建物ホバー表示）

STATUS: 企画確定・実装未定

更新日: 2026-05-01

### 7.1 概要

集結旗または生産建物にマウスカーソルを置いたとき、
「そのフラッグ/建物に紐づくアイドルユニットのクラスター重心」を起点とし、
旗を経由して敵BASEまでの想定進軍ルートをオーバーレイ表示する機能。

バトル前の「設計して観戦する」体験を支援し、旗配置の意図と実際のユニット位置を
即座に把握できるようにする（3秒ルール適合）。

### 7.2 トリガー条件

| イベント | 動作 |
|---------|------|
| InputEventMouseMotion で旗ノードに入った | その旗に紐づく全クラスターの経路を表示 |
| InputEventMouseMotion で生産建物ノードに入った | その建物の建物クラスターの経路を表示 |
| InputEventMouseMotion でノードから出た | 0.3秒後にプレビューをフェードアウト |
| 旗が突撃モード中（is_assault_mode = true） | プレビューは表示しない（突撃中は不要） |

実装箇所:
- 旗ホバー: EconRallyFlag.gd の mouse_entered/mouse_exited シグナル
- 建物ホバー: EconBuilding.gd の mouse_entered/mouse_exited シグナル（EconMain.gd 経由でプレビュー要求）

### 7.3 描画対象（クラスター定義と起点）

#### クラスターの定義

| クラスター種別 | 構成ユニット | 起点 |
|-------------|------------|------|
| 建物クラスター | `_spawn_building_pos == b.grid_pos` かつ `is_idle == true` のユニット集合 | クラスター内ユニットの grid_pos 平均（重心） |
| 旗クラスター | ある旗に接続された全建物の建物クラスターを合算したユニット集合 | クラスター内ユニットの grid_pos 平均（重心） |

- アイドルユニットが 0 体の場合は起点を建物の grid_pos にフォールバックする
- 重心は `Vector2(sum_x / count, sum_y / count)` で計算し、最近傍ヘックス中心にスナップする

#### 描画する経路

| ホバー対象 | 描画内容 |
|---------|---------|
| 集結旗 | 旗クラスター重心 → 旗グリッド中心 → 敵BASE位置 |
| 生産建物 | 建物クラスター重心 → 当該旗グリッド中心 → 敵BASE位置（建物が未接続の場合は旗省略で重心→敵BASEの直線） |

- 経路は直線近似（BFS最短経路ではなく直線で十分）
- 旗ホバー時に接続建物が複数ある場合は全クラスターの経路を同時表示する（種別切り替えなし）
- 接続なし旗（経由旗）はホバープレビューを表示しない

### 7.4 描画仕様

#### クラスター起点マーカー

各経路の開始点（クラスター重心位置）に以下のマーカーを描画する。

| 項目 | 値 |
|------|----|
| 形状 | 塗りつぶし円 |
| 半径 | 8px |
| 色 | 経路線と同色（アルファ 0.9） |
| 描画関数 | draw_circle(cluster_center, 8.0, color) |

アイドルユニットが 0 体でフォールバックした場合はマーカーを描画しない。

#### 線種・太さ

| 項目 | 値 |
|------|----|
| 線種 | 矢印付き破線（矢印で進行方向を明示） |
| 線幅 | 3px |
| ダッシュ長 | 12px |
| ギャップ長 | 6px |
| 矢印サイズ | 8px（旗→敵BASE 線上の中間点に 1 個配置） |

#### ユニット種別ごとの色

UNIT_STATS（EconUnit.gd）の定義色に合わせる。

| ユニット種別 | 建物種別 | 線色 | アルファ |
|------------|---------|------|---------|
| 突（ATTACKER） | 兵舎 | Color.RED（#FF0000） | 0.75 |
| 守（TANK） | 要塞 | Color.CORNFLOWER_BLUE（#6495ED） | 0.75 |
| 崩（BREAKER） | 工房 | Color.LIME_GREEN（#00FF00） | 0.75 |
| その他建物 | − | #888888（グレー） | 0.60 |

#### フェードアニメーション

| フェーズ | 内容 |
|---------|------|
| 表示開始 | 即座に表示（フェードインなし。遅延は不要） |
| フェードアウト | ホバー離脱後 0.3秒で alpha 0.75→0 の Tween |

### 7.5 実装方針

#### クラスタリングロジック

```gdscript
# EconMain.gd（または EconRallyFlag.gd から参照できる場所）に追加

# 建物クラスター重心を返す
func get_building_cluster_center(building_pos: Vector2i) -> Vector2:
    var idle_units = units.filter(func(u):
        return u._spawn_building_pos == building_pos and u.is_idle
    )
    if idle_units.is_empty():
        return Vector2(building_pos)  # フォールバック: 建物位置
    var sum = Vector2.ZERO
    for u in idle_units:
        sum += Vector2(u.grid_pos)
    return sum / idle_units.size()

# 旗クラスター重心を返す（接続建物の全アイドルユニットを合算）
func get_flag_cluster_center(flag: EconRallyFlag) -> Vector2:
    var idle_units = units.filter(func(u):
        return flag.connected_buildings.has(u._spawn_building_pos) and u.is_idle
    )
    if idle_units.is_empty():
        return Vector2(flag.grid_pos)  # フォールバック: 旗位置
    var sum = Vector2.ZERO
    for u in idle_units:
        sum += Vector2(u.grid_pos)
    return sum / idle_units.size()
```

- `_spawn_building_pos` は EconUnit.gd の既存フィールドを使用する
- `is_idle` は EconUnit.gd の既存フィールドを使用する
- クラスター重心はスクリーン座標変換前の grid_pos で計算し、描画時に hex_to_screen() で変換する
- 描画は EconRallyFlag.gd の _draw() 内で行う（建物ホバー時も EconMain 経由で旗に描画要求を委譲）
- ホバー状態を `var _is_hovered: bool` フラグで管理し、queue_redraw() を呼ぶ
- 敵BASE位置は EconMain から参照する（メソッド経由・疎結合ルール遵守）
- 建物の種別情報は connected_buildings リストをもとに EconMain 経由で取得する
- draw_dashed_line() で破線を描画し、矢印は線の中間点に draw_polygon() で三角形を描く
