## 1. 概要

### 1.1 プロジェクト名
Econ MVP v0.2 — 5戦ワンラン型 都市建設デッキバトル

### 1.2 目的・スコープ
- 「盤面を設計して、介入を仕込んで、答え合わせを観戦する」核体験を Econ MVP 上で動作するレベルまで実装する
- セミリアルタイム制（30秒1ターン × 最大10ターン or 5分上限）に基づく1バトル縦切り MVP の完成
- カードデッキの引き継ぎを伴う1ラン5戦ローグライト構造の最低限動作
- バトル単位での建設・強化・人口配分・幸福度・兵力生成・任意/最終突撃の全フローを連結

### 1.3 成功基準
- 1ランを5戦完走できる（バトル間でカードデッキのみ引き継ぎ・盤面/資源/人口は完全リセット）
- 1バトルが「30秒×最大10ターン」または「5分上限」で必ず終結する（タイムアウト時は最終突撃フェーズへ強制移行）
- 兵舎の蓄積兵力 → ユニット化 → 突撃 → 拠点HP削減のフローが GAME_DESIGN §6 のパラメータどおりに動く
- check_syntax.sh 通過（GDScript エラー0件）
- 紙プロト/シミュレーションで GAME_DESIGN §11 の確定パラメータと結果が一致

### 1.4 スコープ外（MVP除外）
本書 §4 を参照。

## 2. 機能要件

### 2.1 ゲームフロー (GD §2)

#### 2.1.1 1ラン構造
- 1ラン = 5戦固定
- 中ボス：3戦目／最終ボス：5戦目
- 引き継ぐもの：カードデッキ（通常建物・政策・偉人・報酬獲得分）のみ
- 引き継がないもの：盤面/資源/人口/兵力/幸福度/宝物開封状態/未達成マイルストーン

#### 2.1.2 セミリアルタイムターン（30秒）
- 時間はリアルタイム進行
- 30秒ごとに1ターン進行（ターン開始時に1ドロー）
- 5秒tickで建物効果・資源生産・幸福度更新・兵舎兵力生成を自動処理
- カード使用・建物配置はリアルタイム（ターン区切り無関係）
- 任意タイミングで旗ON/OFFして突撃可能
- 実装：中央ティッカー（例：`EconBattle.gd` 内のタイマー or `CityTicker.gd` 相当）が `tick(tick_index)` を発火し、全システムが購読

#### 2.1.3 通常フェーズ
- 最大時間：5分（300秒） OR 最大ターン数：10ターン（300秒）
  - どちらかに到達したら最終突撃フェーズへ強制移行
- 通常フェーズ中の許可操作（GD §2.3）：
  - 建設／建物強化／カード使用／リロード／追加ドロー／兵舎の兵力生成／旗ON/OFF／人口配分変更（CTなし）

#### 2.1.4 最終突撃フェーズ
- 移行条件：5分経過 OR 10ターン終了 OR プレイヤー意思（任意突撃→最終切替は MVP では未対応／自動移行のみ）
- 強制発動内容（GD §2.4）：
  - 旗：双方強制ON
  - 蓄積兵力：全兵舎の蓄積兵力をユニット化して全出撃
  - 停止する操作：建設／建物強化／カード使用／リロード／追加ドロー／ターンドロー／兵舎兵力生成
- 終結条件：勝利＝敵拠点HP=0 OR 敵ユニット全滅／敗北＝自拠点HP=0 OR 自軍ユニット全滅

#### 2.1.5 1ラン全体フロー
```
ラン開始 → バトル1（ランダム配置）
       → 60秒設計時間 + カード3択報酬
       → バトル2（バイオーム＋深度）
       → 60秒設計時間 + カード3択報酬
       → バトル3（中ボス）
       → 60秒設計時間 + カード3択報酬
       → バトル4
       → 60秒設計時間 + カード3択報酬
       → バトル5（最終ボス）
       → ラン終了
```

### 2.2 カード・デッキシステム (GD §3)

#### 2.2.1 カード領域
- 山札（UI表示あり）
- 手札（UI表示あり）
- 捨て札（UI表示あり）
- バトル中除外（**UI非表示**・内部処理用）

#### 2.2.2 ドロー仕様
| 項目 | 値 |
|---|---:|
| 初期手札 | 5枚 |
| 手札上限 | 7枚 |
| ターン開始ドロー | 1枚（30秒間隔・バトル開始時の1ターン目はドローしない） |
| リロードCT | 5秒 |
| 追加ドロー消費 | 対象リソース15個 |
| 山札切れ時 | 捨て札シャッフルで山札再構築 |
| 山札+捨て札ともに空 | ドロー失敗（コスト消費なし） |
| 手札上限到達中のドロー要求 | ドローしない（コスト消費なし） |

#### 2.2.3 リロード仕様
- 手札カード1枚選択 → 捨て札へ送る → 山札から1枚引く → リロードCT 5秒開始
- リロードは「使用」扱いではない（政策/偉人をリロードしてもバトル中除外には行かず捨て札へ）

#### 2.2.4 カード使用フロー
- **通常建物カード**：資源確認 → 配置先選択 → 資源支払い+建設キュー投入 → 捨て札へ
- **政策カード**：コスト確認 → 効果即時発動 → バトル中除外へ（バトル終了時にデッキ復帰）
  - **MVP実装範囲**：政策カードの個別効果は未実装。フレームワーク（除外領域処理）のみ実装
- **偉人カード**：配置先選択 → コスト確認 → 盤面に偉人表示 → バトル中除外へ → バトル中効果継続 → バトル終了時にデッキ復帰
  - **MVP実装範囲**：偉人カードの個別効果は未実装。フレームワークのみ実装

#### 2.2.5 リソース-15で追加ドロー
- 対象リソース：cards_econ.json で各カードに紐づくリソース種別（要設計確認）
- 不足時：使用不可（コスト消費なし）
- 手札上限時：ドローしない（コスト消費なし）

#### 2.2.6 設計時間中の挙動
- バトル間60秒の設計時間中：ランデッキシャッフル → 初期手札5枚を確定表示
- マリガン不可・リロード不可・カード使用不可
- 60秒経過 OR プレイヤー準備完了でバトル開始

#### 2.2.7 バトル終了時処理
- 手札・山札・捨て札・バトル中除外を回収
- 盤面上の偉人表示クリア
- ランデッキへ戻す
- 報酬カード追加 → 次バトル開始前にシャッフル

#### 2.2.8 任意突撃中のカード操作
- カード使用・リロード・追加ドロー・ターンドロー全継続

### 2.3 盤面・都市システム (GD §4)

#### 2.3.1 盤面構造
- 六角形パネル（ヘクスグリッド）
- 1パネル = 1建物
- 城下町クラスター = 隣接する建物群のまとまり
- 実装：`EconGrid.gd`

#### 2.3.2 拠点（自軍/敵軍）
| 項目 | 値 |
|---|---|
| 拠点HP（初期値） | 200 |
| 拠点占有 | 1ヘクス |
| 同時攻撃可能ユニット数 | 6パネル × スタック上限3 = 最大18 |
| 拠点LvUP | スコープ外（GD §12.4／本書 §6.3） |

実装：拠点は `EconBattle.gd` で初期 HP=200・最初から `is_built = true` で活動。

#### 2.3.3 建物分類
- アクティブ型：稼働人口割当時のみ生産・効果発動
- パッシブ型：建設完了後、稼働人口なしで効果発揮
- 建設中：種別問わず効果停止・人口消費なし・パネル占有

#### 2.3.4 建物配置フロー（リソース消費 + 建築キュー）
```
建物カードプレイ → 資源支払い → 建設キューに追加
                  → 作業人口が工事を進める → 完了後に建物有効化
```

#### 2.3.5 建設キューで処理する対象
- 新規建物建設
- 建物強化（Lv1→Lv2→Lv3）
- 防壁建設・防壁再建
- 防衛拠点強化
- 拠点レベルアップ（スコープ外）

#### 2.3.6 建設時間計算
- `建設時間 = 残作業量 ÷ 割当作業人口`
- 最大投入人数の上限なし。作業人口は優先度順に自動配分（§2.4.4 都市優先度）

#### 2.3.7 即時建設
- `即時建設コスト = ceil(残作業量 × 0.5)`
- 最低コスト = 通貨1
- 通貨支払で残工数に応じた即時完了が可能

#### 2.3.8 建物Lv（1-3）と強化
- 強化はバトル中のみ有効（次バトルでリセット）
- 強化中も現在Lv効果は維持。強化中の追加強化は不可
| Lv | コスト | 効果差分 |
|---|---|---|
| Lv1 | 建設コスト基準 | 基本効果 |
| Lv2 | 建設コストの50% | +25%生産系 |
| Lv3 | 建設コストの100% | +50%生産系 |

#### 2.3.9 防壁システム
| 項目 | 値 |
|---|---:|
| 1辺あたりHP | 60 |
| 1辺あたり建設コスト（石材） | 2 |
| 1辺あたり必要作業量 | 5 |
| 防壁HP管理単位 | パネル所属防壁グループ単位 |

- `防壁HP = 1辺あたりHP × 設置辺数`
- 防壁HP=0時：該当パネルの防壁群はまとめて消える（1辺だけ穴を開ける仕様にしない）
- 自動再建なし（資源を払って建築キューに入れる必要あり）

##### 城下町外側建設時の防壁更新
1. 新建物の建設確定
2. 城下町クラスターに統合
3. 旧防壁のうち都市内部化したものを撤去（資源は戻らない）
4. 新外周辺を再計算
5. 新外周辺に防壁建設キューを自動追加
6. 完成順に有効化

防壁再建中：旧撤去済み + 新未完成 = 無防備。敵通行可能。

##### 防壁越し攻撃
- 近接ユニット：防壁越しの敵ユニット攻撃**不可**。防壁そのものは攻撃**可能**
- 遠距離ユニット：MVP では未実装（弓兵スコープ外）

### 2.4 リソース・人口管理 (GD §5)

#### 2.4.1 6資源（MVP）
| 資源 | 用途 | 主な生産源 | 初期値（実装値） |
|---|---|---|---:|
| 木材 | 建設コスト | 製材所 | 5 |
| 樹脂 | 林業系リソース | 製材所 | 0 |
| 石材 | 建設・防壁コスト | 採掘所 | 5 |
| 鉄鉱石 | 採掘系リソース | 採掘所 | 0 |
| 食料 | 人口維持 | 農場 | 30 |
| 通貨 | 政策・即時建設・交換所ドロー | 市場 | 100 |

> 注：GD §5.1 では魔力も列挙されるが、MVP範囲では対象外。
> 本要件では **木材・樹脂・石材・鉄鉱石・食料・通貨の6資源** を MVP 採用とする。

#### 2.4.2 人口
- 人口 = 都市の労働力
- **稼働人口**：アクティブ建物を動かす（生産担当）
- **作業人口**：建設・強化・防壁再建・拠点LvUPを進める

##### 配分バー
- 稼働人口 ←→ 作業人口
- スナップポイント：25 / 50 / 75
- 初期値：稼働75 / 作業25
- 変更CT：なし（戦闘中いつでも変更可）
- 再計算：5秒tickごと

##### 人口拡大ルール
- 食料消費式：**未確定（GD §12.2／本書 §6.1 参照）**
- 食料不足時：人口増加停止（既存方針）
- 住居が人口上限を提供（Lv1=+10、Lv2=+15、Lv3=+20）
- 兵力は人口とは別ストック（住居上限を消費しない・幸福度負荷に含めない）

#### 2.4.3 幸福度
| 項目 | 値 |
|---|---:|
| 範囲 | 0〜100 |
| 初期値 | 60 |
| 更新頻度 | 5秒tick |
| 基本式 | `幸福度変動 = 幸福供給 − 人口負荷` |

##### 人口負荷
- `人口10人ごとに 5秒ごと幸福度-1`

| 人口 | 5秒負荷 |
|---:|---:|
| 0〜9 | 0 |
| 10〜19 | -1 |
| 20〜29 | -2 |
| 30〜39 | -3 |
| 40〜49 | -4 |
| 50〜59 | -5 |

##### 幸福供給源（MVP）
- 広場
- 祝祭政策（政策カード未実装のため、フレームワークのみ）
- 宝物の即時報酬

##### 幸福度状態と効果
| 幸福度 | 状態 | 効果 |
|---:|---|---|
| 70〜100 | 高幸福 | 人口増加速度+20%、兵力生成+10% |
| 40〜69 | 通常 | 補正なし |
| 20〜39 | 不満 | 人口増加停止、アクティブ建物生産-10% |
| 0〜19 | 危険 | 人口増加停止、アクティブ建物生産-25%、兵力生成-20% |

> 低幸福ペナルティはアクティブ建物の生産・生成系にのみ適用。
> パッシブ建物・防壁HP・住居上限・広場供給には適用しない。

#### 2.4.4 5秒ティック処理（同期）
| 処理 | 内容 |
|---|---|
| 資源生産 | アクティブ建物の生産 |
| 人口消費 | 食料消費の計算（計算式は §6.1 で実装判断） |
| 兵舎生成 | 兵力生成（Lvに応じて） |
| 幸福度更新 | 幸福度の再計算 |
| 広場供給 | 幸福度+1/+2/+3（Lvにより） |
| 防衛拠点回復 | 範囲内防壁HP+10/+15（Lv2/Lv3） |
| 人口配分 | 稼働/作業の再計算 |

> 処理順序：実装判断（GD §12.5 参照）。本書 §6.2 で実装方針を記載。

#### 2.4.5 都市優先度（アクティブ建物稼働順）
- 候補：バランス／資源優先／食料優先／建設優先／通貨・ドロー優先／軍事優先／防衛優先
- 同カテゴリ内の優先度（確定）：
  1. 高Lv建物
  2. 拠点に近い建物
  3. 先に建てた建物
- 個別建物の手動固定稼働は MVP では実装しない

### 2.5 兵力・ユニットシステム (GD §6)

#### 2.5.1 基本方針
- 兵力は人口を直接消費しない
- 兵舎が時間経過で集める/訓練する戦力ストック
- 兵舎稼働条件：必要稼働人口1（アクティブ型）
- 兵力蓄積先：兵舎ごと（都市プールではない）
- 住居上限消費なし／幸福度負荷に含めない／稼働人口・作業人口計算に含めない

#### 2.5.2 兵舎の兵力生成（5秒tick・整数固定値）
| 兵舎Lv | 5秒ごとの兵力生成量 |
|---|---:|
| Lv1 | +2 |
| Lv2 | +3 |
| Lv3 | +4 |

#### 2.5.3 幸福度補正
- `補正後生成量 = 基礎生成量 × 幸福度補正`
- 幸福度70以上：×1.1
- 幸福度0〜19：×0.8
- 内部値は小数で蓄積、UI表示は整数に丸める

#### 2.5.4 旗ON/OFF挙動
| 状態 | 挙動 |
|---|---|
| 旗OFF | 新規生成兵力は兵舎に蓄積。ユニット出撃なし |
| 旗ON（任意突撃） | 蓄積兵力をユニット化して出撃。新規生成兵力も即出撃 |
| 旗OFFに戻す | 新規生成兵力は再度蓄積。出撃済みユニットは戦闘継続 |
| 任意突撃 | 複数回可能 |

実装：`EconRallyFlag.gd` で旗状態を管理。

#### 2.5.5 兵力 → ユニット変換
| 項目 | 値 |
|---|---:|
| 変換レート | 兵力10 = 1ユニット |
| 1ユニット最大HP | 10 |
| 残存HP | 残存兵力と同値 |
| 端数処理 | 端数兵力も端数ユニットとして出撃 |
| 出撃ペース | 各兵舎0.2秒/ユニット |

例：兵舎の蓄積兵力27 → HP10ユニット×2体 + HP7ユニット×1体

#### 2.5.6 ユニットDPS
- `ユニットDPS = 残存兵力 × 基礎DPS係数`
- 基礎DPS係数 = 0.2

| 残存兵力 | DPS |
|---:|---:|
| 10 | 2.0 |
| 5 | 1.0 |

傷ついたユニットは火力も落ちる（残存HPが残存兵力として機能）。

#### 2.5.7 対象別ダメージ補正（MVP初期値）
| 補正 | 値 |
|---|---:|
| 対ユニット補正 | 1.0 |
| 対防壁補正 | 1.0 |
| 対拠点補正 | 1.0 |

```
対ユニットダメージ = ユニットDPS × 対ユニット補正
対防壁ダメージ   = ユニットDPS × 対防壁補正
対拠点ダメージ   = ユニットDPS × 対拠点補正
```

#### 2.5.8 スタック仕様
- 1パネル最大スタック：3ユニット
- 同パネル内のユニットはそれぞれ攻撃に参加
- 進行先がスタック上限に達している場合は近い代替パネルへ展開

#### 2.5.9 隣接兵舎へのDPS強化（鍛冶屋）
- 鍛冶屋（アクティブ型・必要稼働人口1）が隣接兵舎のユニットDPSを強化
| Lv | 効果 |
|---|---|
| Lv1 | DPS +10% |
| Lv2 | DPS +15% |
| Lv3 | DPS +20% |

- 適用タイミング：ユニット化して出撃する時
- 対象出撃：任意突撃・最終突撃・防衛拠点による防衛出撃
- 非稼働時：効果なし
- 複数隣接時：最も高いLvの効果のみ適用（重複しない）

#### 2.5.10 防衛兵力
```
防衛拠点が範囲内兵舎から兵力を引き出す
↓
防衛ユニット化（同パネル最大3ユニット）
↓
迎撃
↓
敵ユニットがいなくなったら生存分が兵力として戻る
```

| 攻撃側ユニット帰還 | なし（攻撃に出した兵力は消費扱い） |

### 2.6 戦闘 (GD §7)

#### 2.6.1 任意突撃（旗ON）
- 旗ONで蓄積兵力をユニット化して出撃
- 通常フェーズ中の攻撃イベントとして扱う
- カード使用・リロード・追加ドロー・ターンドローはすべて継続
- 兵舎は5秒tickで兵力生成を継続（新規生成分は即出撃）
- 旗OFFに戻すと新規生成兵力は再蓄積（出撃済みユニットは戦闘継続）

#### 2.6.2 最終突撃（強制化）
- 5分経過 OR 10ターン終了で強制移行
- 旗：双方強制ON
- 蓄積兵力をすべてユニット化して全出撃
- 以後、新規ユニット供給なし（兵舎兵力生成停止）

#### 2.6.3 敵ユニット出撃ペース
- 各兵舎：0.2秒ごとに1ユニット出撃
- 意図：ワラワラ感・処理負荷分散・兵舎ごとの出撃ルートの可視化

#### 2.6.4 DPS計算
- 対ユニット：`ユニットDPS × 1.0 × バフ係数（鍛冶屋等）`
- 対防壁：`ユニットDPS × 1.0 × バフ係数`
- 対拠点：`ユニットDPS × 1.0 × バフ係数`
- 拠点への総DPS = 拠点に接敵している全ユニットのDPS合計（最大18ユニット）

#### 2.6.5 防壁破壊ロジック
- 防壁グループHP = 1辺HP(60) × 設置辺数
- 同時攻撃可能ユニット数 = 攻撃可能外側パネル数 × スタック上限(3)
- 防壁HP = 0 で該当パネルの防壁群はまとめて消える
- 自動再建なし

#### 2.6.6 攻撃優先順位

**突撃側**：
1. 敵拠点へ到達可能なら敵拠点を優先
2. 経路上の防壁を攻撃
3. 進路上の敵ユニットを攻撃
4. 攻撃してきた敵ユニットへ反撃

**防衛側**：
1. 拠点に近い敵ユニット
2. 防壁を攻撃中の敵ユニット
3. 防衛範囲内の最も近い敵ユニット

## 6. 実装上の注意

### 6.1 食料 vs 小麦：統一済み（食料に統一）
- 設計文書・仕様書・コード上の用語は **「食料 (food)」** に統一
- 実装：`EconEconomy.gd:11-12,16-23` に `food = 30` で統一済
- 注意：`EconBuilding.gd:49-50` の VILLAGE_WHEAT_INTERVAL=5秒 / VILLAGE_WHEAT_AMOUNT=+2 は変数名に "WHEAT" を含むが、用語は「食料」とする。**変数名は将来リネーム検討（MVPではスコープ外）**
- 食料消費の計算式は GD §12.2 で未確定 → 本要件では実装判断に委ねる
  - **暫定実装方針**：人口10人あたり 5秒ごと 食料-1（負荷の幸福度ペナルティ式と同じ刻み）
  - 食料不足時：人口増加停止（既存方針・GD §5.3）

### 6.2 5秒ティック処理順序：未定義（実装判断）
GD §12.5 で順序未定義。本要件では以下の暫定順序を採用する：
1. 資源生産（アクティブ建物の生産）
2. 兵舎生成（兵力 +2/+3/+4）
3. 食料消費（人口維持）
4. 幸福度更新（広場供給 → 人口負荷 → 状態遷移判定）
5. 防衛拠点回復（範囲内防壁HP+10/+15）
6. 人口配分再計算（スナップ反映）

> 食料消費を兵舎生成の後に置くことで「食料切れによる人口減少」が「兵力生成停止」に直結しないようにする（兵力は人口を消費しないため）。

### 6.3 拠点LvUP：スコープ外（将来検討）
- GD §4.2 で「拠点LvUP効果は未定義」、§12.4 で「機構は未実装、必要作業量30は確定」
- MVP では拠点LvUP実装をスコープ外とする
- 拠点は最初から `is_built = true` で活動（既存実装どおり）

### 6.4 交換所のリソース消費：通貨のみ
- GD §4.4 では「通貨を消費して追加ドロー」と記載
- MVP では **交換所の追加ドロー消費は通貨のみ** に確定
- §2.2.5 の「リソース-15で追加ドロー」とは別経路：
  - 追加ドロー（カード固有）：対象リソース15
  - 交換所の追加ドロー：通貨（CT基準・Lvで短縮/コスト削減）

### 6.5 政策・偉人カード：フレームワークのみ実装
- 個別効果は未実装（GD §12.6 / §12.7）
- 実装するもの：
  - カード種別の判定機構（"building" / "policy" / "great_person"）
  - 使用後の遷移先制御（捨て札 vs バトル中除外）
