# Sprint 9：報酬・マイルストーン・宝箱システム企画書 確定版

## 1. 目的

Sprint 9では、バトルごとの成長報酬を「マイルストーン報酬」と「宝箱」によって構成する。

本Sprintの目的は、バトル中のプレイ目標を明確化し、達成内容に応じたカード・土地・特殊報酬を獲得できる報酬基盤を実装することである。

---

## 2. 用語定義

| 用語 | 定義 |
|---|---|
| 通常資源 | 木・樹脂・石・鉄鉱石・小麦・綿花。バトル中の建築・建物稼働に使う。原則としてバトル間で持ち越さない。 |
| 通貨 | ラン中に保持される通常通貨。マイルストーン難易度選択、将来のショップ、カード削除、イベントなどに使う。リロールには使わない。 |
| 初期難易度 | バトル開始時に選ぶ難易度。低・中・高の3段階。各系統で提示されるマイルストーン難易度レンジと通貨増減を決める。 |
| マイルストーン | バトル中に達成を狙う目標。8系統ごとに、初期難易度に応じた3段階が提示される。 |
| 通常マイルストーン | バトル開始時に提示される基本マイルストーン。 |
| 特殊マイルストーン | 宝箱取得などで追加される追加マイルストーン。 |
| マイルストーン報酬 | マイルストーン達成により得る報酬の総称。通常マイルストーン報酬・特殊マイルストーン報酬・マイルストーン即時報酬に分かれる。 |
| 通常マイルストーン報酬 | 通常マイルストーン達成時に得るバトル後の選択式カード報酬。 |
| 特殊マイルストーン報酬 | 特殊マイルストーン達成時に得るバトル後の選択式報酬。通常より強めの報酬にする。 |
| マイルストーン即時報酬 | 8系統それぞれの中難度マイルストーン達成時に、バトル中に即時発生するサポート報酬。カード報酬には統合しない。 |
| 宝箱 | バトルパネル上に初期配置される報酬オブジェクト。宝箱に隣接するパネルへ建設すると自動取得される。 |
| 宝箱即時報酬 | 宝箱取得時に完全ランダムで即時付与される報酬。 |
| 通常建物カード | 使用後に捨て札/山札循環へ戻る建物カード。 |
| 特殊建物カード | 使用後に捨て札へ行かず除外される建物カード。建物自体は盤面に残る場合がある。 |
| 政策カード | 一時効果または戦略選択を与えるカード。詳細仕様は後続Sprintで拡張する。 |
| 偉人カード | 永続効果によりビルド方針を変えるカード。詳細仕様は後続Sprintで実装する。 |
| 土地カード | マイルストーン報酬で獲得できる土地拡張カード。獲得時点で対象資源と資源値が分かる。 |
| 未建設土地 | 建物が建っておらず、建設予定地にもなっていない土地。 |
| 自領地 | 自建物から3マス以内の未建設土地。 |

## 3. 報酬構造

```text
報酬システム
├─ マイルストーン報酬
│  ├─ 通常マイルストーン報酬
│  │  ├─ 通常建物カード
│  │  ├─ 特殊建物カード
│  │  └─ 政策カード
│  │
│  ├─ 特殊マイルストーン報酬
│  │  ├─ 土地カード
│  │  ├─ 偉人カード
│  │  └─ 特殊建物カード
│  │
│  └─ マイルストーン即時報酬
│     └─ 8系統に応じたバトル中サポート効果
│
└─ 宝箱
   ├─ 宝箱即時報酬
   └─ 特殊マイルストーン追加
```

「通常報酬」という用語は使わない。通常報酬に相当する概念は、通常マイルストーン報酬に統合する。

## 4. 初期難易度

```text
初期難易度：低 / 中 / 高

初期難易度 低：+100G
初期難易度 中：±0G
初期難易度 高：-100G
```

通貨増減は初期難易度にのみ紐づく。極低・低・中・高・極高の個別マイルストーン難易度には通貨増減を持たせない。

| 初期難易度 | 各系統に提示される3段階 |
|---|---|
| 低 | 極低 / 低 / 中 |
| 中 | 低 / 中 / 高 |
| 高 | 中 / 高 / 極高 |

## 5. マイルストーン系統

| 系統 | 役割 |
|---|---|
| 人口系 | 人口・人口上限を伸ばす |
| 食料系 | 小麦・食料値を安定させる |
| 満足度系 | 満足度段階・満足値を維持/改善する |
| 建築系 | 建物数・建設速度・建設展開を伸ばす |
| 資源系 | 木・樹脂・石・鉄鉱石などの採取を伸ばす |
| 兵力系 | 兵力・兵数・ユニット数を伸ばす |
| 土地系 | 土地拡張・高価値土地・特殊タグ土地へ接続する |
| リスク系 | 制約付き達成で高リターンを狙う |


## 7. 難易度別の報酬

| 難易度 | 報酬 |
|---|---|
| 極低 | バトル後カード報酬 |
| 低 | バトル後カード報酬 |
| 中 | バトル中のマイルストーン即時報酬のみ |
| 高 | バトル後カード報酬 |
| 極高 | バトル後カード報酬 |

中難度マイルストーン達成時は、マイルストーン即時報酬のみを得る。中難度マイルストーン達成時にカード報酬は発生しない。

---

## 8. 通常マイルストーン報酬

通常マイルストーン報酬は、通常マイルストーン達成時にバトル後に提示される選択式報酬である。

```text
通常マイルストーン報酬：
- 通常建物カード
- 特殊建物カード
- 政策カード

通常建物：特殊建物：政策 = 1：1：1
```

通常マイルストーン報酬には以下を含めない。

```text
- 土地カード
- 偉人カード
- 通常資源
- 即時補助報酬
```

---

## 9. 特殊マイルストーン報酬

特殊マイルストーン報酬は、特殊マイルストーン達成時にバトル後に提示される選択式報酬である。特殊マイルストーンは宝箱取得などで追加される。

```text
特殊マイルストーン報酬：
- 土地カード
- 偉人カード
- 特殊建物カード
```

特殊マイルストーン報酬は、宝箱取得のリスクに見合う強めの報酬にする。

---

## 10. マイルストーン即時報酬

マイルストーン即時報酬は、8系統それぞれの中難度マイルストーン達成時に、バトル中に即時発生するサポート報酬である。カード報酬には統合しない。

| 系統 | 中難度即時報酬 |
|---|---|
| 人口系 | 人口 +10 |
| 食料系 | 食料値 +10 |
| 満足度系 | 満足値 +10% |
| 建築系 | 建設中タイマーを全建物 +20%進める |
| 資源系 | 通常資源からランダム1種 +5 |
| 兵力系 | そのバトル中、兵力 +10% |
| 土地系 | 自領地内の未建設土地ランダム1マスに特殊資源を発生 |
| リスク系 | 通貨 +100G |

土地系の特殊資源候補：

```text
- 香辛料
- 硫黄
```

## 12. 宝箱

宝箱は、バトルパネル上に初期配置される報酬オブジェクトである。UIではない。

```text
宝箱配置数：1バトル3つ
宝箱種類：作らない
```

配置イメージ：

```text
- 自軍/敵軍から中距離の位置に2つ
- 中央/遠距離寄りの位置に1つ
```

取得条件：

```text
宝箱に隣接するパネルへ建設すると自動取得
```

取得時処理：

```text
1. 宝箱即時報酬を完全ランダムで獲得
2. 特殊マイルストーンを1つ追加
```

MVPでは、敵は宝箱を取得しない。

---

## 13. 宝箱即時報酬

宝箱即時報酬は完全ランダムとする。ただし候補プールは以下を基本とする。

| 候補 | 効果 |
|---|---|
| 木 +5 | 即時獲得 |
| 石 +5 | 即時獲得 |
| 小麦 +5 | 即時獲得 |
| 樹脂 +3 | 即時獲得 |
| 鉄鉱石 +3 | 即時獲得 |
| 食料値 +10 | 即時獲得 |
| 満足値 +5% | 即時獲得 |
| 建設中タイマー1件 +30% | 即時適用 |
| そのバトル中、兵力 +5% | 即時適用 |
| 通貨 +50G | 即時獲得 |

宝箱即時報酬は弱〜中程度にする。宝箱の主目的は、特殊マイルストーン追加とする。

---

## 14. 土地カード

土地カードは特殊マイルストーン報酬に含める。通常マイルストーン報酬には含めない。

土地カードは、獲得時点で以下が分かる。

```text
- 対象資源
- 資源値
- 複合資源の有無
- 特殊タグの有無
```

土地カード選択後は配置モードへ移行する。

配置条件：

```text
自建物に隣接する未建設土地
```

配置不可：

```text
- 自建物に隣接していない土地
- 建設予定地
- 建設後パネル
- 配置可能な土地が存在しない場合
```

配置できない土地カードは選択不可にする。

## 15. 報酬提示

```text
報酬提示：3択
報酬留保：なし
報酬スキップ：あり
```

| 報酬 | タイミング |
|---|---|
| 通常マイルストーン報酬 | バトル後 |
| 特殊マイルストーン報酬 | バトル後 |
| マイルストーン即時報酬 | バトル中に即時 |
| 宝箱即時報酬 | 宝箱取得時に即時 |

スキップした報酬は破棄する。

## 17. 完了条件

```text
- 初期難易度を低/中/高から選択できる
- 初期難易度に応じて通貨を増減できる
- 初期難易度に応じて各系統のマイルストーン提示レンジを切り替えられる

- 通常マイルストーン報酬で通常建物・特殊建物・政策カードを3択提示できる
- 通常マイルストーン報酬に土地カードを含めない
- 宝箱を1バトル3つ配置できる
- 宝箱に隣接するパネルへ建設した時に自動取得できる
- 宝箱取得時に宝箱即時報酬を完全ランダムで付与できる
- 宝箱取得時に特殊マイルストーンを1つ追加できる
- 特殊マイルストーン達成時に特殊マイルストーン報酬対象として記録できる
- 特殊マイルストーン報酬で土地カード・偉人カード・特殊建物カードを3択提示できる
- 土地カード選択時に対象資源・資源値を確認できる
- 土地カード選択後に配置モードへ移行できる
- 土地カードを自建物に隣接する未建設土地へ配置できる
- 建設予定地・建設後パネルには土地カードを配置できない
- 配置不能な土地カードを選択不可にできる
- 報酬をスキップできる
- 報酬を留保できない
```
