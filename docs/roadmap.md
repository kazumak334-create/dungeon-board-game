### ステータス定義

| 段階 | 意味 |
|------|------|
| 企画 | アイデア・方向性が決まった |
| 設計 | 企画を基にした要件定義・データ構造・仕様が決まった |
| 実装 | コードに落とし込み完了 |
| 未着手 | まだ何も手をつけていない |
| 保留 | 未決定事項の判断待ち |
