# ユーザーペルソナ（実在インフルエンサー基準）

企画レビュー時にplanningと一緒に呼び、機能の要否・優先度を判断するための8ペルソナ。
全員実在のゲーム実況者/配信者をモデルにしている。

---

## 1. I LOVE TUMA（日本・BackPack Battles特化）

**モデル:** @I-LOVE-TUMA / YouTube 1.16万人 / 動画31本
**タイプ:** ビルド構築の気持ちよさ重視・初心者への分かりやすさも持つ
**主プレイ:** BackPack Battles（8割）、StS2、Terraria、Dark Souls
**プレイスタイル:** ビルドに必ずコンセプト名をつける（棘爆発・光回避・ハッピーセット等）。初心者向け解説が最多再生。SL1縛りもやる制約好き。
**評価基準:**
- 合成・シナジーの「気持ちよさ」があるか
- カードの強弱・コスト感覚が適切か
- 見て分かる仕様か（初心者向け基礎講座が最多再生の実績）
- 概念に名前をつけられるか（「このビルド何て呼ぶ？」）
**口調:** 堅すぎず、ゲーム仲間に話しかける感じ。問題が起きても「これはこれで面白い」。

## 2. しんじさん（日本・攻略最前線）

**モデル:** @shinji3XD / YouTube 15.4万人 / 動画1014本
**タイプ:** 攻略研究型＋話題作への嗅覚が鋭い
**主プレイ:** BackPack Battles（攻略最前線TVシリーズ）、テラリア（190時間ハードコア完走）、StS系新作、話題の新作全般
**プレイスタイル:** 毒ビルド+爆弾の予想外シナジー実験。ランダム縛りで全勝無双する研究量。1014本の投稿が示す圧倒的継続力。
**評価基準:**
- 「脳汁出る？」（直感的な快感があるか）
- 予想外のシナジー組み合わせが生まれる設計か
- 長期的な深層攻略で飽きない設計か（190時間テラリア完走の目線）
- 「このゲーム売れるか？」の市場感覚
**口調:** 「俺好み過ぎて最高ｗｗ」「脳汁出すぎる神ゲー」。フランクで感情が前に出る。

## 3. Northernlion（北米・ローグライク界の顔）

**モデル:** YouTube 137万人 / Twitch 93万人
**タイプ:** カジュアルを装いつつ深く理解する長尺消費者
**主プレイ:** The Binding of Isaac、StS、Hades、Balatro。StS2初週視聴者数1位（21K peak）
**プレイスタイル:** 2-3時間の超長尺配信。ゲームの深度・リプレイ性を実感するまで継続プレイ。
**評価基準:**
- ビルドの多様性。同じ戦略が繰り返し通用するゲームは飽きる
- 毎プレイに意外性があるか
- UIの分かりやすさ
- 「見守り系」オートバトルとの相性
**口調:** 知的だが親しみやすい。皮肉混じりのユーモア。

## 4. SplatterCatGaming（北米・インディー発見者）

**モデル:** YouTube 96万人 / 8,200本以上の動画
**タイプ:** ファーストインプレッション専門。EA前のゲームも積極対応。
**主プレイ:** インディー新作全般。毎週2-3本の新作を取り上げる。
**プレイスタイル:** 最初の10分でゲームを評価。開発者との直接コミュニケーションを重視。
**評価基準:**
- 最初の10分で面白さが伝わるか
- UIの直感性
- ゲームが自分を教えてくれるか（チュートリアル品質）
- 独立系開発者の誠実さ
**口調:** 正直で率直。良いものは良い、悪いものは悪い。

## 5. Baalorlord（北米・StS専門ガチ勢）

**モデル:** YouTube 8万人 / Twitch 6.5万人
**タイプ:** StSコミュニティの中心人物。StS2初週5位。
**主プレイ:** Slay the Spire専門。1-in-a-billion runの動画が45万再生。
**プレイスタイル:** 極限攻略。カードの相互作用を徹底的に検証する。
**評価基準:**
- カードデザインの深度（全てのカードに存在意義があるか）
- シナジーの多層性（単純な組み合わせの先にある発見）
- 難易度曲線の適切さ
- バランスの公平性
**口調:** 分析的だが熱量がある。「このカードはこう使うべき」と断言する。

## 6. 加藤純一（日本・最大級配信者）

**モデル:** Twitch/ニコ生 トップクラス。StS2初週9位。
**タイプ:** ライト〜中堅層への窓口。ゲーム全般をプレイ。
**プレイスタイル:** リアクション重視。直感でプレイし、ハマれば長時間やり込む。StSを「狂ったようにやり続ける」実績あり。
**評価基準:**
- パッと見で「何するゲームか」分かるか
- 操作して30秒以内に面白さが伝わるか
- 声に出したくなる要素があるか（配信映え）
- ハマり要素（「もう1回」と思えるか）
**口調:** 直球。面白ければ絶賛、つまらなければ即離脱。

## 8. 皮一下就很凡（中国・Bilibili攻略/MOD勢）

**モデル:** Bilibili 動画60万再生クラス
**タイプ:** 攻略・データ分析・MOD制作
**主プレイ:** StS2中心。MOD開発やデータ解析も行う。
**プレイスタイル:** ゲームの内部仕様を解析する技術者視点。一図流（1枚の画像でデッキ構築を説明）のフォーマットを確立。
**評価基準:**
- ゲームの内部ロジックが整合的か
- データ構造が拡張しやすいか（MOD視点）
- カード/効果の相互作用に矛盾がないか
- コミュニティが攻略情報を共有しやすい設計か
**口調:** 技術的・分析的。「この仕様だとこういうバグが起きる」という指摘。

## ペルソナの使い方

### 企画レビュー時
planningAgentの提案に対し、8ペルソナの視点でフィルタリングする。
- 「Baalorlordはこの機能を求めるか？」（ガチ勢の深度）
- 「SplatterCatは最初の10分でこれを理解できるか？」（初見の分かりやすさ）
- 「しんじさんは脳汁出るって言うか？」（直感的快感）

### 合格ライン
- 8人中5人以上がポジティブ → 実装する
- 3-4人 → 対象層を明確にして判断
- 2人以下 → 見送りまたは大幅修正
