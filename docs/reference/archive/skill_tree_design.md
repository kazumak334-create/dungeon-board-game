# スキルツリー設計

作成日: 2026-04-08
更新日: 2026-04-08

## 基本仕様

### ツリー生成ルール

- **階層数**: 1-6階層
- **ランダム生成**: ランごとに異なるツリー構造
- **クラス差別化**: 4+6階層のみクラス固有、1-3+5階層は共通
  - 1-3階層：共通（基礎強化・経済）
  - 4階層：クラス固有（種族特化）
  - 5階層：共通（戦術拡張）
  - 6階層：クラス固有（究極スキル）
- **スキルポイントコスト**: 階層数=必要SP（1階層=1SP、2階層=2SP...6階層=6SP）
- **SP獲得**: バトル報酬3SP（固定）

### 分岐ルール

| 階層 | スキル数 |
|------|---------|
| 1階層 | 1つ（固定） |
| 2階層 | 3つ（固定） |
| 3-6階層 | 1-3つ（ランダム） |

### 制約条件

- **前提スキル**: 最大2つまで
- **最大表示スキル数**: 未定義（要決定）
- **その他制約**: 未定義（要決定）

## データ構造（案）

### スキルプール定義

```gdscript
# 各階層ごとにスキル候補を定義
const SKILL_POOL = {
    1: [  # 1階層スキル候補
        {"id": "skill_1_a", "name": "...", "effect": "..."},
        {"id": "skill_1_b", "name": "...", "effect": "..."},
    ],
    2: [  # 2階層スキル候補
        {"id": "skill_2_a", "name": "...", "effect": "..."},
        # ...
    ],
    # ... 3-6階層
}
```

### 生成ツリー構造

```gdscript
# ランごとに生成されるツリー
var skill_tree = {
    "nodes": [
        {
            "id": "skill_1_a",
            "tier": 1,
            "cost": 1,
            "prerequisites": [],  # 空（1階層は前提なし）
            "unlocked": false
        },
        {
            "id": "skill_2_b",
            "tier": 2,
            "cost": 2,
            "prerequisites": ["skill_1_a"],  # 最大2つまで
            "unlocked": false
        },
        # ...
    ]
}
```

## 未決定事項

1. **最大表示スキル数**: ツリー全体で何スキルまで表示するか
2. **各階層のスキル候補数**: 各階層にいくつのスキル候補を用意するか
3. **スキル効果の種類**: どんなスキルを用意するか（バフ/デバフ/経済/合成/盤面操作等）
4. **クラス固有スキルの扱い**: 共通プールのみか、一部クラス固有を含むか
5. **SP入手ペース**: 1バトルあたり何SP獲得するか（6階層到達の難易度調整）
6. **UI表示方法**: ツリーの視覚的表現（縦？横？）

## Phase 2 実装範囲

- **スキルタブUI**: ツリー表示のモックアップ（スキル候補は仮データ）
- **自動生成ロジック**: 上記ルールに従ったツリー生成
- **解放機能**: SP消費→スキル解放→GameSessionに保存
- **効果適用**: 解放済みスキルの効果をバトルに反映（最低限の効果種類のみ）
