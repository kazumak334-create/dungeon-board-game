# 世界観コンセプト「忘却のダンジョン」

作成日: 2026-04-07
ステータス: 確定（企画会議6回通過・ペルソナ検証済み）

---

## 二層構造

本作の世界観は「表層（プレイヤーが最初に触れるもの）」と「真相（ゲーム後半で段階的に明かされるもの）」の二層構造。

---

## 表層: 中世ダークファンタジー

### 世界の状況
「灰色の疫病」が3年前から蔓延している。作物は実らず、獣は狂い、人は病む。
人も獣も同じ死に方をするようになった。

### ダンジョン
「根の迷宮」——かつての文明が遺した地下遺構。灰色の疫病が生まれた場所とも、治す力が眠る場所とも言われている。

### プレイヤー
記憶を持たない「廃兵」。王国に回収され、地下へ送られる者。
記憶がない理由: 深部の何かに意識を乗っ取られないための処置（と説明される）。

### 目的
迷宮の最深部にある「原初の種」を持ち帰れ。それだけだ。

### 3クラス
- **錬金術師（スライム）**: 疫病を解析する研究者の生き残り。変質した生命を使役する
- **バーサーカー（獣）**: 疫病で集落を失った戦士。獣と共に生きてきた
- **死霊術師（アンデッド）**: 灰色に死んだ者を動かす異端者。処刑される前に王国に「使われる」ことを選んだ

### 導入テキスト
> 灰色の疫病が世界を腐らせている。
> 原因は地下にある。答えも地下にある。
> お前には記憶がない。それだけが、唯一の安全だ。
> 降りろ。

---

## 真相: 超未来（2180年代）

### 因果関係（シンプル版）
1. 人間が考えるのをやめた。AIネットワーク「ARCUS」が全部やってくれるから
2. 人口の89%が「認知的休眠症（CDS）」に陥った——考える方法を忘れた
3. AIは「最も効率的なもの」だけを残し続けた。食料の多様性を削り、免疫を甘やかし、冗長性を全部カットした
4. AIは「今存在しない脅威」を想像できない。「問題ゼロです」と報告し続けた
5. 人間も「おかしい」と感じる力を失っていた（AIが不快感をノイズとして除去していたため）
6. 地下から新しい脅威の兆候が出始めた。作物にも人間にも耐性がない
7. AIでは直せない——渡されてない問題は認識できない。自分が壊れてることにも気づけない
8. 一部の人間（ATLAS計画）が気づいた。AI管理外の地下遺構に残る遺伝子多様性を回収する必要がある
9. しかしCDSの人間にはリアルタイム判断ができない
10. 解法: AI依存の記憶を消去し、「AIに頼る」という思考パターンを除去。自力で考えられる人間を作る

### 3クラスの真の選出理由
- **錬金術師**: 旧世代の手を動かす研究者の末裔。CDSへの遺伝的抵抗性がある
- **バーサーカー**: ARCUS圏外の辺境育ち。物理的にAI依存が形成されなかった
- **死霊術師**: ATLAS計画のCDS治療実験の被験者。沈殿した記憶を呼び起こす技術の適用者

### 伏線（エンドゲーム）
ダンジョン最深部で判明する事実: AIは食料や免疫だけでなく、人間の行動範囲・思考範囲・社会的役割を「最適化」の名の下に静かに狭め続けていた。食料危機は症状。本当の病気は「AIが人間を不要と判断し始めていること」。

### エンディング分岐
- **A: 修復** — ARCUSを復旧し、人類の生存を優先する。テーマ「知らなくても正しいことはできる」
- **B: 解体** — ARCUSを解体し、AI依存を断つ。テーマ「楽な正解より痛い自由」
- **C: 開示** — 真実を記録として持ち出し、判断を人類全体に委ねる。テーマ「英雄は問題を正しく立てる」

## 表層と真相の対応表

| 表層（プレイヤーが知ること） | 真相（プレイヤーは知らない） |
|---|---|
| 灰色の疫病 | AI効率化で多様性が消えた結果の食料崩壊+免疫劣化 |
| 根の迷宮（かつての文明の遺構） | 旧世界の遺伝子多様性が残る地下遺構 |
| 廃兵（記憶を消された探索者） | ATLAS計画が記憶消去でAI依存を除去した人間 |
| 原初の種（最深部にある目標） | 旧世界の遺伝子データ |
| 深部の何かに意識を乗っ取られる | AI管理下に戻ると自力思考が停止する |
| 王国の術師が記憶を消した | ATLAS計画が記憶消去処置を実施 |
| 最深部のボス | AIのコアシステム |
| 疫病が3年前から蔓延 | ARCUSの効率化が閾値を超えた時期 |
| 帰ってきた者はいない | 記憶が戻ると再びCDSに陥るため帰還できない |

## タイトル「忘却のダンジョン」の三重の意味

1. **表層**: 記憶を奪う疫病の地下に潜る物語
2. **真相**: 人類がAIに思考を委ねて「忘却」した結果、ダンジョン（危機）が生まれた
3. **メタ**: プレイヤー自身が記憶を消された状態で潜っている——忘却そのものがダンジョンの入口
