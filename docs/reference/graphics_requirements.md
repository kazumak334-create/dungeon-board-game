# グラフィック必要箇所 画面別整理

## 共通前提
全画面がGDScriptのColorRect+Label+Button構成のプレースホルダー。テクスチャ・アニメーション・SEは一切未実装。

---

## 1. クラス選択画面（Title.tscn）

### テクスチャ
| 対象 | 内容 | サイズ目安 |
|------|------|----------|
| クラスイラスト（3種） | スライム錬金術師・バーサーカー・死霊術師 | 260×160px |
| 背景 | ダンジョン入口イメージ | 1280×720px |
| タイトルロゴ | ゲームタイトル | 800×80px |
| 選択枠グロー | ハイライト枠 | 9スライス |

### アニメーション
- クラス選択時：scale 1.0→1.05、0.15s
- 出発ボタン：フェードアウト→バトル画面

### エフェクト
- 選択クラス背景パーティクル（スライム：緑泡、バーサーカー：炎、死霊術師：骸骨の影）

### SE/BGM
- BGM：タイトル（ループ、重厚ダンジョン系）
- SE：クラス選択クリック、出発ボタン押下

### 優先度
- Phase 2必須：クラスイラスト3種
- Phase 3：背景・パーティクル

## 3. バトル画面（Main.tscn）★最詳細

### 3-1. ユニットセル内
| 要素 | 現在 | 必要なグラフィック |
|------|------|-----------------|
| ユニット本体 | テキスト名 | **ユニットイラスト（48×48px）** ★最優先 |
| HPバー | ColorRect（緑/黄/赤） | テクスチャ付きHPバー枠 |
| バフアイコン | テキスト（「ATK+2」） | **バフアイコン（16×16px 6種）** |
| デバフアイコン | テキスト（「火2」） | **デバフアイコン（16×16px 4種）** |
| チャージ | セル背景色変化 | チャージゲージまたはグロー枠 |
| スキル発動 | オレンジフラッシュ | スキル発動パーティクル |
| 盤面効果 | セル背景色lerp | 床テクスチャ半透明レイヤー |

### 3-2. 攻撃アニメーション
| 種別 | 必要なグラフィック |
|------|-----------------|
| 近接攻撃 | 斬撃/パンチ線エフェクト＋揺れ |
| 遠距離攻撃 | 矢/弾丸飛翔オブジェクト |
| 命中 | ヒットスパーク（白フラッシュ） |
| 貫通 | 後方セルへの波及エフェクト |

### 3-3. ダメージ/回復フロート
- ダメージ：数字専用フォント、赤（実装済みLabel）
- 回復：緑フロート（実装済み）
- クリティカル：大赤文字（未実装）
- 毒ダメージ：紫文字（未実装）

### 3-4. 死亡/復活
- 死亡：崩れ落ちアニメ or 消滅パーティクル
- 復活：光エフェクト

### 3-5. カードキューUI
| 要素 | 現在 | 必要 |
|------|------|------|
| カードパネル | ColorRectベース | イラストエリアをTexture化 |
| マナゲージ | 青→黄ColorRect | マナ水晶アイコン＋枠テクスチャ |

### 3-6. キャラクターパネル

## Phase 2最優先グラフィック（TOP 5）

1. **ユニットイラスト 48×48px** — バトル画面の視認性が根本改善
2. **バフ/デバフ/スキルアイコン 16×16px（25種）** — テキスト→視覚への移行
3. **クラス選択イラスト 3種** — 第一印象
4. **攻撃ヒット・召喚・スキル発動SE** — 配信映え基準で音なしは致命的
5. **VICTORY/DEFEAT入場アニメ** — リザルトの達成感

## テクスチャ差し込み方針
TextureRect（`res://textures/units/xxxx.png`）形式。アニメーションはGodot Tweenで実装可能。アセット調達が先決。
