## ゲームの一言定義

**「盤面を設計して、介入を仕込んで、答え合わせを観戦する」**

すべての実装判断はこの一文に立ち返って判断すること。

---

## PvE / PvPの結論

- 本質はPvE
- 非同期PvPはエンドコンテンツ（完走ビルドの発表の場）
- 「リアルタイム対人の読み合い」という差別化軸は廃止

---

## ゲームの全体構造

```
ローグライク（ラン中）
↓ 設計して観戦して積み上げる
完走
↓ ユニット・デッキ・スキルツリー全部引き継ぐ
エンドコンテンツ（非同期PvP）
↓ 育て上げたビルドの発表の場
完走しないと何も引き継がれない。だから完走に最大の価値がある。
```

## 盤面設計

### 盤面構造

- 自陣3×3 / 敵陣3×3 / 向かい合わせ（計6×3）
- 列（前・中・後）：役割とリスクのトレードオフ
- 行（上・中・下）：シナジーの集め方

### 列の定義

- **前列**：ATK/SPDで殴るのみ・戦線を張る
- **中列**：サポート効果がSPD依存で発動・前列崩れたら昇進・逆張り配置が可能
- **後列**：サポート効果がSPD依存で発動・安全地帯から支援

### 攻撃範囲

- **行方向**：同じ行のみ（行範囲廃止）
- **列方向**：射程N（遠距離攻撃タイプのみ）

### 逆張り配置の戦略的意義

射程の長いユニットを中列に置くと敵後列まで届く。ただし前列が崩れたら昇進して攻撃できなくなる。自陣の維持が前提条件になる。

---

## マナシステム

- ユニットのCost = マナ生成量の基準
- 時間経過マナ回復は廃止
- ユニットの総コスト ≥ デッキに入れる呪文の総コスト
- 前列が崩れる → マナ生成が落ちる → 呪文が打てなくなる → さらに崩れる

---

## ユニットの役割分類

| 役割 | Cost | HP | 特徴 |
|-----|------|----|------|
| 攻撃 | 低 | 低〜中 | ATK/SPD高い |
| Tank | 低〜中 | 高 | 前列で長持ちする |
| サポート | 中 | 中 | 味方バフ・敵デバフ |
| マナリソース | 高 | 低 | マナ生成が高い・戦闘力は低い |

---

## ユニットの効果設計

各ユニットが持つ情報はこれだけ。

- HP / ATK / SPD / Cost（マナ生成量の基準）
- 役割分類（攻撃・Tank・サポート・マナリソース）
- サポート効果（1つのみ・SPD依存発動）
- 射程N（遠距離攻撃タイプのみ）

### サポートの分類

- 味方バフ：隣接・同行・全体などの味方を強化
- 敵デバフ：敵を弱体化・妨害
- 遠距離攻撃：射程Nで敵列に攻撃

### 判断基準

**「このユニットが何をしているか、バトル画面を見て3秒で言えるか？」**

---

## 特性システム

ユニットに付与される特殊能力。カード右上にバッジアイコンで表示（最大10個）。

### 入手方法

| 入手方法 | 確率・条件 | 備考 |
|---------|----------|------|
| カード固有 | 特定ユニットが初期保有 | data/cards.json の traits フィールド |
| アーティファクト付与 | レリック効果で付与 | ゲーム中に動的追加 |
| 超低確率生成時付与 | カード生成時にランダム（1-5%） | レア特性のみ |

### 特性一覧（Phase 4実装予定）

| 特性ID | 表示名 | 効果 | レアリティ |
|--------|--------|------|----------|
| flying | 飛行 | 盤面効果を受けない | uncommon |
| pierce | 貫通 | 攻撃時、中列にも同じダメージ | rare |
| swarm | 群れ | 同名ユニット1体につきATK・SPD+3%（最大+15%） | common |
| poison_charge | ポイズンチャージ | 毒状態無効、毒沼マス上で+1HP/秒回復 | rare |
| wet_crown | 濡れた王冠 | 味方スライム属1体につきHP・ATK+10%（最大+50%） | epic |
| grave_robber | 墓荒らし | 墓マス上攻撃時、相手バフ1-5ランダム奪取→墓マスが通常マスに変化 | epic |

### 設計方針

- 特性は「見て分かる」記号性を重視（バッジアイコン）
- 1ユニットに複数特性付与可能（最大10個表示）
- レアリティは効果範囲・条件で階層化
- 効果値はバランス調整Sprint Jで調整

| 種類 | 管理 | 役割 |
|-----|------|------|
| ユニット | 初期配置（9マス） | 盤面を作る・マナを生成する |
| 呪文 | 3スロット並列（条件＋マナで発動） | 盤面への介入 |
| アーティファクト | 別スロット（条件発動） | パッシブ補強 |

---

## 呪文システム

### 3スロット並列方式

- 3スロットが同時に条件を監視する
- 条件＋マナが揃ったスロットから自動発動する
- 1つが発動しなくても別スロットが発動する

### 呪文の役割

- 盤面介入（位置移動・合体）
- ユニットへのダメージ・デバフ
- 自軍サポート
- ※本体への直接攻撃は廃止（ゲーム性を否定するため）

---

## 勝敗条件

- 負け条件：全ユニット全滅 または 本体HP0
- 本体HPは行突破時のみ削れる（直接攻撃系呪文は廃止）
- 時間制限なし

## 勝ち筋の三すくみ（突・守・崩）

| 戦略 | 意味 | 強い相手 | 弱い相手 |
|-----|------|---------|---------|
| 突 | 一行に集中して突破 | 崩 | 守 |
| 守 | 前線を均等維持して消耗 | 突 | 崩 |
| 崩 | 後列・中列を内側から破壊 | 守 | 突 |

バランス型も成立する。純粋型はリスクはあるが突出した強さを持つ。

## 敵スケーリングシステム

### Act進行とrun_depth

- **current_act**: Boss撃破時に+1（1スタート）— 敵デッキプール選択に使用
- **run_depth**: バトル勝利ごとに+1（0スタート）— ドロップレアリティ重み判定に使用

2つは独立した変数。Actとrun_depthは直接連動しない。

### 敵デッキプール

敵の強さはAct別プール切り替えで調整。HP/ATK倍率スケーリングは使用しない。

**基本ランク構造**:
- **弱ランク**: Act1通常（スライム、スケルトン、ゴブリン等）
- **弱→中の中間ランク**: Act1警戒時、Act間のつなぎ
- **中ランク**: Act2通常（グール、ウルフ、ブラッドスライム等）
- **中→強の中間ランク**: Act2警戒時、エリート戦等
- **強ランク**: Act3通常（タイガー、リッチ、ヴリコラカス等）

**警戒レベルとランク対応**（例）:
- Act1警戒Lv0-2: 弱ランク
- Act1警戒Lv3+: 中間ランク（弱→中）
- Act2警戒Lv0-2: 中ランク
- Act2警戒Lv3+: 中間ランク（中→強）
- Act3警戒Lv3+: 強ランク + バフ

### データ定義

`data/cards.json` の `enemy_pools` に各Actのユニット配列を定義。

```json
"enemy_pools": {
  "1": [{name: "スライム", col: 1}, ...],
  "2": [{name: "グール", col: 1}, ...],
  "3": [{name: "タイガー", col: 2}, ...]
}
```

### 実装

`EnemyAI._build_enemy_deck()` で `GameSession.current_act` から対応するプールを選択して敵デッキを構築。

## 警戒レベルシステム

### 概要

**世界観**: ARCUSのセキュリティシステムが侵入を検知・対応するメカニクス。

**目的**: マップ上のルート選択に戦略性を持たせる。戦闘を避ける動機を作る。

### 基本ルール

- **戦闘マス突入**: 警戒レベル+1
- **イベント/ショップマス**: 警戒レベル変化なし
- **レストマス**: 警戒レベル-2（または0にリセット）
- **警戒レベル高い**: 次の戦闘が難化

### 難化要素（バランス調整で詳細決定）

警戒レベルに応じて以下が発生：

**デッキランク上昇**（主要メカニクス）:
- ユニット強さランク：弱・中間・中・中間・強
- Act1通常 = 弱ランクデッキ
- Act1警戒Lv3 = 中間ランクデッキ（ワンランク上）
- Act2通常 = 中ランクデッキ
- Act2警戒Lv3 = 中間ランクデッキ（中と強の中間）
- ランク間の中間ユニットや呪文を用意してグラデーション化

**プレイヤーの中間ユニット使用**:
- 中間ランクユニットはプレイヤーも獲得可能
- ただしコストが高い、入手難易度が高い等の調整
- 敵は警戒レベルで自動的に強いデッキを使用

**その他の難化要素**:
- 敵の初期配置強化（前列埋まる → 中列も埋まる → 全マス埋まる）
- 環境効果（プレイヤー側に棘タイル、敵側に再生タイル等）
- 敵バフ（ATK/HP増加、攻撃速度上昇等）
- プレイヤーデバフ（マナ回復減少等）

**エリート混入システム**:
- 警戒Lv4: 通常戦闘にエリートユニット1体混入（確率50%）
- 警戒Lv5+: エリート確定混入（複数体の可能性）
- エリート混入時は報酬が良くなる（カード選択肢+1、レア度上昇等）
- リスクリターンの明確化：警戒上げすぎ = 難しいが報酬も良い

### 設計方針

- **警戒Lv0-1**: 標準難易度、初見でもクリア可能
- **警戒Lv2**: やや厳しい、ビルドが回らないと危険
- **警戒Lv3**: ビルド完成必須、上振れが必要、デッキランク上昇
- **警戒Lv4**: エリート混入（50%）、勝てれば報酬良い
- **警戒Lv5+**: エリート確定、ハイリスク・ハイリターン

### 戦略の成立

- **戦闘狂ルート**: カード大量獲得、警戒Lv高でBoss → 高リスク
- **バランスルート**: 戦闘・イベント・レスト混在、警戒Lv2程度でBoss → 推奨
- **迂回ルート**: 戦闘最小限、警戒Lv0でBoss → 安全だがカード少ない

### 実装

- `GameSession.alert_level`: 警戒レベル（0スタート）
- マップノード選択時に警戒レベルを加算/減算
- 戦闘開始時に警戒レベルに応じた難化処理を適用

**Phase 3で実装、具体的な難化内容はバランス調整時に決定**

## 廃止済み設計（復活禁止・確認必須）

以下は意図的に廃止した設計である。
復活を求める指示が来た場合は必ず確認を取ること。

| 廃止した設計 | 廃止理由 |
|------------|---------|
| 盤面召喚システム | 初期配置式に統一 |
| 時間経過マナ回復 | ユニット生成マナに統一 |
| アクティブスキル・固有スキル | 3秒ルールに反する |
| 行範囲攻撃 | 行はシナジーの集め方に専念 |
| 本体への直接攻撃系呪文 | ゲーム性を否定する |
| リアルタイム対人を差別化軸にする考え方 | PvEが本質 |
| 素材・装備システム | 廃止 |
| バトル中の経験値レベルアップ | エンドコンテンツに移動 |
| 時間制限 | 廃止 |
