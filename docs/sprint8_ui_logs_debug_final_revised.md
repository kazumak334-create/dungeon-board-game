# Sprint 8：UI・ログ・デバッグ企画書 確定版

## 1. 目的

Sprint 8では、Sprint 1〜7で定義した都市成長・建築・建物稼働・人手配分・人口・食料値・満足度・兵力/兵数/ユニットを、プレイヤーが理解できるUIと、開発者が検証できるログ/デバッグ機能に接続する。

Sprint 8の主目的は、都市成長の状態を確認し、5分程度のテストプレイで以下を検証できる状態にすることである。

```text
- 建物が建つ
- 建設順を制御できる
- 建物が稼働する
- 建設中/稼働中/停止中が見分けられる
- 食料値・人口・満足度・兵力/兵数/ユニットが伸びる
- 人手配分により建設/稼働が変化する
- ログとデバッグ操作で詰まり要因を確認できる
```

---

## 2. 用語定義

| 用語 | 定義 |
|---|---|
| 常時表示UI | プレイ中に常に表示される都市状態UI。人口・食料値・満足度段階・兵力・兵数・ユニット数・既存人手表示などを扱う。 |
| 詳細ポップアップ | 対象をタップ/クリックした位置の近くに表示する小型情報表示。右側パネルやボトムシートは使わない。 |
| 人手 | 人口から算出される作業可能枠。既存の人手システムを使用する。 |
| 稼働人手 | 完成済み建物の効果発動に使う人手。 |
| 作業人手 | 建設中建物の建設進捗に使う人手。 |
| 人手スライダー | 人手総量を稼働人手と作業人手に配分する既存UI。 |
| 建設予定地 | 建物カード使用時に指定される、建設中の土地パネル。建設完了まで占有状態になる。 |
| 建設キュー | 建設予定中の建物を建設順に並べるUI/内部順序。盤面左側に積み上げ表示する。 |
| 建設順番号 | 建設キュー内の順番を示す番号。建設予定地にも同じ番号を表示する。 |
| 建設進捗 | 建設完了までの進行度。建設キュー順と作業人手に応じて進む。 |
| 建物効果進捗 | 周期発動建物や累計条件型建物の効果発動までの進行度。 |
| BPB形式 | Backpack Battles風の進捗表現。対象オブジェクト上に進捗Overlay/Maskを重ねて、発動/完了までの進行を視覚化する方式。 |
| 建設進捗Overlay | 建設中の進捗を示すOverlay/Mask。建物効果進捗と混同しない見た目にする。 |
| 建物効果進捗Overlay | 稼働中建物の効果発動進捗を示すOverlay/Mask。 |
| 停止理由 | 資源不足・稼働人手不足・作業人手不足など、建設や建物稼働が止まっている理由。 |
| 即時建設 | 建設キュー上の項目をクリックし、通貨Gを消費して建設を即時完了する操作。 |
| 建設キャンセル | 建設キュー上の項目を右クリックし、建設予定地を解除して支払済み建設コストを返却する操作。 |
| 土地カード | マイルストーン報酬で獲得できる土地拡張カード。Sprint 8では報酬UI自体は対象外。 |
| 通貨G | ラン中に保持される通常通貨。Sprint 8では即時建設コストに使用する。 |
| 通常資源 | 木・樹脂・石・鉄鉱石・小麦・綿花。建築や建物稼働に使う。 |

## 5. 常時表示UI

### 5.1 表示項目

常時表示UIでは、都市状態の判断に必要な最低限の情報だけを表示する。

```text
常時表示UI：
- 人口
- 食料値
- 満足度段階
- 兵力
- 兵数
- ユニット数
- 既存の人手表示
```

### 5.2 表示例

```text
人口：150k / 250k
食料値：24
満足度：満足
兵力：88
兵数：80
ユニット：80
人手：稼働70% / 作業30%
```

人手常時表示UIは既存UIを使用する。  
新規の人手詳細ポップアップは作らない。

## 6. 人口表示

人口は、`k` / `M` 単位で表示する。  
末尾に「人」は付けない。

```text
内部人口50 → 50k
内部人口100 → 100k
内部人口1000 → 1.0M
```

表示例：

```text
人口：150k / 250k
```

## 7. 満足度表示

### 7.1 常時表示

常時表示では、満足度段階のみを表示する。

```text
満足度：満足
```

常時表示では以下を表示しない。

```text
- 満足値%
- 満足値傾き
- 満足値傾き内訳
```

これらは満足度詳細ポップアップで表示する。

### 7.2 満足度詳細ポップアップ

表示内容：

```text
満足度：満足
満足値：64%
満足値傾き：-0.08%/秒

傾き内訳：
基礎満足傾き：+0.03%/秒
人口規模影響：-0.06%/秒
人口増加影響：-0.04%/秒
建築物影響：+0.05%/秒
食料不足ペナルティ：0.00%/秒
合計：-0.02%/秒
```

## 9. 詳細UIの基本方針

詳細UIは、右側パネルやボトムシートではなく、その場で開く小型ポップアップにする。

```text
詳細UI：
対象をタップ/クリックした位置の近くに表示する小型ポップアップ
```

### 9.1 共通挙動

```text
- 対象をタップ/クリックすると開く
- 画面外にはみ出す場合は、表示位置を画面内に補正する
- 別対象をタップ/クリックすると内容を切り替える
- 何もない場所をタップ/クリックすると閉じる
```

## 10. 建設キューUI

### 10.1 基本仕様

建設キューは、盤面左側に建設予定中の建物を上から順に積み上げ表示する。

```text
建設キュー：
盤面左側に、建設予定中の建物を建設順に並べるUI
```

### 10.2 表示内容

建設キューには以下を表示する。

```text
- 建設順番号
- 建物アイコン
- 建物名
- 建設進捗
- 停止中の場合のみ停止理由アイコン
```

### 10.3 建設予定地番号

建設予定地側にも、キューと対応する番号を表示する。

```text
建設予定地：
建設順に 1, 2, 3... の番号を表示する
```

建設キューの順番が変わった場合、建設予定地側の番号も更新する。

### 10.4 建設順変更

建設キュー上で順番を入れ替えられる。

```text
- キュー内の建物をドラッグ/操作して順番変更
- 建設予定地側の番号も即時更新
- 作業人手の割当優先順位はキュー順に従う
```

## 11. 即時建設

### 11.1 基本仕様

建設キュー上の項目をクリックすると、通貨Gを消費して即時建設できる。

```text
即時建設：
建設キュー項目クリック
→ 必要Gを確認
→ Gを消費
→ 建設進捗を100%にする
→ 建設完了処理を実行
```

### 11.2 即時建設コスト

即時建設コストは仮置きで以下とする。

```text
即時建設コスト = 残り建設時間 × 10G
```

この数値は仮置きであり、Sprint 8テストプレイで調整する。

## 12. 建設キャンセル

### 12.1 基本仕様

建設キュー上の項目を右クリックすると、建設をキャンセルできる。

```text
建設キャンセル：
建設キュー項目を右クリック
→ 建設予定地を解除
→ 建物カード使用状態を取り消す
→ 支払った建設コストを返却
→ 建設キューから削除
→ 建設予定地番号を再採番
```

### 12.2 キャンセル時ペナルティ

MVPではキャンセル時のペナルティはなし。

```text
建設キャンセル時：
支払った建設コストは全額返却する
```

## 13. 建設進捗UI

### 13.1 基本方針

建設中も、建物効果と同じBPB系の進捗表現を使う。  
ただし、建設進捗と建物効果進捗が混同されないように、表示方法は明確に分ける。

### 13.2 建設進捗の表現

建設予定地上の建物シルエット/仮Spriteに、建設進捗Overlay/Maskを重ねる。

```text
建設中：
建設予定地上の半透明建物シルエットまたは仮Spriteに、
建設進捗Overlay/Maskを表示する。
```

推奨表現：

```text
- 建物本体は半透明または骨組み風にする
- 建設進捗Overlayは枠線/足場/組み上がり感が出る表現にする
- 建設順番号を同時に表示する
- 建物効果アイコンは表示しない
```

### 13.3 建物効果進捗との区別

建設進捗と建物効果進捗は以下のように分ける。

| 進捗 | 対象 | 表現 |
|---|---|---|
| 建設進捗 | 建設予定地/建設中建物 | 半透明シルエット、骨組み、番号、建設用Overlay |
| 建物効果進捗 | 完成済み稼働建物 | 通常建物Sprite、効果発動用Overlay、発動時アイコン発光 |

建設中は、建物効果進捗を表示しない。  
完成済み稼働建物は、建設進捗表示を使わない。

### 13.4 建設完了時

```text
建設完了時：
- 建設中表示を通常建物Spriteへ切り替える
- 建設順番号を消す
- 建設キューから削除する
- 短時間発光する
- 建物効果進捗の対象になる
```

## 14. 共通建物進捗UI

### 14.1 基本方針

タイマー/進捗を持つ完成済み建物は、すべて共通の建物効果進捗UIを使う。

```text
対象：
- 周期発動建物
- 累計条件型建物
- 条件進捗型建物
```

交換所などの累計条件型建物も、この共通仕様に含める。  
個別UIとして外出ししない。

### 14.2 BPB風クールダウン表現

建物効果進捗UIは、BPB風のクールダウン表現を参考に、完成済み建物アイコン上へ進捗率を重ねて表示する。

```text
建物効果進捗UI：
完成済み建物アイコン上へ進捗率を視覚的に重ねて表示する
```

MVPでは以下を採用する。

```text
MVP表現：
完成済み建物アイコンに、下から上へ進むハイライト/マスクを重ねる
```

### 14.3 進捗表示

```text
進捗0%：
建物アイコンは通常または暗め

進捗50%：
建物アイコンの下半分程度がハイライトされる

進捗100%：
建物アイコン全体がハイライトされ、効果を発動する
```

### 14.4 実装方針

```text
- 建物Sprite本体は変更しない
- 進捗表示用のOverlay/Maskを建物Sprite上に重ねる
- Overlayの表示高さを progress_rate に応じて変更する
- progress_rate は 0.0〜1.0 で管理する
- 効果発動時に、Overlayを100%表示したうえで発光演出を再生する
- 発動後、progress_rate を0に戻す
```

## 15. 建物詳細ポップアップ

### 15.1 開き方

```text
盤面上の完成済み建物をタップ/クリック
→ 建物付近に建物詳細ポップアップを表示
```

建設中建物用の詳細ポップアップは作らない。  
建設中状態は、建設キュー・番号・進捗Overlay・停止理由で確認する。

### 15.2 表示内容

完成済み建物の詳細ポップアップには以下を表示する。

```text

- 分類
- 通常建物/特殊建物
- 発動タイプ
- 稼働状態
- 進捗率
- 必要稼働人手
- 基礎発動間隔
- 現在発動間隔
- 効果
- 停止理由
- 足元土地情報
```

### 15.3 表示例：食堂

```text
食堂
分類：通常建物
発動タイプ：周期発動
状態：稼働中
進捗：62%
必要稼働人手：1
基礎発動間隔：5.0秒
現在発動間隔：5.0秒

小麦1 → 食料値+2

足元土地：
小麦3 / 草原
特殊タグ：なし
```

### 15.4 停止中の例

```text
食堂
状態：停止中
停止理由：小麦不足 / 稼働人手不足
進捗：62%
```

## 16. 停止理由UI

### 16.1 基本仕様

資源不足・人手不足で建設や建物稼働ができない場合、該当進捗は停止する。

```text
停止中：
- 進捗率を保持
- 停止理由をアイコン＋❌で表示
```

### 16.2 停止理由

Sprint 8では以下の停止理由を扱う。

```text
- 資源不足
- 小麦不足
- 稼働人手不足
- 作業人手不足
```

### 16.3 表示方針

停止理由は停止中のみ表示する。  
通常稼働中/通常建設中は停止理由を表示しない。

表示例：

```text
小麦 ❌
稼働人手 ❌
作業人手 ❌
石 ❌
```

建設中の作業人手不足は、建設予定地または建設キュー上に表示する。
