# RestScreen UI/UX企画書

## 1. 画面の目的

- BW（大Wave）間の休憩フェーズで、プレイヤーが次のBWに向けた戦略調整を行う
- 具体的な判断: デッキ編成変更 / ショップ購入 / HP=0ユニットの復帰 / 合成
- **バトル画面内のオーバーレイ/モード切替として表示**（画面遷移なし）
- 「次へ進む」でBW開始、スキップも可能

### 視線の流れ

1. **ヘッダー**: 現在のWave状況・所持ゴールドを確認（状況認識）
2. **自陣盤面**: 現在のデッキ配置を確認・編集（メイン操作）
3. **手持ちカード**: 未配置カード・HP=0カードの状態確認（リソース把握）
4. **敵陣盤面（ショップ）**: 購入可能な商品を確認（投資判断）
5. **右パネル**: 選択したカードの詳細・合成情報を確認（情報深掘り）
6. **「次へ進む」**: 準備完了で次BWへ

視線は **左上→左下→右上→右→右上ボタン** のZ型フロー。

## 5. インタラクション

### 5-1. デッキ編集（ドラッグ&ドロップ）

| 操作 | 挙動 |
|------|------|
| 手持ちカードをドラッグ | カードがカーソルに追従。配置可能セルにCOLOR_GLOWハイライト |
| 盤面セルにドロップ | 配置確定。セルにカード表示。手持ちから除去 |
| 盤面カードをドラッグ | 入れ替えモード。他セルにドロップで入れ替え |
| 盤面カードを手持ちにドラッグ | 配置解除。手持ちに戻る |
| HP=0カードをドラッグ | 不可（ドラッグ開始しない） |

### 5-2. ショップ購入（クリック）

| 操作 | 挙動 |
|------|------|
| 商品セルをホバー | COLOR_BTN_HOVER枠線。右パネルに商品詳細表示 |
| 商品セルをクリック | 購入確認不要で即購入（ゴールド減算、手持ちに追加） |
| 購入不可時クリック | 何も起きない（セルがCOLOR_UNAFFORDABLE色で視覚的に購入不可を示す） |
| リロールボタンクリック | 5G消費、ショップ商品を再抽選 |

### 5-3. ユニット復帰（手持ちカード内）

| 操作 | 挙動 |
|------|------|
| HP=0カードの復帰ボタンをクリック | ゴールド消費 → HP全回復 → 通常表示に戻る |
| ゴールド不足時 | 復帰ボタンがCOLOR_DIM（押下不可） |
| 復帰成功 | 短いフラッシュ演出(0.3秒、COLOR_PICKED) → 配置可能に |

### 5-4. 合成（カード選択→候補→実行）

| 操作 | 挙動 |
|------|------|
| 手持ちカードをクリック | 右パネルにカード詳細 + 合成候補表示 |
| 合成候補をクリック | 右パネルに合成ツリーフロート表示（素材→結果） |
| 合成実行ボタン | 素材カード消費 → 結果カードが手持ちに追加 → フロート閉じる |
| 素材不足 | 合成候補がCOLOR_DIM表示（クリック不可） |

### 5-5. ホバー（カード詳細表示）

| 操作 | 挙動 |
|------|------|
| 盤面セルにホバー | 右パネルにユニット詳細（ステータス・効果・特性） |
| 手持ちカードにホバー | 同上 |
| ショップ商品にホバー | 同上（+価格表示） |
| 何もない場所にホバー | 右パネルがガイドテキストに戻る |

### 5-6. 画面遷移

| 操作 | 挙動 |
|------|------|
| 「次のWaveへ」クリック | RestScreenオーバーレイを閉じる → 次BW開始（マナリセット） |
| 「スキップ」クリック | 同上（即座に次BW開始） |
| BW終了 → RestScreen表示 | 0.5秒フェードインでRestScreenモードに切替 |
| RestScreen → BW開始 | 0.3秒フェードアウトでバトルモードに切替 |

## 7. UI基準チェック

### 1. 3秒ルール: この画面で何ができるか3秒で分かるか

**合格**。画面は3領域に明確に分離されている。
- 左=自分の盤面（デッキ編集）
- 右上=ショップ（敵盤面の転用で視覚的に自然）
- 下=手持ちカード（リソース一覧）

「次のWaveへ」ボタンが右上に常に見えるため、目的（準備→進行）も即座に伝わる。注意点として、合成UIは深い操作になるため、初回のみツールチップで「カードを選択すると合成候補が表示されます」を出す。

### 2. 視線の一本化: 複数の注意点がないか、視線の流れは明確か

**合格**。視線はZ型フロー（左上→右上→左下→右下）で自然。右パネルは「選択したものの詳細」に一貫しており、タブ切替がないため注意が分散しない。敵盤面→ショップの転用は、バトル中と同じ位置関係を維持するため認知負荷が低い。

### 3. 状態の可視化: 現在の状態が一目で分かるか

**合格**。
- 配置済みカード: COLOR_PICKED(緑)枠線
- HP=0カード: 半透明 + 復帰ボタン（赤系）
- ショップ購入可/不可: 枠線色で区別（緑/暗赤）
- 合成可能: 右パネルに候補表示（紫ハイライト）
- ゴールド不足: 復帰ボタン・商品がCOLOR_DIM

### 4. 操作の最小化: クリック数は最小か、直感的か

**合格**。
- デッキ編集: 1ドラッグ（DeckPrepと同じ操作感）
- ショップ購入: 1クリック（確認ダイアログなし）
- ユニット復帰: 1クリック（復帰ボタン）
- 合成: 2クリック（カード選択→候補選択→実行で3クリックだが、合成は重い判断なので許容）
- 次へ進む: 1クリック

### 5. 配信映え: 視聴者が見ても何をしているか分かるか

**合格**。バトル画面の盤面構造をそのまま使うため、視聴者はバトル中の盤面と同じレイアウトで「準備中」と認識できる。ショップが敵盤面の位置にあるのは直感的（敵がいた場所に商品が並ぶ）。手持ちカードのHP=0の半透明表示は「やられたユニット」が一目で分かる。

### 6. 世界観の匂わせ: ダークファンタジー+無機質な整合性があるか

**合格**。
- 色彩: UIColors.gdの暗紺/灰系統をそのまま使用。新規色も彩度を抑えた暗色。
- テキスト: 最小限。装飾的な説明文なし。
- 構造: 盤面がただそこにある。ショップの演出も無機質（商品が並んでいるだけ）。
- 復帰ボタン: 「復帰 30G」とだけ表示。理由の説明なし。

## 9. 実装上の注意点

- **Main.gdの拡張として実装**: 新規シーンファイルは作らない。Main.gdにRestScreenモードフラグを追加し、盤面の表示内容を切り替える
- **右パネル表示/非表示**: バトル中は非表示、RestScreen時にのみ表示。アニメーション不要（即時表示/非表示）
- **盤面セルの再利用**: Main.gdのcell_rects/cell_labelsをそのまま使用。RestScreen時は自陣セルがD&D対応、敵陣セルがショップ表示に変わる
- **DeckPrepBoard.gdのロジック再利用**: D&Dロジック、カード表示ロジック、ハイライト処理はDeckPrepBoard.gdから移植または共通化
- **手持ちカードエリア**: DeckPrepBoard.gdのHAND_AREA系定数を参考に、Main.gd内に新規描画
