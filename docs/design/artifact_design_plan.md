# アーティファクト設計企画書

作成日: 2026-04-13  
更新日: 2026-04-13（干渉ポイント拡張）

## 基本方針

**スキルとの完全な棲み分け:**
- **スキル** = プレイヤー全体・システム全体に影響
- **アーティファクト** = ユニット・呪文を個別で強化

## アーティファクトの干渉ポイント

| カテゴリ | 説明 | 例 |
|---------|------|-----|
| 特性付与 | ユニットに特性追加 | ユニット1体に「飛行」付与 |
| スキル強化 | ユニットの前列能力・サポート効果を変更/追加 | 「攻撃時HP吸収+5」追加 |
| 合成促進 | 合成ツリーを1段階進める | スライム→マッドスライムに自動進化 |
| 基礎値上昇 | HP/ATK/SPD/Cost変更 | ユニット1体HP+10 |
| 呪文強化 | 呪文のコスト・効果変更 | 呪文1枚マナコスト-1 |
| カード個別強化 | レアリティ・ステータス変更 | カード1枚レアリティ+1 |

## 干渉ポイント詳細

### 1. 特性付与（15種 / 30種）
- 単体付与（8種）: ユニット1体に特性1つ
- 複数付与（5種）: ユニット2体以上、または条件付き全体
- 全体付与（2種）: 全ユニットに特性付与

### 2. スキル強化（5種）
- **スキル追加**: 既存スキルに追加で新スキル付与
- **スキル強化**: 既存スキルの効果値増幅
- **スキル転写**: あるユニットのスキルを別ユニットにコピー

実装方法: ユニットのskills配列に新規エントリ追加、またはparams変更

### 3. 合成促進（4種）
- **1段階進化**: Common→Uncommon、Uncommon→Rare等
- **自動合成**: 同名ユニット2体を自動で合成

実装方法: synthesis配列参照し、対象ユニットを上位ユニットに置換

### 4. 基礎値上昇（2種）
- 種族全体バフのみ（個別は特性・スキル強化で代替）

### 5. 呪文強化（0種）
- Phase 4では呪文強化は見送り（ユニット強化に集中）

### 6. カード個別強化（2種）
- レアリティ昇華、ステータス+特性複合

## 実装優先度

Phase 4実装対象（30種）:
- Common 12種: 特性付与8 + スキル強化2 + 合成促進2
- Uncommon 10種: 特性付与5 + スキル強化2 + 合成促進1 + 基礎値上昇2
- Rare 6種: 特性付与2 + スキル強化1 + 合成促進1 + カード個別強化2
- Boss 2種: 超強力複合効果
