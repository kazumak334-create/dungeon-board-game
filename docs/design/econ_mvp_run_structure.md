# Econ MVP ランstructure 設計書

**作成日:** 2026-04-29
**ステータス:** 合意済み（未実装）
**対象:** Econ MVP（対AI）

---

## 1. 概要

1ランの全体構造を定義する。
1バトル単位の仕様は `docs/requirements/req_economy_mvp.md` を参照すること。本書はその上位構造（複数バトルのループ）を扱う。

**核となる体験：**
> 限られた資源の流し先を決める → その配分が戦況を作る快感／読み違えた悔しさ → 戦闘は「配分の答え合わせ」

---

## 2. ランの全体構造

```
戦闘1 → 準備フェーズ → 戦闘2 → 準備フェーズ → 戦闘3（中ボス）→ 準備フェーズ → 戦闘4 → 準備フェーズ → 戦闘5（ボス）→ Result
```

### 2.1 戦闘数・時間

| 項目 | 値 |
|------|-----|
| 全戦闘数 | 5戦 |
| 1バトルの目安時間 | 約5分 |
| 総ラン時間の目安 | 約40分（戦闘5戦 + 準備フェーズ4回） |

### 2.2 特殊戦闘

| 戦闘番号 | 種別 |
|---------|------|
| 戦闘1〜2 | 通常戦闘 |
| 戦闘3 | 中ボス戦 |
| 戦闘4 | 通常戦闘 |
| 戦闘5 | ボス戦 |

## 3. 戦闘フェーズ仕様

1バトルの詳細仕様は `docs/requirements/req_economy_mvp.md` §2 に準拠する。

### バトル中のプレイヤー操作範囲（抜粋・再掲）

| 操作 | バトル中の可否 |
|------|--------------|
| ユニット戦闘 | 完全自動（プレイヤー介入不可） |
| 資源配分スライダー | リアルタイムで調整可能 |
| 建物建設 | 手動で配置可能 |

---

## 4. 準備フェーズ仕様

各バトル後（Result前）に挿入される。ベンチマーク：Mechabellum。

### 4.1 構成要素

| 要素 | 内容 |
|------|------|
| カード選択 | 4択から1枚選択。建物強化・資源ボーナス・新建物解放など |
| Shop | 建物プランの購入・強化 |

### 4.2 強化の分類

| 種別 | 効果範囲 | 例 |
|------|---------|-----|
| 永続強化 | 以降の全戦闘に効く | 建物HP+10% |
| 単発投資 | 次の戦闘のみ | 次バトル開始資源+20 |

永続強化と単発投資は、プレイヤーが選択時に明示的に区別できるよう表示すること。

### 4.3 時間制限

90秒固定（Mechabellumに準拠）
