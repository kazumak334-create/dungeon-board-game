# InitialCardPick（初期カード選択）UI/UX企画書

## 1. 画面の目的

- ラン開始時に初期デッキ6枚を構築する
- 「3枚から1枚選ぶ」を6回繰り返す
- プレイヤーが「何を取るか・何を捨てるか」を楽しむ画面（ゲーム哲学 1-1 直結）

### カード3択の配置計算

- CardViewサイズ: 220x320
- 3枚等間隔配置（1280px幅）
- カード間の余白: (1280 - 220*3) / 4 = 155px
- Card1: x=155, y=130 (領域C内 y=30)
- Card2: x=530, y=130
- Card3: x=905, y=130

### 選択済みミニカード配置

- ミニカードサイズ: 60x86（CardViewの約0.27倍）
- 6枚等間隔配置
- 全体幅: 60*6 + 20*5 = 460px
- 開始X: (1280 - 460) / 2 = 410
- Y: 510（領域D内 y=10）

### 視線の流れ

上（進捗確認）→ 中央（3択比較）→ 下（選択済み確認）→ 中央に戻る（次の3択）

一本の縦線で完結する。左右の視線移動は3枚の比較時のみ。

## 5. インタラクション

### 5-1. カード選択フロー

1. **3枚表示**: カードが中央からフェードイン（0.3s, ease_out）
2. **ホバー**: カードがscale 1.0 → 1.05にTween（0.15s）、COLOR_GLOWのアウターグロー表示
3. **クリック（選択）**: 
   - 選択カードにCOLOR_SELECTED枠が点灯
   - 他2枚がopacity 0.4に暗転（0.2s）
   - 「確定」の意味でもう一度クリック、または自動で0.5s後に次へ進む
4. **確定**: 選択カードが下部のPickedSlotにTween移動（0.4s, ease_in_out）
5. **次の3択**: 新しい3枚がフェードイン

### 5-2. 状態表現

| 状態 | 表現 |
|------|------|
| ホバー中 | scale 1.05 + COLOR_GLOW |
| 選択中（クリック直後） | COLOR_SELECTED枠 3px + 他2枚暗転 |
| 選択済み（PickedSlot） | ミニカード表示（60x86） |
| 未選択スロット | COLOR_DIM点線枠 |
| 全6枚選択完了 | ConfirmButton出現 + 進捗ドット全点灯 |

### 5-3. カード選択の確定方式

**ダブルクリック方式**を採用:
1. 1回目クリック: カードを「仮選択」（枠点灯 + 他暗転）
2. 2回目クリック（同じカード）: 確定 → PickedSlotへ移動 → 次の3択
3. 別のカードをクリック: 仮選択が切り替わる（誤選択防止）

理由: 1クリック確定だと誤操作リスクが高い。ダブルクリックで「本当にこれ？」の確認を自然に入れる。

### 5-4. 画面遷移フロー

```
[タイトル/クラス選択] → [InitialCardPick] → [マップ画面]
                         ↑                    
                    6回ピック完了で遷移
```

1. 画面ロード時: ピック1回目の3枚を表示
2. ピック1〜5回目: 選択 → 次の3択
3. ピック6回目: 選択 → ConfirmButton表示
4. ConfirmButton押下 → マップ画面へ遷移（選択した6枚をGameSessionに保存）

### 5-5. アニメーション仕様

| アニメーション | Duration | Easing | トリガー |
|-------------|----------|--------|---------|
| カード出現 | 0.3s | ease_out | 新しい3択表示時 |
| ホバー拡大 | 0.15s | ease_out | マウスenter |
| ホバー縮小 | 0.15s | ease_in | マウスexit |
| 他カード暗転 | 0.2s | linear | 仮選択時 |
| PickedSlot移動 | 0.4s | ease_in_out | 確定時 |
| ConfirmButton出現 | 0.3s | ease_out | 6枚完了時 |
| 進捗ドット点灯 | 0.2s | linear | 確定時 |

## 8. UI基準チェック

### 1. 3秒ルール: PASS
- 画面中央に大きなカード3枚。上部に「PICK 3/6」。3秒で「3枚から1枚選ぶ、今3回目」と分かる。

### 2. 視線の一本化: PASS
- 縦一本の流れ: 進捗（上）→ 3択（中央）→ 選択済み（下）。横方向は3枚比較のみで自然。

### 3. 状態の可視化: PASS
- 仮選択: 金色枠 + 他暗転。選択済み: 下部にミニカード表示。進捗: ドット点灯。全状態が視覚的に即座に判別可能。

### 4. 操作の最小化: PASS
- ダブルクリックのみ。ドラッグ不要。1ピックあたり2クリック（仮選択+確定）。6ピック完了後に確定ボタン1クリック。合計13クリックで完了。

### 5. 配信映え: PASS
- カードが大きく表示される（220x320）。選択の瞬間に暗転演出。視聴者が「あ、こっち選んだ」と分かる。進捗ドットで何回目か一目瞭然。

### 6. 世界観の匂わせ: PASS
- 単色背景 + 無機質なレイアウト。装飾なし。カードだけが「そこにある」。ダークファンタジーのカードフレームが世界観を担う。画面自体は「整いすぎている」無機質さ。
