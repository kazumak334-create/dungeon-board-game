# ビジュアル実装手段の比較

作成日: 2026-04-14  
対象: 超高優先5項目（ユニットスプライト/アイコン/カードフレーム/背景/エフェクト）

---

## 手段A: Gemini（生成AI）による制作

### 概要
Google Gemini 2.0 Flash の画像生成機能を使用してアセット作成。

### メリット
- ✅ **コスト**: ほぼ無料（API使用料のみ）
- ✅ **速度**: プロンプト調整後は高速生成可能
- ✅ **拡張性**: Phase 4の追加ユニットも同じ手法で量産可能
- ✅ **著作権**: 生成AI出力は基本的に利用可能（Gemini利用規約確認必須）
- ✅ **カスタマイズ**: プロンプト調整で世界観統一

### デメリット
- ❌ **品質**: ピクセルパーフェクトな制御が難しい
- ❌ **一貫性**: 同じプロンプトでも毎回違う出力
- ❌ **サイズ制御**: 48×48pxぴったりの生成が難しい（後処理必要）
- ❌ **ドット絵**: AI生成のドット絵は品質が低い傾向
- ⚠️ **学習**: プロンプトエンジニアリングの試行錯誤が必要

### 具体的な手順
1. **プロンプトテンプレート作成**
   ```
   A 48x48 pixel sprite of a {unit_name}, {description},
   style: simple pixel art, transparent background,
   color scheme: {color},
   view: top-down or side view,
   mood: {mood}
   ```

2. **バッチ生成スクリプト作成**
   - cards.jsonから全ユニット情報を読み込み
   - 各ユニットの説明をプロンプトに変換
   - Gemini APIで一括生成

3. **後処理**
   - リサイズ（48×48px）
   - 背景透過処理
   - 手動チェック・リジェネ

4. **品質確保**
   - 5-10パターン生成して最良を選択
   - 種族ごとにスタイル統一
   - 不採用分は予備として保存

### 推奨対象
- 🟢 バトル背景（1280×720）: 高解像度で生成しやすい
- 🟡 ユニットスプライト: 後処理前提なら可
- 🔴 アイコン（16×16）: 小さすぎて難しい
- 🔴 ドット絵エフェクト: AI不得意

### コスト試算
- Gemini 2.0 Flash: 画像生成 ≈ $0.00-0.10/枚（無料枠内で可能）
- 総コスト: ほぼ無料

## 手段B: アセットストア購入

### 概要
既存のゲームアセットパックを購入・組み合わせて使用。

### メリット
- ✅ **品質**: プロのアーティスト制作、高品質
- ✅ **速度**: 購入後すぐ使用可能
- ✅ **一貫性**: セット商品なら統一されたスタイル
- ✅ **著作権**: 商用利用ライセンス明確
- ✅ **量**: 1パックで数十〜数百種類

### デメリット
- ❌ **コスト**: $5-50/パック、複数必要で高額化
- ❌ **世界観**: 完全一致は困難、妥協が必要
- ❌ **拡張性**: 追加ユニットに合うアセットが無い場合困る
- ⚠️ **探索時間**: 適切なアセットを見つけるのに時間がかかる
- ⚠️ **ライセンス**: パックごとに利用規約確認必須

### 調査対象ストア
1. **Godot Asset Library** (https://godotengine.org/asset-library)
   - Godot専用、無料多数
   - 品質はピンキリ

2. **itch.io** (https://itch.io/game-assets)
   - インディー向け、価格幅広い
   - "pixel art" "icon pack" で検索

3. **OpenGameArt** (https://opengameart.org/)
   - 無料、CC0多数
   - 品質は中程度

4. **Kenney Assets** (https://kenney.nl/assets)
   - 高品質、CC0、無料
   - ファンタジー/SF系豊富

### 具体的な手順
1. **キーワード検索**
   - "pixel art monster 48x48"
   - "status icon 16x16"
   - "card frame fantasy"
   - "dungeon background"

2. **候補リスト作成**
   - 5-10個のアセットパックをピックアップ
   - ライセンス・価格・内容を比較

3. **サンプル確認**
   - 無料サンプルで品質チェック
   - 世界観との整合性評価

4. **購入・統合**
   - 必要なパックのみ購入
   - Godotプロジェクトに導入
   - 不足分は他手段で補完

### 推奨対象
- 🟢 アイコン（16×16）: アイコンパックが豊富
- 🟢 カードフレーム: UI素材が充実
- 🟢 エフェクト: VFXパック多数
- 🟡 ユニットスプライト: 世界観次第
- 🟡 バトル背景: ファンタジー系は多いがSF系は少ない

### コスト試算
- アイコンパック: $5-15
- スプライトパック: $10-30
- 背景パック: $5-20
- エフェクトパック: $10-25
- **総額: $30-90**（必要最小限）

## 手段C: Godot標準機能（プレースホルダー）

### 概要
ColorRect、Label、簡易Shaderで代替し、後でリプレイス前提。

### メリット
- ✅ **コスト**: 完全無料
- ✅ **速度**: 最速（コード数行で完成）
- ✅ **柔軟性**: 仕様変更に即座に対応
- ✅ **学習**: Godot機能の理解が深まる
- ✅ **段階的移行**: 一部だけ本物に差し替え可能

### デメリット
- ❌ **品質**: 見た目が地味、商用レベルではない
- ❌ **没入感**: プレイヤー体験が損なわれる
- ❌ **スクリーンショット**: 宣伝材料として使えない
- ⚠️ **二度手間**: 最終的には作り直しが必要

### 具体的な実装例

#### ユニットスプライト代替
```gdscript
# ColorRect + Label で簡易表示
var sprite = ColorRect.new()
sprite.size = Vector2(48, 48)
sprite.color = race_colors[unit.race]  # 種族ごとに色分け

var label = Label.new()
label.text = unit.unit_name[0]  # 頭文字表示
label.position = Vector2(16, 16)
sprite.add_child(label)
```

#### アイコン代替
```gdscript
# 1文字アイコン
var icon = Label.new()
icon.size = Vector2(16, 16)
icon.text = effect_symbols[effect_name]  # "P"=毒, "F"=凍結
icon.add_theme_font_size_override("font_size", 12)
icon.add_theme_color_override("font_color", effect_colors[effect_name])
```

#### カードフレーム代替
```gdscript
# Panel + StyleBox で枠線
var card = Panel.new()
card.size = Vector2(220, 320)
var style = StyleBoxFlat.new()
style.border_color = rarity_colors[rarity]
style.border_width_all = 3
card.add_theme_stylebox_override("panel", style)
```

#### バトル背景代替
```gdscript
# グラデーション背景
var bg = ColorRect.new()
bg.size = Vector2(1280, 720)
var gradient = Gradient.new()
gradient.add_point(0.0, Color(0.1, 0.1, 0.2))  # 暗い青
gradient.add_point(1.0, Color(0.2, 0.2, 0.3))  # やや明るい青
# ShaderでグラデーションをY軸方向に適用
```

#### エフェクト代替
```gdscript
# パーティクルシステムで簡易エフェクト
var particles = GPUParticles2D.new()
particles.amount = 10
particles.lifetime = 0.5
# 白い小さな四角を飛ばす
```

### 推奨対象
- 🟢 **MVP段階**: まず動くものを作る
- 🟢 **仕様確定前**: ビジュアル以外を先に固める
- 🟡 **予算ゼロ**: 他の手段が使えない場合
- 🔴 **Phase 5完成**: 最終的には本物に差し替え必須

### コスト試算
- 無料
