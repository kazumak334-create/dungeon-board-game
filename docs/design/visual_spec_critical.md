## 1. ユニット盤面スプライト（48×48×65体）

### 概要
バトル画面の盤面に配置されるユニットの見た目。プレイヤーが最も長時間見る要素。

### 技術仕様
- **サイズ**: 48×48 px
- **形式**: PNG（透過背景）
- **色数**: 制限なし（フルカラー推奨）
- **アニメーション**: 不要（静止画1枚）
- **命名規則**: `{unit_name}.png`（例: `slime.png`, `skeleton.png`）
- **保存先**: `res://assets/cards/units/`

### 必要な種類（65体）
| 種族 | 数量 | 備考 |
|------|------|------|
| スライム | 24体 | 基本/パラライズ/ヒート/ファット/クリスタル等 |
| 獣 | 21体 | ウルフ/タイガー/ホークス/ストーカー等 |
| アンデッド | 15体 | スケルトン/グール/バンシー/リッチ等 |
| ボス専用 | 5体 | 猛獣使い/母スライム核/融合スライム/屍術師/死骸の王座 |

### 世界観との整合性
- **テーマ**: 実験体・人工生命・データの残骸
- **スタイル**: ドット絵風 or シンプルなローポリ3Dレンダリング
- **色調**: 種族ごとに統一
  - スライム: 青/緑/赤系（透明感）
  - 獣: 茶/黒/灰色（動物的）
  - アンデッド: 灰/紫/黒（不気味）
- **禁止事項**: リアル過ぎる表現、グロテスク表現、著作権侵害

### デザイン要件
- 48×48の小サイズでも識別可能
- 種族が一目で分かる
- 同種族内でもバリエーションが分かる
- シルエットが明瞭

### 参考イメージ
```
スライム系: 丸い塊状、半透明感
獣系: 四足歩行または攻撃的なポーズ
アンデッド系: 骨格・霊体的な表現
```

## 2. バフ/デバフアイコン（16×16×25種）

### 概要
ユニットの状態異常・強化効果を表示する小アイコン。戦況判断に直結。

### 技術仕様
- **サイズ**: 16×16 px
- **形式**: PNG（透過背景）
- **色数**: 制限なし
- **アニメーション**: 不要
- **命名規則**: `{effect_name}_icon.png`（例: `poison_icon.png`）
- **保存先**: `res://assets/icons/buffs/`

### 必要な種類（25種）

#### 状態異常（4種）
- `poison` - 毒: 緑色、ドクロまたは泡
- `frozen` - 凍結: 水色、氷結晶
- `burn` - 火傷: 赤/橙、炎マーク
- `paralysis` - 麻痺: 黄色、稲妻

#### 強化効果（8種）
- `lifesteal` - 吸血: 赤、ハートまたは牙
- `regen` - リジェネ: 緑、＋マークまたは回復
- `armor` - 鎧: 青/灰、盾
- `atk_buff` - ATKバフ: 赤、剣↑
- `spd_buff` - SPDバフ: 黄、稲妻↑
- `penetrate` - 貫通: 橙、矢印貫通
- `flying` - 飛行: 白、翼
- `snipe` - 狙撃: 黒、照準

#### 特殊（13種）
- `impact` - 衝撃: 橙、爆発
- `big_penetrate` - 大貫通: 赤、二重矢印
- `critical` - クリティカル: 金、星
- `kill_bonus` - 撃破累積: 赤、スタック表示
- `invincible` - 無敵（結晶化）: 虹、ダイヤ
- `auto_promote` - 自動前進: 緑、→
- `back_attack` - 後列攻撃: 紫、弓
- `mid_attack` - 中列攻撃: 青、槍
- `damage_reduction` - ダメージ軽減: 灰、盾
- `temp_atk` - 一時ATK: 赤、剣（時計）
- `temp_spd` - 一時SPD: 黄、稲妻（時計）
- `hp_threshold` - HP閾値: 橙、！
- `skill_timer` - スキル発動中: 紫、砂時計

### デザイン要件
- 16×16の極小サイズで判別可能
- 色で直感的に分かる（赤=攻撃、緑=回復、青=防御、黄=速度）
- シンプルなアイコン（線が太い）
- 背景色で種別を区別（バフ=明るい、デバフ=暗い）

## 3. カードイラスト（180×180×65体）

### 概要
カード中央に表示されるユニットの詳細イラスト。DeckPrep/Shop/Result等で見る。

### 技術仕様
- **サイズ**: 180×180 px（カード内枠）
- **形式**: PNG（透過背景推奨）
- **スタイル**: 盤面スプライトより詳細、世界観統一
- **命名規則**: `{unit_name}_card.png`（例: `slime_card.png`）
- **保存先**: `res://assets/cards/units/`（盤面スプライトと同じ）

### 必要な種類（65体）
| 種族 | 数量 |
|------|------|
| スライム | 24体 |
| 獣 | 21体 |
| アンデッド | 15体 |
| ボス専用 | 5体 |

### 世界観との整合性
- **テーマ**: 実験体・人工生命・データの残骸
- **スタイル**: 盤面スプライトと同じ方向性、より詳細
- **色調**: 種族ごとに統一（スライム=青緑、獣=茶、アンデッド=灰紫）
- **表現**: 正面または斜め向き、キャラクター性が伝わる

### デザイン要件
- 180×180で詳細が見える
- 盤面スプライトと同じユニットだと分かる
- カードフレームの色と調和
- 背景は透過または単色

### 盤面スプライトとの関係
```
盤面スプライト（48×48） → シンプル、シルエット重視
      ↓ 同じユニット
カードイラスト（180×180） → 詳細、かっこいい/かわいい
```

## 4. バトル背景（1280×720×最低1種）

### 概要
バトル画面の背景イラスト。戦闘の雰囲気を決定。

### 技術仕様
- **サイズ**: 1280×720 px
- **形式**: PNG or JPG
- **アスペクト比**: 16:9
- **命名規則**: `battle_bg_{variant}.png`
- **保存先**: `res://assets/backgrounds/battle/`

### 必要な種類（最低1種、推奨3種）
1. **基本フィールド** - 汎用バトル背景
2. （推奨）Act1背景 - 初期エリア雰囲気
3. （推奨）ボス戦背景 - 特別感演出

### 世界観との整合性
- **テーマ**: 実験施設内部・データ空間・廃墟
- **雰囲気**: 薄暗い、無機質、デジタル感
- **色調**: 青/灰/黒基調、明度低め
- **構図**: 3×3グリッド配置を邪魔しない（中央は比較的シンプル）
- **禁止事項**: 明るすぎる、賑やかすぎる、UI要素と干渉

### デザイン要件
- 中央3×3グリッドエリアは視認性確保
- 奥行き感（遠近感）
- 静止画（アニメーション不要）
- UI要素（HPバー、マナゲージ等）と色が被らない

### 参考イメージ
```
基本: 暗い実験室、金属の床、配管、モニター
Act1: 初期エリア、比較的明るめ
ボス: 荘厳、圧迫感、特別なライティング
```

## 5. 基本攻撃エフェクト（3種）

### 概要
攻撃時の視覚フィードバック。ゲームの手触りを決定。

### 技術仕様
- **形式**: スプライトシート or 個別PNG連番
- **アニメーション**: 5-10フレーム推奨
- **サイズ**: 64×64 px（エフェクト全体）
- **FPS**: 15-30fps
- **命名規則**: `{effect_type}_00.png` - `{effect_type}_09.png`
- **保存先**: `res://assets/effects/attack/`

### 必要な種類（3種）

#### 1. 近接斬撃エフェクト
- **名前**: `melee_slash`
- **イメージ**: 白い斬撃線、弧を描く
- **フレーム数**: 5-8フレーム
- **サイズ**: 64×64 px
- **色**: 白/銀色、残像あり

#### 2. 遠距離飛翔エフェクト
- **名前**: `ranged_projectile`
- **イメージ**: 小さな弾丸/矢、直線移動
- **フレーム数**: 3-5フレーム
- **サイズ**: 32×32 px（小さめ）
- **色**: 黄/橙、尾を引く

#### 3. ヒットスパークエフェクト
- **名前**: `hit_spark`
- **イメージ**: 衝撃の火花、放射状
- **フレーム数**: 6-10フレーム
- **サイズ**: 48×48 px
- **色**: 白/黄/橙、グラデーション

### デザイン要件
- 視認性が高い（背景に埋もれない）
- 派手すぎず、何度見ても飽きない
- 軽量（ファイルサイズ小）
- ループ不要（1回再生で完結）

## 6. フォント

### 概要
ゲーム全体の可読性と雰囲気を決定。日本語対応必須。

### ✅ 実装済みフォント
既に以下のフォントが `res://assets/fonts/` に配置済み：

1. **PixelMplus10-Regular.ttf** - ドット絵風日本語フォント
   - 用途: メインフォント（UI・本文）
   - 特徴: ドット絵風、日本語対応、可読性高い
   - ライセンス: M+ FONTS派生（商用可）

2. **trajan.ttf** - 英語タイトルフォント
   - 用途: タイトルロゴ、英語表記
   - 特徴: 古代ローマ風、威厳

### 技術仕様
- **形式**: TTF
- **保存先**: `res://assets/fonts/`
- **Godot設定**: FontFileリソースとして読み込み

### Godot設定例
```gdscript
# フォント読み込み
var main_font = load("res://assets/fonts/PixelMplus10-Regular.ttf")
var title_font = load("res://assets/fonts/trajan.ttf")

# Label設定
label.add_theme_font_override("font", main_font)
label.add_theme_font_size_override("font_size", 14)
```

### 追加が必要な場合
- ダメージ数値専用フォント（より太字・視認性重視）を追加するかは検討中
- 現状はPixelMplus10で代用可能
