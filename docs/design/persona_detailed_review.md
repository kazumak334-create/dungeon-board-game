# ペルソナ詳細レビュー & 改善提案

8ペルソナの詳細な意見と、各視点からの改善提案をまとめる。

# 1. I LOVE TUMA（日本・BackPack Battles特化）

## 評価: ★★☆☆☆（2/5）

### 詳細な意見

**× ダメなポイント**:
1. **ユニット数が圧倒的に少ない**: 21ユニット？BPBは300アイテム以上。これじゃ3周で飽きる。「毒ビルド」「群れビルド」の2パターンしか組めない。
2. **アーティファクト・スキルが企画のみ**: 「エンジェルの羽で飛行付与」って言われても、実装されてないなら評価できない。絵に描いた餅。
3. **バトル演出が地味**: BPBは装備配置でキラキラ光る。このゲームは数字が動くだけ。配信で「見てるだけ」は苦痛。

**△ 懸念点**:
- **オートバトルの「待ち時間」**: BPBは全て自分で操作できるから、操作ミスも含めて面白い。オートだと「運ゲー」にしか見えない。
- **コンテンツ量**: 今の状態で動画31本作れる？10本で終わる。初心者向け解説も「これだけ？」で終わる。

**○ 良いポイント**:
- **配置パズルのコンセプトは良い**: 「前列・中列・後列」の役割分担は分かりやすい。ただしBPBと比べるとまだ浅い。
- **ホバー情報**: 全情報が見える設計は初心者に優しい。ここは評価する。

### 改善要求（必須）

1. **ユニット数を最低60まで拡張**（致命的）:
   - スライム30種、獣30種まで拡張
   - BPB（300アイテム）と比較して、最低でも60は必要
   - これが無いと「3周で飽きる」

2. **バトル演出を作り直す**（致命的）:
   - 毒蓄積・ATKバフ・クリティカルにエフェクト追加
   - BPB のような「キラキラ光る」演出
   - 数字だけでは配信で伝わらない

3. **呪文手動発動ボタン追加**（最優先）:
   - オートバトルだけでは「操作してる感」ゼロ
   - 「このタイミングで打ちたい」を実現

# 2. しんじさん（日本・攻略最前線）

## 評価: ★★☆☆☆（2/5）

### 詳細な意見

**× ダメなポイント**:
1. **「100動画作れる」は無理**: 21ユニットで何本撮れる？10本で終わる。スキル30・アーティファクト30は企画だけ。実装されてから評価する。
2. **配信映え演出が皆無**: 毒蓄積してもエフェクト無し。ATKバフ重なっても数値が変わるだけ。これじゃ視聴者に伝わらない。「脳汁出すぎｗｗ」にならない。
3. **シナジーが浅い**: 「Voidblob+血の暴走」って、それだけ？BPBは10層シナジーとか組める。21ユニットじゃ組み合わせが少なすぎる。

**△ 懸念点**:
- **1014本投稿の目線で見ると致命的**: 「このゲーム何周やる？」と聞かれたら「5周で飽きる」と答える。コンテンツ量が足りない。
- **神回が作れない**: 「警戒Lv5でBoss倒した！」ってだけじゃ弱い。演出・エフェクト・BGM変化が無いと盛り上がらない。

**○ 良いポイント**:
- **警戒レベルシステム**: リスクリターンの設計は良い。「やばいけどやる」の動機付けになる。
- **Rageveil逆転の可能性**: 「味方全滅後に1体逆転」は熱い。ただし演出が無いと伝わらない。

### 改善要求（必須）

1. **ユニット数を最低60まで拡張**（致命的）:
   - 21ユニットで「100動画作れる」は絶対無理
   - 最低60、理想は100以上
   - これが無いと10本で終わる

2. **配信映え演出を全面追加**（致命的）:
   - 毒スタック数を大きく表示（「POISON x50」）
   - クリティカル発動時にスローモーション+エフェクト
   - Rageveil逆転時に専用カットイン
   - これが無いと視聴者に伝わらない

3. **シナジー深度を拡張**（最優先）:
   - 現状の2層シナジーでは浅すぎる
   - BPB の10層シナジーレベルまで拡張
   - アーティファクト・スキル実装後に再評価

# 3. Northernlion（北米・ローグライク長尺）

## 評価: ★★☆☆☆（2/5）

### 詳細な意見

**× ダメなポイント**:
1. **リプレイ性が致命的に低い**: 21ユニットで何周やれる？Hades（100周）、StS（数百周）と比較すると、これは5周で終わる。スキルツリーも企画だけ。
2. **長尺配信で「間」が持たない**: オートバトルだからトークのネタが無い。StSは「次何引く？」「このカード取るか？」で2時間話せる。これは30分で黙る。
3. **「毎回違う体験」が浅い**: マップ分岐・カード報酬のランダム性だけでは不足。21ユニットじゃ「また毒ビルドか」で終わる。

**△ 懸念点**:
- **StS2初週21K視聴者は無理**: 今の状態で配信したら「これ30分で飽きるゲームだね」で終わる。コンテンツ量が絶対的に足りない。
- **完走引き継ぎも限界がある**: 「次のランはもっと強い」は最初の3周だけ。4周目以降は「もう全部持ってる」で飽きる。

**○ 良いポイント**:
- **UI明快**: ホバーで全情報が見える設計は評価する。「なぜこれがここに？」と思わせないのは良い。
- **コンセプトは悪くない**: 「見守り系」の方向性は正しい。ただしコンテンツ量が実装されてから評価する。

### 改善要求（必須）

1. **ユニット数を最低100まで拡張**（致命的）:
   - Hades（100周）・StS（数百周）と比較して、21ユニットは5周で終わる
   - 長尺配信するには最低100ユニット必要
   - これが無いと配信ネタが無くなる

2. **リプレイ性の深度を確保**（致命的）:
   - 高難度モード「警戒Lv初期値+5」「Boss HP×2」等
   - デイリーチャレンジ（固定シード）
   - アーティファクト・スキル実装後に再評価

3. **バトル中のトーク余地を作る**（最優先）:
   - バトル速度調整（0.5x, 1x, 2x）
   - バトル一時停止機能
   - ステータス詳細表示（トークネタ提供）

**× ダメなポイント**:

2. **UI・演出が地味すぎる**: カードアートが仮素材レベル。バトル中のエフェクトも無い。これで「スクショ映え」は無理。インディーゲーム300本見てきたが、これは下位10%。
3. **コンテンツ量が見えない**: 21ユニット？「これだけ？」で終わる。視聴者に「このゲーム買う価値ある？」と聞かれたら「まだ早い」と答える。

**△ 懸念点**:
- **「StSのパクリ」に見える**: ローグライク・カードゲーム・デッキ構築。新規性が伝わらない。「3×3配置パズル」は良いが、それだけでは弱い。
- **動画タイトルが付けられない**: 「新作ローグライク紹介」だけでは弱い。「このゲームの魅力」が10分で分からない。

**○ 良いポイント**:
- **ホバー情報**: ゲームが自分を教えてくれる設計は良い。チュートリアル無しでも理解できる（ただし勝てるとは言ってない）。

1. **初戦勝利の保証**（致命的）:
   - 1戦目で負けたら即離脱

   - または初戦のみチュートリアルモード「推奨配置」表示

2. **UI・カードアート高品質化**（致命的）:
   - 現状は仮素材レベル。インディーゲーム下位10%
   - カードアート・エフェクト・パーティクル全面追加
   - これが無いとスクショ映えしない

3. **コンテンツ量を見せる**（最優先）:
   - 21ユニットでは「これだけ？」で終わる
   - 最低60ユニット実装してから再評価
   - 動画タイトルが付けられない

# 7. x5_PiG（中国・StSガチ勢）

## 評価: ★★☆☆☆（2/5）

### 詳細な意見

**× ダメなポイント**:
1. **最適化する要素が少なすぎる**: 21ユニットで「デッキ圧縮」？何を圧縮する？選択肢が少なすぎて最適化の意味が無い。StS は数百カードから選ぶから面白い。
2. **数値の透明性が不足**: 「毒スタック×SPD低下」の計算式は？内部ロジックが不明。中国ガチ勢は全計算式を知りたい。ホバーに書いてない情報が多すぎる。

**△ 懸念点**:
- **デッキ評価スコアが無い**: 「このデッキは強いか？」を数値で判断できない。手動で「このカードは不要」と判断するしかない。ツール不足。
- **スキルツリーは企画のみ**: 実装されてないものは評価できない。企画を見せられても「絵に描いた餅」。

**○ 良いポイント**:
- **データ駆動設計**: 全てが JSON で管理されているのは評価する。数値が明示的なのは良い（ただし計算式が不明な部分が多い）。
- **警戒Lv制御**: リスクリターンを数値で制御できるのは良い設計。ただし他の要素が少なすぎる。

### 改善要求（必須）

1. **ユニット数を最低100まで拡張**（致命的）:
   - 21ユニットでは最適化する意味が無い
   - StS レベルには最低100ユニット必要
   - これが無いと戦略の幅が狭すぎる

2. **数値の透明性を完全化**（最優先）:
   - 全効果の計算式をゲーム内ヘルプに明示
   - ホバーで全計算式表示
   - ダメージ計算ログ（中国ガチ勢は全て知りたい）

3. **デッキ最適化ツール追加**（最優先）:
   - デッキ評価スコア
   - 「このカードは除去推奨」サジェスト
   - デッキ圧縮進捗可視化

1. **ユニット数を最低60まで拡張**（致命的）:
   - 21ユニットでは攻略記事が書けない

   - 最低60、理想は100以上

2. **データ構造ドキュメント整備**（最優先）:
   - 全 effect_id のリファレンス
   - MOD 制作ガイド
   - これが無いと MOD 制作者が試行錯誤

3. **コミュニティ攻略支援**（中優先）:
