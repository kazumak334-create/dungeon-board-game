# ボス戦システム完成企画書

## 1. 設計思想

### 核との整合性
「盤面を設計して、介入を仕込んで、答え合わせを観戦する」-- ボス戦はこの体験の最高到達点。ボスごとに「正解の盤面」が異なり、プレイヤーはAct道中で拾ったカードで対策を組み立てる。

### 3秒ルール遵守
ボス専用ユニットは「見た目のテーマ統一 + 既存スキルの組み合わせ」で設計する。新しい効果IDは追加しない。

### 三すくみとの接続
各ボスは突・守・崩のいずれかの戦略に特化し、プレイヤーにカウンター戦略を要求する。

| 通常 | (なし) | 第1戦 or 警戒Lv0-3 | 既存ユニット中心。テーマに沿った基本構成 |

## 5. alert_level_buffs 調整方針

### 設計原則
- buffsは「デッキ差し替え」で表現しきれない微調整に使う
- 第1戦（通常デッキ）では警戒レベルのバフは適用しない
- 第2戦（連戦システム: 警戒Lv4+）で初めてバフが乗る

### 数値方針

| 警戒Lv | HP bonus | ATK bonus | 適用条件 |
|--------|----------|-----------|---------|
| 0-3 | 0 | 0 | 第1戦のみ。デッキ差し替えなし |
| 4 | +5 | +1 | 第2戦（strongデッキ）。微量バフで圧を上げる |
| 5 | +10 | +2 | 第2戦（enragedデッキ）。強化デッキ+バフで最高難度 |

### Act別の追加調整

| Act | Lv4 HP/ATK | Lv5 HP/ATK | 理由 |
|-----|-----------|-----------|------|
| Act 1 | +5/+1 | +10/+2 | 初心者がギリギリ超えられる程度 |
| Act 2 | +8/+2 | +15/+3 | ビルドが育っている前提 |
| Act 3 | +10/+3 | +20/+5 | 完成ビルドでも歯応えがある |

### 実装時の注意
- `_build_boss_deck()`の既存実装でhp_bonus/atk_bonusは全ユニットに一律加算される
- ボス専用ユニットにも加算される（専用ユニットは元々強いのでバフが乗ると脅威度が跳ね上がる。これは意図的）

## 6. cards.json への反映仕様

### bosses セクション更新

既存3体のact/alert_level_buffsを更新し、新規5体を追加する。

### boss_decks セクション新設

```json
"boss_decks": {
  "boss_act1_beast": [
    {"name": "ウルフ", "col": 0},
    {"name": "ゴブリン", "col": 0},
    ...
  ],
  "boss_act1_beast_strong": [...],
  "boss_act1_beast_enraged": [...],
  ...
}
```

形式はenemy_poolsと完全に同じ（name + col の配列）。_build_boss_deck()がこのセクションからデッキを読み込む。

### boss_exclusive_units セクション新設

```json
"boss_exclusive_units": {
  "猛獣使い": {
    "hp": 25, "atk": 6, "interval": 1.5, "mana": 3,
    "race": "獣", "range": "1行",
    "skills": [{"trigger": "on_hit", "target": "hit_target", "effect_id": "burn_apply", "params": {"stacks": 2}}],
    "boss_exclusive": true
  },
  ...
}
```

CardDB読み込み時にunitsとマージするが、boss_exclusive: trueのユニットはプレイヤーのドロップテーブル・ショップには出現しない。
