# DeckPrep画面 UI/UX企画書

作成日: 2026-04-10
作成者: planning Agent

---

## 1. 画面の目的

プレイヤーが**盤面設計・装備管理・持ち物確認**を行う重要な準備画面。

**核となる体験との整合性**
- 盤面設計: カード配置を試行錯誤する（核となる体験）
- 装備管理: 6スロットに装備を着脱して戦力強化
- 持ち物確認: 所持アイテムを一覧・整理

**ユーザーの判断**
- どのカードをどこに配置するか（前列/中列/後列）
- どの装備を装着するか
- どの素材を持ち歩くか
- 冒険開始の準備完了判断

### 領域分割

| 領域 | 位置（左上） | サイズ（幅×高さ） | 説明 |
|-----|------------|----------------|------|
| 共通タスクバー | (0, 0) | 1280×36 | HP/Gold/Act等表示 |

**設計意図**: 左→中央→右の水平視線、タブ切り替えで垂直移動を最小化

## 5. インタラクション

### 5.1 タブ切り替え（配置⇔持ち物）

1. タブボタンクリック
2. 中央コンテンツを全削除
3. 選択タブのコンテンツを再構築
4. タブボタンの色・背景を更新（選択中: `COLOR_TITLE` + ハイライト、非選択: `COLOR_DIM`）

### 5.2 カード選択（配置タブ）

1. 盤面セル・呪文カード・手持ちカードをクリック
2. 選択カードのインデックスを保存（`_selected_card_idx`）
3. 右パネルにカード詳細を表示
4. 盤面セルの枠線をハイライト（`COLOR_SELECTED`、2px）

### 5.3 ドラッグ&ドロップ（配置タブ）

**開始**:
1. カードを左クリック押下＋ドラッグ
2. ドラッグノード生成（半透明、マウス追従）
3. Ctrl押下: 1枚のみドラッグ / Ctrl離す: 同名カードグループドラッグ

**ドロップ**:
1. マウスボタン離す
2. ドロップ先判定:
   - 盤面セル（col>=0）: ユニットのみ配置可能
   - 呪文デッキエリア（row=0, col=-1）: 呪文のみ配置可能
   - 手持ちカードエリア（row=1, col=-1）: 全カード配置可能
3. ドロップ先に既存カードがある場合: 入れ替え処理
4. placement_config更新
5. UI再描画（`populate_cards()`）

**制約**:
- 盤面: 1マス1枚まで、ユニットのみ
- 呪文デッキ: 呪文のみ
- 手持ちカード: 全カード可

### 5.4 装備着脱（左パネル）

**装備**:
1. 持ち物タブで装備アイテムを選択
2. 装備スロットをクリック
3. スロットタイプチェック（頭装備→頭スロット）
4. 既存装備がある場合: 持ち物に戻す
5. 装備を装着、スロット枠線を `COLOR_SELECTED` に変更

**解除**:
1. 装備スロットを右クリック
2. 装備を持ち物に戻す
3. スロット枠線を `COLOR_BORDER` に戻す

### 5.5 持ち物フィルタ（持ち物タブ）

1. フィルタタブクリック（「全体」「装備」「素材」「呪い」「消費」）
2. `_inventory_filter` 更新
3. フィルタ条件に合致するアイテムのみ表示
4. グリッド再描画

### 5.6 合成（配置タブ）

1. 合成可能エリアの「[合成]」ボタンクリック
2. 確認ダイアログ表示（「確認省略」チェックボックスOFFの場合）
3. 素材カードを削除（selected_deckから除去）
4. 結果カードを追加（selected_deckに追加）
5. placement_config更新
6. UI再描画

### 5.7 状態変化の可視化

| 状態 | 視覚的表現 |
|-----|----------|
| タブ選択中 | タブテキスト `COLOR_TITLE`、背景ハイライト |
| タブ非選択 | タブテキスト `COLOR_DIM`、背景なし |
| カード選択中 | 盤面セル枠線 `COLOR_SELECTED`（2px）、右パネルに詳細表示 |
| ドラッグ中 | 半透明ドラッグノード、マウス追従 |
| 装備装着済み | 装備スロット枠線 `COLOR_SELECTED`（2px）、アイコン表示 |
| 合成可能 | 合成パネル枠線アクセント色（2px）、ボタン有効 |
| 合成不可 | 合成パネル枠線 `COLOR_BORDER`（1px）、modulate 0.5 |

## 6. UI基準チェック

### 6.1 3秒ルール
**評価: ✅ 合格**

- 左パネル: ステータス・装備が常時表示
- 中央タブバー: 「配置」「持ち物」が明確
- 中央コンテンツ: 盤面グリッド・手持ちカード・呪文デッキが一目で分かる
- 右パネル: 選択カード詳細が常時表示
- 冒険ボタン: 大きく目立つ配置

視線の流れが左→中央→右で明確、タブで機能切り替えが直感的。

### 6.2 視線の一本化
**評価: ✅ 合格**

視線の流れ:
1. 左パネル（ステータス確認）
2. 中央コンテンツ（カード配置・手持ち確認）
3. 右パネル（詳細確認）
4. 冒険ボタン（決定）

水平方向の一本道、タブ切り替えで垂直移動最小化。
複数の注意点が散らばらず、3パネル構成で情報整理。

### 6.3 状態の可視化
**評価: ✅ 合格**

- タブ選択: 色・背景で明確
- カード選択: 枠線ハイライト + 右パネル詳細表示
- ドラッグ中: 半透明ノード + マウス追従
- 装備装着: 枠線色変更 + アイコン表示
- 合成可能/不可: 枠線・明度・ボタンテキストで判別

プレイヤーが「今何ができるか」を常に把握できる。

### 6.4 操作の最小化
**評価: ✅ 合格**

- カード配置: ドラッグ&ドロップ（1アクション）
- タブ切り替え: 1クリック
- 装備着脱: 1クリック（装備）/ 右クリック（解除）
- 合成: 1クリック（確認省略ON時）
- 冒険開始: 1クリック

無駄なモーダル・確認ダイアログを最小化（合成のみ確認可能、省略可）。

### 6.5 配信映え
**評価: ✅ 合格**

- 盤面グリッドが大きく表示され、配置戦略が視聴者にも伝わる
- 手持ちカード・呪文デッキが分離表示され、デッキ構成が一目で分かる
- 右パネルのカード詳細（5:7比率TCGカード）が配信画面でも読みやすい
- 装備スロット6個が左パネルに常時表示され、装備状況が明確
- ドラッグ&ドロップの視覚的フィードバックが分かりやすい

### 6.6 世界観の匂わせ
**評価: ✅ 合格**

- MaterialSelect.gd・Shop.mdと統一された色彩設計（ダークファンタジー + 無機質）
- 左右パネルを暗めにして中央コンテンツを強調（盤面＝デバイス画面の演出）
- 装備スロット・持ち物グリッドの正方形セル（機械的な整然さ）
- 合成可能エリアの淡い色分け（無機質な美しさ）
- タブ・ボタンの控えめなハイライト（説明しない・ただそこにある）

## 7. まとめ

DeckPrep画面は**「盤面を設計する」**という核となる体験を最優先にした設計。

- 3パネル構成（左：ステータス・装備 / 中央：配置・持ち物 / 右：詳細）で情報整理
- 視線の流れを水平方向に一本化、タブ切り替えで機能分離
- ドラッグ&ドロップでカード配置を直感的に
- 装備スロット6個を左パネルに常時表示、着脱を1クリックで完結
- 持ち物タブで素材・装備を一覧管理、フィルタで絞り込み
- MaterialSelect.gd・Shop.mdと統一された色彩設計
- 全てのUI基準をクリア（3秒ルール/視線の一本化/状態の可視化/操作の最小化/配信映え/世界観の匂わせ）
