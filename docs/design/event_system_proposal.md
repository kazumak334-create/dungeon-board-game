作成日: 2026-04-11
ステータス: 企画案（承認待ち）

---

## 1. イベントとは

**定義**: マップ上の「？」マスで発生するランダムイベント（StSと同様）

**コンセプト**:
- テキスト + 選択肢 → 結果の分岐
- リスク/リターンの選択（報酬 vs デメリット）
- 世界観の匂わせ（ATLAS、灰色の疫病、実験体など）

---

## 2. イベントの種類

### 2.1 報酬イベント（ローリスク・ハイリターン）

**例: 宝箱**
```
古びた宝箱を見つけた。

選択肢:
A) 開ける → Gold 80-120
B) 慎重に開ける → Gold 40-60 + レリック1個
C) 無視する → 何も起こらない
```

### 2.2 リスクイベント（ハイリスク・ハイリターン）

**例: 怪しげな商人**
```
怪しげな商人が取引を持ちかけてきた。

選択肢:
A) HP10を支払う → レリック1個（確定Uncommon以上）
B) Gold100を支払う → カード3枚から1枚選択（確定Rare）
C) 断る → 何も起こらない
```

### 2.3 選択肢による分岐イベント

**例: 負傷した兵士**
```
負傷した兵士が助けを求めている。

選択肢:
A) 助ける → HP -5、Gold +50、警戒レベル-1
B) 見捨てる → 何も起こらない
C) 装備を奪う → Gold +100、警戒レベル+2
```

### 2.4 世界観イベント（フレーバー重視）

**例: 記憶の断片**
```
床に散らばった古い記録を見つけた。
「実験体#2891 - 適応成功率 12.3% - 次フェーズへ移行不可」

選択肢:
A) 記録を読む → フレーバーテキスト表示
B) 立ち去る → 何も起こらない
```

## 4. result typeの定義

| type | 説明 | value例 |
|------|------|---------|
| gold | Gold増減 | 50, [80, 120]（範囲） |
| hp | 本体HP増減 | -10, 15 |
| relic | レリック獲得 | count + rarity_weights |
| card_choice | カード選択 | count + rarity |
| alert_level | 警戒レベル増減 | -1, 2 |
| remove_card | カード削除選択 | count: 1 |
| upgrade_card | カード強化選択 | count: 1 |
| curse | 呪いカード追加 | card_name: "呪い" |

## 5. UI設計

### レイアウト（1280×720）

```
┌────────────────────────────────────┐
│ [← マップへ]              イベント │ ← タイトルバー (36px)
├────────────────────────────────────┤
│                                    │
│    ┌──────────────────────┐       │
│    │  イベントテキスト     │       │ 340×150, 中央配置
│    │  （2-4行）            │       │
│    └──────────────────────┘       │
│                                    │
│    ┌──────────────────────┐       │
│    │ 選択肢A               │       │ 400×50, 中央配置
│    └──────────────────────┘       │ 各選択肢間隔10px
│    ┌──────────────────────┐       │
│    │ 選択肢B               │       │
│    └──────────────────────┘       │
│    ┌──────────────────────┐       │
│    │ 選択肢C（任意）       │       │
│    └──────────────────────┘       │
│                                    │
└────────────────────────────────────┘
```

### 色彩設計

- 背景: MaterialSelect.gd踏襲（暗灰背景）
- イベントパネル: Color(0.12, 0.12, 0.18) / 枠 Color(0.3, 0.3, 0.4)
- テキスト: UIF.TEXT_COLOR（白）
- 選択肢ボタン:
  - 通常: Color(0.2, 0.25, 0.3)
  - ホバー: Color(0.25, 0.3, 0.35)
  - リスクあり（HP/Gold消費）: Color(0.3, 0.2, 0.15)（暖色系）

### 結果表示

選択後、同じパネル内にアニメーション付きで結果表示：
```
結果:
+ Gold 95
+ レリック「鉄の護符」獲得

[マップへ戻る]
```

## 6. イベントプール設計

### Act別イベント数

| Act | イベント数 | 内訳 |
|-----|-----------|------|
| 1 | 8個 | 報酬5 / リスク2 / 世界観1 |
| 2 | 10個 | 報酬4 / リスク4 / 世界観2 |
| 3 | 12個 | 報酬3 / リスク6 / 世界観3 |

### ランダム選択

- MapSelect.gdでイベントノードクリック時、Actに応じたプールからランダム選択
- 同じイベントは1ラン中に2回出ない（visited_eventsで管理）
