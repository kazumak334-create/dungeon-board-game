# 1. ゲーム体験の核心

## 一言定義
**「盤面を設計して、介入を仕込んで、答え合わせを観戦する」**

## プレイヤーがやること

### Phase 1: 盤面設計（DeckPrep画面）
- 9枚のユニットをどこに配置するか決める
- 3つの呪文をどの条件で発動させるか決める
- 「この配置なら前列が崩れても中列が昇進する」「毒ビルドを組むから後列にJelfix」といった戦略を練る

### Phase 2: 介入を仕込む（呪文スロット）
- バトル中に自動発動する呪文を3つセット
- 「HP50%以下で回復」「敵前列3体以上で全体攻撃」等の条件設定
- 盤面が崩れた時の保険を仕込む

### Phase 3: 答え合わせを観戦（Battle画面）
- リアルタイムで進むバトルを観戦
- 「狙い通り毒が蓄積してる」「前列崩壊したけど中列が昇進して持ちこたえた」
- 完全オートではなく、呪文の微調整は可能（介入の余地）

## このゲームの快感ポイント

1. **配置パズルの楽しさ** - 9マスをどう使うか考える（BPBライク）
2. **ビルド構築の気持ちよさ** - 「毒特化」「群れ物量」「貫通後列狙撃」等のコンセプト
3. **予想外のシナジー** - 「Voidblob（マナ減少）+血の暴走（自傷でATK上昇）で敵のマナ枯渇」
4. **観戦の緊張感** - 「前列持ちこたえてくれ」「呪文発動タイミング完璧」
5. **完走後の引き継ぎ** - 全ユニット・スキル・アーティファクトを次のランに持ち越し

# 2. 勝ち筋の整理（ユニット戦略）

## 2-1. 基本の三すくみ（突・守・崩）

| 戦略 | 狙い | 強み | 弱み | 代表ユニット |
|-----|------|------|------|-------------|
| **突** | 一行集中突破 | 本体ダメージ直行 | 全体攻撃に弱い | Fangos, Wolfpack |
| **守** | 前線均等維持 | 消耗戦に強い | 後列崩しに弱い | Granob, Thornbeast |
| **崩** | 後列・中列破壊 | 守りを内側から崩す | 突進に弱い | Piercor（貫通）, Hawkis（飛行） |

## 2-2. ユニット戦略の5軸

### 軸1: 物理突破型
- **コンセプト**: ATK/SPDで殴り倒す
- **代表ユニット**: Fangos（クリティカル）, Sparkblob（ATK累積）
- **相性**: 敵がHP低い・回復少ない場合に強い
- **弱点**: 棘バフ・カウンター持ちに弱い

### 軸2: 毒蓄積型
- **コンセプト**: 毒スタックを積んで継続ダメージ
- **代表ユニット**: Jelfix（毒付与）, Venpool（毒増幅）, Mudblob（毒依存SPD低下）
- **相性**: 長期戦・高HPボス戦
- **弱点**: 序盤火力不足・毒無効相手

### 軸3: サポート連携型
- **コンセプト**: バフ・回復で味方を強化
- **代表ユニット**: Amoeba（HP回復）, Fangos（同行ATK+3）, Barbzel（棘+盾）
- **相性**: 前列が長持ちする構成
- **弱点**: サポート単体では火力不足

### 軸4: 貫通・飛行型
- **コンセプト**: 前列を無視して後列攻撃
- **代表ユニット**: Piercor（貫通特性）, Hawkis（飛行特性）
- **相性**: 敵前列が堅い場合
- **弱点**: 敵後列が薄い場合は無駄

### 軸5: 群れ物量型
- **コンセプト**: 同名ユニット大量配置でバフ
- **代表ユニット**: Wolfpack（群れ特性・同列獣バフ）
- **相性**: デッキ圧縮せず物量で押す
- **弱点**: 全体攻撃・範囲デバフに弱い

## 2-3. ハイブリッド戦略例

### 「毒貫通」
- Venpool（毒増幅）+ Piercor（貫通）+ Jelfix（毒付与）
- 前列を貫通して後列に毒蓄積 → 全体に毒が回る

### 「群れ突進」
- Wolfpack×3（群れ+同列バフ）+ Fangos（クリティカル）
- 同行配置でバフを重ねて一点突破

### 「不屈の壁」
- Rageveil（不撓不屈・味方死亡時バフ）+ Granob（HP累積）+ Amoeba（回復）
- 味方が倒れるたびにRageveilが強化 → 最後まで残って逆転

# 3. プレイヤースキル企画

## 3-1. スキルツリー構造（既存設計）

| 階層 | 内容 | 種類 |
|-----|------|------|
| 1〜3層 | 通貨倍率・マップ移動・バトル補助 | 共通 |
| 4層 | クラス固有カード（ユニット・呪文） | クラス固定 |
| 5層 | 通貨倍率・マップ移動・バトル補助 | 共通 |
| 6層 | クラス固有カード（より強力） | クラス固有 |

## 3-2. スキルの干渉ポイント（全体・システム）

| カテゴリ | 説明 | 例 |
|---------|------|-----|
| カード入手 | カード入手時の複製・追加獲得 | スカウト、細胞分裂 |
| バトル開始 | 全マスに盤面効果設置・マナ初期値 | マッドサイエンティスト、マナ+5 |
| 全体バフ | 全ユニットのステータス恒久上昇 | 血の暴走（全前列ATK+5） |
| マップ移動 | 警戒レベル上昇減少・ノード選択肢追加 | 警戒-1、レスト2回 |
| 経済 | Gold/SP獲得量倍率 | Gold+50%、SP+1 |
| デッキ操作 | カード除去コスト・圧縮効率 | 除去コスト半額 |
| バトル報酬 | カード選択肢数・レアリティ重み | 選択肢+1、Rare確率+20% |

## 3-3. プレイヤースキル30種企画案

### 階層1-3（共通スキル・10種）

#### 経済系（4種）
1. **黄金の触媒** - Gold獲得量+50%

4. **倹約家** - カード除去コスト-50%

#### マップ移動系（3種）

7. **冒険者の勘** - マップ分岐選択肢+1（MAX_CONNECTIONS 3→4）

#### バトル補助系（3種）
8. **マナの泉** - バトル開始時マナ+5
9. **時の恩恵** - バトル開始10秒間、全ユニットSPD+20%
10. **生命の祝福** - バトル開始時、全ユニットHP20%回復

### 階層4（クラス固有カード・9種）

#### バーサーカー（3種）

### 階層5（共通スキル・7種）

# 4. アーティファクト企画（要約）

詳細は `artifact_design_plan.md` 参照。

**基本方針**: ユニット・呪文を個別で強化

**30種の内訳**:
- 特性付与: 15種（飛行、貫通、群れ等をユニット1体に付与）
- スキル強化: 5種（吸血の牙、反撃の盾等）
- 合成促進: 4種（進化の触媒、融合の核）
- 基礎値上昇: 2種（種族全体バフ）
- カード個別強化: 2種（レアリティ昇華、英雄の証）
- Boss: 2種（世界樹の枝、ATLAS断片）

**スキルとの棲み分け**:
- スキル → 全体・システム
- アーティファクト → 個別・カード

# 5. 育成・やりこみ要素

## 5-1. 短期ループ（1ラン = 30-60分）

### フロー
```
Title → クラス選択 → 初期デッキ編成
  ↓
マップ選択（戦闘/ショップ/イベント/レスト/ボス）
  ↓ ループ
DeckPrep（配置決定） → Battle（観戦） → Result（カード選択）
  ↓
Boss撃破 → 次のAct or 完走
```

### 1ランの中での成長
- カード追加・合成（デッキ強化）
- アーティファクト獲得（個別強化）
- スキルポイント獲得（スキルツリー解放）
- Gold獲得（ショップで強化）

### リプレイ性の源泉
- 初期デッキランダム（3種×3枚）
- マップ分岐ランダム（StS風横ツリー）
- カード報酬ランダム（レアリティ重み）
- イベントランダム（20種以上）
- アーティファクトランダム（30種）

## 5-2. 中期ループ（完走 = スキルツリー1周）

### 完走時の引き継ぎ
- 全ユニットカード
- 全呪文カード
- 全アーティファクト
- 全スキルツリー解放状態

### 完走できない場合
- **何も引き継がれない**
- これが「完走に最大の価値」を生む設計

### 中期目標
- スキルツリー6階層全解放
- クラス固有★5ユニット解放（階層4・6）
- Boss専用アーティファクト獲得（完走の証）

## 5-3. 長期ループ（やりこみ要素）

### エンドコンテンツ
- **非同期PvP** - 完走ビルドの発表の場
- **高難度モード** - 警戒レベル初期値+3、Boss強化等
- **実績システム** - 「毒のみで完走」「ユニット9種縛り」等
- **ランキング** - 完走タイム、完走回数、警戒レベル最小等

### コレクション要素
- 全ユニット解放（約45体）
- 全アーティファクト獲得（30種）
- 全スキル解放（30種）
- 全イベント閲覧（20種以上）

### ビルド多様性
- クラス3種 × スキルツリー分岐 × アーティファクト30種 × ユニット45体
- 「毒貫通」「群れ突進」「不屈の壁」等のビルド名を考える楽しみ
