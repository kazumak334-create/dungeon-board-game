# アーティファクト（アーティファクト）システム企画案

作成日: 2026-04-11
ステータス: 企画案（承認待ち）

---

## 1. アーティファクトとは

**定義**: ラン中に入手するパッシブ効果アイテム（StSのアーティファクトと同様）

**コンセプト**: 
- 素材合成は廃止
- アーティファクトは「盤面設計の補助」と「観戦体験の強化」に特化
- 所持上限なし（複数効果の組み合わせで戦略の幅を広げる）

---

## 2. 入手方法

| 入手元 | レアリティ | 備考 |
|--------|----------|------|
| ボス撃破報酬 | Uncommon / Rare / Boss | 確定入手（3択から1つ選択） |
| ショップ | Common / Uncommon / Rare | Gold購入（在庫2-3個） |
| イベントノード | Common / Uncommon / Rare / Special | 選択肢報酬 |

**削除**: バトル勝利報酬、スキルツリー報酬からは入手不可

---

## 3. アーティファクト効果の分類

### 3.1 盤面強化系（パッシブバフ）
盤面のユニットを強化する常時効果。「設計した盤面が強くなる」

**例:**
- **鉄の護符**: 全ユニットHP+2
- **狂戦士の角笛**: 前列ユニットATK+1
- **賢者の瞳**: 後列ユニットSPD+1
- **血の契約**: 全ユニットATK+2、HP-1

### 3.2 マナ経済系
マナ生成・コスト管理を補助。「呪文をより多く打てる」

**例:**
- **魔石の欠片**: バトル開始時マナ+3
- **倹約の指輪**: 呪文コスト-1（最低1）
- **マナ晶石**: 3秒ごとにマナ+1
- **共鳴の水晶**: ユニット召喚時、追加マナ+1

### 3.3 戦術補助系
バトル中の特殊効果。「観戦中に思わぬ展開が生まれる」

**例:**
- **不死鳥の羽**: バトル中、最初の死亡ユニット1体がHP50%で復活
- **時の砂時計**: バトル開始10秒間、全ユニットSPD+2
- **影の外套**: 後列ユニットは前列が全滅するまでターゲットされない
- **戦場の太鼓**: 3ユニット以上同時に攻撃時、全員ATK+1

### 3.4 環境操作系
バトル開始時に盤面効果を配置。「盤面設計の一部を自動化」

**例:**
- **棘の種**: バトル開始時、自陣前列3マスに棘Lv1配置
- **聖域の石**: バトル開始時、自陣後列3マスに砦Lv1配置
- **呪いの人形**: バトル開始時、敵陣ランダム3マスに呪いLv1配置
- **毒霧の瓶**: バトル開始時、敵陣中列3マスに毒沼Lv1配置

### 3.5 リソース系
Gold・報酬を増やす経済効果。「ラン全体を有利にする」

**例:**
- **黄金のコイン**: バトル勝利Gold+20%
- **宝石商の眼鏡**: ショップ価格-15%
- **幸運のお守り**: バトル報酬選択肢+1（4択になる）
- **経験の書**: スキルツリー報酬SP+1

### 3.6 戦略特化系
特定の戦略を強化する尖った効果。「ビルドの方向性を決める」

**例:**
- **突撃の旗**: 同じ行に3ユニット配置時、その行全体ATK+2
- **守護の盾**: 全列に均等配置時（各列3体）、全ユニットHP+3
- **呪術師の杖**: 呪文デッキ3スロットすべて異なる呪文時、呪文効果+30%
- **合体の触媒**: 盤面合体時、合体後ユニットHP+5

### 3.7 ボスアーティファクト（トレードオフあり）
強力だがデメリット付き。「リスクとリターンの選択」

**例:**
- **血の王冠**: 全ユニットATK+3、SPD+1 / 本体HP半減
- **混沌の指輪**: バトル開始時、自陣配置がランダムシャッフル / 全ユニットHP+5
- **絶望の仮面**: 前列全滅時、残りユニット全員ATK+5 / 復活効果無効
- **時間泥棒**: バトル制限時間-30秒 / Gold報酬+100%

### 3.8 イベント専用アーティファクト（特殊）
イベントでのみ入手可能な記憶の欠片的な効果。「世界観を匂わせる」

**例:**
- **ATLAS破片α**: 本体HP+10 / フレーバー「灰色の疫病以前の記憶」
- **グリッチコア**: バトル中、5%の確率でUI演出発生 / 効果なし
- **記憶の鍵**: イベント選択肢が1つ増える / 「封印された記録へのアクセス」
- **実験体の札**: 盤面配置がロックされない / 「被験者番号#2891」

## 4. レアリティ設計

| レアリティ | 効果規模 | 入手頻度 | 例 |
|----------|---------|---------|-----|
| Common | 小規模バフ・単純効果 | 高 | 鉄の護符、魔石の欠片 |
| Uncommon | 中規模バフ・条件付き効果 | 中 | 不死鳥の羽、棘の種 |
| Rare | 大規模バフ・戦略変化 | 低 | 突撃の旗、幸運のお守り |
| Boss | トレードオフ付き強力効果 | ボス撃破時のみ | 血の王冠、混沌の指輪 |
| Event | 世界観・特殊効果 | イベント限定 | ATLAS破片α、グリッチコア |

## 5. アーティファクト管理UI

### 5.1 DeckPrep画面
- 左パネル「所持情報」に「アーティファクト: X個」表示
- 新規タブ不要（アーティファクトは自動発動のため配置不要）
- クリックで所持アーティファクト一覧ポップアップ表示

### 5.2 バトル画面
- 画面右上に所持アーティファクトアイコン（16×16）を横並び表示
- ホバーで効果説明ツールチップ表示
- 発動時に軽くグロー演出（視覚フィードバック）

### 5.3 Inventory画面（持ち物画面）
- 「アーティファクト」タブ追加（装備・素材タブを削除）
- 所持アーティファクト一覧をグリッド表示
- 各アーティファクトの効果説明を常時表示
