# タイトル画面 UI/UX企画書

## 1. 画面の目的

- プレイヤーに「このゲームが何か」を3秒で伝える
- クラスを選択し、ゲームを開始する導線を提供する
- 世界観（ダークファンタジー + 無機質な整合性）の第一印象を与える

現状の問題点:
- Title.tscnはほぼ空のControlノードのみ。全UIがTitle.gdのコードで動的生成されている
- クラス選択カードが横並びで情報過多（マナ上限・リジェネ・説明文が全部見える）
- タイトルロゴがプレーンテキスト。世界観の匂わせがゼロ
- 開発者モード・テスト実行ボタンが常に表示されている

## 3. 色彩設計

既存DeckPrep.gdのカラーパレットに準拠し統一する。

| 定数名 | 値 | 用途 |
|--------|-----|------|
| COLOR_BG | Color(0.08, 0.08, 0.12) | 画面背景（背景画像がない場合のフォールバック） |
| COLOR_PANEL | Color(0.13, 0.13, 0.2) | クラスカードパネル背景 |
| COLOR_PANEL_DARK | Color(0.07, 0.07, 0.11) | 説明エリア背景 |
| COLOR_BORDER | Color(0.3, 0.3, 0.4) | カード枠線（非選択） |
| COLOR_SELECTED | Color(0.9, 0.75, 0.3) | 選択中カード枠線・出発ボタン枠線 |
| COLOR_TITLE | Color(0.9, 0.85, 0.6) | タイトルテキスト・クラス名 |
| COLOR_TEXT | Color(0.8, 0.8, 0.8) | 通常テキスト |
| COLOR_DIM | Color(0.5, 0.5, 0.5) | 非選択クラス名・バージョン表記 |
| COLOR_SUBTITLE | Color(0.6, 0.55, 0.4) | サブタイトル文字 |
| COLOR_BTN_BG | Color(0.18, 0.16, 0.1) | 出発ボタン背景 |
| COLOR_BTN_HOVER | Color(0.25, 0.22, 0.12) | 出発ボタンホバー時 |
| COLOR_OVERLAY | Color(0, 0, 0, 0.4) | 背景画像の上にかけるオーバーレイ |

### 背景画像の扱い

背景画像の上に半透明の暗いオーバーレイ(COLOR_OVERLAY)を重ね、その上にUIを配置する。背景画像がなくてもCOLOR_BGが見えるのでUIは成立する。

### 4.3 クラス選択カード

HBoxContainer配置。中央寄せ。

| コンポーネント | 型 | 位置 | サイズ | 備考 |
|---|---|---|---|---|
| class_container | HBoxContainer | (165,240) | 950x220 | separation=30 |
| class_card_N | PanelContainer | 自動 | 280x220 | 各クラスカード |

各クラスカード内部構成:

```
PanelContainer (280x220)
  ├─ VBoxContainer
  │   ├─ クラスアイコン (TextureRect) 80x80 中央揃え
  │   │   → 画像なし時はColorRect(0.12, 0.12, 0.18)でプレースホルダ
  │   ├─ クラス名 (Label) trajan.ttf 20pt COLOR_TITLE 中央揃え
  │   ├─ セパレータ (HSeparator) Color(0.25, 0.28, 0.35)
  │   └─ 一行説明 (Label) 14pt COLOR_TEXT 中央揃え 最大2行
```

**現状からの変更: マナ上限・リジェネ表示をカード内から削除。** 情報過多を避け、選択後の説明エリアで詳細を見せる。

## 6. インタラクション

### 6.1 クラス選択
- クリック: カード枠線がCOLOR_SELECTED(金色)に変化、border_width=3
- 非選択カード: 枠線COLOR_BORDER、border_width=2
- 選択時: 説明エリアにクラス説明+パッシブスキルが表示される

### 6.2 ホバー
- クラスカード: パネル背景がわずかに明るくなる Color(0.16, 0.16, 0.24)
- 出発ボタン: COLOR_BTN_HOVER + border_width=3

### 6.3 出発ボタン
- クラス選択済み: 通常表示、クリックでMATERIAL_SELECT画面へ遷移
- クラス未選択: disabled状態、半透明

### 6.4 アニメーション（最小限）

| 対象 | 演出 | 方法 |
|---|---|---|
| タイトルロゴ | フェードイン | Tween alpha 0→1, 0.8秒 |
| サブタイトル | 遅延フェードイン | Tween alpha 0→1, 0.5秒, delay 0.5秒 |
| クラスカード群 | 下からスライドイン | Tween position.y +30→0 + alpha 0→1, 0.4秒, delay 0.8秒 |
| 出発ボタン | 遅延フェードイン | Tween alpha 0→1, 0.3秒, delay 1.2秒 |

全アニメーションは初回表示時のみ。画面戻り時はアニメーションなしで即表示。

## 8. UI基準チェック

| 基準 | 評価 | 根拠 |
|---|---|---|
| 3秒ルール | OK | ロゴ→3つのクラスカード→出発ボタンの一本道。3秒で「クラスを選んで始める」と分かる |
| 視線の一本化 | OK | 上→下の垂直一方向。横方向はクラス選択の3択のみ |
| 状態の可視化 | OK | 選択中クラスは金色枠。未選択時は出発ボタンが半透明disabled |
| 操作の最小化 | OK | クラス1クリック→出発1クリックの計2クリック |
| 配信映え | OK | ロゴ+背景画像+フェードイン演出で「何のゲームか」が視聴者にも伝わる |
| 世界観の匂わせ | OK | ダークな背景+金色アクセント+ビネット。無機質に整った配置。説明しすぎない |
