## 1. 1ランの全体構造

```
1ラン = Act1 → Act2 → Act3
1Act  = BW1 + BW2 + BW3 + BW4(ボス)
1BW   = SW2本（SW1 → SW2）
```

**合計**: 3Act × 4BW × 2SW = 24バトル（ボス含む）

### BW4（ボス）の扱い
- SW1 = ボスPhase1
- SW2 = ボスPhase2（連戦）
- BW4完了 = Actクリア

## 2. 画面遷移フロー

```
タイトル
  ↓
クラス選択
  ↓
DeckPrep（初回：ユニット配置・呪文デッキ組み）
  ↓
【バトルループ】
  ↓ SW勝利
  報酬選択（盤面スクラッチ）         ← 毎SW後
  ↓ BW完了（SW2勝利）時のみ
  ショップ（RestScreen）
  DeckPrep（盤面再設計・デッキ編集）
  ↓ BW4（ボス）完了 = Actクリア
  Actクリア演出 → 次Act DeckPrep → バトルループへ
  ↓ Act3 BW4完了 = 完走
  完走画面
  ↓ 敗北
  Game Over画面
```

## 3. バトル画面フロー

### 3-1. バトル開始

```
DeckPrep「バトル開始」
  ↓
バトル画面フェードイン（0.3秒）
  自陣: 配置済み・静止
  敵陣: 配置済み・静止
  ↓
「WAVE X-X」テキスト表示（1.5秒）
  ※ X-X = BW番号-SW番号（例: WAVE 1-1）
  ↓
テキストフェードアウト → 戦闘開始
```

### 3-2. SW勝利（同BW内・次SWへ）

```
勝利判定
  ↓
敵ユニット フェードアウト（0.5秒）    ← 先にフェードアウト
  ↓
「VICTORY!」表示（1.5秒）
  ↓
報酬選択画面（盤面スクラッチ）へ遷移
  ↓ 選択完了
  【BW内次SWあり（SW1→SW2）】
    DeckPrepなし
    「WAVE X-X」テキスト（1秒）
    新敵 スライドイン（右から 0.4秒）
    戦闘再開（プレイヤー盤面はHP・状態引継ぎ）
  【BW完了（SW2勝利）かつBW4未満】
    ショップ（RestScreen）→ DeckPrep → バトル開始
  【BW4（ボス）完了 = Actクリア】
    Actクリア演出 → DeckPrep → バトル開始（次Act）
```

### 3-3. Wave表示フォーマット

```
「WAVE 1-1」 = Act内BW1 SW1（最初の戦い）
「WAVE 1-2」 = Act内BW1 SW2（BW1最終戦 → 勝てばショップ）
「WAVE 4-1」 = ボスPhase1
「WAVE 4-2」 = ボスPhase2（勝てばActクリア）
```

表示スタイル: 画面中央・大文字・ゴールド系カラー・1.5秒でフェードアウト

### 3-4. 敗北

```
敗北判定
  ↓
「GAME OVER」表示（3秒）
  ↓
Game Over画面へ遷移
```

## 4. 勝敗条件

| 条件 | 種別 |
|---|---|
| 敵の前列・中列が全滅 | **勝利** |
| 敵の1行が全滅 | **勝利** |
| 自陣の前列・中列が全滅 | **敗北** |
| 自陣の1行が全滅 | **敗北** |
| 制限時間 | **廃止** |

## 5. 呪文システム

### 5-1. スロット構成

```
呪文スロット（3枠）
  ├ 左クリック → 発動（マナ消費・条件チェック・キャストゲージチェック）
  ├ 右クリック → 捨て札 → 即座に次の呪文をドロー
  └ 空スロット → 自動ドロー
        デッキ切れ → 捨て札をシャッフルして再利用
```

### 5-2. 発動条件（全部満たすと発動可能）

1. スロットに呪文がある
2. マナ ≥ 呪文コスト
3. 発動条件（常時/前列崩壊時 等）を満たす
4. **キャストゲージが0**（クールダウン完了）

### 5-3. キャストゲージ（グローバルクールダウン）

```
呪文を発動 → キャストタイマーを interval にセット
_process(delta): タイマー -= delta（0以下でクランプ）
発動可否: タイマー == 0 かつ他の条件を満たす

ratio = 1.0 - (timer / max(0.01, interval))
  → ratio=1.0: 発動可（満タン）
  → ratio=0.0: クールダウン中（空）

interval（初期値）: 未定（要調整。例: 5秒）
UIゲージ: 呪文スロット上部に横棒で表示
```

### 5-4. マナ

```
最大値 = 配置ユニットの総コスト
生成  = ユニットの攻撃・サポート発動時
UIゲージ: ヘッダーエリアに表示（実装済み）
```

## 6. 素材ドロップシステム

### 6-1. バトル中のドロップ

```
敵ユニット死亡 → 素材を自動取得（全て・選択不要）
  例) スライム撃破 → 「スライムの核」+1
      Fangos撃破  → 「獣の牙」+1

UIへの表示: 小さいドロップエフェクト（実装後検討）
```

### 6-2. 素材の用途

| 場所 | できること |
|---|---|
| ショップ（RestScreen） | 売る（gold換算）のみ |
| DeckPrep / 合成 | 合成素材として使用（将来実装） |

## 7. 報酬選択（盤面スクラッチ）

```
SW/BW勝利後に表示
9マスのグリッドにカード・呪文・アーティファクトが並ぶ
プレイヤーは3枚選択して手持ちに加える

※素材ドロップとは独立（スクラッチ外で自動取得済み）
※選択枚数は3（暫定・後で調整）
```

---

## 8. DeckPrep（Act間・BWクリア後）

```
左: 手持ちカード（ユニット・呪文タブ切替）
中: 3×3盤面（ドラッグ配置）
右: 呪文デッキ枠

盤面Mana ≥ 呪文デッキ総コストでないと「バトル開始」不可
「バトル開始」→ バトル画面へ
```
