## 1. 目的と位置付け

### 1.1 Designerとして本Sprintで担う領域

Sprint 9は「バトルごとの成長報酬を見せる」フェーズである。Designerは以下5つの新規UIを既存EconMain.gdの世界観に同居させる責務を負う。

| 新規UI | 表示タイミング | 既存UIとの関係 |
|---|---|---|
| 初期難易度選択UI | バトル開始前 | バトル準備フェーズに挿入 |
| マイルストーン提示UI | バトル中・常時表示 | フッター帯（180px）に常設 |
| マイルストーン即時報酬演出 | バトル中 | 中難度達成時の即時フラッシュ |
| 宝箱即時報酬演出 | バトル中 | 宝箱隣接建設時の即時フラッシュ |
| バトル後カード報酬選択UI | バトル後 | 全画面オーバーレイ |
| 土地カード配置モード | バトル後（土地カード選択時） | 盤面に重畳 |

### 1.2 核となる体験との整合確認

> 「盤面を設計して、介入を仕込んで、答え合わせを観戦する」

- 報酬は **「次の盤面設計の素材」** として位置付ける（足し算ではなく、盤面再設計の選択肢）
- マイルストーンは **「介入の指針」** として表示する（プレイヤーが何を狙うかの明確化）
- 即時報酬演出はバトル進行を止めない（観戦体験を損なわない）

### 1.3 KISS原則の遵守

- 8系統 × 3難易度 = 24マイルストーンを **常時全表示しない**（情報過多になる）
- 既存フッター帯（180px）の **空き枠を再利用** することを優先
- 新規パネル・新規色は最小限とする

## 3. 画面フロー

### 3.1 バトル開始前（初期難易度選択）

```
ラン開始
  ↓
[初期難易度選択UI]
  低 / 中 / 高 を3択カードで提示
  - 低: +100G（緑系強調）
  - 中: ±0G（標準）
  - 高: -100G（赤系強調）
  ↓
8系統 × 3段階のマイルストーン自動生成
  ↓
バトル開始
```

### 3.2 バトル中

```
バトル中
  ↓
FOOTER右160pxにマイルストーン進捗を縮約表示
  ↓
中難度マイルストーン達成 → 盤面中央に即時報酬テロップ（1.5秒フェード）
  ↓
宝箱隣接に建設 → 宝箱位置から光のパーティクル + 即時報酬テロップ
  ↓
特殊マイルストーン追加 → FOOTER右下に [+] バッジで通知
  ↓
バトル終了
```

### 3.3 バトル後（報酬提示）

```
バトル終了
  ↓
達成マイルストーン一覧（達成系統数を上に小さく表示）
  ↓
通常マイルストーン報酬 1個目 → 3択選択UI（or SKIP）
  ↓
... 達成数だけ繰り返し
  ↓
特殊マイルストーン報酬（あれば）→ 3択選択UI
  ↓
土地カードを選択した場合 → [配置モード]へ遷移
  ↓
全報酬処理完了 → 次バトル準備フェーズへ
```

## 4. マイルストーン報酬UI詳細

### 4.1 提示方式

#### バトル中の常時表示（FOOTER右160px枠）

```
┌──────────────────┐
│ — MILESTONE —    │  10px ヘッダー
│ POP   ▓░░ 12/30 │  人口系（一番進捗近い1系統）
│ FOOD  ▓▓░ 8/10  │  食料系
│ ...              │
│ +1 SPECIAL       │  特殊マイルストーン追加バッジ
└──────────────────┘
```

- **常時表示するのは進捗が近い上位3系統**（情報過多防止）
- 残り5系統はホバーで全表示（任意）
- 各行: 系統名 (3-4文字大文字略称) + 進捗バー (3segment) + 数値

#### バトル後の選択UI

3択カード形式（既存 BUILD カード形状を流用）:

```
┌──────┐ ┌──────┐ ┌──────┐
│ ICON │ │ ICON │ │ ICON │
│ 名称 │ │ 名称 │ │ 名称 │
│ 説明 │ │ 説明 │ │ 説明 │
│      │ │      │ │      │
└──────┘ └──────┘ └──────┘
   220×280  220×280  220×280
            [SKIP]
```

カードサイズ: 220 × 280（BUILDカード 92×140 の2倍超を新規定義）
カード間スペース: 24px
配置: 画面中央（x: 320–960, y: 200–480）

### 4.2 選択肢表現（カード種別の見分け）

| カード種別 | ボーダー色 | 背景色 | アイコン |
|---|---|---|---|
| 通常建物カード | `COLOR_BORDER` (#3C3628) | `COLOR_PANEL` (#231F1B) | 既存建物アイコン (⚔ 🛡 ⚒ ⌂) |
| 特殊建物カード | `COLOR_ACCENT_GOLD` (#B49448) 1px | `COLOR_PANEL` | 既存建物アイコン + 右上に星マーク |
| 政策カード | `#5D8FB8` (POP色流用) 1px | `COLOR_PANEL` | 巻物アイコン (📜) |
| 偉人カード | `#B89AC7` (SAT色流用) 1px | `COLOR_PANEL` | 王冠アイコン (♛) |
| 土地カード | `#3F6932` (WOOD色流用) 1px | `COLOR_PANEL` | 大地アイコン (◈) + 資源タグ |

> **判断基準:** カード種別ごとに色を増やさず、**既存の8色定数を使い回す**。新規色追加禁止（KISS原則）。

### 4.3 ビジュアル詳細

#### 報酬カード本体レイアウト（220 × 280）

```
┌──────────────────┐
│  [TYPE BADGE]    │  16px ヘッダー（"通常建物" / "特殊" / "政策" / "偉人" / "土地"）
├──────────────────┤
│                  │
│      ICON        │  120px アイコン領域（中央）
│      48px        │
│                  │
├──────────────────┤
│ カード名          │  20px タイトル (font_size=16, Bold)
│ ─────────        │
│ 説明文1行目       │  説明文 (font_size=11, Regular)
│ 説明文2行目       │
│                  │
│ COST: 20W·10S   │  コスト (font_size=10, COLOR_TEXT_DIM)
└──────────────────┘
```

#### SKIPボタン

- 配置: 3カードの下、中央 (x: 600, y: 510)
- サイズ: 80 × 32
- スタイル: 透明背景 + `COLOR_TEXT_DIM` ボーダー1px + テキスト "SKIP" (font_size=12, COLOR_TEXT_DIM)
- ホバー: ボーダーが `COLOR_TEXT` に変化、テキストも同色

## 5. 土地カード配置UI詳細

### 5.1 配置モードエントリー

土地カードを報酬選択した瞬間：

```
報酬選択UI（オーバーレイ）が消える
  ↓
盤面のみ表示状態へ移行（HEADER/FOOTERは半透明 α=0.4）
  ↓
盤面上部に通知バナーが上からスライドイン（300ms）
   "土地カードを自建物隣接マスへ配置してください"
  ↓
配置可能マスがハイライト表示（緑の枠線アニメーション）
```

### 5.2 配置フロー

#### 5.2.1 配置可能マスの可視化

| 状態 | 表現 |
|---|---|
| 配置可能（自建物隣接・未建設土地） | 枠線 `#3F6932` (WOOD色) 2px + パルスアニメーション（α 0.5↔1.0、1.0sサイクル） |
| 配置不可（自建物非隣接） | 枠線なし（通常表示） |
| 配置不可（建設予定地・建設後パネル） | 枠線 `#9C3A2A` (RED色) 1px + α=0.3 で暗転 |
| ホバー中の配置可能マス | 枠線 `COLOR_ACCENT_GOLD` 3px に強調 |

#### 5.2.2 マスクリック時の挙動

```
配置可能マスをクリック
  ↓
土地カードが選択マスにフェードイン（200ms）
  ↓
資源タグ・資源値が小さくマス上に表示
  ↓
配置確定（自動）
  ↓
通知バナー消去・HEADER/FOOTERのα復帰
  ↓
次の報酬処理へ
```

#### 5.2.3 配置不可ケースの扱い

| ケース | 挙動 |
|---|---|
| 配置可能マスが0個（特殊状況） | 土地カードを **3択提示時点で選択不可表示**（α=0.5、ホバーでツールチップ「配置可能マスなし」） |
| 不可マスをクリック | 何も起きない（クリック非反応）+ 一瞬画面端に "配置不可" 文字をフラッシュ表示（500ms） |

### 5.3 キャンセル・確定操作

#### MVP方針: キャンセル不可

- 一度報酬選択した土地カードはキャンセル不可
- 配置確定は **マスクリックのみ**（ドラッグ操作なし、確定ボタンなし）
- 操作の最小化原則（クリック1回で完結）

> **判断:** ドラッグ操作は誤操作リスクが大きく、選択型（マスクリック）の方が直感的。Mechabellumの建物配置と同形式。

## 6. 宝箱即時報酬演出

### 6.1 宝箱の盤面表示

宝箱はUIではなく **盤面上の固定アイコン** として配置（企画書 §12 準拠）。

| 項目 | 仕様 |
|---|---|
| アイコン | ⛁ または木箱風アイコン (24×24) |
| 配置色 | `COLOR_ACCENT_GOLD` (#B49448) ベース、未取得時は通常輝度 |
| 配置位置 | バトル開始時に3つ配置（自軍中距離2、中央/遠距離1） |

### 6.2 演出タイミング

```
宝箱に隣接するパネルへ建設開始
  ↓
建設完了時点で自動取得
  ↓
[演出開始 — 全体所要時間 約2秒]
  ↓
宝箱アイコンから金色パーティクル放射（500ms）
  ↓
画面中央上部にテロップ表示（1500ms フェード）
  "CHEST OBTAINED"
  + 宝箱即時報酬内容（例: "木 +5"）
  + 特殊マイルストーン追加通知（例: "+1 SPECIAL MILESTONE"）
  ↓
宝箱アイコン消滅（フェードアウト 300ms）
  ↓
FOOTER右マイルストーン枠の特殊バッジ更新
```

### 6.3 表現方法

#### テロップデザイン

```
┌──────────────────────────────────┐
│  CHEST OBTAINED                  │  font_size=16, COLOR_ACCENT_GOLD
│  ─────────────                  │
│  木 +5                            │  font_size=14, COLOR_TEXT
│  +1 SPECIAL MILESTONE            │  font_size=12, COLOR_ACCENT_GOLD
└──────────────────────────────────┘
   配置: 盤面中央上部 (x: 中央, y: 100)
   背景: COLOR_PANEL with α=0.85
   ボーダー: COLOR_ACCENT_GOLD 1px
```

#### 中難度即時報酬テロップ（マイルストーン達成時）

宝箱演出と同じ形式を流用、文字色のみ系統色を反映:

```
┌──────────────────────────────────┐
│  POPULATION MILESTONE            │  系統名（POP色 #5D8FB8）
│  人口 +10                         │  即時報酬内容
└──────────────────────────────────┘
```

> **判断:** 演出を統一形式にすることで、視聴者が3秒で「何かいいことが起きた」と把握できる（配信映え）。

## 7. 3秒ルール検証

### 7.1 各UI要素の理解度チェック

| UI要素 | 3秒で伝わるか | 根拠 |
|---|---|---|
| 初期難易度選択 | ◎ | 3択カード+ 通貨増減数値で即理解 |
| マイルストーン進捗（FOOTER常時） | ◯ | 上位3系統に絞ったため情報過多にならない、進捗バーで一目 |
| マイルストーン即時報酬テロップ | ◎ | 系統名+ 数値の2行で完結 |
| 宝箱取得演出 | ◎ | "CHEST OBTAINED" + パーティクルで明確 |
| バトル後カード報酬選択 | ◎ | 既存BUILDカード形状継承、3択+ SKIPの最小構成 |
| 土地カード配置モード | ◎ | 配置可能マスがパルスで明示、クリック1回で完結 |
| カード種別判別 | ◯ | ボーダー色 + アイコン + TYPE BADGEの3重表現で識別可能 |

### 7.2 視線の一本化チェック

| シーン | 注意点が一本化されているか |
|---|---|
| バトル中 | ◯ 盤面（メイン）+ FOOTER左から右への配分→建設→マイルストーン進捗 |
| 即時報酬発生時 | ◎ 盤面中央上部のテロップ1点に集約 |
| バトル後報酬選択 | ◎ 半透明オーバーレイで他UIを暗転、3択カードに集中 |
| 土地カード配置中 | ◯ HEADER/FOOTER暗転、盤面のハイライトマスに集中 |

### 7.3 状態の可視化チェック

| 状態 | 可視化方法 |
|---|---|
| マイルストーン未達 | 進捗バー部分塗り |
| マイルストーン達成 | 進捗バー満タン+ 達成色（COLOR_ACCENT_GOLD）に変化 |
| 特殊マイルストーン追加 | FOOTER右下に [+1] バッジ点滅 |
| 宝箱未取得 | 通常輝度 |
| 宝箱取得済 | アイコン消滅 |
| 配置可能マス（土地カード時） | パルスアニメーション |
| 配置不可カード | カード自体がα=0.5で暗くなる |

## 9. 残論点・次フェーズ

### 9.1 Designer視点の残論点（要件定義フェーズで確定）

| 項目 | 残論点 | 推奨判断 |
|---|---|---|
| マイルストーン進捗UIの常時表示数 | 上位3系統 vs 全8系統 | **上位3系統 + ホバーで全表示** を推奨（情報過多防止） |
| 土地カード配置のキャンセル | 可 vs 不可 | **不可** を推奨（操作最小化、選択時に確定済み扱い） |
| 報酬カードの大きさ | 220×280 vs 既存BUILDカード流用 (92×140) | **220×280 新規** を推奨（バトル中BUILDカードと役割が異なるため大きく） |
| 土地カード配置時の操作方式 | ドラッグ vs 選択型 | **選択型（マスクリック）** を推奨（誤操作リスク低・KISS） |
| 特殊マイルストーン即時視覚フィードバック | 派手な演出 vs 控えめ | **控えめ（FOOTER右バッジ + 音のみ）** を推奨。バトル中の視線分散を避ける |
| 報酬スキップ時の画面状態 | スキップボタン位置 | **3カード下中央** を推奨（既存UIに合わせる） |
| 達成マイルストーン一覧表示 | 必要 vs 不要 | **不要** を推奨（即時に報酬選択へ進む方がテンポ良し） |
| 中難度即時報酬の系統色 | 8色 vs 統一GOLD | **8系統別色を流用**（既存COLOR_*から選択、新規追加なし） |

### 9.3 要件定義書に渡す確定事項リスト

Architect が要件定義書を起こす際の **Designer承認済み事項**:

1. **新規UI座標・サイズ**:
   - FOOTER右マイルストーン枠: 160 × 180 (既存PLACE-ON-BOARD領域転用)
   - バトル後報酬カード: 220 × 280、3枚横並び、間隔24px
   - 土地カード配置時の通知バナー: 1280 × 48、上部スライドイン

2. **使用する色定数**:
   - 既存EconMain.gdの `COLOR_*` 定数のみ
   - 新規色定義は **追加しない**

3. **アニメーション仕様**:
   - 報酬オーバーレイフェードイン: 300ms
   - 配置可能マスパルス: 1.0sサイクル（α 0.5↔1.0）
   - 即時報酬テロップ: 1500ms (in 200ms / hold 1000ms / out 300ms)
   - 宝箱パーティクル: 500ms

4. **インタラクション**:
   - 報酬選択: 1クリックで確定（追加確認なし）
   - 土地カード配置: 1クリックで確定（ドラッグなし、キャンセル不可）
   - SKIP: 3カード下のSKIPボタン1クリック
   - マイルストーン進捗: ホバーで詳細展開（任意）

5. **状態の可視化ルール**:
   - 達成済みマイルストーン: 進捗バーが `COLOR_ACCENT_GOLD` で満タン
   - 特殊マイルストーン追加: `[+N]` バッジで通知
   - 配置不可カード: α=0.5 + ツールチップ
   - 配置不可マス: `COLOR_RED` 1px枠 + α=0.3

## 10. UI基準6項目チェック（最終）

| # | 基準 | 評価 | 根拠 |
|---|---|---|---|
| 1 | **3秒ルール** | ◎ | 報酬選択は3カード+SKIP、テロップは2行、配置はパルス枠で即理解 |
| 2 | **視線の一本化** | ◎ | 報酬選択はオーバーレイで他UI暗転、配置時はHEADER/FOOTER暗転 |
| 3 | **状態の可視化** | ◎ | 進捗バー・バッジ・α変化・色変化で全状態を可視化 |
| 4 | **操作の最小化** | ◎ | 報酬選択1クリック、配置1クリック、ドラッグ・確認ダイアログなし |
| 5 | **配信映え** | ◎ | 「CHEST OBTAINED」「MILESTONE」テロップで視聴者が3秒で達成を把握 |
| 6 | **世界観の匂わせ** | ◎ | 既存色定数のみ使用、装飾線・大文字英字・記号アイコン継承、説明的ツールチップなし |

**総合: 6項目すべて合格水準**
