# 用語定義

## 盤面構造

### 基本構造
- 自・敵それぞれ3×3の計6×3
- 列：前列・中列・後列（相手側に近い順）
- 行：上行・中行・下行

### 対象の指定方法
- 枕詞なし → 全体（自・敵含む6×3）
- 自/敵 → どちらかの3×3
- 自前列/敵前列 → 特定の列（3マス）
- 自上行/敵上行 → 特定の行（自陣・敵陣それぞれ1マス）
- 自同列 → 自陣の同じ列（前中後）・3マス
- 敵同列 → 敵陣の同じ列（前中後）・3マス
- 自同行 → 自陣の同じ行（上中下）・3マス
- 敵同行 → 敵陣の同じ行（上中下）・3マス
- 同行 → 自・敵含む同じ行・6マス
- 前マス → 自分より前列側の同行の1マス
- 後マス → 自分より後列側の同行の1マス
- 周辺 → 周囲8マス（盤面端の場合は存在するマスのみ対象）

---

## カード・ユニット

- **ユニットカード**：デッキ段階のカード
- **ユニット**：盤面に配置された状態のもの
- **デッキ**：呪文デッキのみを指す

---

## ゲームシステム

- **盤面**：自・敵含む6×3全体
- **配置**：ユニットを盤面の特定マスに置くこと
- **初期配置**：バトル開始時の9マス配置
- **撃破**：ユニットのHPが0になること
- **波及**：異常状態が別のユニットに広がること
- **蓄積**：スタックと同義
- **付与**：一時的・永続どちらも含む
- **トリガー**：効果の発動条件
- **発動**：効果が実行される瞬間
- **召喚**：現在未使用（将来的にマナ消費でユニットを配置する機能として保留）

---

## トリガーの種類（実装完全版）

### 基本トリガー（ユニット行動）

| 実装名 | 日本語名 | 発動タイミング |
|---|---|---|
| `on_attack` | 攻撃時 | ユニットが攻撃を行った瞬間 |
| `on_front_attack` | 前列攻撃時 | 前列配置時に攻撃を行った瞬間 |
| `on_hit` | 命中時 | 攻撃が敵に命中した瞬間 |
| `on_damaged` | 被攻撃時 | ユニットが攻撃を受けた瞬間 |

### 状態変化トリガー

| 実装名 | 日本語名 | 発動タイミング |
|---|---|---|
| `on_summon` | 召喚時 | ユニットが盤面に配置された瞬間（初期配置含む・復活除く） |
| `on_unit_placed` | 配置時 | on_summonと同義（統一推奨） |
| `on_death` | 死亡時 | ユニットのHPが0になった瞬間 |
| `on_ally_death` | 味方死亡時 | 同陣営のユニットが死亡した瞬間 |
| `on_unit_died_ally` | 味方死亡時 | on_ally_deathと同義（統一推奨） |
| `on_synthesis` | 合成時 | 盤面合成が発生した瞬間 |

### 効果発動トリガー

| 実装名 | 日本語名 | 発動タイミング |
|---|---|---|
| `on_play` | 呪文発動時 | 呪文カードが発動された瞬間 |
| `on_support` | サポート発動時 | サポート効果が発動された瞬間（SPD依存） |
| `battle_start` | バトル開始時 | バトル開始の瞬間のみ1回 |

### 常時・時間トリガー

| 実装名 | 日本語名 | 発動タイミング |
|---|---|---|
| `always` | 常時 | 条件なく常に有効 |
| `passive` | パッシブ | alwaysと同義（統一推奨） |
| `timer` | 時間経過 | 一定時間ごとに発動 |

### トリガー統一ルール

**同義語の統一推奨：**
- `on_summon` ← 推奨、`on_unit_placed` は非推奨
- `on_ally_death` ← 推奨、`on_unit_died_ally` は非推奨
- `always` ← 推奨、`passive` は非推奨

**復活時の扱い：**
- 復活時は `on_summon` トリガーは発動しない
- 復活専用トリガーは現在未実装（必要なら `on_revive` を追加）

## カード効果の種類

### 前列能力
- **定義**：前列配置時のみ有効・攻撃時トリガーで発動
- **対応トリガー**：`on_front_attack`
- **特徴**：前列から中列・後列に移動すると無効化

### サポート効果
- **定義**：中列・後列配置時に有効・SPDに応じた頻度で発動
- **対応トリガー**：`on_support`
- **特徴**：SPD値に応じた間隔で自動発動・前列に移動すると無効化

### 特性
- **定義**：常時発動パッシブ・配置列に関わらず有効
- **対応トリガー**：`always` / `passive`
- **特徴**：条件なく常に有効・配置列の影響を受けない

### その他の効果
- **呪文効果**：`on_play` トリガーで発動
- **命中時効果**：`on_hit` トリガーで発動（前列能力とは別）
- **被攻撃時効果**：`on_damaged` トリガーで発動
- **死亡時効果**：`on_death` トリガーで発動
- **時間経過効果**：`timer` トリガーで発動

## 呪文システム（キュー式）

### 基本仕様
- **キュー3枠式**：呪文を3枠のキューに並べる
- **先頭から順次処理**：先頭から順に条件が揃ったら自動発動
- **無限待機**：条件が揃わない場合は無限に待機（タイムアウトなし）
- **手動操作**：「捨てる」操作のみ可能（PvE・PvP共通）

### 捨て挙動

| 種類 | 挙動 |
|------|------|
| 通常 | 捨て札→再循環 |
| 消滅型 | 捨てたら消える（カード特性） |

### 待機制約（戦略性）

**強力なカードへの制約候補：**
- 待機時間制限（`max_wait_time`）
- 捨てる操作の禁止（`cannot_discard`）
- 捨てるコスト（`discard_cost`）

※ 具体的な制約設計は未確定（docs/design/pve_wave_pending_issues.md参照）

---

## 注意
- 対象を指定する際は必ず枕詞（自/敵）を使う。枕詞がない場合は全体（6×3）を指す
- 位置関係を示す言葉は定義に沿って使う。混同しやすいので注意
- トリガー名は実装名（英語）を使用。日本語名は説明用
- 同義語トリガーは推奨形式に統一することを推奨（破壊的変更なので慎重に）
