# 素材入手設計・ドロップテーブルリサーチ

> 対象：開発中のリアルタイム盤面カードゲーム（素材レアリティ設計・ドロップテーブル構築の参考）
> 作成日：2026-04-06

---

## 1. ゲーム別の素材入手設計

### モンスターハンター

**レアリティ区分：** コモン（60-80%）/ レア（10-20%）/ 超レア（1-3%）/ 天鱗等（0.5-1%）

**入手方法：**
- 通常ドロップ（剥ぎ取り）：部位ごとに独立した確率テーブル
- **部位破壊ボーナス：** 特定部位を壊すと専用テーブルへ切り替わり、限定素材が確率ドロップ。これが「周回の動機」を作る核心
- クエスト報酬：クリア時に固定+確率の2段階
- 捕獲ボーナス：捕獲すると剥ぎ取り枠より良テーブルが適用される

**設計思想：**
- ドロップ枠が3-5つあり、各枠で独立抽選 → 同一素材を複数枚引ける
- 部位破壊は「確定ではなく確率向上」として設計（天鱗は破壊でも1-3%止まり）
- 「運が絡む確定行動」（部位破壊）があることで、努力の成果と運を両立

---

### Slay the Spire

**レアリティ区分（カード）：** コモン / アンコモン / レア（デフォルト比率 60:37:3）
**レアリティ区分（レリック）：** コモン / アンコモン / レア / ボス限定 / イベント限定

**入手方法：**
- 戦闘後報酬：3枚提示のうち1枚選択。レア出現率は5%前後でスタートし**ジャングルのレリック所持で変動**
- エリート戦：ドロップテーブルにレア・レリックが優遇（通常戦との明確な差分）
- ボス戦：必ずボス限定レリックが1つ確定ドロップ（超レアを確定で提供）
- ショップ：金貨で任意購入（確率ゼロ・価格は固定）
- 宝箱：アンコモン以上のレリック確定

**設計思想：**
- **確定ドロップをゲームのマイルストーン（ボス）に集中配置** → 「ボスを倒した満足感」と「報酬の嬉しさ」を同時に提供
- レア出現率はランダム的に見せつつ、**パーシーワ型保護機構**（レアを引いたらしばらく出にくい）で極端な引き偏りを防ぐ
- ポーションは戦闘後に確率ドロップ（所持上限3個）→ リソース管理のスパイスとして機能

---

### Backpack Battles

**レアリティ区分（アイテム）：** コモン（白）/ アンコモン（緑）/ レア（青）/ エピック（紫）/ レジェンダリ（橙）

**入手方法：**
- **ショップがメイン：** ラウンドごとに更新されるショップで購入（金貨消費）
- バトル報酬：対戦結果に応じてインタレスト（金貨利息）が変動し、購買力に影響
- リロール：追加金貨でショップを再抽選可能

**設計思想：**
- ランダムドロップをほぼ排除。**「買えるかどうか」が確率** → 抽選は出現するかどうかだが、出たら必ず買える
- レジェンダリは出現確率が低いが、出た時点で「買う/買わない」の意思決定が発生 → 運と判断の両立
- ドロップテーブルではなく**プールから抽選**（同アイテムが複数プレイヤーに出る可能性あり）

---

### Diablo / Path of Exile

**レアリティ区分（Diablo）：** ノーマル / マジック / レア / ユニーク / セット
**レアリティ区分（PoE）：** ノーマル / マジック / レア / ユニーク（さらにリーグ限定等）

**入手方法（PoE）：**
- 敵ドロップ：Quantity（数量増加）/ Rarity（レア度増加）の2軸でドロップ調整
- **ドロップレート設計：** ユニークは0.01-0.1%、Mirror of Kalandra（最高レアリティ）は0.0001%前後と推定

**設計思想：**
- **Quantity×Rarity の2変数でドロップ総量を調整** → スケールアップに柔軟
- レアアイテムのドロップは「ロールを振ってベースアイテムが決まり、次にアフィックスが決まる」2段階抽選
- PoEは「特定アイテムは特定コンテンツでしか出ない」島式設計で、やることを強制的に分散させる

---

### テラリア

**レアリティ区分（内部値）：** White / Blue / Green / Orange / Red / Purple / Rainbow / Developer

**入手方法：**
- バイオーム依存ドロップ：同じ敵でもバイオームが異なるとドロップテーブルが変わる
- ボス限定素材：ボスからしか取れない素材で、特定の武器/防具/ツールをクラフトするために必須
- **釣り：** バイオーム×時間×バフで引けるアイテムが変化。釣りもドロップテーブル化

**設計思想：**
- ドロップ確率はシンプルな1/N形式（例：ターサンドラの羽根=1/100）。複雑な階層はない
- 「バイオームを変えるだけで新しいドロップが出る」ことで探索モチベーションを生む
- **ボス素材は確率ドロップだが確率が高め（25-100%）**。ランダム感より「倒せば進める」感を優先

---

### 原神 / グランブルーファンタジー

**レアリティ区分（原神）：** 1-5★（5★が最高）

**入手方法（原神）：**
- デイリー・週次ボス：素材の種類は確定、個数は確率
- 聖遺物（装備）：ドメイン（ダンジョン）周回。セット確定、サブステータスは完全ランダム
- キャラ素材：特定ボス固定。5★素材は低確率または高体力消費

**設計思想（グラブル）：**
- バハムートHL等の高難易度：箱ドロップ制（一定数倒すと箱が確定で開く）→ 超レアは箱の中から確率抽選
- **天井（Pity System）：** 一定回数の外れ後に確定レア付与 → 0.1%の超低確率を「いつかは手に入る」に変換
- 「古戦場」のような期間限定高効率周回でドロップ率×2-4倍 → プレイヤーを特定期間に集中させる

## 2. 共通するドロップテーブル設計パターン

### パターン1：レアリティ階層 × 入手方法の分離

```
コモン素材    → バトルドロップ（高確率・頻繁）
レア素材      → エリート/特定ボス（低確率 or 確定低頻度）
超レア（宝石）→ ボス確定報酬 or 超低確率ドロップ（0.1%）
```

共通して「コモンは頻度で供給、超レアはイベント/努力で取得」の二層設計をしている。

### パターン2：確定ドロップと確率ドロップの役割分担

| 用途 | 方式 | 設計意図 |
|------|------|----------|
| 進行を止めない素材 | 確率ドロップ（高確率） | 「そのうち入手できる」安心感 |
| 到達感を演出する素材 | 確定ドロップ（ボス/マイルストーン） | 「頑張った報酬」として機能 |
| コレクション要素 | 超低確率（0.1%以下） | ガチャ的興奮・希少性の担保 |

### パターン3：努力を確率に変換する仕組み

- MH：部位破壊で確率上昇（努力 → 確率向上）
- PoE：Quantity/Rarity で累積（努力 → ドロップ総量向上）
- グラブル：天井（努力 → 確定ドロップに近づく）
- STS：Pity Systemで直近のレアが少ないと出やすくなる

**核心：完全ランダムは「努力が報われない」感を生む。努力が確率を操作できる仕組みが必要。**

### パターン4：入手方法の多様化によるコンテンツ分散

```
バトルドロップ  → 常時アクセス可能。周回の主軸
探索ノード      → マップ探索への誘導
ショップ        → 金貨リソース変換。確率依存しない安定入手
ボス/エリート   → 集中的な挑戦の報酬
```

入手方法を分散させることで「ショップが貧乏な時はバトルで稼ぐ」等の動的な判断が生まれる。

## 3. このゲームへの適用提案

### 3-1. レアリティ別ドロップ率設計

```
基礎素材（コモン）     60%   通常バトルドロップ
レア素材              12%   エリートバトル / ボス / 採集ノード優遇
宝石（超レア）         0.1-0.3%   全入手経路から極稀に出現
上質素材（アンコモン） 27%   通常バトル優遇層・採集ノード
```

**宝石の0.1%設計根拠：**
- バトル1回を90秒とすると、期待値300回 = 450分 = 7.5時間
- 宝石の効果を「ゲームを変えるが必須ではない」レベルに設定すれば、これは許容範囲
- 0.3%上限（Pity等なし版）でも2.5時間 → 軽量プレイヤーには1-2ランで出ないが十分なモチベーション

### 3-2. 入手方法別の設計

| 入手方法 | コモン | アンコモン | レア | 宝石 |
|---------|--------|-----------|------|------|
| 通常バトル | ★★★ | ★★ | ★ | 0.1% |
| エリートバトル | ★★★ | ★★★ | ★★ | 0.2% |
| ボスバトル | — | 確定1個 | 確定1個 | 0.3% |
| 採集ノード | ★★★ | ★★ | — | — |
| ショップ | 購入可 | 購入可 | 購入可（高額） | 売買不可 |

**設計方針：**
- **宝石はショップで買えない**（合成不可と合わせて「バトルだけが入手手段」を徹底）
- ボスは確定でレア以上を提供 → 「ボスを倒す動機」が素材面でも成立
- ショップは確率ゼロで安定入手の場として位置づけ（Backpack Battles的設計）

### 3-3. 努力を確率に変換する仕組み（推奨）

**「部位破壊ボーナス」的な仕組みを本ゲームで実現する案：**

案A：「特定条件での撃破ボーナス」
- 条件例：3ターン以内に撃破 / 麻痺状態で撃破 / 特定種族で撃破
- 条件達成でドロップテーブルが「通常 → エリート相当」に切り替わる

案B：「連続バトル勝利でドロップ率上昇」
- 3連勝：レア+10% / 5連勝：レア+20% / 負けでリセット
- 「勢い」の要素がドロップに反映 → 連勝のメリットを素材面でも演出

案C：「Pity System」（天井）
- 超レア（宝石）が20回連続で出ないと次のバトルで確定出現
- ガチャ的不満を解消しつつ、0.1%の希少性は維持

**推奨：案A + 案C の組み合わせ**
- 通常プレイには案Aで「努力の可視化」
- 長期プレイには案Cで「絶望的なドライラン防止」

### 3-4. 進行度によるドロップテーブル変化

```
エリア1（序盤）: 基礎素材 80% / アンコモン 20% / レア 0%
エリア2（中盤）: 基礎素材 60% / アンコモン 30% / レア 10%
エリア3（後盤）: 基礎素材 40% / アンコモン 35% / レア 25%
エリアBoss:    レア確定 / 宝石 0.3%
```

- **強い敵からしか出ない素材**を設けることで「強いエリアを攻略する動機」を作る
- 序盤素材は後盤でも使うが、後盤素材は序盤エリアでは出ない（素材の段階的解放）

## 4. 差別化ポイントへの接続

本ゲームの「宝石はドロップ専用・合成不可」という設計は既存ゲームにないユニークな制約。

**この設計を活かすための強化策：**
1. 宝石をデッキ強化（カードアップグレード）にのみ使用 → 「強化の唯一手段が戦闘報酬」という設計がPvP正直性に貢献
2. 宝石は見た目（エフェクト/カードビジュアル）にも反映 → 希少性が対戦相手にも伝わるスタータス化
3. バトル中に「宝石が出たかどうか」をリザルト画面で強調 → ドロップ体験そのものをゲームの報酬に
