# モンスター合成（進化）システム リサーチ

> 作成日：2026-04-07
> 目的：本作のカード合成ツリー設計の参考事例収集
> スコープ：「純粋な派生形で進む」合成システム（ランダム配合除外）

---

## 調査対象と評価軸

### 評価軸

1. **入力**：何×何→何になるか（同種/異種/素材）
2. **ツリー深さ**：最長何段階か
3. **分岐の仕組み**：同素材から複数結果が出るか、条件分岐か
4. **逆戻り**：進化後に元に戻せるか
5. **レアリティとの関係**：合成で上レアリティへ移行できるか

---

## 1. デジモン（デジモンストーリー・デジモンワールド系）

### 合成（進化）ルール

- **入力**：自分のデジモン1体 + 経験値/バトル実績（素材不要の場合も多い）
- デジモンストーリー以降はアイテム「デジメモリ」や「クリスタル」が条件に加わる
- 究極進化・超究極進化は特定アイテム必須

### ツリー深さ

```
幼年I
  └→ 幼年II（ロットモン等）
       └→ 成長期（アグモン等）
            └→ 成熟期（グレイモン等）
                 └→ 完全体（メタルグレイモン等）
                      └→ 究極体（ウォーグレイモン等）
                           └→ 超究極体（omeガモン等）[ゲームによる]
```

**最長7段階**（通常は5〜6段階）

### 分岐の仕組み

- **分岐あり・条件分岐**
- 成長期→成熟期で複数選択肢（例：アグモン→グレイモン or グレイモン（X抗体）or スカルグレイモン）
- 分岐条件：特定ステータス閾値（ATK重視→攻撃型、HP重視→防御型）
- デジモンストーリーでは「DNA進化」（2体→1体の融合）も存在

### 逆戻り

- **不可**（原則）
- ただしデジメモリ消費でフォームチェンジ（一時的な別形態）は可能

### レアリティとの関係

- 進化段階がレアリティに対応（幼年=コモン、究極体=レア相当）
- 合成で必ずレアリティが上がる

### 本作への示唆

- **段階的成長 + 分岐**の組み合わせが強い
- 進化条件にステータス閾値を使うと「どんな育て方をしたか」で分岐できる

---

## 2. ポケモン（進化チェーン・分岐進化）

### 合成（進化）ルール

- **入力**：ポケモン1体 + レベル / アイテム / 特定条件
- アイテム進化：ほのおのいし等を使用
- 友好度進化、通信進化（廃止傾向）も存在

### ツリー深さ

```
1段階：ラッタ（コラッタ→ラッタ）
2段階：リザードン（ヒトカゲ→リザード→リザードン）
3段階：バタフリー（キャタピー→トランセル→バタフリー）
  └→ [メガ進化・キョダイマックス：一時変身]
```

**最長3段階**（本編）

### 分岐の仕組み

- **分岐あり・条件分岐**
- 例：イーブイ→使用アイテム(8種)で8方向分岐、ユキワラシ→時間帯で分岐
- 同素材から複数結果：イーブイが典型例（分岐を一点に集約した設計）
- ゲーム内では「進化候補が複数あるとプレイヤーが選択」できない→条件を満たした側に確定進化

### 逆戻り

- **不可**（石進化・レベル進化いずれも）
- 「もどりのつぼみ」で前段階に戻せる作品もある（外伝）

### レアリティとの関係

- 進化でスペックが大幅上昇、BST（種族値合計）が明示的な強さの指標
- 「ひかりのいし」等の希少アイテム消費で上位フォームに移行=アイテムレアリティが進化の障壁

### 本作への示唆

- **アイテム消費による分岐**が明快：「どのアイテムを使うか＝どの方向に進化させるか」
- イーブイ式「汎用素材→多方向分岐」はデッキカスタマイズ幅を広げる設計として優秀
- 進化不可（3段階が上限）はバランス管理が容易

---

## 3. モンスターファーム（合体ルール）

### 合成ルール

- **入力**：モンスターA（主体）× モンスターB（副体）→ 新モンスター
- 主体の種族が基本に、副体の種族で亜種が変わる
- 例：ピクシー（主）× ゴーレム（副）→ ゴーレムで鎧を着たピクシー（ストーン種族特性付き）

### ツリー深さ

- **実質1段階**（合体回数に制限なし・理論上無限合体可能だが実用は2〜3回）
- 合体のたびに素材が消滅するため深いツリーを作りにくい

### 分岐の仕組み

- **組み合わせマトリクス方式**（分岐というより全パターン網羅）
- 主体×副体の順番で結果が変わる（A×B ≠ B×A）
- 組み合わせが決定論的（確率要素なし）

### 逆戻り

- **不可**（合体後に分離はできない）

### レアリティとの関係

- 特定の希少モンスター同士の合体でのみ出現するレア種が存在
- 合体自体がレアリティ上昇の手段になっている

### 本作への示唆

- **主体×副体で結果が変わる**非対称合成は「どちらをベースにするか」の戦略判断を生む
- 素材が消滅する仕様は「合成コスト」として機能しバランス調整に有効
- 本作では「カードA + 素材B → 上位カード」に相当させやすい

---

## 4. パズドラ（進化ツリー・究極進化・転生進化）

### 合成ルール

- **入力**：メインモンスター + 進化素材モンスター複数体（素材は素材専用モンスターか同種）
- 進化素材は汎用素材（リリス等）または特定限定素材
- 究極進化：基本進化の最終形態 + 上位素材
- 転生進化：究極進化済み + 転生素材（最終形態をさらに別方向へ進化）

### ツリー深さ

```
基本形（レア1-2）
  └→ 進化形（レア3-4）
       └→ 最終進化形（レア5）
            └→ 究極進化（レア6）[複数分岐]
                 └→ 転生進化（レア7相当）[さらに分岐]
                      └→ 超転生進化（最高峰）
```

**最長6段階**（転生まで含む）

### 分岐の仕組み

- **究極進化で分岐が生まれる**
- 例：ルシファー最終進化→究極進化「堕天使」or「威光」の2択
- 究極進化同士はデザインが異なりロールが変わる（攻撃型/回復型等）
- 転生進化でさらに追加分岐することもある

### 逆戻り

- **究極進化のみ可**（「進化前」に戻せる機能が存在）
- 転生進化は一方通行

### レアリティとの関係

- **進化段階＝レアリティが直結**：最終進化がレア6、転生でさらに特殊レア扱い
- 素材の希少性（ダンジョン限定モンスター等）が進化の障壁として機能

### 本作への示唆

- **究極進化の分岐**は同じ最終形態から「特化型分岐」を生む設計として参考になる
- 転生進化の「既存の強さを別軸に再定義」は飽きにくいメタゲームを維持する
- 進化に使う素材の稀少性でゲーム全体の進行コントロールができる

## 5. Siralim（モンスター合成）

### 合成ルール

- **入力**：モンスター3体（素材3体が消滅）→ 新モンスター1体
- 使用する3体のうち「どれを主体にするか」は選択可能
- モンスターの種族・能力が結果に影響（完全ランダムではなく参照式）
- ただしどんな組み合わせでも何らかの結果が出る（失敗なし）

### ツリー深さ

- 理論上無制限だが、**実用は2〜3段階**（3体集めるコストが重いため）
- Siralim 3以降は「伝説モンスター合成」でさらに上位が存在（実質4段階）

### 分岐の仕組み

- **組み合わせ次第で数百種類の結果**が存在
- 完全な分岐ツリーではなく「合成表（レシピ）」として設計
- 特定3体の組み合わせでのみ出現するレアモンスターが存在

### 逆戻り

- **不可**

### レアリティとの関係

- 合成素材の希少度が結果のレアリティに影響
- 伝説モンスター3体→神話級モンスターという明示的な上位合成ルートが存在

### 本作への示唆

- **3体合成で1体生成**はコスト感が強く「合成が特別な行為」になる
- 結果の豊富さは発見の楽しさを生むが、UIが複雑になる（要レシピ帳）
- 本作の盤面ユニット合成（同種ユニットが同マスに配置→自動合成）と相性が良い概念

## 6. Auto Chess / TFT（ユニット合成・スターアップ）

### 合成ルール

- **入力**：同一ユニット × 3体 → 同ユニットの★2（自動発動）
- 同ユニット★2 × 3体 → ★3（最大レア度）
- TFT：特定ゲームでは★3が合体してアーティファクトユニットに変化するケースも

### ツリー深さ

```
★1（3体ストック中）
  └→ ★2（3体ストック中）
       └→ ★3（最高形態）
```

**固定3段階**（全ユニット共通）

### 分岐の仕組み

- **分岐なし**（同一ユニット同種のみ、結果は常に一意）
- TFTのアーティファクト変身等は例外的な特殊レシピとして別管理

### 逆戻り

- **不可**（★2→★1に戻してユニット数を増やすことはできない）

### レアリティとの関係

- ★の段階がそのままレアリティに対応
- 元ユニットのコストが高いほど★3が強くなる（コスト4の★3 > コスト1の★3）

### 本作への示唆

- **同種ユニット3体→上位ユニット**はシンプルで直感的（本作にも部分的に実装済み）
- 「合成は常に同種のみ」にすることでUIを最小化できる
- 分岐なし設計は誰でも理解できるが、戦略の奥行きはユニット選択時に収束する

---

## 7. Backpack Battles（アイテム合成ツリー）

### 合成ルール

- **入力**：アイテムA + アイテムB（インベントリ内で隣接配置 or 重ね置き）→ 上位アイテム
- 素材は消滅し新アイテムに置き換わる
- 隣接配置が発火条件（位置依存の合成）
- レシピは既知（ゲーム内Wikiやツールチップで確認可能）

### ツリー深さ

```
ベースアイテム（Tier1）
  └→ 中位アイテム（Tier2）
       └→ 上位アイテム（Tier3）
            └→ 最上位アイテム（Tier4）[一部ルートのみ]
```

**最長4段階**（多くのルートは3段階）

### 分岐の仕組み

- **素材の組み合わせで分岐**（同ベースアイテムに複数の合成先が存在する）
- 例：「剣」+「ルビー」→ 炎剣、「剣」+「氷の欠片」→ 氷剣
- 分岐の選択は「何と合成するか」でプレイヤーがコントロール

### 逆戻り

- **不可**（合成後は分解できない）

### レアリティとの関係

- Tier段階がレアリティに対応（Tier3以上が希少）
- ショップでTier3を単体購入するより合成の方がコスト効率が良い設計

### 本作への示唆

- **位置依存合成**は本作の盤面3×3と相性が良い（隣接マスのユニットが合成トリガー等）
- 「何と合成するかで方向性が決まる」設計は本作のカードビルド（タンク特化/速攻特化等）と整合する
- 素材の組み合わせが直感的（剣+炎=炎剣）で、説明なしでもプレイヤーが想像できる

## 比較サマリー

| ゲーム | 入力形式 | 最大段階 | 分岐 | 逆戻り | レアリティ上昇 |
|--------|---------|:---:|:---:|:---:|:---:|
| デジモン | 1体+条件/アイテム | 7 | 条件分岐 | 不可 | 連動 |
| ポケモン | 1体+レベル/アイテム | 3 | 条件分岐（アイテム） | 不可 | 連動 |
| モンスターファーム | 2体合体（主/副） | 実質1 | 組み合わせ | 不可 | 希少組み合わせ |
| パズドラ | 1体+素材複数 | 6 | 中盤以降に分岐 | 一部可 | 連動 |
| Siralim | 3体合成 | 実質3〜4 | レシピ数百 | 不可 | 素材依存 |
| TFT | 同種×3 | 3 | なし | 不可 | 連動 |
| Backpack Battles | 2アイテム合成 | 4 | 素材で分岐 | 不可 | Tier連動 |

## このゲームへの適用ポイント

### 現状の整理

CLAUDE.mdには「カード合成ツリー（ドラクエモンスター配合ツリー方式、深い階層を持てる）」と記載済み。
盤面では「同種ユニットが同マスに重なると合成発動（合成or召喚失敗）」が実装済み（place_unit）。

### 採用すべきアーキテクチャ

**A. ベース合成：TFT方式（同種×3 → ★2）**
- 盤面合成の直感性を担保
- 現行の「同マス=合成」仕様と整合
- ★1 → ★2 → ★3の固定3段階を土台にする

**B. カード合成：Backpack Battles方式（カード + 素材 → 上位カード）**
- DeckPrepの「持ち物タブ」での操作に対応
- 「スライム + 炎素材 → マグマスライム」の直感的レシピ設計
- 分岐はポケモンのイーブイ方式（汎用素材から複数方向へ分岐）

**C. 進化ツリーの深さ：パズドラ方式（基本→進化→究極で分岐）**
- 最長4〜5段階（★1→★2→★3→究極A or 究極B）
- 究極進化で「攻撃特化型」「防御特化型」等のロール分岐を生む
- ゲームバランス管理のため「転生」相当の7段目以降は設けない

**D. 素材の役割：ポケモンのアイテム進化**
- 素材の種類（火/氷/獣骨/魔石等）が進化方向を決定
- 素材の希少度がそのまま進化先のレアリティになる
- 「汎用素材」と「レア素材」の2段階で難易度調整

### 禁止する方式

- **モンスターファーム方式（A×B主副合体）**: 組み合わせ爆発でUIが破綻するリスク
- **Siralim方式（3体消滅）**: 本作では盤面ユニットの価値が高く「3体消滅」はコストが重すぎる
- **完全ランダム配合（ドラクエ方式）**: 要件外（純粋な派生形を求めている）

### 具体的な合成設計案（本作）

```
[盤面合成]
  同種 ★1 × 2体（同マス衝突）
    → ★2 ユニット（自動発動、コスト不要）

[カード合成（DeckPrep）]
  ★2 カード + 素材（種族対応）
    → 究極進化A（攻撃ロール）
    → 究極進化B（支援ロール）   ← 素材の種類で分岐

  例：マッドスライム★2 + 「炎石」 → インフェルノスライム（ATK特化）
  例：マッドスライム★2 + 「命の結晶」 → アシッドスライム（毒/回復特化）
```

### 優先実装順

1. **盤面合成（★1×2→★2）**：最小コストで最大の戦略深度（現行実装に追加）
2. **カード合成（★2+素材→究極進化）**：DeckPrepタブで操作
3. **究極進化の分岐（素材で方向決定）**：素材システム完成後に統合

### 差別化ポイントへの貢献

既存Auto Chess（TFT等）と差別化するポイント：
- TFTは★3が上限で分岐なし → 本作は★3到達後に「素材で方向が決まる究極進化」があり戦略奥行きが深い
- デジモンは進化条件が成長過程に依存 → 本作は「何の素材を使うか」というデッキ構築時の判断に依存（戦略の軸が違う）
- Backpack Battlesはアイテム合成のみ → 本作は「盤面ユニット合成」と「カード合成」の二層構造で独自性がある
