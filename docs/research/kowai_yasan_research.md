# こわいやさん リサーチ

> 作成日: 2026-04-07
> 目的: 世界観設計の参考（情報質量×怪異の定義）

## 作品概要
- 作者: カメントツ
- 媒体: 少年ジャンプ+（2025年3月26日〜連載中、毎週水曜更新）
- ジャンル: ホラー→SF（地続きにジャンル転換）

## 設定
- 舞台: かわいい動物たちが暮らす「どうぶつ村」
- 主人公: かえるくん（最近引っ越してきた）
- こわいやさん: うさぎさんが「こわい」を箱に入れて売るお店
- 「こわい箱」: 怪異のエピソードを封じた箱。開封=情報の解放

## 怪異のメカニズム（読者考察含む）
- **質量を持った情報が集まりすぎるとブラックホール的なものになる** → 怪異の発生
- **こわい箱 = 旧世界の情報のzipファイル的存在**
- **「情報を食う虫（バグ）」** の存在 → 情報欠損がキャラクター変容を引き起こす
- 怪異は「世界のバグから生じた現象」
- 「元々何の曰くもないものでも、人の思いが介在することで怪異化する」

## 世界観の構造
- どうぶつ村（簡素化された世界）と現実世界が地続き
- 現実のアイテム（スラムダンク目覚まし、スーパーファミコン等）がどうぶつ村に存在
- キャラクターの絵柄 = 「再構築された世界」の表現（情報が削ぎ落とされた姿）
- ホラー→SFへの転換が「地続きの急カーブ」で行われる

## ナラティブ手法
- メタ的仕掛け: QRコード、偽のゲーム広告など「マンガの外」への侵食
- オムニバス形式に見せかけて第7話で物語が接続・展開
- 読者が「振り回される」構造を意図的に設計

## このゲームへの応用ポイント
- 「情報が質量を持つ」という物理法則で、ファンタジーとSFの境界を自然に溶かす
- ダンジョン深層 = 情報密度が高い = 怪異（モンスター）が強い
- 「バグ」ではなく「情報の歪み」として怪異が存在する（SF的にも詩的にも機能する）
- グリッチ演出 = 情報の過負荷による表層の崩壊
