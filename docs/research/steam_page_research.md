# Steam インディーゲームページ リサーチレポート

**対象ジャンル：** ローグライク・デッキ構築・オートバトラー  
**調査日：** 2026-04-03  
**調査対象：** Slay the Spire / Backpack Battles / Balatro ほか

---

## 1. キャッチコピーの傾向

### パターン分類

- **ジャンル融合型**（最多）
  - 「We fused card games and roguelikes together to make the best single player deckbuilder we could.」（Slay the Spire）
  - 「A PvP inventory management auto battler!」（Backpack Battles）
  - 「a hypnotically satisfying deckbuilder where you play illegal poker hands」（Balatro）
  - → 2ジャンル以上を掛け合わせ、新規性を強調する構造が主流

- **動詞命令形でプレイヤーを引き込む**
  - 「Craft a unique deck, encounter bizarre creatures, discover artifacts of immense power, and Slay the Spire!」
  - 「Prepare your backpack!」「Buy rare and legendary items and organize them」
  - → 短い命令文 → 箇条書き展開 → 具体的な行動イメージを与える

- **感情・感覚ワード**
  - "hypnotically satisfying"（中毒性）
  - "adrenaline-pumping, outrageous"（興奮感）
  - "bizarre creatures"（奇妙さ・意外性）
  - → 理性でなく感情に訴える形容詞を積極使用

- **数字による具体性**
  - 「350+ fully implemented cards」「200+ different items」「50+ unique combat encounters」
  - 「over 500 different items」（Backpack Battles）
  - → ボリューム感をアピールするために具体的な数値を使う

### キャッチコピーの文字数傾向
- **短文キャッチ（1〜2文）** → ストアページ冒頭・タグライン
- **箇条書きFeatures** → 詳細説明セクションで展開
- → 「短く引っかけ → 詳しく説明」の2段構成が標準

## 2. スクリーンショット構成

### 枚数の傾向
- **最低5枚、標準7〜10枚** が業界標準（Steamworks推奨）
- Steam公式ガイドライン：スクリーンショットは純粋にゲームプレイを示すこと（コンセプトアート・受賞表示・ロゴのみ画像は禁止）

### 何を見せているか（推奨構成）

| 順番 | 内容 |
|------|------|
| 1枚目 | **最も魅力的なゲームプレイシーン**（第一印象を決める最重要枠） |
| 2〜3枚目 | **コアメカニクス**（デッキ画面・カード選択・アイテム配置など） |
| 4〜5枚目 | **バトル・戦闘シーン**（緊張感・派手さを演出） |
| 6〜7枚目 | **マップ・メタ進行**（ローグライクの探索感、周回要素） |
| 8〜9枚目 | **多様性アピール**（キャラクター・クラス・ビルドの幅） |
| 最後 | **UI全体像 or 特殊モード**（ゲームの世界観や規模感） |

### ジャンル別の特徴
- **ローグライク系**：マップ探索画面・ランダムイベント画面を入れてランダム性を強調
- **デッキ構築系**：カードを美しく並べた「デッキ画面」は必須。シナジーが一目でわかること
- **オートバトラー系**：バトル中のアニメーション・アイテム配置を静止画でも分かりやすく見せる（Backpack Battlesはバックパックの中身をフィーチャー）

## 3. タグの使われ方

### Slay the Spire のタグ（参考）
```
Roguelike Deckbuilder / Card Game / Card Battler / Roguelike /
Deckbuilding / Turn-Based / Strategy / Singleplayer / Roguelite /
Replay Value / Indie / Difficult / Dungeon Crawler / Mouse only /
RPG / 2D / Fantasy / Procedural Generation / Great Soundtrack / Casual
```

### Backpack Battles のキャッチコピーから読み取れるタグ戦略
- **主軸タグ**：Auto Battler / Inventory Management / PvP / Strategy
- **関連タグ**：Roguelike / Deckbuilder / Crafting / Multiplayer

### Balatro のタグ傾向
- Roguelike / Deckbuilder / Card Game / Singleplayer / Poker

### タグ戦略のまとめ

- **上位5タグが最重要**（Steamがストア表示で使用するため）
  - ジャンルの本質を表すタグを最上位に置く
  - 例：`Roguelike Deckbuilder` > `Card Game` > `Turn-Based` の順

- **タグ構成の基本パターン**
  1. **ジャンル複合タグ**（Roguelike Deckbuilder, Auto Battler）← 新設複合タグが有効
  2. **プレイスタイルタグ**（Singleplayer, Turn-Based, Mouse only）
  3. **テーマ・世界観タグ**（Fantasy, Dungeon Crawler, RPG）
  4. **プレイヤー体験タグ**（Difficult, Replay Value, Procedural Generation）
  5. **感情タグ**（Casual, Relaxing, Great Soundtrack）

- **注意点**
  - ユーザーが付けるタグも重要（開発者設定 + コミュニティ投票で決まる）
  - ニッチすぎるタグは検索流入ゼロになるリスクあり
  - 「Roguelike」と「Roguelite」は別タグ → 両方付けることが多い

## 4. 早期アクセスの開始タイミング傾向

### 代表タイトルの実績

| タイトル | EA開始 | 正式リリース | EA期間 |
|---------|--------|------------|--------|
| Slay the Spire | 2017年11月 | 2019年1月 | 約14ヶ月 |
| Backpack Battles | 2024年3月8日 | 2025年6月13日 | 約15ヶ月 |
| Balatro | EA なし（直接1.0リリース） | 2024年2月20日 | - |

### EA開始の推奨タイミング

- **ウィッシュリスト数の目安**
  - EA開始前に **最低7,000〜10,000件** のウィッシュリストが推奨（業界ガイドライン）
  - 10,000件でSteamの「Popular Upcoming」掲載圏内に入る

- **Steam Next Festとの連動戦略**（最重要）
  - Next Festでデモを出す → ウィッシュリストを稼ぐ → Next Fest後にEAリリース
  - Next Fest終了後すぐのリリースが最も効率的とされる

- **リリース月の傾向**
  - 良い月：**1〜4月、6月**（競合が少なく注目を集めやすい）
  - 避けるべき：11〜12月（大型AAタイトルとSteamセールが重なる）
  - ただし**Steam Next Festやセールに乗る戦略**なら例外もあり

- **EA期間の目安**
  - 業界平均：**約12〜30ヶ月**（平均約2.5年との調査もあり）
  - ローグライク・デッキ構築ジャンルは比較的短め（12〜18ヶ月が多い）
  - コアループが完成している状態でEAに入ることが重要

- **EA開始時に必要なコンテンツ量**
  - コアゲームプレイループが完成していること
  - 最低2〜3時間のプレイ内容
  - ロードマップの公開（コミュニティへの透明性）
  - 早期購入者への特典は不要だが、セールは効果的

## まとめ：自作ゲームへの示唆

- **キャッチコピー**：「〇〇 × △△ の新感覚ゲーム」のジャンル融合型を基軸に。命令形で行動を想起させる。
- **スクリーンショット**：最初の1枚が最重要。コアメカニクスを視覚的に説明できる構成にする（7〜10枚目標）。
- **タグ**：上位5タグにジャンル本質を集中。`Roguelike`・`Deckbuilder` 系は必須。
- **EA タイミング**：Next Festでデモ公開 → 7,000+ウィッシュリスト確保 → Next Fest後すぐにEA開始が最も効率的なパターン。
