# ダンジョンボードゲーム 仕様書

## ゲーム概要

**ジャンル:** リアルタイムボード・カードゲーム / ローグライク要素
**プラットフォーム:** Godot 4.6 / GDScript / Windows・Mac・Linux対応予定
**画面構成:** 1280×720 (Forward Plus renderer)
**概念:** プレイヤーと敵が対立する3×3盤面で、自動巡回デッキから召喚したユニットを配置・戦闘させる。前列ユニット優先攻撃・リアルタイム戦闘・バフ・デバフ・スキルシステム。

---

## コアメカニクス

### 盤面構造

- **3×3×2 レイアウト**
  - side 0 = プレイヤー側（左）、side 1 = 敵側（右）
  - 各side内の row 0–2（上・中・下），col 0–2（左・中・右）
  
- **配置列の意味**
  - プレイヤー（side 0）: col 2 = 前列（中央寄り），col 1 = 中列，col 0 = 後列
  - 敵（side 1）: col 0 = 前列（中央寄り），col 1 = 中列，col 2 = 後列

- **攻撃ルール**
  - 前列ユニットのみ毎フレーム自動攻撃
  - 敵ユニットがいれば最前列敵を優先的に選択
  - 敵がいなければ敵本体にダメージ
  - 後列攻撃サポート効果を持つユニットは、別途後列の攻撃タイマーで敵を攻撃

- **繰り上がり（Promote）**
  - 前列が空いたとき中列から自動的に繰り上がる（イベント駆動・1フレームラグ）
  - 配置時・死亡時に promote_check イベントが遅延キューに積まれる
  - promote 自体は EventQueue の多パスフラッシュで実行

### マナシステム

- **マナ再生**
  - 1.0/秒で自動回復、上限10
  - 初期値3.0

- **自動デッキ巡回**
  - 毎秒チェック（カスタマイズ可）
  - デッキの先頭カード cost ≥ 現マナ なら発動
  - 発動後は捨て札へ移行
  - デッキが空になると捨て札をシャッフルして再利用
  - 呪文・異常状態カードは発動ルールが異なる

- **呪文カード機構**
  - コスト消費して即座に効果発動
  - 大別3種: 通常呪文（捨て札へ）・異常状態カード（消滅・コスト0）

### リアルタイム戦闘

- **攻撃タイマー**
  - 各ユニットが `attack_interval` フィールドで攻撃周期を管理
  - 毎フレーム delta で減算、≤0 のとき攻撃実行・リセット
  
- **効果処理チェーン**
  - イベントキュー（EventQueue）で優先度付き処理
  - 優先度: IMMEDIATE(1) < STATUS(2) < SUPPORT(3) < ACTIVE(4) < ARTIFACT(5) < BOARD(6) < MERGE(7)
  - 同フレーム複数イベントは優先度順・同優先度は発火順で実行
  - 多パスフラッシュ: ダメージ→死亡後処理→遅延キューの順で最大20パス実行

- **敵AI（EnemyAI）**
  - 3.5秒ごとにユニットを順序抽選で配置
  - 敵用デッキも自動巡回
  - 配置位置はランダム

## カードシステム

### ユニットカード

**構成:** 9枚（スライム系3・アンデッド系3・獣系3）

**基本属性**
| 属性 | 説明 |
|-----|------|
| unit_name | カード名 |
| max_hp | 最大HP |
| attack | 攻撃力 |
| attack_interval | 攻撃周期（秒） |
| cost | マナコスト |
| assigned_col | 初期配置列（0=後列, 1=中列, 2=前列） |
| race | 種族（スライム / アンデッド / 獣） |
| attack_range | 攻撃範囲（1行 / 上含む2行 / 下含む2行 / 上下含む3行） |

**効果層（2層構造）**
| 層 | フィールド | 発動タイプ |
|----|-----------|-----------|
| サポート効果 | support_effect | 常時発動 / 召喚時 / 条件達成時 |
| アクティブスキル | active_skill | 命中時 / 撃破時 / HP閾値時 / 時間経過 / 召喚時 |

**カード例：アメーバ**
- HP 5 / ATK 1 / SPD 0.5s / Cost 1
- support: "HPバフ〈常時発動・前列の味方のみ・微回復〉"
- active: "追加召喚〈召喚時・隣接マスに同種を1体〉"

### 呪文カード

**構成:** 3枚（基本呪文） + 異常状態カード 4種（動的）

**基本呪文（初期デッキ）**

| カード名 | Cost | 対象 | 効果 |
|---------|------|------|------|
| 召喚加速 | 1 | 自身 | マナ即時+3回復 |
| 生命の雫 | 2 | 味方1体 | HP15%回復 |
| 盤面強化 | 3 | 全味方 | HP+10・ATK+2 |

**異常状態カード（フィールド発動で生成）**

| カード名 | Cost | 効果 |
|---------|------|------|
| 毒カード | 0 | 味方ランダム1体に毒2付与（消滅） |
| 凍結カード | 0 | 味方ランダム1体に凍結2付与（消滅） |
| 火傷カード | 0 | 味方ランダム1体に火傷2付与（消滅） |
| 麻痺カード | 0 | 味方ランダム1体に麻痺2付与（消滅） |

**呪文効果のバリエーション（SpellExecutor 実装済み31種）**
- 自己強化系: 血の契約・戦場の鼓動・急召・連鎖の触媒・強化の儀式・盤面強化
- 回復系: 生命の雫・再召喚
- デッキ操作系: 先読みの書・怒涛の展開・召喚の呼び声
- 敵攻撃系: 毒霧・寒波・山火事・落雷・烈風斬
- 敵デバフ系: 弱体の呪詛・盤面凍結
- 位置操作系: 混沌の手・反転の波・押し込み
- キュー干渉系: 召喚妨害・配置崩し
- 異常状態カード: 毒カード・凍結カード・火傷カード・麻痺カード

**デッキ構成（初期値）**
- ユニット 9 枚
- 呪文 3 枚 + 呪文フィールド発動で異常状態カード 4 種類が動的追加
- 合計 12–16 枚（呪文数で変動）

## バフ・デバフシステム

### バフ一覧（常時発動またはアクティブ経由）

| バフ名 | 発動元 | 効果 | スタック |
|--------|--------|------|---------|
| ATKバフ | サポート効果・アクティブ | ATK +N（隣接/同行/全体対象） | 重複可・加算 |
| SPDバフ | サポート効果・アクティブ | 攻撃周期 -0.3s（最小0.3s） | 重複可・加算 |
| HPバフ | サポート効果 | 毎秒 HP 回復（常時） | 累積不可・最大1 |
| 後列攻撃 | サポート効果 | 後列ユニットが攻撃可（低ATK・スキル非発動） | 固定 |
| 吸血 | サポート効果・アクティブ | 攻撃ダメージの 25–30% 回復 | 固定 |
| 貫通 | アクティブ | 前列敵攻撃後、後列敵に 50% ダメージ波及 | 固定 |
| 障壁（鎧） | サポート効果 | 受けるダメージ -1（常時） | 重複可・加算 |
| リジェネ | サポート効果 | 2秒ごと HP 5% × スタック数 回復 | 重複可・加算 |
| 再起付与 | サポート効果 | 対象が撃破時 HP 1 で復活（1回限り） | 固定・1体1回 |

### 状態異常一覧

| 状態 | フィールド | 効果 | 逓減公式 |
|------|-----------|------|---------|
| 火傷（burn） | burn_turns | ATK 低下・毎秒処理 | `reduction = 0.8 * stacks / (stacks + 2)` |
| 凍結（frozen） | frozen_turns | 攻撃速度低下・毎秒処理 | `reduction = 0.8 * stacks / (stacks + 2)` |
| 麻痺（paralysis） | paralysis_turns | 行動不能・攻撃スキップ | 固定・単純カウント |
| 毒（poison） | poison_stacks | 毎秒 stacks ダメージ・倒した敵を復活可 | 線形・スタック可 |

**スケーリング詳細**
- 火傷・�凍結: 逓減公式で最大 80% 低下（stacks → ∞ のとき）
- 毒: 毎秒処理・スタック数に比例・線形スケーリング・毒で死亡したユニットは killer = null で処理

| スキル | ユニット | 効果 |

## 技術仕様

### アーキテクチャ

**実行フロー**
```
Main.gd（フレームループ）
  ├─ DeckManager.process_deck（マナ再生・デッキ巡回）
  ├─ EnemyAI.process_ai（敵ユニット配置）
  ├─ BoardManager.process_combat（攻撃・タイマー・イベント処理）
  │  └─ EventQueue.flush（優先度付きイベント一括処理・多パス）
  └─ UI更新（盤面・次カード・ログ出力）
```

**主要クラス**
- `Main.gd`: UI・ゲームループ統合・シグナルハンドラー
- `BoardManager.gd`: 盤面状態・攻撃解決・イベント駆動型 promote
- `DeckManager.gd`: プレイヤーデッキ管理・マナ・自動プレイ
- `EnemyAI.gd`: 敵デッキ管理・3.5s タイマー配置
- `UnitData.gd`: ユニット値オブジェクト・clone() で配置時リセット
- `SpellExecutor.gd`: 呪文効果 31 種実装
- `EventQueue.gd`: 優先度付きイベントキュー・多パスフラッシュ
- `DevUI.gd`: 開発モード UI（カード手動配置・ツールボタン）

### シグナル（BoardManager）

| シグナル | パラメータ | 説明 |
|---------|----------|------|
| unit_placed | (side, row, col, unit) | ユニット配置時 |
| unit_died | (side, row, col) | ユニット死亡時 |
