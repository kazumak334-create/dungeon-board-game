## 1. 概要

### 1.1 核となる体験

```text
盤面を設計して、介入を仕込んで、答え合わせを観戦する。
```

六角形パネル上に建物カードを配置し、都市を拡張しながら資源・食料・人口・幸福度・通貨・兵力を管理し、最終的に敵城下町へ突撃して勝利を目指す、都市建設 × デッキ構築 × 配置パズル型バトル。

### 1.2 ローグライト構造

| 項目 | 値 |
|---|---|
| 1ラン構成 | 全5戦 |
| 中ボス | 3戦目 |
| 最終ボス | 5戦目 |
| 引き継ぐもの | カードデッキのみ |
| 引き継がないもの | 盤面・資源・人口・兵力・幸福度すべて |

### 1.3 必須概念

| 概念 | 定義 |
|---|---|
| 人口 | 都市の労働力。稼働人口（生産）と作業人口（建設）に分割 |
| 幸福度 | 0-100 の数値。人口拡大・生産・兵力生成にペナルティ/ボーナス付与 |
| 兵力 | 兵舎が時間経過で蓄積する戦力ストック。突撃時にユニット化 |
| 資源 | 木材・石材・食料・硫黄・通貨（MVPは5資源、魔力・鉄鉱石は後回し） |
| 拠点HP | 自軍/敵軍の本拠地HP。任意突撃で削れる |
| 防壁 | 城下町外周の防衛構造。資源消費 + 建築キューで建設 |

### 1.4 戦闘ごとのマップ生成

| 戦闘 | マップ生成方式 |
|---:|---|
| 1戦目 | 初期パネル配分をもとにランダム配置（導入戦） |
| 2戦目 | バイオーム + 深度 |
| 3戦目（中ボス） | バイオーム + 深度（敵強化） |
| 4戦目 | バイオーム + 深度 |
| 5戦目（最終ボス） | バイオーム + 深度（最終ボス強化） |

## 2. ゲームフロー

### 2.1 1バトルの進行

| 項目 | 値 |
|---|---|
| 1ターン時間 | 30秒 |
| 最大ターン数 | 10ターン |
| 通常フェーズ最大時間 | 5分 |
| バトル間設計時間 | 60秒（プレイヤー準備完了で短縮可） |

### 2.2 進行モデル：セミリアルタイム制

```text
・時間はリアルタイムで進行する
・30秒ごとに1ターン進行する
・各ターン開始時に1ドローする
・建物効果は5秒tickで自動発動する
・カード使用・建物配置はリアルタイム
・任意タイミングで旗ON/OFFして突撃できる
・5分または10ターン終了で最終突撃フェーズへ移行
```

### 2.3 通常フェーズ（許可される操作）

| 操作 | 可否 |
|---|---|
| 建設 | 可 |
| 建物強化 | 可 |
| カード使用 | 可 |
| リロード | 可 |
| 追加ドロー | 可 |
| 兵力生成（兵舎） | 可 |
| 旗ON/OFF（任意突撃） | 可 |
| 人口配分（稼働/作業）変更 | 可（CTなし） |

### 2.4 最終突撃フェーズ

5分経過または10ターン終了時に強制移行する決戦フェーズ。

| 操作 | 可否 |
|---|---|
| 旗 | 双方強制ON |
| 蓄積兵力 | ユニット化して全出撃 |
| 建設 | 停止 |
| 建物強化 | 停止 |
| カード使用 | 停止 |
| リロード | 停止 |
| 追加ドロー | 停止 |
| ターンドロー | 停止 |
| 兵力生成 | 停止 |

### 2.5 勝敗条件

#### 通常フェーズ中

```text
勝利：敵拠点HP = 0
敗北：自拠点HP = 0
```

#### 最終突撃フェーズ中

```text
勝利：敵拠点HP = 0 または 敵ユニット全滅
敗北：自拠点HP = 0 または 自軍ユニット全滅
```

### 2.6 1ラン全体フロー

```text
ラン開始
↓
バトル1（初期パネル配分でランダム配置）
↓
60秒設計時間 + カード報酬選択
↓
バトル2（バイオーム + 深度）
↓
60秒設計時間 + カード報酬選択
↓
バトル3（中ボス）
↓
60秒設計時間 + カード報酬選択
↓
バトル4
↓
60秒設計時間 + カード報酬選択
↓
バトル5（最終ボス）
↓
ラン終了
```

## 3. カード・デッキシステム

### 3.1 カード領域（4領域）

| 領域 | 役割 | UI表示 |
|---|---|---|
| 山札 | これから引くカードの束 | あり |
| 手札 | 使用・リロード対象 | あり |
| 捨て札 | 使用済み通常建物・リロード捨て札 | あり |
| バトル中除外 | 使用済み政策・偉人。同一バトル中再ドロー不可 | **非表示**（内部処理用） |

### 3.2 カード種別と循環

| 種別 | 使用後の行き先 | 同一バトル循環 | 次バトル復帰 |
|---|---|---|---|
| 通常建物カード | 捨て札 | する | する |
| 政策カード | バトル中除外 | しない | する |
| 偉人カード | バトル中除外（盤面に偉人表示） | しない | する |

### 3.3 ドロー仕様

| 項目 | 値 |
|---|---|
| 初期手札 | 5枚 |
| 手札上限 | 7枚 |
| ターン開始ドロー | 1枚（30秒間隔） |
| バトル開始時のターン1ドロー | なし（初期手札5枚のみ） |
| リロードCT | 5秒 |
| リロード対象 | 全カード（種別不問） |
| 追加ドロー消費 | 対象リソース15個 |
| 山札切れ時 | 捨て札シャッフルで山札再構築 |
| 山札も捨て札も空 | ドロー失敗（コスト消費なし） |
| 手札上限時のドロー要求 | ドローしない（コスト消費なし） |

### 3.4 リロード仕様

```text
手札カードを1枚選択
↓
リロード実行
↓
選択カードを捨て札へ送る
↓
山札から1枚引く
↓
リロードCT 5秒開始
```

リロードは使用扱いではない。政策/偉人をリロードしてもバトル中除外には行かず、捨て札へ送る。

### 3.5 通常建物カード使用フロー

```text
建物カード使用
↓
資源確認（不足なら使用不可・手札に残る）
↓
配置先選択（不可なら使用不可・手札に残る）
↓
資源支払い・建設キュー投入
↓
カードは捨て札へ
```

### 3.6 政策カード使用フロー

```text
政策カード使用
↓
コスト確認（不足なら使用不可・手札に残る）
↓
効果即時発動
↓
カードはバトル中除外へ（UI上は手札から消える）
↓
バトル終了時にデッキ復帰
```

### 3.7 偉人カード使用フロー

```text
偉人カード使用
↓
配置可能パネル選択
↓
コスト/条件確認（不足なら使用不可・手札に残る）
↓
盤面に偉人を表示
↓
カードはバトル中除外へ
↓
偉人効果はバトル中継続
↓
バトル終了時にデッキ復帰
```

### 3.8 デッキ編集ルール（MVP）

| 項目 | MVP仕様 |
|---|---|
| 同名カード制限 | なし |
| デッキ上限 | なし |
| デッキ圧縮 | なし |
| 自由なデッキ編集 | なし |
| マリガン | なし |
| バトル中カード報酬選択 | なし（バトル後に処理） |

### 3.9 設計時間中の初期手札表示

```text
バトル間設計時間（60秒）開始
↓
ランデッキをシャッフル
↓
初期手札5枚を確定して表示
↓
プレイヤーはマップと手札を見て方針を考える
↓
60秒経過または準備完了でバトル開始
```

設計時間中：マリガン不可、リロード不可、カード使用不可。バトル開始後にリロード可能。

### 3.10 バトル終了時の処理

```text
バトル終了
↓
手札・山札・捨て札・バトル中除外を回収
↓
盤面上の偉人表示をクリア
↓
ランデッキへ戻す
↓
報酬カードを追加
↓
次バトル開始前にシャッフル
```

### 3.11 任意突撃中のカード操作

任意突撃は通常フェーズ中の攻撃イベントとして扱う。  
**カード使用・リロード・追加ドロー・ターンドローはすべて継続**。

## 4. 盤面システム

### 4.1 盤面構造

- 六角形パネル（ヘクスグリッド）で構成
- 1パネル = 1建物（1建物が1ヘクスを占有）
- 城下町クラスター = 隣接する建物群のまとまり

### 4.2 拠点（自軍/敵軍）

| 項目 | 値 |
|---|---|
| 拠点HP（初期値） | 200 |
| 拠点占有 | 1ヘクス |
| 同時攻撃可能ユニット数 | 周囲6パネル × スタック上限3 = 最大18 |
| 拠点LvUP | 建設キューで処理（必要作業量30） |

**拠点LvUP効果**：Sprint 0 で詳細を決定（未定義パラメータ）。

### 4.3 建物分類

| 分類 | 定義 | 例 |
|---|---|---|
| アクティブ型 | 稼働人口割当時のみ生産・効果発動 | 製材所・採掘所・農場・市場・交換所・兵舎・防衛拠点・鍛冶屋 |
| パッシブ型 | 建設完了後、稼働人口なしで効果発揮 | 住居・広場・防壁・拠点 |
| 建設中 | 種別問わず効果停止・人口消費なし・パネル占有 | - |

### 4.4 建物一覧（MVP）

| 建物 | 種別 | 必要稼働人口 | 必要作業量 | 効果概要 |
|---|---|---:|---:|---|
| 製材所 | アクティブ | 1 | 10 | 木材生産 |
| 採掘所 | アクティブ | 1 | 10 | 採掘リソース生産（石材・硫黄）※鉄鉱石はMVP範囲外 |
| 農場 | アクティブ | 1 | 10 | 食料生産 |
| 住居 | パッシブ | 0 | TBD | 人口上限+10〜20（Lvにより） |
| 広場 | パッシブ | 0 | TBD | 5秒ごとに幸福度供給 |
| 市場 | アクティブ | 1 | TBD | 通貨生産 |
| 交換所 | アクティブ | 1 | TBD | 通貨を消費して追加ドロー（Lv1基準、Lv2以上はCT短縮またはコスト削減） |
| 兵舎 | アクティブ | 1 | 15 | 兵力生成 |
| 防衛拠点 | アクティブ | 1 | TBD | 防衛兵力統括・防壁回復 |
| 防壁 | パッシブ（建築のみ） | 0 | 5/辺 | 通行遮断・敵迂回 |
| 鍛冶屋 | アクティブ | 1 | TBD | 隣接兵舎のユニットDPS強化 |

各建物の資源コストは **Sprint 0 で決定**（未定義パラメータ）。

### 4.5 建物詳細仕様 — 鍛冶屋

**種別**：アクティブ型

**必要稼働人口**：1

**対象**：隣接する兵舎

**効果**：隣接兵舎から出撃するユニットのDPS+X%

**Lv別効果**：
- Lv1：DPS +10%
- Lv2：DPS +15%
- Lv3：DPS +20%

**適用タイミング**：ユニット化して出撃する時

**対象出撃**：
- 任意突撃
- 最終突撃
- 防衛拠点による防衛出撃

**非稼働時**：効果なし

**複数隣接時**：最も高いLvの効果のみ適用（重複しない）

**建物コスト**：初期実装値を参照（未定義の場合は要件定義時に決定）

### 4.6 初期配置ルール

- 1戦目：初期パネル配分をもとにランダム配置
- 2戦目以降：バイオーム + 深度でマップ生成
- バイオーム/深度生成詳細は Sprint 5 で決定

### 4.7 建設システム

```text
建物カードプレイ
↓
資源支払い
↓
建設キューに追加
↓
作業人口が工事を進める
↓
完了後に建物有効化
```

建設キューで処理する対象：
- 新規建物建設
- 建物強化（Lv1→Lv2→Lv3）
- 防壁建設・防壁再建
- 防衛拠点強化
- 拠点レベルアップ

#### 建設時間計算

```text
建設時間 = 残作業量 ÷ 割当作業人口
```

最大投入人数の上限なし。作業人口は優先度順に自動配分。

#### 即時建設

```text
即時建設コスト = ceil(残作業量 × 0.5)
最低コスト = 通貨1
```

通貨を支払うことで残工数に応じた即時完了が可能。

### 4.8 建物強化（Lv1〜Lv3）

| Lv | コスト | 効果差分 |
|---|---|---|
| Lv1 | 建設コスト基準 | 基本効果 |
| Lv2 | 建設コストの50% | +25%生産系 |
| Lv3 | 建設コストの100% | +50%生産系 |

**強化はバトル中のみ有効**（次バトルにはリセット）。  
強化中も現在Lv効果は維持。強化中の追加強化は不可。

#### 主要建物の強化効果

| 建物 | Lv1 | Lv2 | Lv3 |
|---|---|---|---|
| 製材所 | 通常生産 | 木材+25% | 木材+50% |
| 採掘所 | 通常生産 | 採掘リソース+25% | 採掘リソース+50% |
| 農場 | 通常生産 | 食料+25% | 食料+50% |
| 住居 | 人口上限+10 | +15 | +20 |
| 広場 | 5秒ごと幸福度+1（隣接住居+1/件） | +2（隣接+1/件） | +3（隣接+1/件） |
| 市場 | 通常通貨生産 | +25% | +50% |
| 交換所 | 通貨で追加ドロー（CT基準） | CT短縮またはコスト削減 | CT短縮またはコスト削減（強化）|
| 兵舎 | 5秒ごと兵力+2 | +3 | +4 |
| 防衛拠点 | 防衛範囲2 | 範囲2・防壁+10HP/5秒 | 範囲3・防壁+15HP/5秒 |
| 鍛冶屋 | 隣接兵舎DPS+10% | 隣接兵舎DPS+15% | 隣接兵舎DPS+20% |

## 5. リソース・人口システム

### 5.1 資源（MVP範囲）

| 資源 | 用途 | 主な生産源 |
|---|---|---|
| 木材 | 建設コスト | 製材所 |
| 石材 | 建設・防壁コスト | 採掘所 |
| 硫黄 | 建設コスト補助 | 採掘所 |
| 食料 | 人口維持 | 農場 |
| 通貨 | 政策・即時建設・交換所ドロー | 市場 |
| 鉄鉱石 | （MVPでは後回し・将来Lv2以上の建設コスト補助予定） | - |
| 魔力 | （MVPでは後回し） | - |

**MVPでは交易は実装しない**。通貨用途は政策コスト・祝祭コスト・交換所ドロー・即時建設に限定。

### 5.2 5秒ティック処理（同期）

以下の処理は5秒tickに同期して実行する：

| 処理 | 内容 |
|---|---|
| 資源生産 | アクティブ建物の生産 |
| 人口消費 | 食料消費の計算（計算式は Sprint 0 で決定） |
| 兵舎生成 | 兵力生成（Lvに応じて） |
| 幸福度更新 | 幸福度の再計算 |
| 広場供給 | 幸福度+1/+2/+3（Lvにより） |
| 防衛拠点回復 | 範囲内防壁HP+10/+15（Lv2/Lv3） |
| 人口配分 | 稼働/作業の再計算 |

**処理順序は Sprint 0 で決定**（未定義パラメータ）。

### 5.3 人口

```text
人口 = 都市の労働力
```

| 人口種別 | 役割 |
|---|---|
| 稼働人口 | アクティブ建物を動かす |
| 作業人口 | 建設・強化・防壁再建・拠点LvUPを進める |

#### 配分バー

```text
稼働人口 ←→ 作業人口
スナップポイント：25 / 50 / 75
初期値：稼働75 / 作業25
変更CT：なし（戦闘中いつでも変更可）
再計算：5秒tickごと
```

#### アクティブ建物稼働順（都市優先度）

候補：
- バランス
- 資源優先
- 食料優先
- 建設優先
- 通貨・ドロー優先
- 軍事優先
- 防衛優先

同カテゴリ内：
1. 高Lv建物
2. 拠点に近い建物
3. 先に建てた建物

**個別建物の手動固定稼働は MVP では実装しない**。

#### 人口拡大のルール

- 食料消費の計算式：**Sprint 0 で決定**（未定義パラメータ）
- 食料不足時の挙動：人口増加停止（既存方針）
- 住居が人口上限を提供（Lv1=+10, Lv2=+15, Lv3=+20）
- 兵力は人口とは別ストック（住居上限を消費しない・幸福度負荷に含めない）

### 5.4 幸福度

| 項目 | 値 |
|---|---|
| 範囲 | 0〜100 |
| 初期値 | 60 |
| 更新頻度 | 5秒tick |
| 基本式 | 幸福度変動 = 幸福供給 − 人口負荷 |

#### 人口負荷

```text
人口10人ごとに、5秒ごと幸福度-1
```

| 人口 | 5秒負荷 |
|---:|---:|
| 0〜9 | 0 |
| 10〜19 | -1 |
| 20〜29 | -2 |
| 30〜39 | -3 |
| 40〜49 | -4 |
| 50〜59 | -5 |

#### 幸福供給源（MVP）

- 広場
- 祝祭政策
- 宝物の即時報酬

#### 幸福度状態と効果

| 幸福度 | 状態 | 効果 |
|---:|---|---|
| 70〜100 | 高幸福 | 人口増加速度+20%、兵力生成+10% |
| 40〜69 | 通常 | 補正なし |
| 20〜39 | 不満 | 人口増加停止、アクティブ建物生産-10% |
| 0〜19 | 危険 | 人口増加停止、アクティブ建物生産-25%、兵力生成-20% |

**低幸福ペナルティはアクティブ建物の生産・生成系にのみ適用**。  
パッシブ建物・防壁HP・住居上限・広場供給には適用しない。

## 6. 兵力・ユニットシステム

### 6.1 兵力の基本方針

```text
兵力は人口を直接消費しない。
兵舎が時間経過で集める/訓練する戦力ストック。
```

| 項目 | 仕様 |
|---|---|
| 兵舎稼働条件 | 必要稼働人口1（アクティブ型） |
| 兵力蓄積先 | 兵舎ごと（都市プールではない） |
| 住居上限消費 | しない |
| 幸福度負荷 | 含めない |
| 稼働人口/作業人口計算 | 含めない |

### 6.2 兵舎の兵力生成（5秒tick・整数固定値）

| 兵舎Lv | 5秒ごとの兵力生成量 |
|---|---:|
| Lv1 | +2 |
| Lv2 | +3 |
| Lv3 | +4 |

**割合補正ではなく整数固定値で扱う**（表示・調整の容易さ優先）。

### 6.3 幸福度補正

```text
補正後生成量 = 基礎生成量 × 幸福度補正
```

- 幸福度70以上：×1.1
- 幸福度0〜19：×0.8

内部値は小数で蓄積、UI表示は整数に丸める。

### 6.4 任意突撃中の兵力生成

**継続する**（統合優先で確定）。

```text
旗ON中の通常フェーズ：
・兵舎は5秒tickで兵力生成を継続
・新規生成された兵力は即出撃する（蓄積されず流れる）
```

### 6.5 最終突撃フェーズの兵力生成

**停止する**。

```text
最終突撃フェーズ：
・兵力生成停止
・蓄積兵力をすべてユニット化して全出撃
・以後、新規ユニット供給なし
```

### 6.6 旗ON/OFFの挙動

| 状態 | 挙動 |
|---|---|
| 旗OFF | 新規生成兵力は兵舎に蓄積。ユニット出撃なし |
| 旗ON（任意突撃） | 蓄積兵力をユニット化して出撃。新規生成兵力も即出撃 |
| 旗OFFに戻す | 新規生成兵力は再度蓄積。出撃済みユニットは戦闘継続 |
| 任意突撃 | 複数回可能 |

### 6.7 兵力 → ユニット変換

| 項目 | 値 |
|---|---:|
| 変換レート | 兵力10 = 1ユニット |
| 1ユニット最大HP | 10 |
| 残存HP | 残存兵力と同値 |
| 端数処理 | 端数兵力も端数ユニットとして出撃 |
| 出撃ペース | 各兵舎0.2秒/ユニット |

#### 例

```text
兵舎の蓄積兵力27
↓
HP10ユニット × 2体
HP7ユニット × 1体
```

### 6.8 ユニットDPS

```text
ユニットDPS = 残存兵力 × 基礎DPS係数
基礎DPS係数 = 0.2
```

#### 例

| 残存兵力 | DPS |
|---:|---:|
| 10 | 2.0 |
| 5 | 1.0 |

傷ついたユニットは火力も落ちる（残存HPが残存兵力として機能）。

### 6.9 対象別ダメージ補正（MVP初期値）

| 補正 | 値 |
|---|---:|
| 対ユニット補正 | 1.0 |
| 対防壁補正 | 1.0 |
| 対拠点補正 | 1.0 |

```text
対ユニットダメージ = ユニットDPS × 対ユニット補正
対防壁ダメージ   = ユニットDPS × 対防壁補正
対拠点ダメージ   = ユニットDPS × 対拠点補正
```

### 6.10 スタック仕様

| 項目 | 値 |
|---|---:|
| 1パネル最大スタック | 3ユニット |

- 同パネル内のユニットはそれぞれ攻撃に参加
- 進行先がスタック上限に達している場合は近い代替パネルへ展開
- 「集中して、詰まったら広がる」挙動

### 6.11 防壁

| 項目 | 値 |
|---|---:|
| 1辺あたりHP | 60 |
| 1辺あたり建設コスト（石材） | 2 |
| 1辺あたり必要作業量 | 5 |
| 防壁HP管理単位 | パネル所属防壁グループ単位 |

```text
防壁HP = 1辺あたりHP × 設置辺数
```

#### 防壁攻撃

```text
同時攻撃可能ユニット数 = 攻撃可能外側パネル数 × 1パネル最大スタック数（=3）
防壁への総DPS = 接敵全ユニットのDPS合計
```

#### 防壁HP0時の挙動

- 該当パネルの防壁群はまとめて消える（1辺だけ穴を開ける仕様にしない）
- 自動再建なし（資源を払って建築キューに入れる必要あり）

#### 城下町外側建設時の防壁更新

```text
1. 新建物の建設確定
2. 城下町クラスターに統合
3. 旧防壁のうち都市内部化したものを撤去（資源は戻らない）
4. 新外周辺を再計算
5. 新外周辺に防壁建設キューを自動追加
6. 完成順に有効化
```

防壁再建中：旧撤去済み + 新未完成 = 無防備。敵通行可能。

#### 防壁越し攻撃

- 近接ユニット：防壁越しの敵ユニット攻撃**不可**。防壁そのものは攻撃**可能**
- 遠距離ユニット：射程内なら防壁越し攻撃**可能**（MVP では弓兵未実装）

### 6.12 見張り塔（防衛拠点）

| Lv | 名称 | 効果 |
|---|---|---|
| Lv1 | 防衛指揮所 | 防衛範囲2、範囲内兵舎から防衛兵力出撃、敵がいなくなったら生存兵力返還 |
| Lv2 | 修復指揮所 | 防衛範囲2、範囲内防壁を5秒ごとにHP+10回復（攻撃中も対象、破壊済みは復活しない） |
| Lv3 | 広域防衛司令部 | 防衛範囲3、範囲内防壁を5秒ごとにHP+15回復、防衛ユニット反応/帰還範囲も3 |

**MVP の見張り塔HP**：要件定義書では 200（注：v0.2 MVP は防衛拠点が「見張り塔」を兼ねる）

### 6.13 拠点ダメージの目安

```text
拠点HP = 200
1ユニットDPS = 2.0
最大攻撃ユニット = 6パネル × 3ユニット = 18

10ユニット接敵：合計DPS 20 → 拠点撃破 10秒
18ユニット包囲：合計DPS 36 → 拠点撃破 約5.6秒
```

包囲できたら一気に落ちる感覚を作る。

### 6.14 防壁破壊時間の目安

| 防壁辺数 | 防壁HP | 攻撃面 | 最大ユニット | 合計DPS | 破壊時間 |
|---:|---:|---:|---:|---:|---:|
| 2辺 | 120 | 2パネル | 6 | 12 | 10秒 |
| 3辺 | 180 | 3パネル | 9 | 18 | 10秒 |

辺数が増えてもHPと攻撃面が比例して増えるため、突破時間はおおむね一定。

### 6.15 攻撃優先順位

#### 突撃側

1. 敵拠点へ到達可能なら敵拠点を優先
2. 経路上の防壁を攻撃
3. 進路上の敵ユニットを攻撃
4. 攻撃してきた敵ユニットへ反撃

突撃側は防衛ユニットを深追いしない（目的は敵拠点到達）。

#### 防衛側

1. 拠点に近い敵ユニット
2. 防壁を攻撃中の敵ユニット
3. 防衛範囲内の最も近い敵ユニット

### 6.16 防衛兵力

```text
防衛拠点が範囲内兵舎から兵力を引き出す
↓
防衛ユニット化（同パネル最大3ユニット）
↓
迎撃
↓
敵ユニットがいなくなったら生存分が兵力として戻る
```

| 項目 | 値 |
|---|---|
| 防衛兵力返還率 | 100%（生存兵力ぶん） |
| 攻撃側ユニット帰還 | なし（攻撃に出した兵力は消費扱い） |

「攻撃は戻らない、防衛は戻る」非対称設計が攻める/守るの判断に緊張感を与える。

## 14. 最終方針（要約）

```text
盤面は毎バトル作り直す。
ラン中に成長するのはカードデッキ。

人口は都市の労働力として、稼働人口（現在出力）と作業人口（未来出力）に分ける。
兵力は人口を直接消費せず、兵舎が時間経過で訓練・徴募する戦力ストックとして扱う。

防壁は都市外周を守るが、都市拡張時には旧防壁を撤去し新防壁を建設キューで再建する。

突撃は一度きりの決戦ではなく、通常フェーズでは旗ON/OFFによって兵力を放出・蓄積する。
任意突撃中も兵力生成と内政は継続する。
5分/10ターン後の最終突撃フェーズでは、兵力生成を停止して決着をつける。

通常建物カードは循環し、政策・偉人カードはバトル中除外として扱う。
リロード5秒CTと初期手札5枚で初動事故を緩和し、追加ドローはリソース15消費で行う。

MVPでは特殊ユニット変換・マリガン・デッキ圧縮・交易などは実装せず、
基礎ループの完成度に集中する。
```

## 付録A: 廃止済み設計（復活禁止）

以下は意図的に廃止した設計。復活要望があれば必ず確認を取ること。

| 廃止した設計 | 廃止理由 |
|---|---|
| 旧書庫仕様（通貨1で1ドロー） | リソース15消費ドローに統一 |
| 兵力の人口直接消費 | 兵舎による時間経過生成に統一 |
| 1辺ごとの個別防壁HP管理 | パネル単位の防壁グループHPに統一 |
| 防壁HP0時の部分破壊（穴） | パネル単位でまとめて破壊 |
| 防壁の自動復旧 | 手動再建（資源払って建築キュー） |
| ラン中永続の建物強化 | バトル中限定強化に統一（成長はデッキに集約） |
| バトル中カード報酬選択 | バトル後にまとめて処理（テンポ優先） |
| 兵力ストックの兵種別管理 | 通常兵力一本化（変換は突撃時のみ） |
| 攻撃側ユニットの帰還 | 攻撃は戻らない（リスク非対称設計） |
