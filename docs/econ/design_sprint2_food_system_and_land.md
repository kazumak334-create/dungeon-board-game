# Sprint 2 企画書：食料値・食堂・製粉所システム

## 1. 目的

Sprint 2では、食料値システムを実装し、食堂・製粉所を土地パネル上の小麦・香辛料タグに接続する。

本企画書は、食料値の定義、食堂・製粉所の効果、小麦パネルとの連携、香辛料タグボーナスを定義する。

---

## 2. 食料値システム基盤

### 2.1 食料値の定義

```
食料値（FoodValue）：
- 都市ステータスの1つ
- 人口維持・満足度に影響
- 建物（食堂）で獲得
- 食堂・製粉所で消費
```

### 2.2 初期値と範囲

```
初期値：10
最小値：0
最大値：200（仮）
```

### 2.3 食料値の役割

```
人口維持コスト：
- 毎ターン人口による食料値消費
- 例：人口100 → 食料値消費0.1/ターン

満足度への影響：
- 食料値充足時：満足度安定
- 食料値不足時：満足度低下
```

## 3. 小麦リソース管理

### 3.1 小麦の定義と取得

```
小麦（Wheat）：
- 通常資源の1種
- 農村で土地パネルから獲得
- 食堂で食料値へ変換
- 製粉所で小麦生産をブースト
```

### 3.2 小麦パネル配置の制約

小麦パネルは農村の配置場所に制約を与える。

```
農村を配置できる土地：
- 小麦単一資源パネル（値1以上）
- 綿花単一資源パネル（値1以上）
- 小麦/綿花複合パネル

農村を配置できない土地：
- 木・樹脂パネル
- 石・鉄鉱石パネル
- 特殊タグのみパネル
- 地形パネル
```

### 3.3 小麦値の意味

小麦値が高いパネルほど、農村の効率が良くなる（将来）。

```
小麦値 1-2：低効率
小麦値 3-4：標準効率
小麦値 5+：高効率
```

### 3.5 建物配置・資源値開示ルールの継承（Sprint 1 §12.3 参照）

Sprint 1 で定義された配置ルールは、Sprint 2 の農村・食堂・製粉所にも継承される。

```
配置可能条件（必須2要件）：
- 条件1：自建物隣接（既存の自建物の上下左右4マスのいずれか）
- 条件2：資源値開示済み（is_discovered = true）

両条件を満たさないパネルへの配置は禁止。
未開示パネル（「?」表示）には農村・食堂・製粉所も配置できない。
```

### 3.6 建物別の追加配置条件

Sprint 1 共通ルールに加えて、各建物には固有の配置制約がある（§5.2 / §6.2 参照）。

| 建物 | 共通条件（§3.5） | 固有制約 |
|---|---|---|
| 農村 | 隣接 + 開示済み | 小麦/綿花単一 or 小麦/綿花複合パネル |
| 食堂 | 隣接 + 開示済み | 制限なし（任意パネル） |
| 製粉所 | 隣接 + 開示済み | 小麦単一 or 小麦/綿花複合（小麦値1以上） |

## 4. 小麦/綿花複合パネル

### 4.1 複合パネルの定義

小麦/綿花複合パネルは、2種類の農業資源を持つパネル。

```
例：
- 小麦2 / 綿花1
- 小麦3 / 綿花2
```

### 4.2 複合パネルの特性

```
農村の配置選択肢：
- 小麦重視：小麦値が高い側を活かす
- 綿花重視：綿花値が高い側を活かす
- 柔軟性：どちらでも配置可能

施設の対応関係：
農村：小麦/綿花両対応
食堂：小麦値に基づく（綿花値は無視）
製粉所：小麦値に基づく
```

### 4.3 複合パネルの出現比率

```
近距離：20%
中距離：25%
遠距離：25%
報酬：30%～50%
```

## 5. 食堂システム

### 5.1 食堂の基本効果

```
食堂（通常）：
- 小麦1を消費
- 食料値+2を獲得
- タイマーで定期的に発動（5秒ごと）
```

### 5.2 配置条件

```
食堂を配置できる土地：
- 全ての土地パネル（特殊タグパネル含む）

食堂を配置できない土地：
- なし（制限なし）
```

### 5.3 香辛料タグ上の食堂ボーナス

香辛料タグが付いているパネルに食堂を配置すると、食料値獲得量が増える。

```
食堂（香辛料タグ上）：
- 小麦1を消費
- 食料値+3を獲得（通常+1）
- タイマーで定期的に発動（5秒ごと）
```

### 5.4 稼働条件

食堂が稼働するには、以下の条件を満たす必要がある。

```
稼働必須条件：
- 小麦1以上が在庫にある（消費可能）
- 必要人手が割当済みである
- 建物タイマーが発動可能状態
```

### 5.5 停止条件

以下の条件で食堂は稼働を停止する。

```
停止条件：
- 小麦が0になった（消費不可）
- 割当人手が不足した
- タイマーがリセット状態
- 建物が破壊/撤去された
```

### 5.6 小麦消費メカニクス

```
Step 1: タイマー発火
Step 2: 小麦在庫確認
Step 3: 小麦1を消費
Step 4: 食料値を加算（+2 or +3）
Step 5: ログに記録
```

### 5.7 香辛料タグの判定

```
Step 1: 建物の足元パネルを確認
Step 2: パネルが香辛料タグを持つか判定
Step 3: 持つ場合、ボーナス適用（+1）
Step 4: ログに「香辛料ボーナス適用」と記録
```

## 6. 製粉所システム

### 6.1 製粉所の基本効果

```
製粉所（通常）：
- 小麦1を消費
- 小麦+2を獲得
- タイマーで定期的に発動（5秒ごと）
```

### 6.2 配置条件

```
製粉所を配置できる土地：
- 小麦単一資源パネル（値1以上）
- 小麦/綿花複合パネル（小麦値1以上）

製粉所を配置できない土地：
- 木・樹脂パネル
- 石・鉄鉱石パネル
- 特殊タグのみパネル
- 地形パネル
```

### 6.3 小麦高値パネル上のボーナス

小麦値が3以上のパネルに製粉所を配置すると、小麦獲得量が増える。

```
製粉所（小麦3以上パネル上）：
- 小麦1を消費
- 小麦+2を獲得
- さらに小麦+1ボーナス
- 合計小麦+3を獲得
- タイマーで定期的に発動（5秒ごと）
```

### 6.4 稼働条件

製粉所が稼働するには、以下の条件を満たす必要がある。

```
稼働必須条件：
- 小麦1以上が在庫にある（消費可能）
- 必要人手が割当済みである
- 建物タイマーが発動可能状態
```

### 6.5 停止条件

以下の条件で製粉所は稼働を停止する。

```
停止条件：
- 小麦が0になった（消費不可）
- 割当人手が不足した
- タイマーがリセット状態
- 建物が破壊/撤去された
```

### 6.6 小麦値判定ロジック

```
Step 1: タイマー発火
Step 2: 建物の足元パネルを確認
Step 3: パネルから小麦値を取得
Step 4: 小麦値 >= 3 か判定
Step 5: YES の場合、小麦+3（ボーナス+1）
Step 6: NO の場合、小麦+2（通常）
Step 7: ログに小麦値・ボーナス適用有無を記録
```

### 6.7 複合パネル上の製粉所

複合パネル上に製粉所を配置した場合、小麦値のみを参照する。

```
パネル例：小麦2 / 綿花3

製粉所の判定：
- 参照する値：小麦2
- 条件：小麦値2 < 3 → ボーナスなし
- 獲得：小麦+2（通常）

パネル例：小麦4 / 綿花1

製粉所の判定：
- 参照する値：小麦4
- 条件：小麦値4 >= 3 → ボーナスあり
- 獲得：小麦+3（ボーナス+1）
```

## 8. 建物タイマーシステム

### 8.1 タイマーの基本仕様

食堂・製粉所は定期的に動作するため、タイマーメカニクスを持つ。

```
建物タイマー：
- 種類ごとに異なる周期
- ゲームのメインループと連動
- ポーズ時は停止
- リセット機能
```

### 8.2 食堂・製粉所のタイマー周期

```
周期：5秒（Google Drive確定版で統一）
```

### 8.3 タイマー発火フロー

```
Step 1: タイマーをカウントダウン
Step 2: タイマーが0に達する
Step 3: 稼働条件をチェック
Step 4: 条件をすべて満たす場合、効果を実行
Step 5: タイマーをリセット
Step 6: ログに記録
```

## 9. リソース流通ネットワーク

### 9.1 小麦の流通図

```
小麦パネル
  ↓
農村 → 小麦獲得
  ↓
  ├→ 食堂（小麦消費 → 食料値+2/+3）
  └→ 製粉所（小麦消費 → 小麦+2/+3 → 再流通）

小麦高値パネル（3以上）
  ↓
製粉所 → 小麦+3ボーナス

香辛料タグパネル
  ↓
食堂 → 食料値+3ボーナス
```

### 9.2 多重建物による効率化

複数の農村・製粉所を配置することで、小麦生産を加速できる。

```
例：3個の農村 + 2個の製粉所
- 農村3個で小麦定期獲得
- 製粉所2個で小麦再生産
- 小麦獲得スピードが加速
```

## 10. 食料値の消費フロー

### 10.1 食料値消費箇所

```
人口維持：
- 毎ターン人口に基づく消費
- 例：人口100 → 食料値-0.1/ターン

満足度低下防止：
- 食料値不足時、満足度が低下
```

### 10.2 食料値獲得フロー

```
食堂で獲得：
- 小麦1消費 → 食料値+2 or +3
```

### 10.3 食料値バランス

プレイヤーは以下のバランスを取る必要がある。

```
獲得 vs 消費：
- 食堂で小麦→食料値変換
- 人口で食料値消費
- 製粉所で小麦再生産

リソース選択：
- 小麦を食堂に使う（食料値重視）
- 小麦を製粉所に使う（小麦生産重視）
```
