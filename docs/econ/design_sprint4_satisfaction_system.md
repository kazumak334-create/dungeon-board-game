# Sprint 4：満足度システム企画書 確定版

## 1. 目的

Sprint 4では、都市の満足度を管理するために、満足値・満足値傾き・満足度段階を実装する。

本企画書は、満足度システムの計算式、基礎満足傾き、人口規模影響、人口変化量影響、食料不足ペナルティ、建築物影響の受け口、満足度段階を定義する。

---

## 2. 対象

Sprint 4で扱う対象は以下。

```text
- 満足値
- 満足値傾き
- 満足度段階
- 基礎満足傾き
- 人口規模影響
- 人口変化量影響
- 食料不足ペナルティ
- 建築物影響の受け口
- 満足度段階算出
- 人口システムへの満足度段階連携
```

---

## 3. 前提

### 3.1 人口スケール

人口は内部的には抽象人口値として管理する。

```text
内部人口1 = 1k人
```

表示例：

| 内部人口 | UI表示 |
|---:|---|
| 50 | 50k人 |
| 100 | 100k人 |
| 500 | 500k人 |
| 1000 | 1.0M人 |

### 3.2 人口システムとの関係

Sprint 3では、満足度段階が人口増加率・人口減少率に接続する。

Sprint 4では、満足度段階を正しく算出し、人口システムへ渡せるようにする。

---

## 4. 満足値

### 4.1 定義

満足値は、都市の現在の満足状態を表す値である。

```text
満足値：
0〜100%
```

### 4.2 初期値

```text
初期満足値：
60%
```

初期状態は「満足」段階から開始する。  
ただし、少し悪化すると「安定」へ落ちるため、改善・悪化の両方を確認しやすい。

### 4.3 クランプ

満足値は0〜100%にクランプする。

```text
満足値下限：0%
満足値上限：100%
```

---

## 5. 満足値傾き

### 5.1 定義

満足値傾きは、満足値が時間経過で増減する速度である。

```text
満足値 = 満足値 + 満足値傾き × 経過秒数
```

### 5.2 上限/下限

満足値傾きには、上限/下限を設定しない。

```text
満足値傾き：
上限なし
下限なし
```

満足値傾きは、要因合算の結果として自然に決まる。  
食料不足・人口過多・人口急増などの悪化要因が重なった場合、急激に満足値が低下してよい。

ただし、満足値そのものは0〜100%にクランプする。

---

## 6. 満足値傾きの式

### 6.1 基本式

```text
満足値傾き =
基礎満足傾き
+ 人口規模影響
+ 人口変化量影響
+ 建築物影響
+ 政策影響
+ 特殊タグ影響
- 食料不足ペナルティ
- その他ペナルティ
```

### 6.2 MVPで使う項目

```text
- 基礎満足傾き
- 人口規模影響
- 人口変化量影響
- 建築物影響の受け口
- 食料不足ペナルティ
```

### 6.3 MVP非対象

```text
- 政策影響
- 特殊タグ影響
- その他ペナルティ
```

---

## 7. 基礎満足傾き

### 7.1 定義

基礎満足傾きは、都市が最低限機能している場合に発生する自然な満足回復である。

```text
基礎満足傾き = +0.03%/秒
```

### 7.2 役割

基礎満足傾きは、人口規模が小さい段階では満足値が自然に上がりやすい状態を作る。

人口が増えると、人口規模影響によって基礎満足傾きが相殺される。  
さらに人口が増えると、人口規模影響が基礎満足傾きを上回り、満足値傾きは自然に悪化しやすくなる。

---

## 8. 人口規模影響

人口が多いこと自体による、満足値傾きへの補正である。

人口が増えるほど、要望の多様化・都市サービス負荷・政策カバレッジ低下によって満足度維持が難しくなる。

| 内部人口 | UI表示 | 人口規模影響 |
|---:|---|---:|
| 1〜50 | 1k〜50k人 | +0.02%/秒 |
| 51〜100 | 51k〜100k人 | 0%/秒 |
| 101〜250 | 101k〜250k人 | -0.03%/秒 |
| 251〜500 | 251k〜500k人 | -0.06%/秒 |
| 501〜750 | 501k〜750k人 | -0.10%/秒 |
| 751〜1000 | 751k〜1.0M人 | -0.14%/秒 |
| 1001以上 | 1.0M人超 | -0.18%/秒 |

### 8.1 基礎満足傾きとの関係

人口規模影響は、人口増加に伴う都市運営負荷として、基礎満足傾きを相殺・悪化させる。

例：

```text
内部人口50以下：
基礎満足傾き +0.03
人口規模影響 +0.02
合計 +0.05%/秒
```

```text
内部人口51〜100：
基礎満足傾き +0.03
人口規模影響 0
合計 +0.03%/秒
```

```text
内部人口101〜250：
基礎満足傾き +0.03
人口規模影響 -0.03
合計 0%/秒
```

```text
内部人口251〜500：
基礎満足傾き +0.03
人口規模影響 -0.06
合計 -0.03%/秒
```

```text
内部人口751〜1000：
基礎満足傾き +0.03
人口規模影響 -0.14
合計 -0.11%/秒
```

---

## 9. 人口変化量影響

人口が増えている状態は、都市運営への負荷として満足値傾きを下げる。

### 9.1 計算式

```text
人口変化量影響 = max(0, 人口増加速度) × -0.2
```

単位：

```text
人口増加速度：
内部人口/秒

人口変化量影響：
%/秒
```

### 9.2 例

```text
人口増加速度 +0.2/秒
→ 満足値傾き -0.04%/秒
```

```text
人口増加速度 +0.3/秒
→ 満足値傾き -0.06%/秒
```

### 9.3 人口減少中

MVPでは、人口減少中の人口変化量影響は加算しない。

```text
人口減少中：
人口変化量影響 = 0
```

## 10. 食料不足ペナルティ

### 10.1 定義

食料不足ペナルティは、食料不足カウントに応じて満足値傾きを悪化させるペナルティである。

```text
食料不足ペナルティ = 食料不足カウント × 0.50%/秒
```

満足値傾きの式では、マイナス項目として扱う。

### 10.2 例

```text
食料不足カウント1：
満足値傾き -0.50%/秒

食料不足カウント2：
満足値傾き -1.00%/秒

食料不足カウント3：
満足値傾き -1.50%/秒
```

### 10.3 方針

食料不足は都市運営上の深刻な問題として扱う。  
食料不足が続く場合、満足値は急激に低下し、不満・衰退へ落ちやすくなる。

---

## 11. 建築物影響

### 11.1 定義

建築物影響は、建物から満足値傾きに加算される補正値である。

```text
建築物影響：
建物から満足値傾きに加算される補正値
```

### 11.2 Sprint 4で実装するもの

Sprint 4では、建築物影響の受け口のみ実装する。

```text
- 建物から満足値傾き補正を受け取る構造
- 複数建物の補正を合算する処理
- 満足値傾きログに建築物影響を表示できる構造
```

### 11.3 具体建物効果

広場・レストラン・市場・香辛料市場などの具体効果は、満足度施設企画で扱う。

Sprint 4では、具体建物の最終仕様は確定しない。

---

## 12. 満足度段階

### 12.1 定義

満足度段階は、満足値%からリアルタイムに算出する。

```text
満足度段階 = 満足値%に応じて算出
```

### 12.2 段階表

| 満足値 | 満足度段階 |
|---:|---|
| 0〜19% | 衰退 |
| 20〜39% | 不満 |
| 40〜59% | 安定 |
| 60〜79% | 満足 |
| 80〜100% | 繁栄 |

---

## 13. 人口システムとの接続

満足度段階は、人口システムの増減率計算に使用される。

### 13.1 人口増加率

| 満足度段階 | 人口増加率 |
|---|---:|
| 衰退 | 0%/秒 |
| 不満 | 0%/秒 |
| 安定 | +0.02%/秒 |
| 満足 | +0.04%/秒 |
| 繁栄 | +0.06%/秒 |

### 13.2 人口減少率

| 満足度段階 | 人口減少率 |
|---|---:|
| 不満 | -0.04%/秒 |
| 衰退 | -0.12%/秒 |

```text
- 満足値は0〜100%で管理する
- 初期満足値は60%

- 満足値は0〜100%にクランプする
- 満足値傾きの上限/下限は設定しない
- 基礎満足傾きは +0.03%/秒
- 人口規模影響は内部人口スケールで算出する
- 人口規模影響は、人口増加に伴う都市運営負荷として基礎満足傾きを相殺・悪化させる
- 人口変化量影響は max(0, 人口増加速度) × -0.2
- 食料不足ペナルティは 食料不足カウント × 0.50%/秒
- 建築物影響は受け口のみSprint 4で実装する

- 満足度段階は人口システムへ渡す
- 政策・特殊タグ・イベントによる満足度補正はMVP非対象
```
