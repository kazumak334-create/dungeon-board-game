# Sprint 3：人口システム企画書 確定版

## 1. 目的

Sprint 3では、人口をリアルタイムに増減する都市ステータスとして実装する。

本企画書は、人口の内部管理、表示単位、人口変化量、食料値消費、人口増加確定処理、即時人口減少の受け口を定義する。

---

### 2.1 人口スケール

人口は内部的には抽象人口値として管理する。

```text
内部人口1 = 1k人
```

表示例：

| 内部人口 | UI表示 |
|---:|---|
| 10 | 10k人 |
| 50 | 50k人 |
| 100 | 100k人 |
| 500 | 500k人 |
| 1000 | 1.0M人 |

### 2.2 初期人口

```text
初期人口：
内部人口50
```

UI表示：

```text
50k人
```

### 2.3 初期人口上限

```text
初期人口上限：
内部人口100
```

UI表示：

```text
100k人
```

### 2.4 到達目標

MVPでは、上手くプレイすれば内部人口1000を目指せる設計にする。

UI表示：


## 3. 人口の基本仕様

### 3.1 内部管理

人口は内部的には小数で管理する。

```text
内部人口：
float
```

例：

```text
内部人口：53.82
UI表示：53k人
```

内部人口の小数は通常UIでは表示しない。  
デバッグUIでは小数込みで表示してよい。

### 3.2 表示人口

```text
表示人口 = floor(内部人口)
```

UIでは、表示人口をk人/M人表記に変換する。

例：

```text
内部人口50.8 → 50k人
内部人口999.9 → 999k人
内部人口1000.0 → 1.0M人
```

### 3.3 人口下限

```text
人口下限：
内部人口10
```

UI表示：

```text
10k人
```

人口は人口下限を下回らない。

### 3.4 人口上限

現在人口は人口上限を超えない。

```text
population >= population_cap の場合：
人口増加要因 = 0
```

```text
population_cap：
1000以上を扱える
```

住宅・上位住宅・報酬による人口上限拡張は後続Sprintで扱う。

## 4. 人口変化量

### 4.1 基本式

```text
人口変化量 =
人口増加要因合計
-
人口減少要因合計
```

人口変化量が正の場合、人口は増える。  
人口変化量が負の場合、人口は減る。  
人口変化量が0の場合、人口は維持される。

### 4.2 割合ベース

人口50〜1000まで扱うため、人口増減は固定人数/秒ではなく、割合ベースにする。

```text
人口増加速度 = 現在人口 × 人口増加率
人口減少速度 = 現在人口 × 人口減少率
```

---

## 5. 人口増加要因

MVPでは、満足度段階を主な人口増加要因とする。

| 満足度段階 | 人口増加率 |
|---|---:|
| 衰退 | 0%/秒 |
| 不満 | 0%/秒 |
| 安定 | +0.02%/秒 |
| 満足 | +0.04%/秒 |
| 繁栄 | +0.06%/秒 |

計算式：

```text
人口増加速度 = 現在人口 × 満足度段階別人口増加率
```

### 5.1 増加例

内部人口50・満足：

```text
50 × 0.04%/秒 = 0.02人口/秒
```

約50秒で内部人口+1。

UI上は、約50秒で+1k人。

内部人口500・満足：

```text
500 × 0.04%/秒 = 0.2人口/秒
```

約5秒で内部人口+1。

UI上は、約5秒で+1k人。

内部人口500・繁栄：

```text
500 × 0.06%/秒 = 0.3人口/秒
```

約33秒で内部人口+10。

UI上は、約33秒で+10k人。

---

## 6. 人口減少要因

MVPで採用するリアルタイム人口減少要因は以下。

| 減少要因 | 人口減少率 |
|---|---:|
| 食料値不足 | -0.04%/秒 |
| 不満 | -0.04%/秒 |
| 衰退 | -0.12%/秒 |

計算式：

```text
人口減少速度 = 現在人口 × 人口減少率
```

### 6.1 減少要因の加算

食料値不足と不満/衰退は加算される。

例：

```text
不満 かつ 食料値不足：
人口減少率 = -0.04%/秒 -0.04%/秒
= -0.08%/秒
```

### 6.2 衰退時の扱い

衰退は都市崩壊状態として扱う。

```text
衰退：
人口増加なし
人口減少率 -0.12%/秒
```

衰退に食料値不足が重なる場合、人口減少率は加算される。

```text
衰退 + 食料値不足：
-0.12%/秒 -0.04%/秒
= -0.16%/秒
```

---

## 7. 食料値不足状態

### 7.1 定義

```text
食料不足カウント >= 1 の場合、食料値不足状態とみなす。
```

### 7.2 食料値不足時の効果

食料値不足状態では、人口減少要因を加算する。

```text
食料値不足：
-0.04%/秒
```

### 7.3 食料不足カウント

人口維持処理で食料値が足りない場合：

```text
食料不足カウント +1
```

人口維持処理で食料値が足りた場合：

```text
食料不足カウント -1
最低値は0
```

---

## 8. 人口維持必要食料値

### 8.1 基本仕様

```text
人口維持必要食料値 = ceil(現在人口 / 50)
最低値 = 1
```

発動間隔：

```text
5秒ごと
```

### 8.2 維持必要食料値の例

| 内部人口 | UI表示 | 5秒ごとの維持必要食料値 |
|---:|---:|---:|
| 50 | 50k人 | 1 |
| 100 | 100k人 | 2 |
| 250 | 250k人 | 5 |
| 500 | 500k人 | 10 |
| 1000 | 1.0M人 | 20 |

### 8.3 食料値が足りる場合

```text
- 維持必要食料値ぶん食料値を消費する
- 食料不足カウントを1減らす
- 食料不足カウントの最低値は0
```

### 8.4 食料値が不足する場合

```text
- 残っている食料値をすべて消費する
- 食料不足カウント+1
- 食料値不足状態として扱う
```

## 9. 人口増加確定処理

### 9.1 人口増加確定単位

```text
人口増加確定単位：
内部人口10
```

UI表示：

```text
10k人単位
```

### 9.2 次の確定人口

```text
次の確定人口 = ceil(現在人口 / 10) × 10
```

例：

```text
現在人口：151.2
次の確定人口：160
```

### 9.3 人口増加必要食料値

```text
人口増加必要食料値 = ceil(次の確定人口 / 50)
最低値 = 1
```

繁栄時：

```text
人口増加必要食料値 = max(1, ceil(次の確定人口 / 50) - 1)
```

### 9.4 食料値が足りる場合

```text
- 人口増加必要食料値ぶん食料値を消費する
- 次の確定人口への到達を確定する
```

### 9.5 食料値が不足する場合

```text
- 次の確定人口への到達を確定しない
- 食料値が足りるまで人口増加を停止する
```

実装上は、次の確定人口直前で停止する。

例：

```text
現在人口：159.8
次の確定人口：160
必要食料値：ceil(160 / 50) = 4
食料値不足
→ 160に到達せず、159.99付近で停止
```

### 9.6 growth_blocked

食料値不足で次の確定人口に到達できない場合、`growth_blocked = true` とする。

```text
growth_blocked = true
```

食料値が足りたら、`growth_blocked = false` とする。

```text
growth_blocked = false
```

## 10. 即時人口減少の受け口

Sprint 3では、突撃・防衛突破などの即時人口減少を受け取れる処理を用意する。

### 10.1 基本仕様

```text
即時人口減少：
現在人口を即時に減らす処理。
人口下限10を下回らない。
```

### 10.2 関数案

```text
apply_population_loss(amount)
```

処理：

```text
population = max(population_min, population - amount)
```

### 10.3 突撃・防衛突破との接続

突撃・防衛突破との具体接続はSprint 6で扱う。

Sprint 3では、以下の仮置きに対応できるようにする。

```text
1ユニット = 内部人口5
```

UI表現：

```text
1ユニット = 5k人相当
```
