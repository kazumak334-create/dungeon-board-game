# Sprint 7：初期デッキ・住宅・交換所・土地カード報酬企画書 確定版

## 1. 目的

Sprint 7では、初期デッキ、住宅、兵舎、広場、交換所、土地カード報酬を定義する。

本企画書は、Sprint 1〜6で定義した土地パネル・食料値・人口・満足度・兵数/ユニット変換を、初期デッキおよび報酬設計に接続する。


## 3. 初期デッキ

### 3.1 同一カード重複

初期デッキでは、同一カードの重複を許可する。

```text
同一カード重複：
許可
```

### 3.2 初期デッキ枚数

```text
初期デッキ枚数：
13枚
```

### 3.3 初期デッキ構成

```text
初期デッキ：
- 住宅 ×3
- 農村 ×2
- 森小屋 ×2
- 採掘所 ×2
- 食堂 ×1
- 兵舎 ×1
- 広場 ×1
- 交換所 ×1
```

### 3.4 初期デッキの設計意図

初期デッキは、都市成長の基本ループを安定して回すための構成にする。

```text
1. 住宅を建てて人口上限を増やす
2. 農村で小麦を確保する
3. 食堂で小麦を食料値に変換する
4. 食料値で人口維持・人口増加を支える
5. 兵舎で兵数/ユニット導線を作る
6. 森小屋・採掘所で建築資源を強化する
7. 広場で満足度低下を支える
8. 交換所でドローを補助する
9. さらに住宅を建てて人口上限を伸ばす
```

```text

建物効率：対象外
```

## 4.8 交換所

### 4.8.1 分類

```text
交換所：
分類：特殊建物
初期デッキ枚数：1
```

### 4.8.2 効果

```text
交換所効果：
足元土地パネルの通常資源を累計10獲得するたびに1ドローする
```

### 4.8.3 使用後のカード挙動

```text
使用後：
交換所カードは捨て札へ行かず除外される
```

### 4.8.4 盤面上の扱い

```text
盤面：
交換所建物は盤面に残る
```

### 4.8.5 対象資源

```text
対象資源：
- 木
- 樹脂
- 石
- 鉄鉱石
- 小麦
- 綿花
```

### 4.8.6 複合資源パネルの場合

複合資源パネル上の交換所は、足元土地パネルの対象資源獲得量を合算する。

例：

```text
小麦/綿花パネル上の交換所

小麦+6
綿花+4
合計10
→ 1ドロー
```

### 4.8.7 対象外

```text
交換所の対象外：
- 食料値
- 兵力
- 人口
- 満足値
- 特殊タグ
```

### 4.8.8 コスト

```text
交換所コスト：
木1・樹脂1
```

### 4.8.9 意図

ドロー補助を入れるが、特殊建物としてカードは除外する。  
ドロー系を通常デッキ循環に残し続けないことで、後半のデッキ挙動の破綻を防ぐ。

## 5. 特殊建物

### 5.1 定義

```text
特殊建物：
- 建物カードの一種
- カードは使用後に捨て札へ行かず除外される
- 建物自体は盤面に残る場合がある
- ドロー系・手札交換系・資源交換系・一時補助系に使う
```

### 5.2 通常建物との違い

| 分類 | カード挙動 | 盤面 |
|---|---|---|
| 通常建物 | 捨て札/山札循環に戻る | 建物として残る |
| 特殊建物 | 使用後に除外 | 仕様により残る場合がある |

交換所は以下として扱う。

```text
交換所：
カードは除外されるが、建物は盤面に残る特殊建物
```

### 5.3 ドロー系の扱い

```text
ドロー系建物：
原則として特殊建物にする
```

理由：

```text
ドロー系を通常デッキ循環に残し続けると、後半の手札・山札・リロード挙動が破綻しやすい。
そのため、ドロー系は原則として特殊建物に分類し、使用後に除外する。
```

## 6. 樹脂のコスト設計方針

### 6.1 基本方針

```text
樹脂：
加工・特殊・便利系建物のコストに使う
```

### 6.2 建物カテゴリ別の方針

| 建物カテゴリ | 主なコスト資源 | 方針 |
|---|---|---|
| 基礎採取施設 | 木・石 | 序盤導線を詰まらせない |
| 住宅 | 木・石 | 人口上限の基礎なのでシンプル |
| 加工施設 | 木・樹脂・石 | 樹脂を入れる |
| 食料値施設 | 木・石・小麦 | 食料導線に寄せる |
| 特殊建物 | 樹脂を含める | 一時/便利/ドロー系効果の対価 |
| 軍事施設 | 木・石・鉄鉱石 | 鉄鉱石は上位軍事寄りに温存 |

## 14. 残論点

Sprint 7の主要仕様は確定済みとする。  
以下はテストプレイ調整項目として扱う。

```text
- 初期デッキ13枚が重すぎないか
- 住宅×3が人口上限拡張として強すぎないか
- 農村×2で小麦供給が安定しすぎないか
- 森小屋×2・採掘所×2で資源供給が安定しすぎないか
- 兵舎の内部兵数補正+10%が適切か
- 広場の満足値傾き+0.05%/秒が適切か
- 交換所の累計10資源で1ドローが強すぎないか
- 交換所が盤面に残る特殊建物として扱いやすいか
- 交換所コスト 木1・樹脂1 が適切か
- 土地カード3択の頻度が毎戦闘後でよいか
- 報酬土地の資源値4〜6が強すぎないか
```
