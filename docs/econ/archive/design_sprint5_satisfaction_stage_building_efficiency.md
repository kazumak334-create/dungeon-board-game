# Sprint 5：満足度段階効果・建物効率企画書 確定版

## 1. 目的

Sprint 5では、Sprint 4で算出した満足度段階を、人口・兵力・建物効率へ反映する。

本企画書は、満足度段階ごとの効果、兵力補正、建物効率補正、建物効率の適用対象、発動間隔補正、反映タイミングを定義する。

---

## 2. 対象

Sprint 5で扱う対象は以下。

```text
- 満足度段階ごとの人口効果
- 満足度段階ごとの兵力獲得量補正
- 満足度段階ごとの兵力効果補正
- 満足度段階ごとの建物効率
- 建物効率の適用対象
- 建物効率の計算方法
- 建物効率の反映タイミング
```

---

## 3. 前提

### 3.1 満足度段階

満足度段階は、満足値%からリアルタイムに算出される。

| 満足値 | 満足度段階 |
|---:|---|
| 0〜19% | 衰退 |
| 20〜39% | 不満 |
| 40〜59% | 安定 |
| 60〜79% | 満足 |
| 80〜100% | 繁栄 |

### 3.2 人口システム

人口は内部的には抽象人口値として管理する。

```text
内部人口1 = 1k人
```

Sprint 3で定義済みの人口増減率を、満足度段階に応じて参照する。

### 3.3 兵力システム

以下は既存実装済み前提とする。

```text
- 兵力のユニット変換
- 戦闘での兵力消費
```

Sprint 5では、満足度段階による兵力補正のみを定義する。

## 4. 満足度段階別効果

| 満足度段階 | 人口効果 | 兵力効果 | 建物効率 |
|---|---|---|---:|
| 衰退 | 人口増加なし / 人口減少率 -0.12%/秒 | 兵力獲得量 -30% / 兵力効果 -20% | -10% |
| 不満 | 人口増加なし / 人口減少率 -0.04%/秒 | 兵力獲得量 -20% / 兵力効果 -10% | -5% |
| 安定 | 人口増加率 +0.02%/秒 | 補正なし | 0% |
| 満足 | 人口増加率 +0.04%/秒 | 兵力獲得量 +10% | +5% |
| 繁栄 | 人口増加率 +0.06%/秒 / 人口増加必要食料値 -1 | 兵力獲得量 +20% / 兵力効果 +10% | +30% |

## 5. 人口効果

人口効果はSprint 3で定義済みの値を使用する。

### 5.1 人口増加率

| 満足度段階 | 人口増加率 |
|---|---:|
| 衰退 | 0%/秒 |
| 不満 | 0%/秒 |
| 安定 | +0.02%/秒 |
| 満足 | +0.04%/秒 |
| 繁栄 | +0.06%/秒 |

### 5.2 人口減少率

| 満足度段階 | 人口減少率 |
|---|---:|
| 衰退 | -0.12%/秒 |
| 不満 | -0.04%/秒 |
| 安定 | 0%/秒 |
| 満足 | 0%/秒 |
| 繁栄 | 0%/秒 |

### 5.3 繁栄時の食料値軽減

繁栄時は、人口増加確定時の必要食料値を軽減する。

通常時：

```text
人口増加必要食料値 = ceil(次の確定人口 / 50)
```

繁栄時：

```text
人口増加必要食料値 = max(1, ceil(次の確定人口 / 50) - 1)
```

## 6. 兵力効果

### 6.1 兵力獲得量補正

兵力獲得量補正は、兵力を得る建物・効果にかかる補正である。

| 満足度段階 | 兵力獲得量補正 |
|---|---:|
| 衰退 | -30% |
| 不満 | -20% |
| 安定 | 0% |
| 満足 | +10% |
| 繁栄 | +20% |

### 6.2 兵力効果補正

兵力効果補正は、保有兵力や戦闘変換後の有効倍率にかかる補正である。

| 満足度段階 | 兵力効果補正 |
|---|---:|
| 衰退 | -20% |
| 不満 | -10% |
| 安定 | 0% |
| 満足 | 0% |
| 繁栄 | +10% |

### 6.3 設計方針

```text
兵力獲得量補正：
兵舎などで兵力を獲得する時に使う。

兵力効果補正：
戦闘時の兵力有効倍率として使う。
```

兵力獲得量補正と兵力効果補正は別管理する。

満足時は兵力を集めやすいが、戦闘性能までは上げない。  
繁栄時のみ、兵力の質・士気・統制が上がる扱いで兵力効果も上げる。

## 7. 建物効率

### 7.1 定義

建物効率は、周期発動建物の作業速度を変える補正である。

```text
建物効率：
周期発動建物の発動間隔に適用する補正
```

満足度が高いほど建物の処理が早くなり、満足度が低いほど処理が遅くなる。

### 7.2 満足度段階別の建物効率

| 満足度段階 | 建物効率 |
|---|---:|
| 衰退 | -10% |
| 不満 | -5% |
| 安定 | 0% |
| 満足 | +5% |
| 繁栄 | +30% |

---

## 8. 建物効率の適用対象

### 8.1 適用する建物

MVPでは、周期発動建物に適用する。

```text
- 採取施設
- 加工施設
- 食料値生成施設
- 兵力獲得施設
```

例：

```text
農村：
発動間隔に適用

森小屋：
発動間隔に適用

採掘所：
発動間隔に適用

食堂：
発動間隔に適用

製粉所：
発動間隔に適用

兵舎：
発動間隔に適用
```

### 8.2 適用しない建物

MVPでは、以下には建物効率を適用しない。

```text
- 住宅
- 人口上限を増やす常時補正施設
- 満足値傾きを増やす常時補正施設
- 土地タグ
- 建築時効果
- 戦闘開始時効果
- 戦闘終了時効果
```

理由：

```text
建物効率は「周期的に稼働する建物の作業速度」として扱うため。
```

---

## 9. 建物効率の計算方法

### 9.1 基本式

```text
補正後発動間隔 = 基礎発動間隔 / (1 + 建物効率補正)
```

建物効率補正は、パーセントを小数に変換して計算する。

例：

```text
+30% → 0.30
-10% → -0.10
```

### 9.2 5秒建物の例

| 満足度段階 | 建物効率 | 5秒建物の発動間隔 |
|---|---:|---:|
| 衰退 | -10% | 5.56秒 |
| 不満 | -5% | 5.26秒 |
| 安定 | 0% | 5.00秒 |
| 満足 | +5% | 4.76秒 |
| 繁栄 | +30% | 3.85秒 |

### 9.3 出力量には適用しない

Sprint 5では、建物効率は出力量に適用しない。

```text
建物効率：
発動間隔にのみ適用

出力量：
変更しない
```

例：

```text
食堂：
通常時 5秒ごとに食料値+2
繁栄時 3.85秒ごとに食料値+2
```

```text
製粉所：
通常時 5秒ごとに小麦+2
衰退時 5.56秒ごとに小麦+2
```

### 9.4 小数出力バッファ

出力量には補正しないため、小数出力バッファはMVPでは使用しない。

```text
小数出力バッファ：
MVP非対象
```

## 10. 発動間隔のクランプ

将来の政策・LvUP・建物バフに備え、補正後発動間隔には最小値・最大値を設定する。

```text
最小発動間隔：2秒
最大発動間隔：15秒
```

計算式：

```text
補正後発動間隔 = clamp(
  基礎発動間隔 / (1 + 建物効率補正),
  2秒,
  15秒
)
```

Sprint 5の満足度補正だけでは、通常このクランプに引っかからない。  
安全装置として実装する。

---

## 11. 満足度段階変化時のタイマー処理

満足度段階が変化した場合、建物タイマーの進捗率を維持して、発動間隔を再計算する。

### 11.1 進捗率

```text
進捗率 = 経過時間 / 現在の発動間隔
```

### 11.2 段階変化後

```text
新しい経過時間 = 進捗率 × 新しい発動間隔
```

これにより、満足度段階が変わってもタイマーが不自然にリセットされない。

### 11.3 例

```text
食堂タイマー進行中に「安定」→「繁栄」へ変化
基礎発動間隔5秒
安定時：5.00秒
繁栄時：3.85秒

進捗率を維持して、次回発動までの時間を再計算する。
```

## 12. 建物停止との関係

建物停止は、資源不足・人手不足などの稼働条件未達で発生する。

満足度段階だけでは建物を停止させない。

```text
資源不足・人手不足時：
建物タイマー停止

条件回復時：
停止時点からタイマー再開
```

衰退・不満時も建物は停止しない。  
建物効率低下により、発動間隔が遅くなる。

---

## 13. 満足度段階効果の反映タイミング

満足度段階効果は、リアルタイムに反映する。

```text
満足度段階が変化したら、人口・兵力・建物効率への補正も即時更新する。
```

ただし、既に発動済みの周期処理には遡って適用しない。  
次回発動から新しい補正を適用する。
