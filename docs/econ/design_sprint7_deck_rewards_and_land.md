# Sprint 7 企画書：初期デッキ・序盤カード・土地報酬

## 1. 目的

Sprint 7では、初期デッキ決定機能、序盤カード報酬システム、土地カード報酬システムを実装する。

本企画書は、初期デッキ確定、序盤カード報酬、土地カード報酬（高数値土地・複合資源土地・特殊タグ土地・地形土地）の仕様を定義する。

---

## 2. 初期デッキシステム

### 2.1 初期デッキの役割

```
初期デッキ：
- ゲーム開始時に確定したカード組成
- プレイヤーがカード選択画面で決定
- 序盤の建物配置戦略に影響
- 盤面と初期盤面保証の相互作用
```

### 2.2 初期デッキ決定フロー

```
Step 1: ゲーム開始画面でカード選択
Step 2: 複数のカードセット案から選択（3案）
Step 3: 選択したデッキを確定
Step 4: 確定後、盤面生成開始
Step 5: 初期保証ロジックがデッキと整合するか確認
Step 6: 整合しない場合、盤面を再生成
```

### 2.3 初期デッキ確定の条件

```
確定条件：
- カード選択完了
- 盤面初期保証クリア
- ゲーム開始ボタン押下
```

### 2.4 確定デッキの操作

```
確定後：
- デッキの組み換え不可
- 序盤の困難を回避するためのデッキ変更禁止
- 盤面と戦略が確定した状態でゲーム開始
```

---

## 3. 序盤カード報酬システム

### 3.1 序盤カード報酬の定義

```
序盤カード報酬：
- ゲーム開始直後（初期ターン）に付与される報酬カード
- 初期デッキの補完・強化
- 複数枚の選択肢から選択（3案）
```

### 3.2 報酬時期

```
時期1：初期ターン完了時
時期2：マイルストーン到達時（建物数、食料値、人口等）
時期3：特定イベント発生時
```

### 3.3 報酬カード種類

```
建物カード：
- 初期デッキに含まれる建物と異なるタイプ
- 例：食堂、住宅、防衛施設

発動系カード：
- 即座に効果を発動できるカード
- 例：資源獲得カード、人口増加カード
```

---

## 4. 土地カード報酬システム

### 4.1 土地カード報酬の定義

```
土地カード報酬：
- 盤面に新しい土地パネルを追加できる報酬カード
- 既存土地パネルに隣接する空きマスへ配置
- 建物配置の土台を拡張
- 盤面戦略の自由度を増加
```

### 4.2 土地カード報酬の出現時期

```
時期1：マイルストーン報酬（建物数到達時、人口到達時）
時期2：特定イベント完了時
時期3：ウェーブクリア時
```

### 4.3 報酬形式

```
報酬形式：3択から1枚選択

構成例：
1. 高数値単一資源土地
2. 高総量複合資源土地
3. 特殊タグ土地 or 地形土地

プレイヤーは以下の観点で選択：
- 現在不足している資源
- 建物配置の拡張方針
- 長期戦略（香辛料 / 硫黄）
```

## 5. 高数値単一資源土地

### 5.1 定義

通常盤面に自生しない、または出にくい高数値資源土地。

```
例：
- 木6
- 石6
- 小麦6
- 鉄鉱石5
- 樹脂5
- 綿花5
```

### 5.2 資源値範囲

```
単一資源パネル：
値6：最高値（報酬専用）
値5：高値（遠距離では低確率で出現）
```

### 5.3 役割と影響

```
特定資源の供給を大きく伸ばす：
- 木6 → 森小屋での木獲得2倍化
- 小麦6 → 農村での小麦獲得2倍化

対応建物の価値を高める：
- 高数値パネル上の建物は効率が上がる（将来）

デッキ・建物配置方針の変更：
- 高数値パネルを獲得したら戦略を再編成
```

### 5.4 出現頻度

```
3択報酬での出現：
高数値単一資源土地が候補になる確率：40%～50%

複数回報酬で複数の高数値パネルを獲得可能
```

### 5.5 戦略的価値

```
序盤：初期安定用ではなく、中盤以降の特化用
中盤：特定リソース供給の加速
終盤：勝利条件達成の最終リソース源
```

## 6. 高総量複合資源土地

### 6.1 定義

2種類の資源を高めに持つ土地。

```
例：
- 小麦3 / 綿花3
- 木3 / 樹脂3
- 石3 / 鉄鉱石3
```

### 6.2 資源値範囲

```
複合パネル：
各値3：高総量（報酬専用）
各値2～3：標準～高総量
```

### 6.3 役割と影響

```
汎用性の高さ：
- 2種類の資源を同時に確保
- 複数施設の配置候補になる

複数施設の価値向上：
- 例：小麦3/綿花3パネル上に農村+他施設配置
- 両施設の効率が上がる

特化より柔軟な選択肢：
- 高数値単一と異なり、戦略選択肢が増える
```

### 6.4 出現頻度

```
3択報酬での出現：
高総量複合資源土地が候補になる確率：30%～40%

単一資源より頻度が低い（特化性重視）
```

### 6.5 戦略的価値

```
序盤：複合施設配置の多様化
中盤：リソースバランスの調整
終盤：最後の拡張候補（柔軟対応）
```

## 7. 香辛料タグ土地

### 7.1 定義

香辛料タグが付いているパネル。

```
実装形式：
- 通常資源値は持たない（タグのみ）
- または低値資源＋香辛料タグ

候補：
- 香辛料（タグのみ）
- 香辛料 + 石1 等
```

### 7.2 役割と影響

```
食堂強化用：
- 香辛料タグ上の食堂：食料値+3（通常+1）
- 食堂の効率が大幅向上

将来施設への接続候補：
- レストラン・香辛料市場へ接続予定
```

### 7.3 出現頻度

```
3択報酬での出現：
香辛料タグ土地が候補になる確率：20%～30%

3択構成例での登場：
選択肢3（特殊タグ）に含まれる
```

### 7.4 戦略的価値

```
序盤：香辛料タグは希少（重要度は中程度）
中盤：食堂強化による食料値加速
終盤：都市満足度向上の手段
```

### 7.5 出現パターン

```
パターンA：香辛料（タグのみ）
- 視覚効果：スパイスアイコン
- 用途：食堂配置用

パターンB：香辛料 + 低値資源
- 例：香辛料 + 石1
- 視覚効果：スパイス + 資源アイコン
- 用途：柔軟な建物配置
```

## 9. 地形土地

地形タイプが主体のパネル。

```
地形タイプ：
- 草原
- 砂漠
- 荒地
- 湿地
```

### 9.2 MVPでの特性

```
現状：
- 地形パネルに固有効果は実装しない
- 見た目差別化のみ
- UI表示対象
- 将来への土台
```

### 9.3 役割と影響

```
ビジュアル多様性：
- 盤面の見た目を豊かにする

将来への準備：
- 地形ボーナス
- バイオーム概念
- イベントトリガー
```

### 9.4 出現頻度

```
3択報酬での出現：
地形土地が候補になる確率：10%～15%

3択構成例での登場：
選択肢3（特殊タグまたは地形）に含まれる
```

### 9.5 戦略的価値

```
序盤：優先度が低い（効果なし）

```

## 10. 土地カード3択の構成

### 10.1 標準的な3択構成

```
候補1（特化型）：
- 高数値単一資源土地
- 特定リソースに特化
- 例：木6、小麦6

候補2（汎用型）：
- 高総量複合資源土地
- 2種リソースのバランス
- 例：小麦3/綿花3

候補3（特殊型）：
- 香辛料タグ土地
- 硫黄タグ土地
- 地形土地
- いずれか1種を選定

選択のポイント：
- リソース充足状況
- 建物配置方針
- 長期戦略の優先度
```

### 10.2 構成比率

```
候補1（高数値単一）：40%～50%
候補2（高総量複合）：30%～40%
候補3（特殊タグ/地形）：20%～30%

3択内での比率（複数回報酬で変動）
```

### 10.3 構成の多様性

```
複数回報酬で異なる3択を提示：
- 1回目：木系 vs 石系 vs 香辛料
- 2回目：小麦系 vs 綿花系 vs 硫黄
- 3回目：特化系 vs 複合系 vs 地形系

プレイヤーの戦略判断を促す
```

## 11. 配置メカニクス

### 11.1 配置条件

```
配置必須条件：
- 土地カード報酬で選択
- 既存自陣土地パネルに隣接する空きマス
- 盤面有効範囲内（26×13盤面）
```

### 11.2 隣接の定義

```
隣接：上下左右4マスのいずれかに既存土地がある状態

例：
既存パネル
  ↓
[空き] ← 配置可能（隣接）
  ↓
[空き] ← 配置可能（隣接）

[空き] [既存] [空き] ← 両側隣接
```

### 11.3 配置UI

```
UI流れ：
Step 1: 土地カード3択を表示
Step 2: プレイヤーが1枚を選択
Step 3: 盤面に置きモード進入
Step 4: 配置可能マスをハイライト表示
Step 5: プレイヤーが配置マスをクリック
Step 6: 土地パネルが配置完了
Step 7: ゲーム再開
```

### 11.4 キャンセル機能

```
キャンセル可否：
- 3択表示時：キャンセル可能
- 配置選択中：キャンセル不可（選択確定）

ただし将来の「やり直し」機能で再配置可能にする
```

## 12. マイルストーン報酬の流れ

### 12.1 報酬トリガー

```
建物数到達：
- 建物5個配置時 → 報酬1
- 建物10個配置時 → 報酬2
- 建物15個配置時 → 報酬3

人口到達：
- 人口150到達時 → 報酬1
- 人口250到達時 → 報酬2

食料値到達：
- 食料値50到達時 → 報酬1
- 食料値100到達時 → 報酬2
```

### 12.2 報酬の内容

```
マイルストーン報酬：
- 建物カード or 土地カード
- 複数報酬が混在する場合あり
- 累積で都市発展を加速
```
