# 人口・満足度・食料値システム企画書

## 1. 基本方針

本ゲームはリアルタイム進行である。

人口・満足度・食料値は、都市運営の中核ステータスとして扱う。

```text
小麦 = 通常資源
食料値 = 人口の維持・定着に使う都市ステータス
満足度 = 人口変化・兵力・建物効率に影響する都市状態
人口 = 満足度・食料値・人口上限・戦闘結果によって変動する都市ステータス
```

処理方式は以下とする。

| 要素 | 処理方式 |
|---|---|
| 人口 | リアルタイムに増減する |
| 満足度 | リアルタイムに変化する |
| 食料値獲得 | 建物ごとの周期発動 |
| 食料値消費 | 周期処理・人口増加確定時の処理 |
| 突撃・防衛人口被害 | 即時処理 |

---

## 2. 通常資源と都市ステータス

### 2.1 通常資源

通常資源は以下の6種とする。

```text
- 木
- 樹脂
- 石
- 鉄鉱石
- 小麦
- 綿花
```

### 2.2 小麦の位置づけ

小麦は通常資源であり、人口を直接増やす資源ではない。

```text
小麦：
- 農村で得る
- 食堂・製粉所・レストランなどで消費される
- 食料値を生み出すための原材料
- 人口を直接増やさない
```

### 2.3 都市ステータス

本企画で扱う都市ステータスは以下。

```text
- 人口
- 人口上限
- 食料値
- 満足値
- 満足値傾き
- 満足度段階
- 兵力
- 建物効率補正
```

---

## 3. 食料値システム

### 3.1 食料値の定義

食料値は、人口の維持と定着に使う都市ステータスである。

```text
食料値：
- 小麦などの通常資源を加工・提供することで得られる
- 人口維持に消費される
- 人口増加確定時にも消費される
- 食堂などの建物で獲得する
- 人口を直接増やすのではなく、人口を維持・定着させるためのコストとして機能する
```

---

### 3.2 食堂

食堂は初期デッキに入れる。

```text
食堂：
- 分類：建物 / 都市ステータス生成施設
- 初期デッキ：採用
- 発動トリガー：周期発動
- 発動間隔：5秒
- 効果：小麦1を消費して、食料値+2
- 足元パネルに香辛料タグがある場合、獲得食料値+50%
- 香辛料タグありの場合：小麦1を消費して、食料値+3
- 小麦が不足している場合は発動しない
```

食堂は満足値傾きには直接影響しない。

満足値傾きに効く施設は、レストラン・広場・市場などの別系統施設として扱う。

---

### 3.3 製粉所

製粉所は採用する。初期デッキには入れず、序盤カードプールに入れる。

```text
製粉所：
- 分類：建物 / 加工施設
- 初期デッキ：不採用
- 序盤カードプール：採用
- 発動トリガー：周期発動
- 発動間隔：5秒
- 効果：小麦1を消費して、小麦+2
- 足元パネルの小麦値が3以上なら、追加で小麦+1
- 小麦が不足している場合は発動しない
```

通常時：

```text
小麦-1 / 小麦+2
差し引き：小麦+1
```

小麦3以上パネル上：

```text
小麦-1 / 小麦+3
差し引き：小麦+2
```

製粉所は、小麦を食料値に変換する施設ではなく、食堂やレストランを回すための小麦供給ブースト施設である。

---

### 3.4 食料値の消費タイミング

食料値消費は、完全なリアルタイム連続消費ではなく、以下のタイミングで発生する。

```text
- 人口維持処理：5秒ごと
- 人口増加確定処理：人口が次の整数に到達するタイミング
```

---

### 3.5 人口維持処理

人口維持処理は、リアルタイム上で5秒ごとに発動する周期処理である。

```text
維持必要食料値 = floor(現在人口)
最低値 = 1
```

食料値が足りる場合：

```text
- 維持必要食料値ぶん食料値を消費する
- 食料不足カウントを1減らす
- 食料不足カウントの最低値は0
```

食料値が不足する場合：

```text
- 残っている食料値をすべて消費する
- 食料不足カウント+1
- 食料値不足状態になる
```

食料値不足状態は、以下に影響する。

```text
- 満足値傾きの悪化
- 人口減少要因
```

---

### 3.6 人口増加確定時の食料値消費

人口は内部的に小数で増える。

人口が次の整数に到達するタイミングで、人口増加確定処理を行う。

```text
人口増加必要食料値 = floor(現在人口)
最低値 = 1
```

食料値が足りる場合：

```text
- 人口増加必要食料値ぶん食料値を消費する
- 次の整数人口への到達を確定する
```

食料値が不足する場合：

```text
- 人口増加を確定しない
- 人口増加を停止する
- 食料値が足りるまで次の整数人口に到達しない
```

繁栄時は、人口増加必要食料値を軽減する。

```text
繁栄時：
人口増加必要食料値 = max(1, floor(現在人口) - 1)
```

## 4. 人口システム

### 4.1 人口の定義

人口は、都市ステータスである。

```text
人口：
- 内部的には小数で管理する
- UI上は整数表示する
- 複数の人口増加要因・人口減少要因の合算によってリアルタイムに変化する
- 住宅などで決まる人口上限を超えない
```

表示人口：

```text
表示人口 = floor(現在人口)
ただし最低1
```

---

### 4.2 人口上限

人口上限は、住宅などで決まる物理的な受け入れ上限である。

```text
人口上限：
- 住宅などで増える
- 現在人口は人口上限を超えない
```

実効人口上限は使用しない。

```text
実効人口上限：廃止
```

満足度段階が人口増加速度・人口減少速度に直接影響するため、実効人口上限を別途設けると人口制御が重複する。

---

### 4.3 人口変化量

人口は、複数の人口増加要因・人口減少要因の合算によってリアルタイムに変化する。

```text
人口変化量 = 人口増加要因合計 - 人口減少要因合計
```

人口変化量が正の場合、人口は増加する。

人口変化量が負の場合、人口は減少する。

人口変化量が0の場合、人口は維持される。

```text
現在人口 = 現在人口 + 人口変化量 × 経過秒数
```

現在人口は以下の範囲に収める。

```text
1 <= 現在人口 <= 人口上限
```

---

### 4.4 人口増加要因

人口増加要因は、人が都市に定着・流入する理由を表す。

MVPでは、満足度段階を主な人口増加要因とする。

| 満足度段階 | 人口増加要因 |
|---|---:|
| 衰退 | +0.00 人口/秒 |
| 不満 | +0.00 人口/秒 |
| 安定 | +0.02 人口/秒 |
| 満足 | +0.04 人口/秒 |
| 繁栄 | +0.05 人口/秒 |

以下の場合、人口増加要因は0扱いにする。

```text
- 現在人口 >= 人口上限
- 人口増加確定時に必要食料値を払えない状態
```

---

### 4.5 人口減少要因

人口減少要因は、人が都市に住み続けられない、または失われる理由を表す。

MVPで採用するリアルタイム人口減少要因：

```text
- 食料値不足
- 不満
- 衰退
```

初期仮置き：

| 減少要因 | 人口減少要因 |
|---|---:|
| 食料値不足 | -0.04 人口/秒 |
| 不満 | -0.04 人口/秒 |
| 衰退 | -0.10 人口/秒 |

食料値不足と不満/衰退は加算されうる。

例：

```text
不満 かつ 食料値不足：
人口減少要因 = -0.04 + -0.04 = -0.08 人口/秒
```

MVPで採用する即時人口減少要因：

```text
- 突撃
- 防衛突破
```

将来拡張候補：

```text
- 政策・イベント副作用
- 災害
- 疫病
- 戦闘損耗
- 敵の妨害
```

---

### 4.6 人口変化量ログ

人口変化量は、増加要因・減少要因ごとの内訳をログ出力する。

例：

```text
人口変化量：+0.04 人口/秒
+ 満足度：満足 +0.04
- 食料値不足 0.00
- 不満/衰退 0.00
```

例：

```text
人口変化量：-0.08 人口/秒
+ 満足度：不満 +0.00
- 不満 -0.04
- 食料値不足 -0.04
```

---

## 5. 突撃・防衛による人口減少

### 5.1 突撃による人口消費

突撃は、都市人口を戦闘ユニットとして送り出す行動である。

```text
突撃：
- 突撃時、送り出したユニット数ぶん人口が即時減少する
- 突撃ユニット1体につき人口-1
- 人口は最低1を下回らない
- 突撃可能ユニット数は現在人口-1を上限とする
- 突撃人口消費は、人口変化量とは別枠で処理する
```

例：

```text
現在人口：8
突撃ユニット数：3
人口 8 → 5
```

---

### 5.2 防衛突破による人口被害

防衛突破は、敵ユニットが防衛を突破し、都市へ到達することである。

```text
防衛突破：
- 防衛突破した敵ユニット1体につき人口-1
- 人口は最低1を下回らない
- 防衛人口被害は即時処理
- 人口変化量とは別枠で処理する
```

例：

```text
現在人口：7
敵ユニット2体が防衛突破
人口 7 → 5
```

---

## 6. 満足度システム

### 6.1 満足度の定義

満足度は、都市の生活品質・食料安定性・政策カバレッジ・人口規模に対する都市サービス充足度を表す。

満足度は以下の2つで管理する。

```text
満足値：
- 0〜100%で管理する
- 現在の都市満足度を表す
- 満足度段階は満足値%から算出する

満足値傾き：
- 満足値が時間経過で増減する速度
- 正なら満足値が上がる
- 負なら満足値が下がる
- 人口、食料不足、建築物、政策などから算出する
```

---

### 6.2 満足度はリアルタイム処理

満足度は、ターン終了時にまとめて判定するものではない。

満足値・満足値傾き・満足度段階は、リアルタイム上で継続的に更新される。

```text
満足値 = 満足値 + 満足値傾き × 経過秒数
```

満足値は以下に収める。

```text
0% <= 満足値 <= 100%
```

---

### 6.3 初期満足値

初期仮置き：

```text
初期満足値：60%
```

---

### 6.4 満足値傾き

満足値傾きは、複数要因の合算で算出する。

```text
満足値傾き =
基礎傾き
+ 人口規模影響
+ 人口変化量影響
+ 建築物影響
+ 政策影響
+ 特殊タグ影響
- 食料不足ペナルティ
- 防衛突破ペナルティ
- 突撃負荷ペナルティ
- その他ペナルティ
```

MVPで使う項目：

```text
- 基礎傾き
- 人口規模影響
- 人口変化量影響
- 建築物影響
- 食料不足ペナルティ
```

将来拡張枠：

```text
- 政策影響
- 特殊タグ影響
- 防衛突破ペナルティ
- 突撃負荷ペナルティ
- その他ペナルティ
```

---

### 6.5 基礎傾き

初期仮置き：

```text
基礎傾き：0%/秒
```

---

### 6.6 人口規模影響

人口規模影響は、現在人口の大きさによる恒常的な満足値傾き補正である。

人口が多いほど、住民要望の幅が広がり、都市サービス・政策カバレッジが難しくなるため、満足値傾きにマイナス補正を与える。

初期仮置き：

| 現在人口 | 人口規模影響 |
|---:|---:|
| 1〜2 | +0.02%/秒 |
| 3〜4 | 0%/秒 |
| 5〜6 | -0.03%/秒 |
| 7〜9 | -0.06%/秒 |
| 10以上 | -0.10%/秒 |

---

### 6.7 人口変化量影響

人口変化量影響は、人口が増加している状態による一時的な満足値傾き補正である。

人口増加中は、新規需要の増加により、満足値傾きに追加マイナス補正を与える。

初期仮置き：

```text
人口増加中：
人口変化量 × -1.0%/秒
```

例：

```text
人口変化量 +0.04 人口/秒
→ 満足値傾き -0.04%/秒
```

人口減少中は、MVPでは補正なしとする。

---

### 6.8 食料不足ペナルティ

食料不足カウントに応じて、満足値傾きが悪化する。

```text
食料不足ペナルティ = 食料不足カウント × -0.20%/秒
```

食料不足カウント：

```text
人口維持処理で食料値が不足した場合：
食料不足カウント+1

人口維持処理で食料値が足りた場合：
食料不足カウント-1
最低値は0
```

---

### 6.9 建築物影響

建築物影響は、満足値傾きを改善する建物由来の補正である。

初期仮置き：

```text
広場：
満足値傾き +0.05%/秒

レストラン：
稼働中、満足値傾き +0.10%/秒

市場：
満足値傾き +0.05%/秒

香辛料市場：
香辛料タグ付きパネル上なら、満足値傾き +0.15%/秒
```

食堂は満足値傾きには直接効かせない。

---

### 6.10 満足値傾きログ

満足値傾きは、要因ごとの内訳をログ出力する。

例：

```text
満足値傾き：-0.11%/秒

内訳：
+ 広場：+0.05
+ レストラン：+0.10
- 人口規模影響：-0.06
- 人口変化量影響：-0.04
- 食料不足ペナルティ：-0.16
```

---

## 7. 満足度5段階

満足値%から、以下の5段階を算出する。

初期仮置き：

| 満足値 | 満足度段階 | 状態 |
|---:|---|---|
| 0〜19% | 衰退 | 都市崩壊状態 |
| 20〜39% | 不満 | 人口流出状態 |
| 40〜59% | 安定 | 最低限維持できる状態 |
| 60〜79% | 満足 | 良好な成長状態 |
| 80〜100% | 繁栄 | 高効率な成長状態 |

---



人口：

```text
- 人口増加要因+0.05 人口/秒
- 人口増加必要食料値-1

```

兵力：

```text
- 兵力獲得量+20%
- 兵力効果+10%
```

建物効率：

```text
- 全建物効率+10%
```

## 9. 兵力関連の定義

### 9.1 兵力獲得量

兵力獲得量は、兵舎・訓練所・徴兵所などが新たに得る兵力の量である。

例：

```text
兵舎：
5秒ごとに兵力+2
```

満足度段階によって、兵力獲得量に補正がかかる。

---

### 9.2 兵力効果

兵力効果は、保有兵力が戦闘・防衛・攻撃力などに変換される際の有効倍率である。

例：

```text
兵力10
兵力効果+10%の場合、戦闘上は11相当として扱う
```

## 10. 建物効率

建物効率は、建物の出力にかかる全体補正である。

対象候補：

```text
- 資源獲得量
- 食料値獲得量
- 小麦/綿花/木/石などの生産量
- 加工施設の出力
- 兵力獲得量
```

MVPでは、建物効率補正の適用範囲は要検討とする。

ただし、満足度段階効果としては初期からテーブルに保持する。

---

## 11. 初期デッキへの反映

初期デッキに入れる食料値建物は食堂で確定する。

```text
初期デッキに追加：
- 食堂
```

製粉所は採用するが、初期デッキには入れない。

```text
序盤カードプールに追加：
- 製粉所
```

初期デッキ案：

```text
- 森小屋 ×1
- 採掘所 ×1
- 農村 ×2
- 食堂 ×1
- 住宅 ×1
```

合計6枚。

## 12. リアルタイム処理仕様

### 12.1 建物効果

建物は個別の発動トリガーを持つ。

主なトリガー：

```text
- 建築時
- 周期発動
- 条件発動
- 常時補正
- 戦闘開始時
- 戦闘終了時
```

MVPでは、採取・加工・食料値生成系施設は周期発動とする。

```text
農村：5秒ごと
製粉所：5秒ごと
食堂：5秒ごと
```

---

### 12.2 満足度

```text
満足値・満足値傾き・満足度段階はリアルタイムに更新される。
```

---

### 12.3 人口

```text
人口は人口変化量に基づき、リアルタイムに増減する。
```

---

### 12.4 食料値

```text
食料値の獲得：
建物の周期発動で行う。

食料値の消費：
- 人口維持処理：5秒ごと
- 人口増加確定処理：整数人口到達時
```

---

## 13. 確定仕様まとめ

```text
- 小麦と食料値は別管理
- 小麦は通常資源
- 食料値は都市ステータス
- 食料値は人口維持と人口増加確定時に消費される
- 食堂は初期デッキに入れる
- 食堂は5秒ごとに小麦1を消費して食料値+2
- 香辛料タグ上の食堂は食料値+3
- 製粉所は採用し、序盤カードプールに入れる
- 製粉所は5秒ごとに小麦1を消費して小麦+2
- 小麦3以上パネル上の製粉所は追加で小麦+1
- 人口は内部的に小数で管理する
- 人口はリアルタイムに増減する
- 人口変化量は人口増加要因と人口減少要因の合算で決まる
- 人口上限は住宅などで決まる
- 実効人口上限は使わない
- 突撃時は吐き出したユニット数ぶん人口が即時減少する
- 防衛突破時は突破した敵ユニット数ぶん人口が即時減少する
- 満足度は満足値%と満足値傾きで管理する
- 満足度はリアルタイムに更新する
- 満足度は5段階：衰退 / 不満 / 安定 / 満足 / 繁栄
- 満足度段階は人口・兵力・建物効率に影響する
- 満足値傾きと人口変化量は内訳ログを出す
```

## 14. 残論点

### 14.1 食料値関連

```text
- 食料値の最大保有上限を設けるか
- 人口維持必要食料値を floor(現在人口) でよいか
- 人口維持必要食料値の最低値1でよいか
- 人口増加必要食料値を floor(現在人口) でよいか
- 人口増加確定時に食料値不足だった場合の停止表現
- 食堂LvUP時の効果量
- 製粉所LvUP時の効果量
- レストランの具体効果
- 香辛料市場の具体効果
```

### 14.2 人口関連

```text
- 内部人口を小数で管理してよいか
- UI表示は floor でよいか
- 人口変化量をUIでどう見せるか
- 人口増加要因の初期仮置き値が適切か
- 人口減少要因の初期仮置き値が適切か
- 人口上限の初期値
- 住宅の具体効果
- 人口下限1でよいか
- 人口減少時に食料値や満足値へ追加影響を与えるか
- 突撃したユニットが生還した場合に人口へ戻すか
- 防衛突破時に満足値傾きペナルティも入れるか
```

### 14.3 満足度関連

```text
- 初期満足値60%でよいか
- 満足度段階の閾値
- 人口規模影響の人口帯
- 人口規模影響の傾き値
- 人口変化量影響の係数
- 食料不足カウントの最大値
- 食料不足ペナルティの強さ
- 維持成功時に食料不足カウントを1ずつ減らす仕様でよいか
- 満足値傾きの上限・下限を設けるか
- 建築物影響を満足値そのものに加えるか、満足値傾きに加えるか
- イベント・政策で満足値を直接増減させるか
- 政策効果をMVPで使うか
- 特殊タグ効果をMVPで使うか
```

### 14.4 兵力関連

```text
- 兵力獲得量補正をMVPから適用するか
- 兵力効果補正をMVPから適用するか
- 兵力獲得量と兵力効果をUIでどう説明するか
- 突撃ユニット数と兵力の関係
- 兵力を人口から生成するか、別リソースとして扱うか
- 兵力損耗を人口減少に接続するか
```

### 14.5 建物効率関連

```text
- 建物効率補正を全建物にかけるか
- 採取施設だけにかけるか
- 加工施設だけにかけるか
- 食料値生成施設にもかけるか
- 建物効率補正が重複した場合の計算方法
- 衰退時-30%、繁栄時+10%が適切か
```
