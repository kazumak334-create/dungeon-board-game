## 1. 目的

本スプリント計画書は、都市ステータス基盤、人口・満足度・食料値システム、土地パネル選定ロジック、初期デッキ・報酬システムを統合し、Sprint 1〜8の実装範囲を定義する。

---

## 2. 全体構成

経済MVP は以下の8つのSprintで実装される。各Sprintは前後Sprintと依存関係を持つ。

| Sprint | 主対象 | 土地パネル | 人口・満足度 | 食料値 |
|---:|---|---|---|---|
| Sprint 1 | 都市ステータス基盤・土地パネル基盤 | 26×13盤面、初期配置、基本生成 | 基盤構造 | 基盤構造 |
| Sprint 2 | 食料値・食堂・製粉所 | 小麦パネル、複合パネル、香辛料タグ | - | 食料値変換、食堂、製粉所 |
| Sprint 3 | 人口システム | - | 人口生成、人手割当 | - |
| Sprint 4 | 満足度システム | - | 満足度変動、影響度判定 | - |
| Sprint 5 | 満足度段階効果・建物効率 | 地形・特殊タグ接続候補 | 段階効果、効率修正 | - |
| Sprint 6 | 突撃・防衛人口減少 | - | 戦闘による人口減 | - |
| Sprint 7 | 初期デッキ・序盤カード・土地報酬 | 土地カード報酬システム | - | - |
| Sprint 8 | ログ・UI・デバッグ | 土地パネルUI、地形表示 | - | - |

#### 土地パネル基盤

```
- 26列×13行の盤面
- 自拠点初期位置：2列目7行目
```

### 4.4 盤面仕様

#### 4.4.1 サイズと座標

```
盤面サイズ：26列 × 13行
座標表記：col (1-26), row (1-13)
```

#### 4.4.2 自拠点初期位置

```
自拠点：col=2, row=7
盤面左寄り中央に配置
```

### 4.5 土地パネル基本仕様

#### 4.5.1 通常資源

| 資源 | 用途 |
|---|---|
| 木 | 森小屋で獲得、建物建設基盤 |
| 樹脂 | 森小屋で獲得、施設アップグレード |
| 石 | 採掘所で獲得、建物建設基盤 |
| 鉄鉱石 | 採掘所で獲得、兵力・武装 |
| 小麦 | 農村で獲得、食料値変換 |
| 綿花 | 農村で獲得、衣料・施設 |

#### 4.5.2 土地パネルカテゴリ

| カテゴリ | 説明 | 資源値範囲 |
|---|---|---|
| 単一資源パネル | 1種類の通常資源 | 1-4（遠距離は5まで） |
| 複合資源パネル | 2種類の通常資源 | 各1-3 |
| 高数値資源パネル | 高く特化した資源 | 5-6 |
| 特殊パネル | 特殊タグを持つパネル | タグのみ |
| 地形パネル | 地形タイプ主体 | タグ・特殊効果なし |
| 空白・低価値 | リソース価値が低い | 0-1 |

#### 4.5.3 特殊タグ

| タグ | Sprint | 役割 |
|---|---|---|
| 香辛料 | 2 | 食堂の食料値ボーナス |
| 硫黄 | 将来 | 兵力・火薬・攻撃施設接続候補 |

### 4.6 距離帯システム

#### 4.6.1 距離計算

```
距離 = abs(col - 2) + abs(row - 7)  // マンハッタン距離
```

#### 4.6.2 距離帯分類

| 距離帯 | 距離 | 役割 | 資源値レンジ |
|---|---:|---|---|
| 近距離 | 0-4 | 初期安定用 | 1-3 |
| 中距離 | 5-10 | 拡張・選択用 | 1-4 |
| 遠距離 | 11+ | 高価値・特殊用 | 2-5 |

### 4.7 資源値開示ルール（v1.1 追加）

```
開示距離：自建物（自拠点を含む）から距離3以内（マンハッタン距離）
開示の永続性：一度 is_discovered = true になったら戻らない
初期開示範囲：自拠点(col=2, row=7) から距離3以内
初期保証範囲：自拠点から距離4以内（保証 ≠ 開示）
```

### 4.8 建物配置ルール（v1.1 追加）

```
配置可能条件（必須2要件）：
- 条件1：自建物隣接（既存自建物の上下左右4マスのいずれか）
- 条件2：資源値開示済み（is_discovered = true）

両条件を満たさないパネルへの配置は禁止。
未開示パネル（「?」表示）への配置不可。
```

### 4.9 初期保証ロジック

#### 保証範囲

```
自拠点から距離4以内
```

#### 保証内容

```
- 木2以上のパネル：1枚以上
- 石2以上のパネル：1枚以上
- 小麦2以上のパネル：1枚以上
- 小麦/綿花複合パネル：1枚以上
```

#### 対応初期建物

```
- 森小屋（木・樹脂獲得）
- 採掘所（石・鉄鉱石獲得）
- 農村（小麦・綿花獲得）
- 食堂（食料値変換）
- 住宅（人口基盤）
```

### 4.10 完了条件

```
- 26×13盤面を扱える
- 自拠点を2列目7行目に初期配置できる
- 土地パネルデータ構造がある
- 通常資源6種を土地パネルに設定できる
- 単一資源パネルを生成できる
- 複合資源パネルを生成できる
- 特殊タグを保持できる
- 地形タイプを保持できる
- 距離帯に応じて土地生成内容を変えられる
- 初期保証ロジックが機能する

- 人口・満足度・食料値フィールドを持つ
- 資源値開示ルールが機能する（v1.1）
```

### 10.4 土地カード報酬仕様

#### 10.4.1 定義

```
土地カード：
- 盤面に新しい土地パネルを追加する報酬
- 既存土地パネルに隣接する空きマスへ配置
- 建物配置の土台になる
```

#### 10.4.2 配置条件

```
配置条件：
既存自陣土地パネルに隣接する空きマス
配置後、is_discovered = true として開示扱いになる
```

#### 10.4.3 報酬候補

| カテゴリ | 説明 | 例 |
|---|---|---|
| 高数値単一資源 | 通常盤面に自生しない高数値 | 木6、石6、小麦6 |
| 高総量複合資源 | 2種類の資源を高めに持つ | 小麦3/綿花3 |
| 香辛料タグ土地 | 食堂強化用 | 香辛料タグ単体 |
| 硫黄タグ土地 | 将来兵力・火薬接続 | 硫黄タグ単体 |
| 地形土地 | 将来建物ボーナス接続 | 砂漠、荒地など |

#### 10.4.4 高数値6の扱い

```
資源値6：
- 通常盤面には自生しない
- 土地カード報酬・マイルストーン報酬専用
- 希少性を演出
```

#### 10.4.5 報酬選択形式

```
土地カード報酬：
3択から1枚選択

構成例：
1. 高数値単一資源（例：木6）
2. 高総量複合資源（例：小麦3/綿花3）
3. 特殊タグまたは地形土地（例：香辛料タグ土地）
```

### 10.5 完了条件

```
- 初期デッキ13枚での確定が機能（v1.1）
```
