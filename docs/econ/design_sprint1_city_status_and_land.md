# Sprint 1 企画書：都市ステータス基盤・土地パネル基盤

## 1. 目的

Sprint 1では、都市ステータスシステムの基盤と、土地パネルシステムの基盤を実装する。

本企画書は、都市データ構造、土地パネルデータ構造、土地生成ロジック、初期保証ロジックを定義する。

---

## 2. 都市ステータス基盤

### 2.1 都市データ構造

都市は以下のフィールドを持つ。

```
- 人口（Population）
  初期値：100
  最小値：0
  最大値：1000（将来調整）

- 満足度（Satisfaction）
  初期値：50
  範囲：0-100

- 食料値（FoodValue）
  初期値：10
  最小値：0
  消費可能性あり

- ターン数（Turn）
  初期値：0
  毎ターンインクリメント
```

### 2.2 ターンシステム連動

都市ステータスはゲームのターンシステムに連動する。

```
- ターン開始時：各建物の処理開始
- ターン中：人口・満足度・食料値の変動
- ターン終了時：ステータス確定・ログ記録
```

### 2.3 初期設定条件

```
- 新規都市作成時の初期化
- セーブ・ロード時の復元
- リセット時の状態確認
```

## 3. 土地パネルシステム基盤

### 3.1 盤面仕様

#### 3.1.1 盤面サイズ

```
26列 × 13行
```

#### 3.1.2 座標体系

```
列：1 ～ 26（左から右）
行：1 ～ 13（上から下）
```

#### 3.1.3 自拠点初期位置

```
col = 2
row = 7

盤面左寄り中央に配置
```

### 3.2 土地パネルデータ構造

土地パネルは以下の情報を持つ。

```
class LandPanel:
  - position: Vector2i              # col, row
  - land_type: String               # パネルタイプ
  - primary_resource: Resource      # 主資源
  - primary_value: int              # 主資源値
  - secondary_resource: Resource    # 副資源（複合パネルのみ）
  - secondary_value: int            # 副資源値（複合パネルのみ）
  - terrain_type: String            # 地形タイプ
  - special_tags: Array[String]     # 特殊タグ配列
  - distance: int                   # 自拠点からの距離
  - distance_tier: String           # 距離帯分類
  - is_discovered: bool             # 発見済みか
  - building: Building              # 配置中の建物（参照）
```

## 5. 単一資源パネル

### 5.1 定義

単一資源パネルは、1種類の通常資源値を持つ土地パネルである。

```
例：
- 木3
- 石2
- 小麦4
- 鉄鉱石3
```

### 5.2 基本資源値

```
通常資源値：
1 ～ 4

遠距離高値：
5（低確率）

最高値6：
報酬専用、自生しない
```

### 5.3 出現パターン

| パターン | 資源値 | 出現距離帯 | 役割 |
|---|---|---|---|
| 低値（1-2） | 1-2 | 近距離中心 | 初期基盤 |
| 標準値（3-4） | 3-4 | 全距離帯 | 標準獲得量 |
| 高値（5） | 5 | 遠距離・中距離 | 特化強化 |
| 最高値（6） | 6 | 報酬専用 | 稀少性 |

## 6. 複合資源パネル

### 6.1 定義

複合資源パネルは、2種類の通常資源値を持つ土地パネルである。

```
例：
- 小麦2 / 綿花1
- 石2 / 鉄鉱石1
- 木2 / 樹脂1
```

### 6.2 対応施設

| 複合パターン | 対応施設 | 役割 |
|---|---|---|
| 木 / 樹脂 | 森小屋 | 森林資源統合 |
| 石 / 鉄鉱石 | 採掘所 | 採掘資源統合 |
| 小麦 / 綿花 | 農村 | 農業資源統合 |

### 6.3 複合パネルの価値

```
複合パネル：
- 2種類の資源を得られる汎用性
- 施設オプションの選択肢増加
- 単一パネルより希少
```

### 6.4 出現比率

```
近距離：20%
中距離：25%
遠距離：25%
報酬：30%～50%
```

## 7. 特殊タグシステム

### 7.1 特殊タグ定義

特殊タグは、通常資源値を持たない特殊属性である。

```
特殊タグ：
- 香辛料（Spice）
- 硫黄（Sulfur）
```

### 7.2 タグ保持構造

```
土地パネルは特殊タグ配列を持つ
複数タグの同時保持可能（将来拡張用）

例：
- 香辛料タグ単体
- 硫黄タグ単体
- 香辛料 + 硫黄（将来）
```

### 7.3 香辛料タグ（Sprint 2で接続）

```
定義：
- 食料値・満足度強化用タグ
- Sprint 2では食堂の食料値ボーナス（+1）

出現方針：
- 近距離：5%以下（希少）
- 中距離：10%～15%
- 遠距離：20%～30%
```

### 7.4 硫黄タグ（将来接続予定）

```
定義：
- 兵力・火薬・攻撃施設接続用
- Sprint 1では保持・表示のみ

出現方針：
- 近距離：0%～5%
- 中距離：10%～15%
- 遠距離：15%～20%
```

### 7.5 タグの生成フロー

```
1. 土地カテゴリを決定（単一 / 複合 / 特殊）
2. タグ付きパネルなら特殊タグを抽選
3. 香辛料 / 硫黄のいずれかを選択
4. 複数タグの同時付与は低確率
```

## 9. 距離帯システム

### 9.1 距離計算式

```
distance = abs(col - 2) + abs(row - 7)
```

自拠点(col=2, row=7)からのマンハッタン距離を計算。

### 9.2 距離帯分類

| 距離帯 | 距離 | 説明 | 資源値 | タグ出現 |
|---|---:|---|---|---|
| 近距離 | 0-4 | 初期安定地帯 | 1-3 | 低い |
| 中距離 | 5-10 | 拡張選択地帯 | 1-4 | 中程度 |
| 遠距離 | 11+ | 高価値特殊地帯 | 2-5 | 高い |

### 9.3 距離帯による生成内容の変化

距離帯が増えるごとに：

```
1. 資源値の平均が上昇
2. 複合パネンの比率が増加
3. 特殊タグ出現率が増加
4. 地形の多様性が増加
5. 高価値パネルが出現しやすくなる
```

## 9.4 資源値開示ルール（§10-11）

### 9.4.1 開示距離

```
自建物（自拠点を含む）から距離3以内（マンハッタン距離）のパネルは
資源値・特殊タグ・地形を開示する。

距離計算式：
distance = abs(panel.col - building.col) + abs(panel.row - building.row)
```

`is_discovered: bool` フィールドは本ルールで True/False が決まる。
True に切り替わったパネルは永続的に表示状態を保持する（hidden 状態は不可逆に終わる）。

### 9.4.2 開示の永続性

```
開示済みフラグの遷移：
- 初期状態：false（自拠点付近の保証範囲を除く）
- 自建物の距離3以内に入った瞬間：true
- 一度 true になったら、自建物が破壊・撤去されても false に戻らない
```

開示済みパネルから建物が遠ざかっても情報は保持される。
これは「探索の足跡を残す」ためのルールであり、再探索コストを発生させない。

### 9.4.3 開示と資源獲得の分離

```
開示（is_discovered = true）：
- 資源値・タグ・地形を確認できる
- 建物配置の前提条件（§19参照）

資源獲得：
- 別途、建物がパネル上に配置されている必要あり
- 開示しただけでは資源は得られない
```

## 10. 土地パネル生成ロジック

### 10.1 生成手順

```
Step 1: 生成位置を決定（盤面の空きマス）
Step 2: 自拠点からの距離帯を判定（近 / 中 / 遠）
Step 3: 土地カテゴリを抽選（確率テーブル参照）
Step 4: 土地タイプを決定（資源 or 地形）
Step 5: （資源パネルの場合）通常資源カテゴリを抽選
Step 6: 資源値を決定（距離帯別レンジ参照）
Step 7: 特殊タグを付与（低確率抽選）
Step 8: 初期保証ロジックをチェック
Step 9: 保証条件失敗なら再抽選（最大3回）
Step 10: パネルを確定・配置
```

### 10.2 カテゴリ抽選テーブル

#### 近距離（距離 0-4）

| カテゴリ | 確率 | パターン |
|---|---|---|
| 単一資源 | 70% | 資源1種類 |
| 複合資源 | 20% | 資源2種類 |
| 地形 | 10% | 地形のみ |
| 特殊 | 0% | タグのみ |

#### 中距離（距離 5-10）

| カテゴリ | 確率 | パターン |
|---|---|---|
| 単一資源 | 55% | 資源1種類 |
| 複合資源 | 25% | 資源2種類 |
| 地形 | 10% | 地形のみ |
| 特殊 | 10% | タグのみ |

#### 遠距離（距離 11+）

| カテゴリ | 確率 | パターン |
|---|---|---|
| 単一資源 | 40% | 資源1種類 |
| 複合資源 | 25% | 資源2種類 |
| 地形 | 15% | 地形のみ |
| 特殊 | 20% | タグのみ |

### 10.3 資源値決定ロジック

```
Step 1: 距離帯を確認
Step 2: 距離帯別レンジを取得
Step 3: レンジ内で資源値をランダム選択
Step 4: 複合パネルの場合、副資源値は主資源値 - 1 or 同値
```

#### 資源値レンジ

| 距離帯 | 単一パネル | 複合パネル | 説明 |
|---|---|---|---|
| 近距離 | 1-3 | 各1-3 | 安定供給 |
| 中距離 | 1-4 | 各1-4 | 標準レンジ |
| 遠距離 | 2-5 | 各2-5 | 高価値化 |

### 10.4 タグ付与ロジック

```
Step 1: タグ出現確率を距離帯別に取得
Step 2: ランダムで付与判定（確率テーブル参照）
Step 3: 付与する場合、香辛料 / 硫黄を選択
Step 4: 複数タグ同時付与は極低確率（将来）
```

#### タグ出現確率

| 距離帯 | 香辛料 | 硫黄 | 複数 |
|---|---|---|---|
| 近距離 | 3% | 2% | 0.1% |
| 中距離 | 10% | 12% | 0.5% |
| 遠距離 | 20% | 20% | 1% |

### 10.5 再抽選条件

生成後、以下の条件で再抽選を行う（最大3回）。

```
- 初期保証条件を満たしていない
- 近距離で高価値パネル（値5以上）が出た
- 近距離で香辛料が出た場合
```

## 11. 初期保証ロジック

### 11.1 目的

初期盤面で、プレイヤーが最低限の建物を配置できることを保証する。

### 11.2 保証範囲

```
自拠点(col=2, row=7)から距離4以内
つまり近距離地帯全域
```

### 11.3 保証内容

初期盤面では、以下の条件を満たすことを保証する。

```
1. 木2以上のパネル：1枚以上（森小屋配置用）
2. 石2以上のパネル：1枚以上（採掘所配置用）
3. 小麦2以上のパネル：1枚以上（農村配置用）
4. 小麦/綿花複合パネル：1枚以上（農村選択肢用）
```

### 11.4 対応初期建物

| 建物 | 対応パネル | 役割 |
|---|---|---|
| 森小屋 | 木2以上 | 木・樹脂獲得 |
| 採掘所 | 石2以上 | 石・鉄鉱石獲得 |
| 農村 | 小麦2以上 or 小麦/綿花複合 | 小麦・綿花獲得 |
| 食堂 | 任意パネル | 食料値変換 |
| 住宅 | 任意パネル | 人口基盤 |

### 11.5 保証チェック手順

```
Step 1: 初期盤面生成完了
Step 2: 近距離内の全パネルをスキャン
Step 3: 各保証条件をカウント
Step 4: 1つ以上満たしていない条件がある場合、盤面を再生成
Step 5: 最大5回までリトライ、5回失敗したら手動調整
```

## 11.6 初期化範囲（§17）と開示の関係

### 11.6.1 初期保証範囲と初期開示範囲

```
初期保証範囲（§4.3 / §11.2）：
- 自拠点(col=2, row=7)から距離4以内
- 「ここに最低限の資源パネルが置かれる」ことを保証
- = ゲーム成立性のための保証

初期開示範囲（§9.4）：
- 自拠点(col=2, row=7)から距離3以内
- 「ここの資源値が見える」ことを保証
- = 視覚的なスタート地点
```

両者は範囲が異なる（保証 4以内 / 開示 3以内）ことに注意する。
保証範囲＞開示範囲なので、初期盤面では「保証されているが見えていない」リング（距離4のみ）が存在する。
このリングは、自拠点から距離3以内にある自建物が距離4のパネルを開示するか、
プレイヤーが拠点付近に建物を増やすことで段階的に開示される。

### 11.6.2 ゲーム開始時の開示処理

```
Step 1: 盤面生成完了（§10-11）
Step 2: 自拠点(col=2, row=7) を中心に、距離3以内の全パネルを is_discovered = true に設定
Step 3: 距離4のパネルは is_discovered = false のまま（資源は保証されているが非表示）
Step 4: プレイヤーは見えている範囲（距離3以内）から建物配置を開始する
```

### 11.6.3 開示≠保証の明示

```
「保証された」 = そのパネルに最低限の資源値が必ず置かれる
「開示された」 = そのパネルの資源値をプレイヤーが見られる

保証されていても開示されていないパネルがある（距離4のリング）。
保証されていなくても開示されるパネルがある（建物を建てて拡張した先）。
```

## 12. 盤面初期化フロー

### 12.1 新規都市作成時

```
1. 都市データ構造を初期化
   - 人口：100
   - 満足度：50
   - 食料値：10

2. 盤面を初期化（26×13）

3. 自拠点パネルを配置
   - col=2, row=7 に自拠点マーカー

4. 土地パネルを生成
   - 全盤面に対して生成ロジックを適用
   - または初期保証範囲のみ生成（未開放方式）

5. 初期保証チェック実行

6. 盤面確定・ゲーム開始可能状態
```

### 12.2 開放方式の選択肢

```
方式A：全盤面事前生成
- 利点：全パネルが決定済み、乱数安定
- 欠点：メモリ使用量が多い

方式B：初期保証範囲のみ生成
- 利点：メモリ効率、段階的な盤面展開
- 欠点：実装複雑度が高い

推奨：方式A（MVP）
```

## 12.3 建物配置ルール（§19-20）

### 12.3.1 配置可能条件（必須2要件）

建物を土地パネルに配置するには、以下の **両方** を満たす必要がある。

```
条件1：自建物隣接
- 配置先パネルの上下左右4マスのいずれかに既存の自建物（自拠点を含む）がある

条件2：資源値開示済み
- 配置先パネルが is_discovered = true である
- 未開示パネル（is_discovered = false）への配置は禁止
```

両条件のうち1つでも欠けた場合、建物は配置できない。

### 12.3.2 配置不可ケースの整理

| 隣接 | 開示 | 配置可否 | 理由 |
|---|---|---|---|
| あり | あり | 配置可能 | 両条件を満たす |
| あり | なし | 配置不可 | 資源値が見えない場所には建てられない |
| なし | あり | 配置不可 | 自陣から離れた孤立地への建設禁止 |
| なし | なし | 配置不可 | 両条件不成立 |

### 12.3.3 建物配置による開示連鎖

```
建物を配置 → 配置位置が「自建物」になる
 → §9.4.1 により、その建物から距離3以内のパネルが開示される
 → 開示されたパネルは新たに建物配置の候補となる（隣接していれば）
```

このループにより、プレイヤーは盤面を段階的に拡大できる。
盤面探索は「建物を建てて隣接マスを開示し、その先に建てる」という反復で進む。

## 14.5 UI表示ルール（§25-26）

### 14.5.1 開示状態と表示

```
is_discovered = true（開示済み）：
- 資源アイコン + 資源値を表示
- 特殊タグアイコンを表示
- 地形タイプを背景色で表現
- ホバーで詳細情報を表示

is_discovered = false（未開示）：
- パネル全体に「?」を表示
- 資源値・タグ・地形は一切表示しない
- 背景色は中立色（グレー系）で統一
- ホバーしても「未開示」とのみ表示
```

### 14.5.2 「?」表示の仕様

```
表示要素：
- 中央に大きく「?」記号（フォントサイズ 24pt 以上）
- 文字色：白または淡いグレー
- 背景色：濃いグレー（#444444 程度）
- 枠線：通常パネルと同じ

ホバー時：
- 「未開示エリア」のみ表示
- 座標は表示しない（位置情報も隠す方針）
```

### 14.5.3 開示時の表示遷移

```
未開示 → 開示の遷移：
- 「?」表示から通常表示へ切り替え
- 短いフェードイン演出（0.3秒程度）を推奨
- 演出は将来実装、Sprint 1では即時切り替えで可
```

これにより §15 残論点「未開放マスをどう見せるか」は **「?」表示で確定** とする。
