# Sprint 8 企画書：ログ・UI・デバッグ・土地パネル表示

## 1. 目的

Sprint 8では、土地パネルの資源値・特殊タグ・地形タイプをプレイヤーと開発者が確認できるようにするUI・ログシステムを実装する。

本企画書は、土地パネルUI表示、詳細情報、ログ出力、デバッグ表示の仕様を定義する。

---

## 2. UI表示戦略

### 2.1 UI表示対象

土地パネル上に以下を表示する。

```
- 資源アイコン
- 資源値
- 特殊タグアイコン
- 地形タイプ
```

### 2.2 情報表示の優先度

```
優先度1：資源（アイコン + 数値）
優先度2：特殊タグ（タグアイコン）
優先度3：地形タイプ（背景 or 枠で表現）
```

### 2.3 表示タイミング

```
常時表示：
- 資源アイコン + 資源値（単一パネル）
- 資源アイコン + 資源値 ×2（複合パネル）

ホバー時追加表示：
- 地形タイプ名
- 特殊タグ詳細
- パネル座標・距離

詳細UI時表示：
- 全情報（資源・タグ・地形・座標・建物）
```

## 6. 地形パネル表示

### 6.1 地形タイプの定義

MVP地形タイプ：

| 地形 | ビジュアル色 | パターン |
|---|---|---|
| 草原 | 緑色 | 草パターン |
| 森林 | 濃緑 | 木パターン |
| 岩場 | 灰色 | 岩パターン |
| 砂漠 | 黄色 | 砂パターン |
| 湿地 | 茶色 | 湿地パターン |
| 荒地 | 灰茶色 | グレースケール |

### 6.2 表示形式

```
形式1：背景色で表現
- パネル背景を地形色に設定
- シンプル・高速描画

形式2：背景パターンで表現
- パネル背景にテクスチャ追加
- ビジュアル多様性向上

推奨：形式1（MVP）
```

### 6.3 地形名の表示

地形パネルの場合、地形名を表示。

```
ホバー時：
- 地形名ラベル表示（「草原」等）
- フォントサイズ10、グレー色

詳細UI時：
- 地形タイプ項目に表示
```

### 6.4 レイアウト図

```
背景色表現：
┌────────────────┐
│ [背景：緑色]   │
│    草原        │ ← ホバー時表示
└────────────────┘
```

## 7. 土地パネル詳細UI

### 7.1 詳細UI発動条件

```
詳細UI表示：
- 土地パネルを左クリック
- または右クリック
- または長押し（タッチデバイス）
```

### 7.2 詳細UI表示内容

詳細UIは以下の情報を表示する。

```
基本情報：
- パネルID
- 座標（col, row）
- 距離（マンハッタン距離）
- 距離帯（近/中/遠）

パネル情報：
- 土地カテゴリ（単一/複合/特殊/地形）
- 土地タイプ（資源 or 地形）
- 通常資源値（ある場合）
- 特殊タグ（ある場合）
- 地形タイプ

配置情報：
- 配置中の建物（あれば名称・レベル）
- 割当人手数
```

### 7.3 詳細UIレイアウト

```
┌─────────────────────────────┐
│ 土地パネル詳細 #ID           │
├─────────────────────────────┤
│ 座標：col=5, row=7          │
│ 距離：3（近距離）            │
│                             │
│ カテゴリ：複合資源パネル     │
│ 資源：小麦2 / 綿花1         │
│ タグ：なし                  │
│ 地形：草原                  │
│                             │
│ 配置中の建物：農村（L1）    │
│ 割当人手：5人               │
├─────────────────────────────┤
│ [詳細] [配置] [キャンセル]  │
└─────────────────────────────┘
```

### 7.4 詳細UI動作

```
動作：
- クリック外で閉じる
- または閉じるボタンで閉じる
- 詳細UIが開いている間、ゲーム進行は停止（ポーズ）
```

## 8. ホバー表示

### 8.1 ホバー発動条件

```
ホバー表示：
- マウスをパネル上に置く（PC）
- 短時間（0.5秒）留置
- 画面端の場合も表示位置調整
```

### 8.2 ホバー表示内容

```
最小限：
- 土地タイプ名（例「小麦」「香辛料」「草原」）
- 資源値（ある場合）

拡張：
- 座標・距離（1行）
- タグ名（特殊タグある場合）
```

### 8.3 ホバー表示の位置

```
配置：
- パネルの上部または上下左右から、画面内に収まる位置
- フォローマウス方式（マウス追従）
- 画面外はみ出し防止あり
```

## 9. 土地生成ログ

### 9.1 ログ出力タイミング

```
出力タイミング：
- 土地パネルが生成される（初期盤面、報酬等）
- 毎パネル生成時に1行のログ出力
```

### 9.2 ログ出力形式

```
基本ログ：
[土地生成] 位置：col=5 row=7 | 距離=3 | 距離帯=近距離 | カテゴリ=複合資源 | 資源=小麦2/綿花1 | タグ=なし | 地形=草原

詳細ログ：
[土地生成]
 位置：col=5 row=7
 距離：3（マンハッタン距離）
 距離帯：近距離
 カテゴリ：複合資源パネル
 資源：小麦2/綿花1
 タグ：なし
 地形：草原
 再抽選：0回
```

### 9.3 ログに含む情報

```
必須：
- 生成位置
- 距離
- 距離帯
- 土地カテゴリ
- 資源値

任意：
- 特殊タグ
- 地形タイプ
- 再抽選回数
- 抽選種別（初期/報酬/探索）
```

### 9.4 再抽選ログ

再抽選が発生した場合、ログに理由を記録。

```
[土地生成] 位置：col=3 row=7 → 再抽選
[土地生成] 理由：初期保証条件 再抽選1回目
[土地生成] 位置：col=3 row=8 → 採用
```

## 11. デバッグ表示

### 11.1 デバッグモードの有効化

```
有効化方法：
- ゲーム起動時フラグ（DEBUG_MODE=true）
- または開発者コンソールコマンド（debug land on）
- UIトグルボタン（オプション画面）

無効化方法：
- ゲーム起動時フラグ（DEBUG_MODE=false）
- または開発者コンソールコマンド（debug land off）
```

### 11.2 デバッグ表示内容

デバッグモード時、パネル上に以下を表示：

```
画面表示：
- 座標（col,row）
- 距離
- 距離帯
- 土地カテゴリ
- 資源値
- 特殊タグ
- 地形タイプ
- 再抽選回数
```

### 11.3 デバッグ表示例

```
┌───────────────────┐
│ (5,7) dist=3      │
│ 近距離            │
│ 複合資源          │
│ 小麦2/綿花1       │
│ tag: -            │
│ 地形: 草原        │
│ reroll: 0         │
└───────────────────┘
```

### 11.4 デバッグ表示フォント

```
フォント：等幅フォント（Courier）
フォントサイズ：8pt（小さく、邪魔にならないように）
色：灰色（背景に馴染むが見える程度）
透明度：70%
```

## 16. 残論点

```
- 通常UIでどこまで情報を常時表示するか（座標など）
- 資源値を常時表示するか、ホバー時表示にするか
- 特殊タグアイコンの視認性（サイズ・色）
- 複合資源表示のレイアウト（左右 vs 上下）
- 地形タイプ名を通常UIに表示するか（詳細UImust）
- デバッグ表示の切り替え方法（UI vs コマンド）
- 土地カード報酬UIのレイアウト（カード選択画面の見た目）
- ホバー表示の遅延時間（0.5秒が適切か）
- 詳細UI時のゲーム一時停止要否
- ログレベル分類（INFO/DEBUG/WARN）の詳細定義
```
