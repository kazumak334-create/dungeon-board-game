# 経済MVP統合スプリント計画書 v0.2

## 1. 目的

本スプリント計画書は、都市ステータス基盤、人口・満足度・食料値システム、土地パネル選定ロジック、初期デッキ・報酬システムを統合し、Sprint 1〜8の実装範囲を定義する。

---

## 2. 全体構成

経済MVP は以下の8つのSprintで実装される。各Sprintは前後Sprintと依存関係を持つ。

| Sprint | 主対象 | 土地パネル | 人口・満足度 | 食料値 |
|---:|---|---|---|---|
| Sprint 1 | 都市ステータス基盤・土地パネル基盤 | 26×13盤面、初期配置、基本生成 | 基盤構造 | 基盤構造 |
| Sprint 2 | 食料値・食堂・製粉所 | 小麦パネル、複合パネル、香辛料タグ | - | 食料値変換、食堂、製粉所 |
| Sprint 3 | 人口システム | - | 人口生成、人手割当 | - |
| Sprint 4 | 満足度システム | - | 満足度変動、影響度判定 | - |
| Sprint 5 | 満足度段階効果・建物効率 | 地形・特殊タグ接続候補 | 段階効果、効率修正 | - |
| Sprint 6 | 突撃・防衛人口減少 | - | 戦闘による人口減 | - |
| Sprint 7 | 初期デッキ・序盤カード・土地報酬 | 土地カード報酬システム | - | - |
| Sprint 8 | ログ・UI・デバッグ | 土地パネルUI、地形表示 | - | - |

---

## 4. Sprint 1：都市ステータス基盤・土地パネル基盤

### 4.1 目的

都市ステータス基盤システムと土地パネルシステムの基盤を実装する。

### 4.2 実装対象

#### 都市ステータス基盤

```
- 都市データ構造
- 人口フィールド（初期値）
- 満足度フィールド（初期値）
- 食料値フィールド（初期値）
- ターンシステム連動
```

#### 土地パネル基盤

```
- 26列×13行の盤面
- 自拠点初期位置：2列目7行目
- 土地パネルデータ構造
- 通常資源6種（木、樹脂、石、鉄鉱石、小麦、綿花）
- 単一資源パネル生成
- 複合資源パネル生成
- 特殊タグ保持構造（香辛料、硫黄）
- 地形タイプ保持構造（6種）
- 距離帯判定（近・中・遠）
- 資源値レンジ管理
- 初期保証ロジック
```

### 4.3 盤面仕様

#### 4.3.1 サイズと座標

```
盤面サイズ：26列 × 13行
座標表記：col (1-26), row (1-13)
```

#### 4.3.2 自拠点初期位置

```
自拠点：col=2, row=7
盤面左寄り中央に配置
```

### 4.4 土地パネル基本仕様

#### 4.4.1 通常資源

| 資源 | 用途 |
|---|---|
| 木 | 森小屋で獲得、建物建設基盤 |
| 樹脂 | 森小屋で獲得、施設アップグレード |
| 石 | 採掘所で獲得、建物建設基盤 |
| 鉄鉱石 | 採掘所で獲得、兵力・武装 |
| 小麦 | 農村で獲得、食料値変換 |
| 綿花 | 農村で獲得、衣料・施設 |

#### 4.4.2 土地パネルカテゴリ

| カテゴリ | 説明 | 資源値範囲 |
|---|---|---|
| 単一資源パネル | 1種類の通常資源 | 1-4（遠距離は5まで） |
| 複合資源パネル | 2種類の通常資源 | 各1-3 |
| 高数値資源パネル | 高く特化した資源 | 5-6 |
| 特殊パネル | 特殊タグを持つパネル | タグのみ |
| 地形パネル | 地形タイプ主体 | タグ・特殊効果なし |
| 空白・低価値 | リソース価値が低い | 0-1 |

#### 4.4.3 複合資源パネル対応施設

| パネル組み合わせ | 対応施設 |
|---|---|
| 木 / 樹脂 | 森小屋 |
| 石 / 鉄鉱石 | 採掘所 |
| 小麦 / 綿花 | 農村 |

#### 4.4.4 特殊タグ

| タグ | Sprint | 役割 |
|---|---|---|
| 香辛料 | 2 | 食堂の食料値ボーナス |
| 硫黄 | 将来 | 兵力・火薬・攻撃施設接続候補 |

#### 4.4.5 地形タイプ

| 地形 | 説明 |
|---|---|
| 草原 | 基本地形、建物配置向け |
| 森林 | 木・樹脂親和性 |
| 岩場 | 石・鉄鉱石親和性 |
| 砂漠 | 特殊資源親和性 |
| 湿地 | 食料・綿花親和性 |
| 荒地 | 低価値・特殊用途 |

### 4.5 距離帯システム

#### 4.5.1 距離計算

```
距離 = abs(col - 2) + abs(row - 7)  // マンハッタン距離
```

#### 4.5.2 距離帯分類

| 距離帯 | 距離 | 役割 | 資源値レンジ |
|---|---:|---|---|
| 近距離 | 0-4 | 初期安定用 | 1-3 |
| 中距離 | 5-10 | 拡張・選択用 | 1-4 |
| 遠距離 | 11+ | 高価値・特殊用 | 2-5 |

### 4.6 距離帯別出現方針

#### 4.6.1 近距離の出現方針

出現しやすい：
```
- 木、石、小麦、綿花
- 草原、森林、岩場
- 小麦/綿花低値複合
- 木/樹脂低値複合
```

出現しにくい：
```
- 高数値5以上
- 特殊タグ
- 砂漠、荒地
```

#### 4.6.2 中距離の出現方針

```
- 複合資源パネル
- 樹脂、綿花、鉄鉱石
- 中数値資源（3-4）
- 香辛料、硫黄
- 砂漠、湿地、荒地
```

#### 4.6.3 遠距離の出現方針

```
- 高数値資源（5-6）
- 複合資源パネル
- 香辛料、硫黄
- 砂漠、荒地、希少地形
```

### 4.7 土地パネル生成比率

#### 近距離

| 種類 | 比率 |
|---|---:|
| 単一資源パネル | 70% |
| 複合資源パネル | 20% |
| 地形パネル | 10% |
| 特殊パネル | 0% |

#### 中距離

| 種類 | 比率 |
|---|---:|
| 単一資源パネル | 55% |
| 複合資源パネル | 25% |
| 地形パネル | 10% |
| 特殊パネル | 10% |

#### 遠距離

| 種類 | 比率 |
|---|---:|
| 単一資源パネル | 40% |
| 複合資源パネル | 25% |
| 地形パネル | 15% |
| 特殊パネル | 20% |

### 4.8 初期保証ロジック

#### 保証範囲

```
自拠点から距離4以内
```

#### 保証内容

```
- 木2以上のパネル：1枚以上
- 石2以上のパネル：1枚以上
- 小麦2以上のパネル：1枚以上
- 小麦/綿花複合パネル：1枚以上
```

#### 対応初期建物

```
- 森小屋（木・樹脂獲得）
- 採掘所（石・鉄鉱石獲得）
- 農村（小麦・綿花獲得）
- 食堂（食料値変換）
- 住宅（人口基盤）
```

### 4.9 土地パネル生成手順

```
1. 生成位置を決定
2. 自拠点からの距離帯を判定
3. 土地カテゴリを抽選
4. 土地タイプを決定
5. 通常資源カテゴリを抽選
6. 資源値を決定
7. 特殊タグを付与
8. 初期保証条件をチェック
9. 必要なら再抽選
```

### 4.10 完了条件

```
- 26×13盤面を扱える
- 自拠点を2列目7行目に初期配置できる
- 土地パネルデータ構造がある
- 通常資源6種を土地パネルに設定できる
- 単一資源パネルを生成できる
- 複合資源パネルを生成できる
- 特殊タグを保持できる
- 地形タイプを保持できる
- 距離帯に応じて土地生成内容を変えられる
- 初期保証ロジックが機能する
- 都市データ構造を持つ
- 人口・満足度・食料値フィールドを持つ
```

## 5. Sprint 2：食料値・食堂・製粉所システム

### 5.1 目的

土地パネル上の小麦・香辛料タグを、食料値システムおよび食堂・製粉所の効果に接続する。

### 5.2 実装対象

```
- 小麦資源値管理
- 小麦/綿花複合パネル
- 香辛料タグ管理
- 食堂の香辛料ボーナス
- 製粉所の小麦パネル参照
- 食料値変換システム
```

### 5.3 小麦資源管理

#### 5.3.1 定義

```
小麦：
- 通常資源
- 農村で獲得
- 食堂で食料値へ変換
- 製粉所で小麦生産ブースト
```

#### 5.3.2 対応建物

| 建物 | 役割 | 条件 |
|---|---|---|
| 農村 | 小麦・綿花獲得 | 足元に対応パネル |
| 食堂 | 食料値変換 | 小麦1以上、人手充足 |
| 製粉所 | 小麦ブースト | 小麦1以上、人手充足 |

### 5.4 小麦パネルと農村

農村は、足元パネルの小麦・綿花を参照する。

対象土地：
```
- 小麦単一資源パネル
- 綿花単一資源パネル
- 小麦/綿花複合パネル
```

### 5.5 香辛料タグシステム

#### 5.5.1 定義

```
香辛料タグ：
- 通常資源値を持たない特殊タグ
- 食料値・満足度強化用
- Sprint 2では食堂に接続
```

#### 5.5.2 出現方針

- 中距離：10%程度
- 遠距離：20%程度に含まれる
- 土地カード報酬で確実に獲得可能

### 5.6 食堂システム

#### 5.6.1 通常時の効果

```
食堂：
- 小麦1を消費
- 食料値+2を獲得
- タイマーで定期的に発動
```

#### 5.6.2 香辛料タグ上の効果

```
食堂（香辛料タグ上）：
- 小麦1を消費
- 食料値+3を獲得（ボーナス+1）
```

#### 5.6.3 稼働条件

```
- 小麦1以上（消費可能）
- 必要人手が割当済み
- タイマーが発動状態
```

#### 5.6.4 停止条件

```
- 小麦不足
- 人手不足
- 稼働対象建物なし
```

### 5.7 製粉所システム

#### 5.7.1 通常時の効果

```
製粉所：
- 小麦1を消費
- 小麦+2を獲得
- タイマーで定期的に発動
```

#### 5.7.2 小麦高値パネル上の効果

```
製粉所（小麦3以上パネル上）：
- 小麦1を消費
- 小麦+2を獲得
- さらに小麦+1ボーナス
- 合計小麦+3獲得
```

#### 5.7.3 稼働条件

```
- 小麦1以上（消費可能）
- 必要人手が割当済み
- タイマーが発動状態
```

#### 5.7.4 パネル条件判定

```
足元パネルの小麦値 >= 3 なら追加効果発動
```

### 5.8 硫黄タグの扱い

硫黄タグはMVPで土地タグとして実装するが、Sprint 2では食料値システムには接続しない。

```
硫黄タグ：
- 土地パネルに保持
- UI表示対象
- 食料値効果なし
- Sprint 後続で兵力・火薬・攻撃施設に接続予定
```

### 5.9 完了条件

```
- 小麦パネルが農村・食堂・製粉所の導線に接続
- 小麦/綿花複合パネルが農村の配置候補として機能
- 香辛料タグが土地パネルに保持
- 香辛料タグ上の食堂が食料値+3生成
- 製粉所が小麦3以上パネルを参照して追加効果発動
- 硫黄タグを土地タグとして保持・表示
- 食料値変換が正常に機能
```

## 10. Sprint 7：初期デッキ・序盤カード・土地報酬

### 10.1 目的

初期デッキ決定、序盤カード報酬、土地カード報酬を実装する。

### 10.2 実装対象

```
- 初期デッキ確定機能
- 序盤カード報酬システム
- 土地カード報酬システム
- 高数値土地生成
- 複合資源土地生成
- 香辛料土地生成
- 硫黄土地生成
- 地形土地生成
- 3択表示メカニクス
```

### 10.3 土地カード報酬仕様

#### 10.3.1 定義

```
土地カード：
- 盤面に新しい土地パネルを追加する報酬
- 既存土地パネルに隣接する空きマスへ配置
- 建物配置の土台になる
```

#### 10.3.2 配置条件

```
配置条件：
既存自陣土地パネルに隣接する空きマス
```

#### 10.3.3 報酬候補

| カテゴリ | 説明 | 例 |
|---|---|---|
| 高数値単一資源 | 通常盤面に自生しない高数値 | 木6、石6、小麦6 |
| 高総量複合資源 | 2種類の資源を高めに持つ | 小麦3/綿花3 |
| 香辛料タグ土地 | 食堂強化用 | 香辛料タグ単体 |
| 硫黄タグ土地 | 将来兵力・火薬接続 | 硫黄タグ単体 |
| 地形土地 | 将来建物ボーナス接続 | 砂漠、荒地など |

#### 10.3.4 高数値6の扱い

```
資源値6：
- 通常盤面には自生しない
- 土地カード報酬・マイルストーン報酬専用
- 希少性を演出
```

#### 10.3.5 報酬選択形式

```
土地カード報酬：
3択から1枚選択

構成例：
1. 高数値単一資源（例：木6）
2. 高総量複合資源（例：小麦3/綿花3）
3. 特殊タグまたは地形土地（例：香辛料タグ土地）
```

### 10.4 完了条件

```
- 土地カード報酬を生成できる
- 土地カード3択を表示できる
- 選択した土地パネルを盤面に追加できる
- 既存土地に隣接する空きマスへ配置できる
- 高数値単一資源土地を出せる
- 高総量複合資源土地を出せる
```
