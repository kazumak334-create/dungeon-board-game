## 実装概要

Sprint 5 では、Sprint 4 で算出した満足度段階を、人口・兵力・建物効率へ反映する。

**核となる仕様:**
- 満足度段階ごとの人口効果（Sprint 3 で使用）
- 満足度段階ごとの兵力補正（獲得量・効果）
- 満足度段階ごとの建物効率（-10%～+30%）
- 建物効率の適用: 周期発動建物の発動間隔のみ
- 発動間隔計算: `補正後間隔 = 基礎間隔 / (1 + 効率補正)`
- 発動間隔クランプ: 2秒～15秒

## 実装内容

### 1. 満足度段階別効果テーブル

| 満足度段階 | 人口増加率 | 人口減少率 | 兵力獲得量補正 | 兵力効果補正 | 建物効率 |
|---|---|---|---|---|---|
| 衰退 | 0%/秒 | -0.12%/秒 | -30% | -20% | -10% |
| 不満 | 0%/秒 | -0.04%/秒 | -20% | -10% | -5% |
| 安定 | +0.02%/秒 | 0%/秒 | 0% | 0% | 0% |
| 満足 | +0.04%/秒 | 0%/秒 | +10% | 0% | +5% |
| 繁栄 | +0.06%/秒 | 0%/秒 | +20% | +10% | +30% |

### 2. 建物効率の計算

#### 2.1 効率補正値取得
```gdscript
func get_building_efficiency_modifier(satisfaction_stage: String) -> float:
    # 満足度段階から効率補正を返す (-0.10 ～ +0.30)
    # 例: "衰退" → -0.10, "繁栄" → +0.30
```

#### 2.2 発動間隔計算
```
補正後発動間隔 = 基礎発動間隔 / (1 + 効率補正)

例:
基礎間隔: 5秒
繁栄時: 5 / (1 + 0.30) = 3.85秒
衰退時: 5 / (1 - 0.10) = 5.56秒
```

#### 2.3 発動間隔クランプ
```
clamp(補正後発動間隔, 2秒, 15秒)
```

### 3. 建物効率の適用対象

**適用する建物（周期発動）:**
- 採取施設（農村、森小屋、採掘所など）
- 加工施設（製粉所など）
- 食料値生成施設（食堂など）
- 兵力獲得施設（兵舎など）

**適用しない（常時補正・一回限りなど）:**
- 住宅
- 満足値傾き補正施設
- 土地タグ効果
- 建築時効果
- 戦闘開始時効果
- 戦闘終了時効果

### 4. 満足度段階変化時のタイマー処理

建物のタイマー進捗率を維持して発動間隔を再計算：

```gdscript
# 変化前の進捗率を記録
progress_ratio = elapsed_time / current_interval

# 新しい効率補正を取得して発動間隔を再計算
new_interval = base_interval / (1 + new_efficiency_modifier)
new_interval = clamp(new_interval, 2.0, 15.0)

# 進捗率を保持して新しい経過時間を設定
elapsed_time = progress_ratio * new_interval
```

**例:**
```
食堂タイマー：経過2.5秒（5秒建物）
安定（進捗率: 50%） → 繁栄（新間隔: 3.85秒）
新経過時間 = 0.5 × 3.85 = 1.925秒
```

### 5. 建物停止との関係

- 資源不足・人手不足時: タイマー停止（従来通り）
- 満足度段階低下時: タイマーは停止しない、発動間隔が長くなるのみ

### 6. 兵力補正の実装

**兵力獲得量補正:** 兵力獲得時に適用
```
獲得兵力 = 基礎兵力 × (1 + 兵力獲得量補正)
```

**兵力効果補正:** 戦闘時に適用
```
有効兵力 = 保有兵力 × (1 + 兵力効果補正)
```

### 7. 繁栄時の人口増加軽減

繁栄時のみ、人口増加確定時の必要食料値を軽減：

```
通常時: ceil(次の確定人口 / 50)
繁栄時: max(1, ceil(次の確定人口 / 50) - 1)
```
