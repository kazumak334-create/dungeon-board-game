## 変更概要

- 満足度段階から建物効率補正を返す処理を、旧倍率方式から Final 仕様の加算補正値（-0.30 / -0.10 / 0 / +0.05 / +0.10）へ変更した。
- 兵力獲得量補正・兵力効果補正で、既存段階キーと要件定義書側キーの両方を扱えるようにした。
- 旧 `get_happiness_production_modifier()` は後方互換ラッパー化し、出力量補正としての直接利用を外した。
- 周期発動建物の発動間隔を `基礎間隔 / (1 + 建物効率補正)` で計算し、2秒〜15秒にクランプする共通処理を追加した。
- 満足度段階変化時に、各タイマーの進捗率を維持して新しい発動間隔へ再マッピングする処理を追加した。
- BARRACKS / WORKSHOP / VILLAGE / DINER / MILL の周期処理で、出力量補正をやめて発動間隔補正を適用した。
- DINER / MILL / BARRACKS / WORKSHOP は、必要資源不足時にタイマーが進まないようにした。
