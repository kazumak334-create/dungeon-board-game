## 変更概要

- 初期手札5枚、手札上限7枚、リロードCT5秒、追加ドロー消費15を定数化。
- `setup()` で山札シャッフル、手札/捨て札/除外/ターン状態を初期化し、初期手札5枚を確定ドロー。
- ターン開始ドローは `current_turn = 1` / `_last_processed_turn = 1` から開始し、30秒経過後のターン2以降のみ発火。
- `draw_card()` は手札上限到達時に即失敗し、山札再構築などの副作用を起こさないよう修正。
- 山札切れ時は捨て札をシャッフルして山札に戻し、山札も捨て札も空ならドロー失敗。
- 右クリックリロード用 `request_library_draw(card_idx)` を、選択カードを捨て札へ送り、山札から1枚引き、成功時のみ5秒CTを開始する処理に修正。
- 追加ドロー用 `request_extra_draw(resource_key)` を分離し、手札上限/山札空チェック後に対象リソース15個を消費する順序にした。
