## 仕様

| 項目 | 値 |
|------|-----|
| 初期手札 | 5枚（バトル開始時） |
| 手札上限 | 7枚 |
| ターン開始ドロー | 1枚 / 30秒間隔 |
| バトル1ターン目のドロー | なし（初期手札5枚のみ） |
| リロードCT | 5秒 |
| リロード対象 | 全カード（種別不問） |
| リロード動作 | 選択カード→捨て札、山札から1枚引く |
| 追加ドロー消費 | 対象リソース 15個 |
| 山札切れ時 | 捨て札シャッフルで山札再構築 |
| 山札も捨て札も空 | ドロー失敗（コスト消費なし） |
| 手札上限時のドロー要求 | ドローしない（コスト消費なし） |
