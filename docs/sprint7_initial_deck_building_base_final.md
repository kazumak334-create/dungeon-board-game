# Sprint 7：初期デッキ・住宅・交換所・建築基盤企画書 確定版

## 1. 目的

Sprint 7では、初期デッキ・住宅・兵舎・広場・交換所を定義し、あわせて建物カードを使用して建物が建つまでの建築基盤を実装する。

Sprint 8で都市成長を検証できるように、Sprint 7時点で以下を成立させる。

```text
- 建物カードを使える
- 建設予定地を指定できる
- 建設コストを支払える
- 建設時間に応じて建設進捗が進む
- 稼働人手/作業人手に応じて建物稼働・建設進捗が止まる
- 建設完了後に建物が稼働開始する
```

---

## 2. 用語定義

| 用語 | 定義 |
|---|---|
| 建物カード | 手札から使用し、土地パネル上に建物を建設するためのカード。 |
| 通常建物 | 使用後に捨て札/山札循環へ戻る建物カードで建てる建物。 |
| 特殊建物 | 使用後に捨て札へ行かず除外される建物カードで建てる建物。建物自体は盤面に残る場合がある。 |
| 建設予定地 | 建物カード使用時に指定される、建設中の土地パネル。建設完了まで占有状態になる。 |
| 未建設土地 | 建物が建っておらず、建設予定地にもなっていない土地。 |
| 建設後パネル | 建設が完了し、建物が建っている土地パネル。 |
| 建設コスト | 建物カード使用時に支払う通常資源コスト。 |
| 建設時間 | 建設開始から建設完了までに必要な時間。建物ごとに設定する。 |
| 建設進捗 | 建設時間に対する進行度。作業人手が足りている間だけ進む。 |
| 人手 | 人口から算出される作業可能枠。既存の人手システムを使用する。 |
| 稼働人手 | 完成済み建物の効果発動に使う人手。 |
| 作業人手 | 建設中建物の建設進捗に使う人手。 |
| 人手スライダー | 人手総量を稼働人手と作業人手に配分するUI/内部設定。 |
| 人手総量 | 人口から算出される人手の総量。仮置きとして `floor(人口 × 20%)` を使う。 |
| 住宅 | 人口上限を増やす通常建物。 |
| 農村 | 小麦系の土地から小麦を得る通常建物。 |
| 森小屋 | 木/樹脂系の土地から資源を得る通常建物。 |
| 採掘所 | 石/鉄鉱石系の土地から資源を得る通常建物。 |
| 食堂 | 小麦を消費して食料値を生成する通常建物。 |
| 兵舎 | 兵力/兵数導線に接続する通常建物。 |
| 広場 | 満足値傾きに良い影響を与える通常建物。 |
| 交換所 | 足元土地の通常資源累計10獲得ごとに1ドローする特殊建物。 |

## 5. 確定仕様

### 5.1 初期デッキ

初期デッキは13枚とする。  
同一カードの重複を許可する。

```text
初期デッキ：
- 住宅 ×3
- 農村 ×2
- 森小屋 ×2
- 採掘所 ×2
- 食堂 ×1
- 兵舎 ×1
- 広場 ×1
- 交換所 ×1
```

### 5.2 初期デッキの意図

初期デッキは、以下の都市成長ループが回りやすいように設計する。

```text
住宅で人口上限を増やす
→ 農村/食堂で食料値維持
→ 兵舎で兵力導線を作る
→ 森小屋/採掘所で資源採取を強化する
→ 広場で満足度を支える
→ 交換所でドロー補助を得る
→ さらに住宅・建物展開へ進む
```

## 6. 建物カード・建築基盤

### 6.1 建物カード使用

建物カードは、手札から使用して建設予定地を指定する。

```text
建物カード使用
→ 配置可能土地を選択
→ 建設コスト支払い
→ 建設予定地化
→ 建設進捗開始
→ 建設完了
→ 建物稼働開始
```

### 6.2 建設予定地指定

建設予定地は以下を満たす必要がある。

```text
建設予定地条件：
- 自建物に隣接している
- 未建設土地である
- 建設予定地ではない
- 建設後パネルではない
- 資源値が開示済みである
```

### 6.3 建設予定地の扱い

建設予定地は建設完了まで占有状態とする。

```text
建設予定地には以下を配置できない：
- 他の建物カード
- 土地カード
```

### 6.4 建設コスト

建設コストは建物カード使用時に支払う。

```text
資源不足時：
建設開始不可
```

建設開始後に追加で資源を要求しない。  
建設中の資源不足による進捗停止はMVPでは扱わない。

### 6.5 建設時間

建物ごとに建設時間を持つ。  
具体的な数値は仮置きとし、Sprint 8テストプレイで調整する。

### 6.6 建設進捗

建設進捗はリアルタイムに進む。  
作業人手が足りている間だけ進行する。

```text
作業人手不足時：
建設進捗停止
```

停止しても以下は発生しない。

```text
- 建設失敗
- 建物破壊
- コスト返却
- 建設予定地解除
```

### 6.7 建設完了

建設進捗が100%に達すると、建設完了とする。

```text
建設完了時：
- 建設予定地を建設後パネルに変更
- 建物を配置済み状態にする
- 建物効果を有効化
- 稼働人手が足りる場合は稼働開始
```

## 7. 人手システム

### 7.1 基本方針

Sprint 7では既存の人手システムを使用する。  
人手は、稼働人手と作業人手に分けて扱う。

```text
人手総量
├─ 稼働人手
└─ 作業人手
```

余剰人手は仕様上扱わない。  
余った人手をUIやログで明示する必要はない。

### 7.2 人手総量

人手総量は人口から算出する。

```text
人手総量 = floor(人口 × 20%)
```

この数値は仮置きとし、Sprint 8テストプレイで調整する。

### 7.3 人手スライダー

人手総量は、人手スライダーで稼働人手と作業人手に配分する。

```text
稼働人手 = floor(人手総量 × 稼働配分率)
作業人手 = 人手総量 - 稼働人手
```

初期値は以下を仮置きとする。

```text
稼働：70%
作業：30%
```

スライダー刻みは10%刻みを仮置きとする。

### 7.4 稼働人手

稼働人手は、完成済み建物の効果発動に使う。

```text
稼働人手不足時：
完成済み建物の効果発動タイマーが停止する
```

人手が足りるようになったら自動再開する。

### 7.5 作業人手

作業人手は、建設中建物の建設進捗に使う。

```text
作業人手不足時：
建設中建物の建設進捗が停止する
```

人手が足りるようになったら自動再開する。

### 7.6 部分稼働

部分稼働はしない。  
必要人手を満たせない建物・建設は停止する。

### 7.7 割当優先順位

人手不足時は、優先順位に従って稼働・作業を維持する。

稼働人手の優先順位：

```text
1. 食料系建物
2. 資源系建物
3. 兵力系建物
4. 満足度系建物
5. その他
```

作業人手の優先順位：

```text
建設開始が古い順
```

優先度変更UIはMVP非対象とする。

## 8. 建物ごとの仮必要人手

建物ごとの必要人手は仮置きとし、Sprint 8テストプレイで調整する。

| 建物 | 建設時 作業人手 | 完成後 稼働人手 |
|---|---:|---:|
| 住宅 | 1 | 0 |
| 農村 | 1 | 1 |
| 森小屋 | 1 | 1 |
| 採掘所 | 1 | 1 |
| 食堂 | 1 | 1 |
| 兵舎 | 2 | 1 |
| 広場 | 1 | 0 |
| 交換所 | 1 | 1 |

### 8.1 仮置きの意図

```text
- 住宅/広場はMVPでは稼働人手0とする
- 小型建物は建設時/稼働時ともに基本1とする
- 兵舎はやや重い建物として建設時作業人手2を仮置きする
- 数値はSprint 8の都市成長テストで調整する
```

## 9. 交換所

### 9.1 分類

交換所は特殊建物として扱う。

```text
交換所カード：
使用後、捨て札へ行かず除外される。
```

交換所の建物自体は盤面に残る。

### 9.2 効果

```text
交換所：
建てた資源パネルの資源を10獲得する毎に1ドロー
```

「建てた資源パネルの資源」とは、交換所の足元土地に対応する通常資源を指す。

### 9.3 進捗

交換所は累計条件型建物として扱う。

```text
進捗率 = 現在累計値 / 10
```

交換所の進捗UIはSprint 8の共通建物進捗UIで扱う。

## 13. 残論点

Sprint 7の主要仕様は確定済みとする。

```text

- 稼働70% / 作業30% の初期値が適切か
- スライダー刻み10%が適切か
- 建物ごとの建設時間
- 建物ごとの建設コスト
- 建物ごとの作業人手/稼働人手
- 稼働人手の優先順位が適切か
- 作業人手の優先順位が適切か
- 建設予定地が増えた時に建設が詰まりすぎないか
- 住宅/広場の稼働人手0が適切か
- 交換所の累計10資源で1ドローが強すぎないか
- 住宅上位建物の詳細仕様
```
