## バランス調整に必要な情報

### カードデータスキーマ (cards.json)

```json
{
  "units": {
    "ユニット名": {
      "hp": 20,           // 体力
      "atk": 5,           // 攻撃力
      "spd": 7.0,         // 攻撃速度（10秒あたり攻撃回数、10スケール）
      "mana": 2,          // マナ生成基準値
      "race": "獣",       // 種族（スライム/獣/アンデッド）
      "rarity": "uncommon", // レアリティ
      "col": 0,           // 初期配置列（0=前列, 1=中列, 2=後列）
      "range": "1行",     // 攻撃範囲
      "en_name": "Wolf",
      "skills": [         // スキル配列
        {
          "effect_id": "packbond",
          "params": {"atk_boost": 2},
          "target": "ally_same_race",
          "trigger": "on_deploy"
        }
      ]
    }
  }
}
```

### 主要パラメータの意味

| フィールド | 意味 | 単位 | 計算式 |
|----------|------|------|--------|
| hp | 体力 | HP | - |
| atk | 攻撃力 | ダメージ/回 | - |
| spd | 攻撃速度 | 1/秒 | 攻撃間隔 = 10/spd 秒 |
| mana | マナ生成 | マナ | 撃破時にこの値を獲得 |

**重要:** SPDは「10秒あたりの攻撃回数」として統一（2026-04-14変更）
