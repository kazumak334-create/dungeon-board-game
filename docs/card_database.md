# カードデータベース

## 概要

### カード分類
- **ユニットカード**：召喚されて盤面に残る（倒されるまで）
- **呪文カード**：使い捨て即時効果・発動後捨て札へ
- **アーティファクト**：別スロット管理・永続パッシブ効果・最大3枠

### ユニットの効果層（2層構造）

| 層 | フィールド | 発動タイプ |
|----|-----------|-----------|
| サポート効果 | `support_effect` | 常時発動 / 召喚時 / 条件達成時 |
| アクティブスキル | `active_skill` | 命中時 / 撃破時 / HP閾値時 / 時間経過 / 召喚時 / その他 |

> ※ 旧「攻撃時効果」はアクティブスキル（命中時）に統合。固有スキルもアクティブスキルとして記載（【固有】プレフィックスで識別）。

### 攻撃範囲
- `1行`：同じ行のみ
- `上含む2行`：自分の行＋上の行
- `下含む2行`：自分の行＋下の行
- `上下含む3行`：全行

### サポート効果の対象範囲
- `隣接`：上下左右に隣接するユニット
- `同行`：同じ行の味方全員
- `同列`：同じ列の味方全員
- `全体`：盤面全体の味方
- `前列の味方のみ`：前列にいる味方のみ
- `後列の味方のみ`：後列にいる味方のみ

| カード名 | Cost | 効果 | 対象 | 対応型 |
|---------|------|------|------|--------|
| 召喚加速 | 1 | マナを即時+3回復 | 自分 | テンポ×流れ×自己 |
| 血の契約 | 2 | 対象ユニット1体に吸血付与 | 単体 | テンポ×個×自己 |
| 戦場の鼓動 | 2 | 全味方のSPD+50%（5s） | 全体 | テンポ×場×自己 |
| 急召 | 1 | デッキから低コストユニットを1体即時召喚 | 自分 | テンポ×流れ×自己 |
| 連鎖の触媒 | 2 | 次の3枚のカードのコストを1下げる | 自分 | テンポ×流れ×自己 |
| 強化の儀式 | 3 | 指定ユニット1体のATK+5・HP+10 | 単体 | 安定×個×自己 |
| 盤面強化 | 3 | 全味方のHP+10・ATK+2 | 全体 | 安定×場×自己 |

## バフ・デバフ定義

### バフ（付与されている間は常時効果発動）

| バフ名 | 効果 | 処理タイミング | 付与手段の例 |
|--------|------|--------------|-------------|
| ATK↑ | ATKにボーナス加算 | 攻撃時のダメージ計算 | サポート効果・時間経過スキル |
| SPD↑ | 攻撃間隔を短縮 | 攻撃タイマーリセット時 | サポート効果・時間経過スキル |
| 吸血 | 攻撃時にダメージの30%をHP回復 | 攻撃命中時（命中時効果の前） | 呪文「血の契約」・サポート効果 |
| 貫通 | 攻撃対象の後ろ1マスにも同量のダメージ（攻撃時効果は発生しない） | 攻撃命中時 | 呪文・サポート効果 |
| 鎧 | 1スタック=10%ダメージ軽減（最大10スタック=100%） | ダメージ計算時 | 呪文「泥の鎧」・サポート効果 |
| リジェネ | 2秒ごとにHP5%×スタック数回復（重複可） | 2秒ごとのティック | 呪文・サポート効果 |

### 状態異常（デバフ・スタック制）

| 状態異常 | 効果 | スケーリング | 持続 |
|---------|------|------------|------|
| 火傷 | ATK低下 | 逓減（最大80%）: `0.8 * stacks / (stacks + 2)` | 毎秒-1 |
| 凍結 | 攻撃速度低下 | 逓減（最大50%）: `0.5 * stacks / (stacks + 2)` | 毎秒-1 |
| 麻痺 | 行動不能 | スタック数=行動不能秒数（最大3秒） | 毎秒-1 |
| 毒 | 毎秒スタック数分ダメージ | 線形（スタック=ダメージ/秒） | 永続（自然解除なし） |

## ゲームルール参照

### 初期配置
- 3コスト以下のユニットをデッキからランダム3枚選定
- 無料・デッキから抜ける（巡回に含まれない）
- 配置アルゴリズムに従って自動配置

### カード発動方式（キュー方式）
- デッキ先頭をキューに積む
- マナが足りるまでキュー先頭で待機
- 発動後は捨て札へ・次のカードをキューへ
- 捨て札が尽きたらデッキに戻って再巡回

### 配置アルゴリズム
- 列指定：カードごとに設定（0=前列・1=中列・2=後列）
- 行：デフォルトでランダム
- 条件分岐：ランダム生成アイテムで付与

### 配置失敗
- 同種または合体可能パターンなら合体
- それ以外は召喚失敗→マナ消費済み・捨て札へ

### 合体
- 戦闘中：同種が同マスに重なると上位個体に変換・元カードはデッキに残る
- 準備段階：元カード→合体カードに洗い替え（枚数減少）

### シナジー
- 上下左右の隣接ユニット同士の相互作用
- 斜めは含まない

### アーティファクト
- 別スロット管理（巡回に混ぜない）
- 最大3枠
- 初期0枚（ダンジョン報酬で入手）
