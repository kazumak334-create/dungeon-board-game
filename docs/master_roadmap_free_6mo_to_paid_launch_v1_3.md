# 4. Sprint 7 更新内容

## 4.1 更新後の目的

Sprint 7では、初期デッキ・住宅・兵舎・広場・交換所を定義し、あわせて建物カードを使用して建物が建つまでの建築基盤を実装する。

Sprint 8で都市成長を検証できるように、Sprint 7時点で以下を成立させる。

```text
- 建物カードを使える
- 建設予定地を指定できる
- 建設コストを支払える
- 建設時間に応じて建設進捗が進む
- 稼働人手/作業人手に応じて建物稼働・建設進捗が止まる
- 建設完了後に建物が稼働開始する
```

## 5.3 建設キューUI

建設キューは、盤面左側に建設予定中の建物を上から順に積み上げ表示する。

```text
建設キュー：
盤面左側に、建設予定中の建物を建設順に並べるUI
```

表示内容：

```text
- 建設順番号
- 建物アイコン
- 建物名
- 建設進捗
- 停止中の場合のみ停止理由アイコン
```

建設予定地側にも、キューと対応する番号を表示する。

```text
建設予定地：
建設順に 1, 2, 3... の番号を表示する
```

---

## 5.4 建設順変更

```text
- 建設キュー上で順番を入れ替えられる
- 建設予定地側の番号も即時更新する
- 作業人手の割当優先順位は建設キュー順に従う
```

---

## 5.5 即時建設

建設キュー上の項目をクリックすると、通貨Gを消費して即時建設できる。

```text
即時建設：
建設キュー項目クリック
→ 必要Gを確認
→ Gを消費
→ 建設進捗を100%にする
→ 建設完了処理を実行
```

即時建設コストは仮置きで以下とする。

```text
即時建設コスト = 残り建設時間 × 10G
```

---

## 5.6 建設キャンセル

建設キュー上の項目を右クリックすると、建設をキャンセルできる。

```text
建設キャンセル：
建設キュー項目を右クリック
→ 建設予定地を解除
→ 建物カード使用状態を取り消す
→ 支払った建設コストを返却
→ 建設キューから削除
→ 建設予定地番号を再採番
```

MVPではキャンセル時のペナルティはなし。

---

## 5.7 建設進捗と建物効果進捗の区別

建設中もBPB系の進捗Overlay/Maskで可視化する。  
ただし、建設進捗と建物効果進捗が混同されないように、表示方法を分ける。

| 進捗 | 対象 | 表現 |
|---|---|---|
| 建設進捗 | 建設予定地/建設中建物 | 半透明シルエット、骨組み、番号、建設用Overlay |
| 建物効果進捗 | 完成済み稼働建物 | 通常建物Sprite、効果発動用Overlay、発動時アイコン発光 |

```text
- 建設中は建物効果進捗を表示しない
- 完成済み稼働建物は建設進捗表示を使わない
```
