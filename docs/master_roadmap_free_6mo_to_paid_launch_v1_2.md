# Master Roadmap v1.2
# 無料6ヶ月版 → 有料ローンチ版 スプリント計画 更新版

## 0. この計画の最終ゴール

```text
無料6ヶ月版：
20〜30時間遊べる、都市建設 × デッキ構築 × 攻城戦の中核ループを公開し、
プレイヤーからバグ・バランス・面白さのフィードバックを集める。

有料ローンチ版：
50時間以上遊んでも、まだ別ビルド・別ルート・別難易度を試したくなるゲームとして発売する。
```

このゴールを前提に、すべてのSprintを設計する。

### 1.2 バージョン命名ルール

```text
vX.Y
```

| 種別 | 更新条件 |
|---|---|
| vX.0 | フェーズ構成・ローンチ方針・スプリント順序が大きく変わる場合 |
| vX.Y | 既存Sprint内の仕様・完了条件・残論点を更新する場合 |
| draft | チャット上の検討案・未確定案 |
| final | 確定版としてMarkdownファイル出力済み |

### 1.3 ロードマップ更新ルール

ロードマップを更新する場合は、必ず以下を行う。

```text
- バージョン番号を更新する
- ファイル名にバージョン番号を含める
- 更新履歴を追記する
- 変更内容を簡潔に記載する
- 旧版は上書きせず残す
```

ファイル名形式：

```text
master_roadmap_free_6mo_to_paid_launch_v{major}_{minor}.md
```

例：

```text
master_roadmap_free_6mo_to_paid_launch_v1_2.md
master_roadmap_free_6mo_to_paid_launch_v1_3.md
```


## 5. Sprint 9：報酬・マイルストーン・宝箱システム

## 目的

バトルごとの成長報酬を、マイルストーン報酬と宝箱によって構成する。  
バトル中のプレイ目標を明確化し、達成内容に応じたカード・土地・特殊報酬を獲得できる報酬基盤を実装する。

## 用語定義

| 用語 | 定義 |
|---|---|
| 初期難易度 | バトル開始時に選ぶ難易度。低・中・高の3段階。 |
| マイルストーン | バトル中に達成を狙う目標。 |
| 通常マイルストーン | バトル開始時に提示される基本マイルストーン。 |
| 特殊マイルストーン | 宝箱取得などで追加される追加マイルストーン。 |
| 通常マイルストーン報酬 | 通常マイルストーン達成で得る選択式カード報酬。 |
| 特殊マイルストーン報酬 | 特殊マイルストーン達成で得る選択式報酬。 |
| マイルストーン即時報酬 | 中難度マイルストーン達成時にバトル中に即時発生するサポート報酬。 |
| 宝箱 | バトルパネル上に初期配置される報酬オブジェクト。 |
| 宝箱即時報酬 | 宝箱取得時に完全ランダムで即時付与される報酬。 |

## 実装対象

```text
- 初期難易度 低/中/高
- 初期難易度による通貨増減
- 初期難易度によるマイルストーン提示レンジ変更
- 8系統の通常マイルストーン
- 通常マイルストーン報酬
- 特殊マイルストーン報酬
- マイルストーン即時報酬
- 宝箱
- 宝箱即時報酬
- 特殊マイルストーン追加
- 土地カード配置条件
- 報酬スキップ
```

## 完了条件

```text
- 初期難易度を低/中/高から選択できる
- 初期難易度に応じて通貨を増減できる
- 初期難易度に応じて各系統のマイルストーン提示レンジを切り替えられる
- 8系統×3段階の通常マイルストーンを生成できる
- 中難度マイルストーン達成時にマイルストーン即時報酬をバトル中に発生できる
- 極低/低/高/極高マイルストーン達成時にバトル後報酬対象として記録できる
- 宝箱を1バトル3つ配置できる
- 宝箱取得時に宝箱即時報酬と特殊マイルストーン追加を実行できる
- 土地カードを自建物に隣接する未建設土地へ配置できる
```

## 非対象

```text
- 悪魔の釜型の詳細係数
- 失敗時ペナルティ
- ショップ
- カード削除
- イベントでの通貨使用
- 報酬レアリティ詳細
- 偉人カードの詳細実装
- 住宅上位建物の詳細実装
```
