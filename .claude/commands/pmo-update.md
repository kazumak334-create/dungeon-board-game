# PMO Update

Update project tracking after implementation is verified.

Read:

- `docs/roadmap.md`
- `CHANGELOG.md`
- the requirement/design document cited by the implementation
- `git diff --stat`

Then update only the necessary tracking entries:

- mark completed roadmap task with date and concise note
- add a changelog entry for user-visible or workflow-visible changes
- preserve existing terminology from the relevant design document

Do not invent completion status. If verification failed, record nothing as complete.
