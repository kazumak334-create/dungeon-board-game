# unit-prompt

ユニットイラストのGPT生成用プロンプトをグループ単位で出力するスキル。

## 実行手順

1. `tools/unit_illustration_data.md` を Read で読み込む
2. 以下のグループ一覧を表示してユーザーに選択させる:

```
スライム系:
  S1: 基本スライム
  S2: 毒・腐食スライム
  S3: 氷・結晶スライム
  S4: 魔法・沈黙スライム
  S5: 上位スライム
  S6: 神スライム

獣系:
  B1: 基本獣（前衛・斥候）
  B2: 飛行・速攻獣
  B3: 上位獣（特殊能力）
  B4: 神獣（伝説・最強）

アンデッド系:
  U1: 基本アンデッド（雑兵）
  U2: 中位アンデッド（魔術・呪縛）
  U3: 上位アンデッド（術師・召喚）
  U4: 支配者アンデッド（王・終極）
```

3. ユーザーが選択したグループIDに対応するデータを data ファイルから取得する
4. 以下のフォーマットで出力する:

```
=== Group {ID}: {グループ名} ===

【共通部分】
{グローバル共通} + {種族共通} + {グループ共通}

---

[N/総数] {ユニット名}
Scene: {シーン説明}
Specific:
{Specificプロンプト}
```

5. 出力後「次のグループを出しますか？」と聞く

## 注意
- 共通部分はグローバル共通・種族共通・グループ共通を結合して出力する
- Specific は改行区切りで視認しやすく出力する
- 全体をひとつのコードブロック(```) で囲む
